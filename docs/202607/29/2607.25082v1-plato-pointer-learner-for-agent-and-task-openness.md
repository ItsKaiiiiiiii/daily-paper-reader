## 摘要
开放智能体系统（OASYS）在现实领域中日益普遍，其中智能体和任务集随时间不可预测地变化。这种开放性，包括智能体开放性（AO）和任务开放性（TO），对通常假设固定状态和动作空间的多智能体强化学习（MARL）构成了根本性挑战。现有方法仅部分解决开放性问题：填充和掩码方法引入人为边界，而最近的基于图或超图的方法处理单一维度的开放性，但仍依赖于限制性假设。在本文中，我们提出了针对智能体与任务开放性的指针学习器（PLATO），一种基于指针网络的actor与集中式图神经网络（GNN）critic相结合的方法，采用集中式训练与分布式执行范式下的多智能体近端策略优化进行训练。我们的基于指针的actor直接在当前任务集上输出分布，这直接支持了动作空间的变化，无需掩码或重新训练。我们的GNN critic将智能体-任务交互编码为一个随任务和智能体组成而改变形状的图。这些组件共同考虑了AO和TO，没有现有方法的边界限制。我们在任务和智能体开放的马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前的任务开放公式，并证明了其在产生的无界状态和动作空间上的良定义性。我们使用开放智能体系统评估方法倡议（MOASEI）的野火抑制领域来评估PLATO，该环境专为开放多智能体系统评估而设计，我们展示了相比OASYS中最先进的基线，PLATO具有更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：开放多智能体系统（OASYS）中，智能体集合（Agent Openness, AO）和任务集合（Task Openness, TO）会动态变化，导致状态和动作空间随时间无界。传统多智能体强化学习（MARL）假设固定集合，无法直接应对这种开放性。
- **背景**：现有方法要么通过填充/掩码引入人工边界（如DGN、DICG），要么仅处理单一开放维度（如MOHITO仅处理任务开放，未考虑智能体随机进出）。尚无方法能同时处理AO和TO且不依赖有界假设。
- **研究意义**：首次提出一种在无界状态/动作空间下联合处理AO和TO的MARL框架，为开放系统的可部署智能体提供理论保障和实用算法。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 使用**指针网络（Pointer Network）**作为decoder，将动作选择从固定索引分类转化为基于内容的**指向（pointing）**：每个智能体根据当前团队上下文（query）和每个任务的特征（key），通过注意力计算选择当前任务集中的动作。
- **集中式图神经网络（GNN）critic**：将全局状态编码为二分图（智能体节点+任务节点），通过图卷积传播信息，再全局池化估计状态值，支持变数量的节点。

### 关键技术细节
- **Actor（指针网络）**：
  - 预处理：将局部观测分解为智能体特征矩阵 \(o^t_N \in \mathbb{R}^{|N^t| \times f_N}\) 和任务特征矩阵 \(o^t_X \in \mathbb{R}^{|X^t| \times f_X}\)。
  - 智能体编码：对 \(o^t_N\) 计算统计量（均值、方差、min、max），得到固定长度向量 \(d^t\)，再经MLP得到查询向量 \(q^t\)（排列不变性）。
  - 任务编码：对每个任务 \(x \in X^t\) 独立经MLP得到键 \(k^x_t\)，再加上一个NO-OP键。
  - 通过加性注意力 \(u^x_t = v^\top \tanh(W_K k^x_t + W_q q^t)\) 计算每个任务的分数，softmax得到分布。
- **Critic（GNN）**：
  - 构建二分图 \(G^t = \langle X^t, N^t, E^t \rangle\)，边连接所有智能体-任务对。
  - 初始节点嵌入：分别用MLP编码智能体和任务特征，拼接得到 \(h^0_t\)。
  - 两层GCN消息传递，加残差连接。
  - 全局均值池化后经MLP输出标量价值 \(V(s^t)\)。
- **训练**：采用CTDE框架和MAPPO（PPO-clip），集中式critic在训练时使用，执行时只用分布式actor。损失函数包括PPO截断策略损失和value回归损失，使用GAE估计优势。

### 算法流程（简化）
1. 每个时间步 \(t\)，每个智能体 \(i\) 运行Pointer Actor得到动作分布并采样。
2. 执行动作，环境返回新观测、状态、奖励。
3. 集中式GNN Critic计算价值估计。
4. 计算GAE优势，更新actor和critic。

## 3. 实验设计

### 数据集/场景
- **领域**：MOASEI Wildfire抑制任务（firefighter agents，网格地图）。
- **网格大小**：2×3、3×3、4×4（用于原生评估），5×5（仅用于零样本泛化测试）。
- **开放设置（S0-S3）**：
  - S0：封闭（无任务开放、无智能体开放，无限灭火剂）。
  - S1：内源性任务开放（火势蔓延概率0.6）+ 智能体开放（灭火剂补充成功率1.0）。
  - S2：外源性任务开放（随机点火概率0.6）+ 智能体开放（补充成功率0.8）。
  - S3：两者结合（蔓延+点火各0.6，补充成功率0.6），最严苛的联合开放条件。

### Benchmark与对比方法
- **智能基线（learned）**：
  - DGN（图卷积强化学习）
  - DICG（深度隐式协调图）
  - MOHITO（超图方法，处理任务开放但未处理智能体开放）
- **启发式基线（heuristic）**：
  - NOOP（始终不行动）
  - Random（均匀随机）
  - Weakest（优先压制最小火）
  - Strongest（优先压制最大火）

- **效率**：reward per fight action（每次灭火行动的平均奖励）

## 6. 主要结论与发现

1. **性能优势**：
   - 在3×3和4×4网格上，PLATO在开放设置（S2、S3）中episode return显著高于所有智能基线。
   - 在4×4网格上，PLATO在S1-S3均显著领先；在2×3上，PLATO在S1-S3显著最优。
2. **效率优势**：
   - PLATO在多数开放设置下获得最高的reward per fight，表明其更有效地使用灭火行动。
3. **零样本泛化**：
   - 训练于2×3网格的PLATO在3×3和4×4上的S1-S2设置中表现最好；训练于3×3的PLATO在5×5上的S1-S3显著领先。
   - PLATO的泛化性能比DGN/MOHITO更稳定，DICG在某些设置下竞争但整体不如PLATO。
4. **消融研究**：
   - LSTM编码器 + 加性注意力组合（lstm+add）在联合开放（S3）的零样本设置中表现最佳。
   - MLP + 点积注意力（mlp+dot）在封闭（S0）零样本设置中最佳。
   - 无单一因子普遍最优，编码器和注意力选择需根据开放程度权衡。
5. **理论保障**：证明了PLATO在无界状态/动作空间上的良定义性和排列不变性。
