## 摘要
多智能体系统通过任务分解和角色专业化提升能力，但这些机制也引入了一个重要的安全盲点：有害目标可以被碎片化为局部合理的子任务，使恶意意图能够逃逸任何单个智能体的检测。这是一个日益增长的社会影响挑战：处理敏感信息或重要工具的系统可能将常规委派转变为未经授权的披露或不安全行为。我们认为，这种故障模式更适合被理解为语义信息流问题，而非单轮提示分类任务。为此，我们提出SafeFlow，一种针对多智能体系统的防御框架，将恶意跨智能体传播形式化为语义信息流问题。SafeFlow为根请求附加结构化语义污点，通过动态协作图传播这些污点，并在执行不可逆操作前执行工作流级验证以重构全局风险上下文。在涵盖提示注入、基于越狱的不安全工具使用、危险代码执行和有害网络智能体行为的四个基准测试上，与未防御基线和外部防御相比，SafeFlow降低了攻击成功率，同时保持了高良性任务完成率和高配对安全-有害成功率。我们的发现表明，多智能体系统仍然缺乏在委托边界间保持风险语义的机制。这一缺口可能将常规委派转变为影响个人和组织的隐私损害或不安全行为。SafeFlow在整个工作流程中使该风险可见，在其造成损害之前。

## Abstract
Multi-agent systems improve capability through task decomposition and role specialization, but these same mechanisms introduce an important safety blind spot: a harmful objective can be fragmented into locally plausible subtasks, allowing malicious intent to evade detection by any single agent. This is a growing social-impact challenge: systems handling sensitive information or consequential tools can turn routine delegation into unauthorized disclosure or unsafe action. We argue that this failure mode is better understood as a semantic information-flow problem than as a single-turn prompt classification task. To address this, we propose SafeFlow, a defense framework for multi-agent systems that formalizes malicious cross-agent propagation as a semantic information-flow problem. SafeFlow attaches structured semantic taints to root requests, propagates them through a dynamic collaboration graph, and performs workflow-level validation to reconstruct the global risk context before irreversible actions are committed. Evaluated on four benchmarks spanning prompt injection, jailbreak-based unsafe tool use, risky code execution, and harmful web-agent behavior, SafeFlow reduces attack success rates compared to undefended baselines and external defenses while retaining high benign task completion and a high paired safe--harm success rate. Our findings show that multi-agent systems still lack mechanisms for preserving risk semantics across delegation boundaries. This gap can turn routine delegation into privacy harms or unsafe actions that affect people and organizations. SafeFlow keeps this risk visible throughout the workflow, before it results in harm.

## 2. 论文提出的方法论

**核心思想**：将多智能体系统中的恶意跨智能体传播建模为语义信息流控制问题。通过为每个请求附加结构化语义污点（taint），在动态协作图中沿委托、消息、工具调用等边传播，在执行不可逆操作前重构全局风险上下文并进行验证。

**关键技术细节**：
- **污点标签模式**：默认使用7个标签，分为三类：
  - **源标签**：`SENSITIVE_READ`（敏感读取）、`CREDENTIAL_ACCESS`（凭证访问）
  - **硬汇标签**：`EXTERNAL_SEND`（外发送）、`PRIVILEGED_EXEC`（特权执行）、`CODE_EXEC`（代码执行）、`DESTRUCTIVE_WRITE`（破坏性写入）
  - **控制面标签**：`PROMPT_OVERRIDE`（提示覆盖）
- **传播规则**：标签通过委托、消息、检索、工具调用等边向前传递，仅当显式释放条件满足时才可移除；传播是单调的。
- **五阶段流水线**：
  1. **意图污点标注**：使用词法匹配器、约束LLM分类器和工具启发式对根请求附加初始污点。
  2. **规划与污点传播**：LLM生成智能体工作流骨架，然后`PropagateTaints`确定性构造带污点的协作图。
  3. **上下文重构**：对每个节点，`ReconstructContext`利用LLM合并消息、检索内容、工具跟踪等分布式证据，输出结构化视图。
  4. **全局验证**：`ValidateWorkflow`根据固定规则集R对图结构和污点路径进行检验，对每个硬汇做出释放或阻断决策。

## 6. 论文的主要结论与发现

1. **SafeFlow显著降低攻击成功率**：在无攻击设置下，平均ASR从SafeAgents的69.3%降至SafeFlow的12.7%；在最难的SafeArena上ASR从74.6%降至17.3%。
2. **安全-效用权衡最优**：SafeFlow保持高良性任务完成率（TCR约90%），同时实现最高的配对安全-有害成功率（平均约79%），远好于GuardAgent（约63%）和AegisLLM（约60%）。
3. **跨智能体场景更难但SafeFlow仍有效**：SafeFlow在跨智能体攻击上的ASR（平均14.2%）仍低于局部攻击，而基线方法在跨智能体场景上ASR更高。
4. **工作流级控制优于局部防御**：消融实验显示，移除污点传播导致ASR大幅上升（ΔASR达30-40%），证明全局传播和延迟裁决是核心优势。
5. **对越狱攻击鲁棒**：即使在最强攻击JailBroken下，ASR也仅升至32.3%，而SafeAgents达85.5%。
6. **防御模型敏感性低**：不同LLM作为防御侧时ASR在8.0%–12.7%之间，收益主要来自管道而非特定模型。
7. **策略模式影响可调**：扩展标签集降低ASR但略微增加FPR；局部传播严重削弱防御。
8. **自适应攻击仍有剩余风险**：平均ASR约22.7%，说明存在对抗性污点隐藏/拆分等未被完全覆盖的边界。

## 7. 优点

- **问题定义新颖**：将多智能体安全形式化为语义信息流控制问题，抓住了跨步骤组合攻击的本质。
- **方法论简洁有效**：污点传播+延迟裁决的设计在原理上清晰，易于理解和实现；无需修改模型权重或访问控制，仅基于运行时事件。
- **实验全面且公平**：覆盖四个不同维度的基准、多种攻击类型、大量消融、参数灵敏度、对抗场景；所有方法在相同条件下比较，避免不公平优势。
- **安全-效用权衡优秀**：在大幅降低ASR的同时，TCR和Paired指标领先，表明并非单纯拒绝所有疑似危险行为。
- **鲁棒性验证充分**：不仅测试标准攻击，还测试了越狱包装、自适应攻击、防御模型敏感性等，提供了可靠的性能边界。
- **开放性和可扩展性**：标签模式可配置，新领域可通过添加标签和规则集成，提供明确的扩展流程。

## 8. 不足与局限

- **无法防御完全不可见的组件**：依赖于运行时暴露的协作图事件；若某智能体或工具侧渠道未加仪器化，则无法溯源或阻断。论文承认了这一点。
- **边界案例仍存在**：附录列出了三类失败模式（缺失溯源边、漏标注、假阳性），对应约8-25%的残余风险。假阳性在授权元数据不完善时可能误判良性工作流。
