## 摘要
多智能体强化学习系统在平衡不同时间尺度上的全局协调与局部执行方面面临基本挑战。本文介绍了耦合分层多智能体系统（CHMAS），这是一种新颖的框架，将多智能体决策分解为集中式策略规划和分布式战术执行，并具有双向信息流。策略层整合所有智能体的状态与专属全局环境状态，每T个时间步生成引导动作，而战术智能体执行由策略引导和局部邻域观测增强的分布式策略。与现有单向控制的分层方法不同，CHMAS建立了一种反馈机制，其中累积的战术奖励通过耦合系数λ影响策略目标，确保策略计划基于战术可行性。为了解决分层学习固有的非平稳性问题，我们提出了一种异步更新协议，其中策略参数每N_f个战术轮次更新一次，使得战术策略在策略变化之间收敛到准平稳点。我们提出了一个捕捉完整系统动态的一般双层公式和一个可处理的加性近似，以便进行严格分析。理论分析证明，在标准假设下，该异步方案在K次策略更新后为策略层实现了O(log K/√K)的收敛速度。在多智能体觅食领域的实验验证表明，尽管存在分层耦合，但成功学习了空间划分的探索策略，且两层均稳定收敛。

## Abstract
Multi-agent reinforcement learning (MARL) systems face fundamental   challenges in balancing global coordination with local execution   across different temporal scales. This paper introduces the Coupled   Hierarchical Multi-Agent System (CHMAS), a novel framework that   decomposes multi-agent decision-making into centralized strategic   planning and distributed tactical execution with bidirectional   information flow. The strategic layer integrates all agents' states   with an exclusive global environmental state to generate guidance   actions every $T$ timesteps, while tactical agents execute   distributed policies augmented by strategic guidance and local   neighborhood observations. Unlike existing hierarchical approaches   with unidirectional control, CHMAS establishes a feedback mechanism   where accumulated tactical rewards influence strategic objectives   through a coupling coefficient $λ$, ensuring strategic plans   remain grounded in tactical feasibility. To address the   non-stationarity inherent in hierarchical learning, we propose an   asynchronous update protocol where strategic parameters update every   $N_f$ tactical episodes, allowing tactical policies to converge to   quasi-stationary points between strategic changes. We present both a   general bi-level formulation capturing full system dynamics and a   tractable additive approximation enabling rigorous analysis.   Theoretical analysis proves that this asynchronous scheme achieves   $\mathcal{O}(\log K/\sqrt{K})$ convergence for the strategic layer   after $K$ strategic updates under standard assumptions. Experimental   validation in a multi-agent foraging domain demonstrates successful   learning of spatially partitioned exploration strategies, with both   layers converging stably despite hierarchical coupling.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：多智能体强化学习（MARL）系统在全局协调与局部执行之间存在**时间尺度失衡**：战略决策（如任务分配、编队控制）需要全局信息且时间跨度长，战术决策（如避障、局部适应）依赖即时观测且需快速响应。现有方法要么完全集中导致维数灾难（状态空间随智能体数量指数增长），要么完全分布牺牲长期协调质量；而传统分层强化学习多为单向控制（高层指导低层），缺乏战术层向战略层的反馈，使战略计划脱离执行可行性。同时，分层学习中战略改变会破坏战术层的平稳性假设，导致训练不稳定。
- **背景**：多智能体协同在机器人、交通管理、资源分配等领域需求迫切。现有集中训练分布执行方法（如QMIX、MADDPG）假设训练时可访问全局信息，但在部分可观测和通信受限场景下失效。层次化方法（如option-critic）依赖领域知识设计选项，泛化性差。
- **整体含义**：本文提出一种**双向耦合的分层框架（CHMAS）**，通过战略层（集中式）与战术层（分布式）之间的双向信息流和异步更新协议，同时解决多时间尺度协调、信息不对称和训练非平稳性，为大规模多智能体分层协同提供理论收敛保证与实证验证。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将多智能体决策分解为两个层次：
  - **战略层**：每 T 个时间步（一个战略epoch），利用全局状态（所有智能体状态 + 独家全局环境状态 $s_{env}$）生成每个智能体的个性化引导动作 $a^{str}_{i,k}$，该引导持续整个 epoch。
  - **战术层**：每个智能体 $i$ 在时刻 $t$ 的观测为其局部状态、邻居状态和当前战略引导的组合 $o^{tac}_{i,t} = \phi_i(s_{i,t}, \{s_{j,t}\}_{j\in N_i}, a^{str}_{i,k})$，执行分布式策略 $\pi^{tac}_i$ 选择 $a^{tac}_{i,t}$。
  - **双向耦合**：
    - 向下耦合（战略→战术）：引导动作通过增强观测和奖励调制影响战术行为。
    - 向上耦合（战术→战略）：战术层累积奖励 $R^{tac}_k = \sum_{t=kT}^{(k+1)T-1} \sum_{i=1}^N r^{tac}_{i,t}$ 乘以耦合系数 $\lambda$（本文取0.5）后加入战略奖励：$R^{str}_k = R^{global}(s^{env}_k, a^{str}_k) + \lambda R^{tac}_k$，使战略计划贴合战术可行性。
- **关键技术细节**：
  - **双目标优化**：战略目标 $J^{str}(\theta^{str}|\{\theta^{tac*}_i\})$ 依赖战术最优响应；战术目标 $J^{tac}_i(\theta^{tac}_i|\theta^{str})$ 依赖战略参数。这是双层优化问题，一般难解。
  - **加性近似**：为简化，将全局目标近似为 $J^{global} = J^{str} + \sum_i J^{tac}_i$，采用异步更新使近似误差可控（由战术最优间隙 $\delta_k$ 界定，随学习减小）。
  - **异步更新协议**：战略参数每 $N_f$ 个战术回合更新一次（本文 $N_f=5$），战略学习率 $\eta^{str}_k = \alpha/\sqrt{k}$，战术学习率 $\eta^{tac} = \beta/\sqrt{K}$。这使得战术策略能在战略变化之间收敛到准平稳点，将非平稳问题转化为交替的平稳子问题。
  - **算法：异步分层策略梯度（AHPG）**：
    1. 每个epoch开始（即 $e \bmod N_f = 1$），战略层观察全局状态，生成引导，广播给各智能体。
    2. 战术层在接下来的 T 个时间步内执行分布式策略，收集经验。
    3. 每个战术回合结束后，各智能体使用当前局部缓冲区更新战术参数。
    4. 每 $N_f$ 个战术回合结束时，战略层从累计战术奖励计算战略奖励，更新战略参数（使用梯度下降，步长 $\alpha/\sqrt{k}$）。
- **理论结果**（Theorem 1）：
  - 在标准假设（L-光滑、PL条件、耦合Lipschitz、方差有界）下，$K$ 次战略更新后，战略梯度范数 $\min_k \mathbb{E}[\|\nabla J^{str}(\theta^{str}_k)\|^2] = \mathcal{O}(\log K / \sqrt{K})$；战术平均梯度范数 $\mathcal{O}(1/\sqrt{K})$。
  - 证明基于两层时间尺度随机逼近：战术层快速收敛（$N_f = c\sqrt{K}$），战略层慢速更新，偏差主要来自战术未收敛部分，可通过PL条件控制。

## 6. 主要结论与发现

- 战略层能够学习到**非重叠的区域分配策略**，将四个智能体分别置于网格的不同角落，并随着探索不断调整分配至未访问区域，实现集体网格覆盖。
- 战术层在固定引导下，能够兼顾**区域服从**与**资源收集**，回报从约-80提升至-10。
- 异步更新协议成功管理了分层非平稳性：战略层在前10-20 episodes延迟学习，待战术层稳定后开始提升，后期两者均稳定收敛，方差低。
- 理论保证战略层 $\mathcal{O}(\log K/\sqrt{K})$ 收敛，实验定性符合。
