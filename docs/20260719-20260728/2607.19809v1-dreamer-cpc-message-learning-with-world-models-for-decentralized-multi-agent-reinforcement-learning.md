## 摘要
在多智能体强化学习（MARL）中，智能体间的通信对于部分可观测条件下的性能提升非常有效。基于表示学习的方法使去中心化智能体能够学习基于自身观测的消息，但这些方法仅依赖当前观测，无法传递随时间累积的信息。我们提出了Dreamer-CPC，一种基于模型的去中心化MARL方法，它将基于集体预测编码（CPC）的消息学习集成到DreamerV3的世界模型中。每个智能体独立维护一个世界模型和一个消息模块，并从反映过去观测和动作历史的世界模型潜在状态中推断和交换消息。我们在两个环境中评估了Dreamer-CPC：Observer（一个非合作信息共享任务）和CatchApple（一个新引入的任务，其中任务相关观测暂时缺失）。在两个环境中，Dreamer-CPC均优于IPPO-CPC（一种现有的基于CPC的方法，从当前观测生成消息）以及无通信基线。特别是在CatchApple中，Dreamer-CPC达到了IPPO-CPC的4至5倍的回合回报，展示了在其他方法因观测缺失而失败的情况下有效协调的能力。这些结果表明，当仅依靠当前观测不足时，基于世界模型潜在动力学的通信可以支持去中心化决策。

## Abstract
In multi-agent reinforcement learning (MARL), inter-agent communication is effective for improving performance under partial observability. Representation learning-based approaches enable decentralized agents to learn messages grounded in their own observations, but they rely only on current observations and cannot convey information accumulated over time. We propose Dreamer-CPC, a decentralized model-based MARL method that integrates message learning based on Collective Predictive Coding (CPC) into the world model of DreamerV3. Each agent independently maintains a world model and a message module, and infers and exchanges messages from the latent states of the world model that reflect the history of past observations and actions. We evaluated Dreamer-CPC in two environments: Observer, a non-cooperative information-sharing task, and CatchApple, a newly introduced task in which task-relevant observations are temporarily missing. In both environments, Dreamer-CPC outperformed IPPO-CPC, an existing CPC-based method that generates messages from current observations, as well as no-communication baselines. In particular, in CatchApple, Dreamer-CPC achieved 4 to 5 times the episode return of IPPO-CPC, demonstrating effective coordination where other methods fail due to missing observations. These results suggest that communication grounded in the latent dynamics of world models can support decentralized decision-making when current observations alone are insufficient.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 每个智能体独立维护一个**RSSM世界模型**（包含确定性递归状态 \(h_t^k\) 和随机潜在状态 \(z_t^k\)）和一个**消息模块**（包含消息递归状态 \(\xi_t^k\)）。
- 消息模块从世界模型的潜状态（\(h_t^k, z_t^k\)）中**推断**当前消息 \(m_t^k\)，并从先前消息的递归历史中生成**先验预测** \(\hat{m}_t^k\)。
- 所有智能体同步交换消息。每个智能体将接收到的其他智能体消息（经**stop-gradient**处理）作为世界模型**转移**和**观测预测**的条件输入。
- 世界模型学习和消息学习通过**统一的变分下界**（ELBO）联合优化，包含预测损失以及潜状态和消息的KL正则化项（采用DreamerV3的KL-balanced与free bits策略）。

### 关键技术细节
- **世界模型（RSSM）**：  
  \(h_t^k = f_{\phi_k}(h_{t-1}^k, z_{t-1}^k, a_{t-1}^k, \hat{m}_t)\)  
  先验潜状态：\(\hat{z}_t^k \sim p_{\phi_k}(\cdot|h_t^k)\)  
  后验潜状态：\(z_t^k \sim q_{\phi_k}(\cdot|h_t^k, x_t^k)\)  
  解码观测：\(\hat{x}_t^k \sim p_{\phi_k}(\cdot|h_t^k, z_t^k, m_t)\)  
  同时预测奖励和继续标志。

- **消息模块**：  
  消息递归：\(\xi_t^k = g_{\psi_k}(\xi_{t-1}^k, m_{t-1})\)  
  消息先验：\(\hat{m}_t^k \sim p_{\psi_k}(\cdot|\xi_t^k)\)  
  消息后验：\(m_t^k \sim q_{\psi_k}(\cdot|\xi_t^k, h_t^k, z_t^k)\)

- **损失函数**：联合最小化各智能体的 \(L^k_{\text{wm-msg}}\)，包含预测损失 \(L^k_{\text{pred}}\)、潜状态动态损失 \(L^k_{\text{dyn}}\) 和表示损失 \(L^k_{\text{rep}}\)（加权 \(\beta_{\text{dyn}}=1, \beta_{\text{rep}}=0.1\)），以及消息的动态损失 \(L^k_{\text{m-dyn}}\) 和表示损失 \(L^k_{\text{m-rep}}\)（加权 \(1\times10^{-3}, 1\times10^{-4}\)）。

- **去中心化学习**：每个智能体更新自己的世界模型和消息模块参数，不依赖中心化梯度传播；其他智能体的消息用stop-gradient阻断梯度回传。

- **想象力 rollout 训练**：在想象轨迹中，每个时间步所有智能体首先从当前世界模型潜状态推断消息并交换，然后利用接收到的消息进行下一步转移和策略动作采样，再基于想象轨迹更新Actor-Critic（遵循DreamerV3流程）。

### 算法流程（文字描述）
1. **世界模型与消息模块学习**（Algorithm 1）：从回放缓冲区采样轨迹 → 按时间步依次更新每个智能体的消息递归、消息先验采样、RSSM转移、潜状态后验与先验、消息后验 → 联合计算损失并更新参数。
2. **Actor-Critic学习**（Algorithm 2）：初始化潜状态和消息递归 → 在想象地平线内循环：每个智能体更新消息递归并采样消息先验 → RSSM转移 → 潜状态先验采样 → 消息后验采样 → 策略采样动作 → 预测奖励和继续标志 → 收集想象轨迹后按DreamerV3方式更新Actor和Critic。

## 3. 实验设计

### 实验环境
- **Observer**：一个非合作信息共享任务。两个智能体，Agent1静止且能观测奖励位置（不获得奖励），Agent2可移动且只能观测自身位置，需通过通信获知奖励位置。Agent2执行“dig”动作获得+1，其他动作-0.01。回合长度200步。该场景下完整状态可通过聚合所有智能体当前观测重建。
- **CatchApple**：作者新引入的任务。两个智能体，Agent1静止且观测下落物体轨迹，Agent2控制地面接球器，只能观测自身列位置。物体下落时有一段行被遮挡（观测变为“隐藏标志”），Agent2必须在物体到达最低行前预测其落点并移动到对应列。成功接住+1，否则-0.01。回合长度500步。该场景存在观测暂时缺失的时间步，无法通过聚合当前观测恢复完整状态。

### 对比方法
- **IPPO-CPC**：基于PPO的CPC消息学习方法，消息从当前观测生成。
- **IPPO**：无通信的独立PPO。
- **DreamerV3 (no-comm)**：独立DreamerV3，无消息通道。
- **DreamerV3 (obs-shared)**：智能体共享完整观测的上界基准。
- **Dreamer-CPC**：本文方法，测试两种消息配置：20维one-hot（单通道）和5×4维one-hot（四通道）。

### 基准与指标
- 每个方法在每种配置下进行10次独立运行。
- 评估指标为Agent2的**回合回报**（episode return），报告**IQM（四分位均值）**及95%置信区间（bootstrap重采样2000次）。

## 6. 论文的主要结论与发现

- **Dreamer-CPC在Observer中显著优于IPPO-CPC**：5×4消息配置的IQM达39.85（95% CI [34.22,40.82]），而IPPO-CPC最佳仅7.31，无通信基线接近0。表明基于世界模型潜动态的通信在非合作信息共享中更有效。
