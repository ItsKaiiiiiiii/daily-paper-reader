## 摘要
将LLM多智能体系统的通信拓扑适应于每个查询能够提升准确性和效率，然而当前的设计者将其视为条件图生成问题：变分、自回归或扩散解码器搜索N×N邻接空间，而训练于效用和结构成本（如边数）的图网络代理对采样候选项进行排序。我们认为这种表述与问题不一致。实验表明，即使在码本容量从8增至64时，通过奖励筛选存活的拓扑仍收缩至约六种不同图；边数与实测token消耗呈负相关（Pearson r ≈ -0.4），因此稀疏化图反而使推理成本增加；同时，当智能体共享同一配置文件（即已发布基准的默认配置）时，基于智能体配置文件节点的消息传递评分器是邻接不变的，因此在那种情境下根本无法对候选项排序。这三个事实催生了码本智能体：向量量化自编码器将成功拓扑压缩为与查询无关的16条目码本；奖励加权MLP将查询嵌入映射至码本分布；而读取扁平化邻接的MLP代理（回归于实测效用和每任务归一化token成本）在单次批处理前向传播中重排序解码后的顶级候选项。测试时无需迭代搜索和消息传递，码本智能体在所有六个对比基准中均达到最高精度（平均84.6对先前最强设计者的83.0），并以2.4毫秒发出拓扑，同时节省21.9%至33.2%的LLM token。

## Abstract
Adapting the communication topology of an LLM multi-agent system to each query improves both accuracy and efficiency, yet current designers treat this as conditional graph generation: a variational, autoregressive, or diffusion decoder searches the $N \times N$ adjacency space, and a graph-network proxy trained on utility and a structural cost such as edge count ranks the sampled candidates. We argue that this formulation is misaligned with the problem. Empirically, topologies that survive a reward filter collapse to about six distinct graphs even when the codebook capacity grows from 8 to 64; edge count is negatively correlated with measured token consumption (Pearson $r \approx -0.4$), so sparsifying the graph makes inference more expensive; and a message-passing scorer over agent-profile nodes is adjacency-invariant whenever agents share a profile---the default configuration of published benchmarks---so it cannot rank candidates at all in that regime. These three facts motivate Codebook Agent: a vector-quantized autoencoder compresses successful topologies into a query-independent 16-entry codebook; a reward-weighted MLP maps the query embedding to a distribution over codes; and an MLP proxy that reads the flattened adjacency, regressed on measured utility and per-task normalized token cost, reranks the top decoded candidates in a single batched forward pass. With no iterative search and no message passing at test time, Codebook Agent is the most accurate method on all six benchmarks we compare (84.6 average against 83.0 for the strongest prior designer), emits a topology in 2.4 ms, and uses 21.9--33.2% fewer LLM tokens.

### 1. 论文的核心问题与整体含义

**研究动机与背景：**
- LLM多智能体系统的通信拓扑结构（哪个智能体向哪个智能体发送消息）对任务准确性和token消耗有重大影响。领域发展经历了手工设计→学习优化→查询条件生成三个阶段。
- 现有最前沿方法（其中代表性的是G-Designer、ARG-Designer、TopoDIM、GTD等）采用统一的范式：将拓扑设计视为**条件图生成**问题——用变分、自回归或扩散解码器在 N×N 邻接空间中搜索，再用图神经网络（GNN）代理对候选图按效用和结构成本（通常是边数）进行排名。
- 论文认为此范式存在根本性**表述失配**，通过三项实证测量作了论证，这些测量同时构成了论文的核心论点。

**核心矛盾（三组观测事实）：**
- **可用设计空间极窄**：通过奖励筛选的可用拓扑即使在码本容量从8增至64时，也只收缩至约6种不同图。最好的固定拓扑与所有生成式拓扑之间仅差1.4个精度点。也就是说，生成模型所建模的邻接空间绝大多数是无效区域。
- **结构成本代理被倒置**：边数（|E|）与实测token消耗呈显著**负相关**（Pearson r ≈ −0.4）。稀疏图会导致智能体无法高效协作，产生更长的推理文本、更高的成本。以最小化|E|为目标的评分器，反而会把系统推向成本更高的图。
- **消息传递评分器拓扑盲**：当智能体共享同一profile文本（同质团队，也是发布基准测试的默认配置）时，基于智能体profile节点的消息传播网络对邻接矩阵不变——所有候选都会得到完全相同的分数，排序根本不存在。

**整体含义：**
既然真实问题是"从少数可行图中选一个"，而不是"在连续邻接空间中搜索"，那么应该采用的不是另一套生成式解码器，而是一种**摊销成本极低的离散索引选择**方案。作者据此提出Codebook Agent，将拓扑设计近似为"离线聚类压缩+在线查询检索"，实现了全方法中效率最高、精度最优的效果。

### 2. 论文提出的方法论：核心思想、技术与算法流程

**核心思想：**
用向量量化将成功拓扑压缩成与查询无关的16条目码本，将任务查询映射到码本分布，然后在批量前向传播中评分、重排序少量解码候选，最终选出最优拓扑——整个过程如图2所示，测试期间没有任何迭代采样或消息传递，**设计过程完全不需要调用LLM**。

**整体框架三阶段（与图2对应）：**

#### 阶段一：离线数据收集
- 在训练集上对每个基准执行50个任务 × 6种固定拓扑（完全图、链、星型、3个Erdős–Rényi随机样本），获得300条真实执行记录 D={(Aⱼ, cⱼ, uⱼ, τⱼ)}，其中 c 为查询嵌入，u 为效用（0/1），τ 为token消耗。
- 复合奖励 Rⱼ = uⱼ − 0.1·τ̃ⱼ，其中 τ̃ⱼ 是该任务下token消耗的归一化值（以同一任务所有拓扑的平均token消耗为分母），以消除任务难度对成本的干扰。

#### 阶段二：三个子模型离线训练（均已无额外LLM调用）

**(1) 拓扑码本（VQ-VAE压缩）**
- 将邻接矩阵展平为 a = vec(A) ∈ {0,1}^N(N−1)（去掉对角线）。
- 编码器 Enc_ψ 得到连续向量 zₑ ∈ R³²，与K=16个码本向量中最接近的一个量化：k* = argmin||zₑ−eₖ||，得到 z_q = e_k*。
- 镜像解码器 Dec_ω 将码本向量映射为边logits，通过sigmoid和二值化还原为有向拓扑图（无自环）。
- 训练目标 L_vq = BCE_w(â, a) + β·||zₑ − sg[z_q]||²，β=0.25；BCE正样本加权以应对边的稀疏性；码本用EMA（衰减0.99）更新，死码自动重置。
- **仅在 u>0.5 即成功记录上训练**，确保码本编码的是"解决了任务的拓扑"，而非全部六种模板。
- 编码器/解码器均不依查询条件——训练完成后码 k 经解码即得到一个固定二值拓扑 A(k)。

**(2) 奖励加权码本预测器（查询→码分布）**
- 将全部训练记录送入冻结的编码器量化后得到码索引 kⱼ，对每个查询条件 c 构造软目标：

  y_k(c) = Σⱼ(exp(2Rⱼ) · 1[cⱼ=c, kⱼ=k]) / Σ_{k'}Σⱼ(exp(2Rⱼ) · 1[cⱼ=c, kⱼ=k′])
  
  即同一条件下各码的奖励加权softmax，γ=2，使高奖励拓扑的码获得更大质量分布。
- 预测器 p_θ(k|c) 为 MLP：d→256→256→K（dropout=0.1），用软交叉熵训练，使查询到候选拓扑的映射成为单一矩阵流水线。

**(3) 执行接地MLP代理（评分器）**
- 以 MLP 读取展平邻接向量和查询嵌入的拼接：f_φ(A, c) = MLP_φ([vec(A); c]) ∈ R²，输出预测效用 û 和预测归一化token成本 ĉ。
- 奖励损失 L_rew 直接回归实测目标（均方误差），两个输出头同时优化。
- 辅助结构标记损失：借鉴VQGraph，用32个额外码字的辅助量化器在扩张拓扑池 A⁺（静态族、8种密度随机图、单边扰动、平滑边剖面的伯努利样本，每条件上限100）上预拟合结构token，辅助头预测软码分配 q，贡献 λ_code=0.1 的L_code。该损失只为正则化代理内部的表示，不引入额外奖励监督。

#### 阶段三：一次性测试推理（式11）

1. 输入查询嵌入 c。
2. 预测器 p_θ 输出前5个码（Top-M=5）；解码为候选集 A(c) 并去重。
3. 对全部幸存候选执行**一次批量MLP前向**，计算 û − 0.1·ĉ，取最大者为最终拓扑 A*(c)。
4. 执行该拓扑。

总成本：一次预测器前向 + 至多5次解码器前向 + 一次稠密MLP前向。无采样循环、无稀疏图构建、无消息传递。设计延迟仅约2.4毫秒。

### 6. 论文的主要结论与发现

1. **可用拓扑空间是短列表而非流形**：无论码本容量如何增加，成功拓扑只收缩到约6种——多出的生成建模是在建模问题之外浪费算力。
2. **边数是最差成本代理**：边数与实测token消耗负相关（r≈−0.4），稀疏化图形使得LLM必须生成更长更详细的文本，因此最小化边数会导致成本高涨。
3. **消息传递评分器在同质团队上退化为常数**：当智能体共享同一profile时，图神经网络无法区分任何两个候选图的分数差，这是现有评分机制的根本失效。
4. **摊销索引方案完胜生成式方法**：Codebook Agent在所有6个基准数据上均优于最强的先前设计者（平均84.62 vs GTD 83.02，差距主要体现在MBPP +3.1、SVAMP +2.4等），并保持每查询仅2.4 ms的毫秒级生成延迟。
5. **实质性节省token与运行时间**：与完整的现有深度学习管线相比，token消耗减少21.9%–33.2%；端到端推理时间相应缩短。
6. **跨骨干迁移稳健**：在将主模型切换到Qwen-3-8B后，相对排序保持（Ours平均74.0 vs GTD 72.7），表明方法并非对特定API的过拟合。
7. **消融确认各组件均必要**：MLP代理重排序对成本降低至关重要；软目标预测器的单一机制能区分优劣拓扑；训练成本权重 λ=−0.1 处于精度/成本前沿的平衡点。

- **极致的计算效率设计**：以一次预测器前向+一次批量MLP评分取代了上千次GNN迭代评估。将设计时延从几百毫秒压缩到几毫秒，并能进行近似对实时调用的系统进行快速适应。
- **推理路径无损**：测试时路径不依赖LLM，只需一次前向传播即可发牌，使设计开销低于整体端到端延迟的0.1%，这与现有迭代采样方案相比架构性更强。
- **模型无关性**：因为只在向量量化、MLP代理中操作，与关系骨干的表现无耦合，便于在任一新骨干之上快速训练拓扑选择器。
- **消融设计的精准性**：将Axis A（生成器）和Axis B（评分器）作为独立控制变量，精确揭示了每个设计的边际贡献，同时也使"GNN不可用"这一问题可从因果上归因。
- **清晰的问题阐述路线**：无论是对三个副作用的单独诊断实验，还是在重构、随机与GNN的对比中有意识地控制候选集合，都比一味报告新SOTA更能显著推进该领域方法的理解。
