## 摘要
人工智能生成内容（AIGC）服务利用生成式AI（GenAI）模型自动生成多样化内容。移动AIGC网络将GenAI模型部署在边缘AIGC服务提供商（ASP）上，以为移动用户提供低延迟和个性化的AIGC服务。然而，AIGC推理任务通常会占用GPU内存直至任务完成，这会导致服务ASP处的GPU内存耗尽，并触发内存不足故障，而不仅仅是增加服务延迟。现有关于AIGC任务编排的研究在很大程度上忽视了GPU内存可行性约束。为解决这一问题，我们开发了一种协作式多智能体编排框架，其中每个边缘节点配备一个调度智能体，将任务路由到本地ASP或相邻边缘节点。由于调度智能体仅基于局部观测做出决策，而同伴卸载会耦合其资源状态和长期效用，因此我们将编排过程建模为协作式去中心化部分可观察马尔可夫决策过程（Dec-POMDP）。为了解决该Dec-POMDP，我们提出了一种在集中训练与去中心化执行范式下的注意力引导多智能体深度强化学习算法（A-MADiff），该算法采用基于扩散的去中心化Actor来生成对可行编排动作的多模式偏好，并利用注意力引导的中心化Critic在GPU内存异质性下从跨智能体状态中估计每个智能体的价值。数值结果表明，A-MADiff在累积奖励上显著优于最先进的基线方法。

## Abstract
Artificial Intelligence-Generated Content (AIGC) services employ Generative AI (GenAI) models to automatically generate diverse content. Mobile AIGC networks host GenAI models on edge-located AIGC Service Providers (ASPs) to deliver low-latency and personalized AIGC services for mobile users. However, AIGC inference tasks typically occupy GPU memory until task completion, causing GPU memory exhaustion at serving ASPs and triggering out-of-memory failures rather than merely increasing service latency. Existing studies on AIGC task orchestration have largely overlooked GPU memory feasibility constraints. To address this issue, we develop a cooperative multi-agent orchestration framework, in which each edge node is equipped with a scheduling agent to route tasks to local ASPs or neighboring edge nodes. Since scheduling agents make decisions based only on local observations, while peer offloading couples their resource states and long-term utilities, we formulate the orchestration process as a cooperative Decentralized Partially Observable Markov Decision Process (Dec-POMDP). To solve the Dec-POMDP, we propose an \underline{A}ttention-guided \underline{M}ulti-\underline{A}gent deep reinforcement learning algorithm with \underline{Diff}usion policies (A-MADiff) under the centralized training with a decentralized execution paradigm. A-MADiff employs diffusion-based decentralized actors to generate multi-modal preferences over feasible orchestration actions, and an attention-guided centralized critic to estimate per-agent values from cross-agent states under GPU memory heterogeneity. Numerical results demonstrate that A-MADiff significantly improves the cumulative reward over the state-of-the-art baseline.

- 在资源受限的移动设备上执行GenAI推理不现实，因此普遍采用移动边缘计算（MEC）范式：将GenAI模型托管在边缘AIGC服务提供商（ASP）上，由用户将请求卸载至边缘节点执行。
- 现有AIGC任务编排研究大多聚焦计算资源、通信带宽、缓存策略、服务质量等软性约束，**普遍忽略了GPU显存可行性这一硬性约束**。

**核心矛盾（关键洞察）：**
- GPU显存和计算资源之间存在根本的不对称性：算力不足时任务只会变慢（延迟增加）但最终仍可完成；若运行显存不足，任务将直接触发 **OOM（Out-of-Memory）失败**，根本无法执行。
- 因此，任务显存需求与ASP可用显存之间的匹配是**执行层的硬可行性条件**，而非普通的软性服务质量影响因素。
- 在分布式多边缘节点场景下，请求动态到达各节点、各节点ASP的推理速率/服务能力/显存容量异构、任务可跨节点转发，使得任务编排问题具有分布式、部分可观察、长期耦合的特性，单智能体/集中式优化方法无法解决。

**研究意义：**
- 这是首批在移动AIGC网络任务编排研究中系统考虑GPU显存硬可行性约束的工作之一。
- 该研究填补了AIGC任务编排中显存约束建模的空白，对提升边缘AIGC服务的实际可用性和吞吐量具有理论价值与应用意义。

## 2. 方法论：核心思想、技术细节

### 2.1 系统建模与问题形式化

**系统架构：**
- 协作式多智能体编排框架：每个边缘节点配有**一个调度智能体（Agent）**，负责将到达的AIGC任务路由至：① 本地ASP执行（Local Execution）、② 相邻调度智能体（Peer Offloading）、③ 本地等待队列（Queue Deferral）。
- 各ASP可异构（不同的推理速率、服务能力和GPU显存容量）；各调度智能体只能基于各自的**局部观测**做决策（部分可观察性），但任务卸载会耦合多方节点资源状态和长期效用。

**任务定义：** 第 i 个 AIGC 任务定义为 τi=(tarr_i, wi, mi, Di, hi)，分别代表到达时间、推理工作量、GPU 显存需求、数据传输量、已卸载跳数。

**Dec-POMDP 形式化：** 将任务编排过程建模为协作式 Decentralized Partially Observable Markov Decision Process (Dec-POMDP)，表示为 M=⟨N,S,{On},{An},P,Ω,R,γ⟩。

**关键建模创新：**
- **显存可行性作为硬约束**：局部执行需要满足运行时可用的显存条件 M_av(n,k)^t ≥ m_i，并设置运行时接纳检查（Runtime Admission Check）；只有物理容量可容纳(M_cap ≥ m_i)的任务才会被结构可行掩码保留，运行时显存不足将产生失败惩罚 R_fail，而不是简单增加延迟。
- **结构可行动作集（Structurally Feasible Action Set）**：定义 F_t^n ⊆ A_n，排除物理显存容量不足、超过最大跳数限制和队列已满等确定不可行的动作。

### 2.2 A-MADiff 算法

**总体框架：** 采用集中训练与去中心化执行（CTDE）范式，结合三类关键机制：

**(a) 基于扩散模型的去中心化 Actor**
- 动机：最优编排动作偏好随系统状态变化，且具有**多模态性**（如本地显存充足时执行本地、本地产紧时卸载、条件不稳定时入队延迟），标准高斯策略或单次前馈网络无法精确刻画此类分布。
- 具体机制：从高斯噪声 x_Td 出发，以局部观测 o_t^n 和扩散步骤 ℓ 为条件，通过噪声预测网络 ε_θ(o_t^n, x_t^n,ℓ, ℓ) 进行迭代反向去噪（reverse denoising），最终输出 x_0 作为动作偏好向量 z_t^n。通过掩蔽 Softmax 保证只对结构上可行的动作分配概率：
  - π_θ(a|o_t^n, F_t^n)= exp(z_t^n(a))/Σ_{ã∈F_t^n} exp(z_t^n(ã)), a∈F_t^n；a∉F_t^n 时概率为 0。
- **扩散Actor的端到端训练**：采用软 Actor-Critic（SAC）风格策略梯度信号训练，而非独立的监督去噪重构损失。

**(b) 注意力引导的中心化 Critic**
- 动机：集中训练时，并非所有智能体的状态对当前决策同等重要（例如，显存容量大的近邻/队列负载低的近邻应获得更高关注），标准拼接式 Critic 无法感知这种非均匀依赖关系。
- 具体机制：将各智能体的联合局部观测 s̃^t 通过共享编码器提取特征 E_t，经过**多头自注意力（MHA）** 对跨智能体信息进行自适应加权得到 H_t；对每个智能体 n，将其自身的编码和注意力上下文（连同 one-hot 智能体标识）拼接后经价值头输出动作价值向量。
- **双重 Critic 结构**：采用两个 Critic(Q_φ1, Q_φ2)，取其最小值来缓解过估计问题。
- **按智能体边际价值**估计而非联合 Q 值，避免动作空间随智能体数量指数爆炸，与奖励分解目标一致。

**(c) SAC 目标函数与训练**
- 对收集的经验样本，以最小化 TD 误差更新 Critic（公式38）；对 Actor 以最小化 log 概率加权损失来优化策略（公式39）；自适应更新熵系数 α_ent（公式41）；目标网络以软更新方式同步（公式42）。
- 经验样本格式为 ζ=(s̃^t, a^t, r^t, s̃^{t+1}, d^t, F^t, F^{t+1})，存储了所有智能体的结构可行集供后续策略更新使用。

## 6. 主要结论与发现

**定量结论（全部来自表II）：**
- A-MADiff累积奖励比最佳基线 MADiff 提升约 **29.4%**，比 MASAC 提升约 **38.1%**。

- A-MADiff 负完成率最低：1.77%（MADiff 4.73%，MAPPO 8.94%）。

- A-MADiff 达到 Greedy 水平所需环境步数最少（7.2k步），比 MADiff（9.2k步）减少约 21.7%。

**定性结论：**
- 随机/轮询等无协调调度策略在GPU显存约束下表现差（有效成功率低于9%）。
- 基于学习的策略优于单步贪心，能捕捉长期编排价值。
- 扩散策略相比单次前馈MLP Actor 能更有效地刻画状态依赖的多模态动作偏好（MADiff vs MASAC 对比）。
- 在训练中通过注意力机制有选择地聚合跨Agent状态可显著提升Critic价值估计精度和策略优化效果（A-MADiff vs MADiff 对比）。
- 可解释性分析展示了两个实例：扩散Actor 能够学会避免运行时显存不足的本地动作而无须完美逐ASP显存知识；注意力Critic分配给相关性最高的邻居非均匀的高权重，且注意力目标与实际路由目标并不等效。

5. **实验提供可解释性**：不仅有数值对比，还通过追踪扩散去噪过程和可视化注意力权重提供了策略行为合理性的直接证据。

## 8. 不足与局限

1. **仿真验证的局限性**：未在真实物理边缘测试平台或真实GPU推理系统中验证，也未引入真实世界AIGC任务的数据集；现实验证仅基于仿真模拟环境（参数合成建模）。
2. **少数关键假设的理想化**：
   - 假定移动性体现为各节点到达率的变化而不追踪每个用户的具体位置；
   - 卸载所涉及的通信时延模型较为简化（带宽/链路时延恒定）；
   - 未考虑GPU显存碎片化、KV Cache分页管理、模型并行/张量并行等低层细节，论文将它们明确列为未来扩展对象，但也使模型难以确切反映真实OOM行为（如显存碎片引发的实际OOM可能早于理论分配需求）。
3. **实验仅进行了单一场景验证**：仿真只在一个固定拓扑规模下进行（20个节点），各方法在不同节点密度/连接拓扑下的可扩展性和泛化能力不明。
4. **缺少更丰富的消融实验**：只隔离了注意力Critic的贡献（MADiff vs A-MADiff），但**没有单独消融扩散Actor**与普通MLP的对照（MASAC替代了此角色但二者不是严格的单一变量消融关系，因为MASAC的Critic结构也不含注意力）。
5. **对比基线更新不足**：缺少与更新的基于Transformer的多智能体方法、其他扩散离线/在线RL方法的对比。
6. **训练开销**：多步去噪过程（T_d=20步）增加了训练/推断线上开销；文中虽给出理论复杂度，但无实际训练收敛时间对比。
