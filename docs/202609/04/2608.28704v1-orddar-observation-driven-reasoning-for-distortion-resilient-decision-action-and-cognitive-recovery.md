## 摘要
AI智能体日益执行长期推理、规划、工具使用、记忆整合和自主决策，然而错误的中间状态可能传播并导致不一致的决策和不可靠的输出。现有推理方法主要依赖于迭代规划、自我反思、增强记忆或验证，但很少定位并选择性修复有缺陷的推理。我们提出ORDDAR（基于观察驱动的推理，用于抗失真决策、行动与认知恢复），一种将推理建模为认知状态转换的推理框架，检测局部失真，从先前经验中检索相关推理，并仅修复受影响的状态。因此，ORDDAR在局部推理转换层面执行恢复，而不是重新生成完整轨迹。在数学、常识、多跳和临床推理基准上的实验表明，与多种评估的推理基线相比，其推理质量、恢复能力和可解释性均有所提升。

## Abstract
AI agents increasingly perform long-term reasoning, planning, tool use, memory integration, and autonomous decision making, yet erroneous intermediate states can propagate and cause inconsistent decisions and unreliable outputs. Existing reasoning approaches mainly rely on iterative planning, self-reflection, augmented memory, or verification, but rarely localize and selectively repair faulty reasoning. We present ORDDAR (Observation-Driven Reasoning for Distortion-Resilient Decision, Action, and Cognitive Recovery), a reasoning framework that models reasoning as cognitive state transitions, detects localized distortions, retrieves related reasoning from prior experiences, and repairs only the affected states. ORDDAR therefore performs recovery at the local reasoning-transition level rather than regenerating the complete trajectory. Experiments across mathematical, commonsense, multi-hop, and clinical reasoning benchmarks demonstrate improved reasoning quality, recovery ability, and interpretability over multiple evaluated reasoning baselines.

## 一、核心问题与整体含义

- **背景**：AI 智能体可以执行长期推理、规划、工具调用、记忆整合和自主决策，但其推理过程容易在中间步骤出现错误，且错误会沿着推理轨迹逐步传播，最终导致决策不一致和输出不可靠。
- **核心问题**：现有推理增强方法（如迭代自反思、树搜索、记忆增强）大多在**整体推理路径**上进行规划或修正，很少能够**局部定位并选择性修复**错误的中间推理状态，因此常常被迫重新生成整条推理链，既低效又容易引入新误差。
- **核心命题**：如果能把推理看作一系列**认知状态转换**，在转换级别检测“推理失真”，并从既往经验中检索匹配的修复信息，就能只修复被污染的状态，而无需重建完整推理轨迹。
- **整体含义**：ORDDAR 提出了一种“基于观察驱动的推理”框架，将推理失真检测——状态诊断——互补推理检索——局部认知恢复整合为一个端到端流程，力图提升智能体的推理稳健性、恢复效率和可解释性。

## 二、方法论

- **核心思想**：
  - 将推理建模为观察驱动的**认知状态转移**序列（cognitive state transitions）。
  - 仅在局部转移层面对失真状态进行修复，不做整体重生成。
  - 引入“认知镜像”（Cognitive Mirror）存储紧凑的“失真签名—恢复互补”条目，跨任务复用。
- **问题形式化**：
  - 输入 `q` 经观察抽取函数 `φ` 变为观察集 `O = {o1, ..., om}`；
  - 推理引擎生成认知状态轨迹 `R = {s1, ..., sT}`，其中状态递归更新为 `st = f(s_{t-1}, ot)`；
  - 目标为学习恢复函数 `F: R → R̂`，得到修复后路径。
- **失真检测与签名编码**：
  - 对每个转移 `et = (st, s_{t+1})` 计算**语义转移距离** `dsem = 1 − cos(E(st), E(s_{t+1}))`；
  - 同时计算**认知锚点距离** `danchor = ∥ψt − ψ{t+1}∥₂`；
  - 两者归一化后用平方和开方合并为联合失真分数 `Dt`；
  - 以轨迹内平均失真为自适应阈值 `τR`，超过阈值的转移判定为失真；
  - 将每个真实失真编码为签名 `kt = {ψ_shift, A_gain, A_loss}`，分别表示语义转移位移、新增推理锚点、丢弃的推理锚点。
- **认知镜像记忆**：
  - 以 `M = {(ki, ci)}` 存储失真签名 `ki` 及对应修复互补 `ci`；
  - 获取的是“失真签名→恢复模式”对，而非整条推理轨迹；
  - 仅在验证通过后才会将新条目追加进内存，防止评估数据污染。
- **互补检索**：
  - 对失真签名 `kt`，按下式计算打分 `S(kt, ki) = α₁·S_shift + α₂·S_gain + α₃·S_loss`，采用 60–20–20 权重；
  - 取分值最高的互补信息 `c*` 用于修复。
- **局部恢复**：
  - 通过 `ŝt = R(st, c*)` 只替换失真的认知状态，恢复轨迹为 `R̂ = {s1, ..., ŝt, ..., sT}`；
  - 如果记忆中没有匹配的互补信息，则保持原轨迹不变。
- **预测与记忆更新**：
  - 最终预测由 `ŷ = P(R̂)` 得到；
  - 验证有效的恢复模式才更新缓存，保障跨任务复用且不被评测污染。
- **整体算法流程清晰**（见 Algorithm 1）：先基于已验证轨迹构建认知镜像，然后推理中对每个转移做检测、检索和局部修复，最后输出预测并选择性地更新记忆。

## 三、实验设计

- **基准数据集（Benchmarks）**：
  - **GSM8K**：数学推理；
  - **HotpotQA**：多跳问答；
  - **StrategyQA**：常识推理；
  - **CKDQA**：临床（慢性肾病）推理，私人数据集，经机构与医院伦理审批后构建。
- **基线方法**：CoT（思维链）、Self-Refine、Reflexion、Tree of Thoughts（ToT）、ProCo。
- **模型与设置**：所有方法统一使用 Qwen2.5-7B-Instruct，采用标准 tokenizer、chat 模板和确定性贪婪解码（do_sample=False），最大生成长度 512，每个评测抽取 100 个测试实例（随机种子 42）。
- **语义编码对比**：评估 MPNet、all-MiniLM-L6-v2、BAAI/bge-base-en-v1.5 三个嵌入模型，主实验选择 MPNet，其余用于鲁棒性分析。
- **评测指标**：多数任务以准确率报告；HotpotQA 同时给出 EM 和 F1。
- **主要结果**：ORDDAR 在四个基准上都优于所有基线。如 GSM8K 92 vs CoT 81；StrategyQA 86 vs CoT 81；HotpotQA F1 79.22 vs Self-Refine 78；CKDQA 94.38，为提升反常高。
- **消融实验**：分别移除互补记忆（CM）、失真记忆（DM）、恢复记忆（RM），在四个数据集上验证各组件贡献。DM 移除对 GSM8K 影响最大，CM/DM 移除在 CKDQA 上造成的下降最显著。
- **地面真实验证**：在独立标注的真实转换数据集上对比基于 MPNet 语义的检测、单独认知锚点检测以及 ORDDAR 联合检测的 P/R/F1，跨 GSM8K、HotpotQA、StrategyQA、Clinical-CKD 四个基准。
- **定性分析**：给出临床 CKD 病例的修复示例与 UMAP 可视化，展示检索到的互补内容与失真签名邻近性。

  - 对三种嵌入模型做对比（MPNet、MiniLM、BGE）；
  - 对最佳权重 60–20–20 做敏感性验证；

## 六、主要结论与发现

- ORDDAR 在数学、常识、多跳与临床四个推理任务上的表现均优于现有基线，说明局部修复比完整推理重生成更有效。
- 可靠地识别“在哪个转换处出了问题”是提升中间误差恢复能力的关键。
- 失真签名能够携带足够语义信息来检索相近的恢复模式，提供跨任务的迁移能力。
- 认知镜像的记忆更新机制在不引入额外验证模型的前提下，能够有效支持长时间运行的恢复需求。
- 实验结果提示不同错误类型（如临床“阶段误判”与多跳“证据分布错误”）对修复策略的敏感性存在差异。

## 七、优点

- **思想创新**：将推理从“整链生成与修改”转化为“状态转移检测 + 局部修复”，显著降低修复成本。
- **模块化流程**：观察提取、失真检测、签名编码、记忆检索、局部恢复和记忆更新六个环节解耦清晰，易于组合与扩展。
- **轻量化、去模型化信号**：明确不引入额外 LLM 验证器，采用基于嵌入的轻量检测信号，降低开销并减少与推理自纠正混淆的风险。
- **记忆设计合理**：认知镜像存“签名—互补”，避免冗余存储整条轨迹，同时设定仅在验证后更新内存，防止评测污染。
- **实验分析较完整**：除总体性能外，还提供消融、嵌入鲁棒性、地面真实验证与检索可视化，证据链较扎实。
- **跨领域评测**：同时覆盖数学、多跳、常识和临床，体现方法具备一定泛化基础。

## 八、不足与局限

- **评测规模偏小**：每个基准只以 100 个实例进行验证，统计敏感度不高，尤其面对波动大的复杂推理任务时说服力有限。
- **模型覆盖单一**：仅使用 Qwen2.5-7B-Instruct，未验证在更大模型、不同模型家族或开源/闭源模型之间的普遍性。
- **检测方法依赖嵌入表达**：语义距离与认知锚点距离的质量受句嵌入模型影响，对抽象推理或深层隐含逻辑的失真可能不够敏感。
- **非参数记忆本身不生成知识**：当缓存中不存在兼容签名时，方法会退化为保留原始路径，缺乏在故障时主动构造新替代方案的能力。

- **与真实智能体闭环的验证不足**：论文重点在推理链的离线恢复层面，没有深入讨论动作执行、环境反馈、工具使用等智能体完整场景中的失真恢复实践。
