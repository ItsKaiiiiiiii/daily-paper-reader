## 摘要
近年来，大语言模型和多模态模型的进展已将遥感（RS）处理从简单的感知模型推向旨在解决复杂、长时程遥感任务的智能体系统。然而，现有系统通常依赖单一的决策框架，难以适应遥感任务多阶段、相互依赖的特性。这种集中式方法导致任务执行不稳定、工具使用错误以及跨阶段错误传播等挑战。为解决这些问题，我们提出了HiRS-Agent，一种用于长时程遥感任务求解的层次化多智能体系统。HiRS-Agent采用两层协作架构：管理层负责动态路由、逐步验证、重新规划与终止控制，而专家层根据遥感工作流组织领域专用工具，并负责子任务推理与工具执行。为进一步增强系统能力，我们引入了两阶段监督微调策略和验证引导的层次化强化学习阶段，以联合优化协调与工具使用策略。在Earth-Agent Benchmark和ThinkGeo上的实验表明，HiRS-Agent显著提升了长时程工具使用能力和最终任务正确性，展示了结构化多智能体协作在构建可靠遥感智能体方面的有效性。代码公开于 https://github.com/IntelliSensing/HiRS-Agent。

## Abstract
Recent advances in large language models and multimodal models have pushed remote sensing (RS) processing from simple perception models to agentic systems designed to tackle complex, long-horizon RS tasks. However, existing systems often rely on monolithic decision-making frameworks, which fail to accommodate the multi-stage, interdependent nature of RS tasks. This centralized approach leads to challenges such as unstable task execution, incorrect tool usage, and error propagation across stages. To address these issues, we propose HiRS-Agent, a hierarchical multi-agent system for long-horizon RS task solving. HiRS-Agent adopts a two-level collaborative architecture: the Manager Layer handles dynamic routing, step-level verification, replanning, and termination control, while the Specialist Layer organizes domain-specific tools according to the RS workflow and is responsible for subtask reasoning and tool execution. To further enhance the system's capability, we introduce a two-stage supervised tuning strategy and a verification-guided hierarchical reinforcement learning stage to jointly optimize coordination and tool-use policies. Experiments on Earth-Agent Benchmark and ThinkGeo show that HiRS-Agent substantially improves long-horizon tool-use capability and final-task correctness, demonstrating the effectiveness of structured multi-agent collaboration for reliable RS agents. The code is publicly available at https://github.com/IntelliSensing/HiRS-Agent.

## 1. 论文的核心问题与整体含义

### 研究动机与背景

- 遥感（RS）领域正从单一的感知模型（如视觉问答、目标检测、语义分割）向能够自主组织与执行复杂工作流的智能体系统演进。现代遥感应用（如灾害评估、环境监测、土地利用分析）往往需要多步推理、工具调用、中间结果解读和迭代决策，形成“长时程”（long-horizon）处理链路。
- 然而，现有遥感智能体大多从通用智能体范式直接迁移而来，未围绕遥感工作流的内在结构进行设计，存在三大关键“不匹配”：
  - **工作流不匹配**：遥感任务具有多阶段、强上下游耦合的特征（如洪灾制图中“将云影误判为水体”会直接污染下游的水体指数计算与淹没面积估算），但通用智能体框架未显式建模这种阶段依赖关系。
  - **知识不匹配**：作为智能体“大脑”的LLM未充分对齐遥感领域专业知识（如物理机制、光谱约束、专业数据处理流程）。
  - **控制不匹配**：现有系统缺乏中间状态的验证与失败恢复机制，早期错误会在长流程中不断累积与传播。
- 核心论点：仅靠扩大模型规模不足以解决上述问题；显式建模遥感工作流的结构与阶段依赖，并配以结构化多智能体协作，才是实现可靠长时程执行的关键。

## 2. 论文提出的方法论

### 核心思想

HiRS-Agent 采用“管理层–专家层”两层协同架构，围绕遥感工作流的标准递进逻辑展开：**光谱/地表解析 → 物理反演/检索 → 统计/空间分析**。系统本质上是共享同一LLM骨干、通过角色提示（role prompt）区分的多角色单策略架构。

### 关键技术细节（分层架构）

- **Manager Layer（管理层，即协调者智能体 OA）**：
  - 负责任务分解、动态路由、历史感知验证和自适应执行控制。
  - 维护结构化的全局状态 \( s_t = \{x, d, g_t, H_t, C_t\} \)，其中 \( H_t \) 为结构化全局记忆，存储任务上下文、路由状态、执行轨迹、中间证据，用于显式建模跨阶段依赖。
  - 采用**历史感知验证机制**：每步执行后，输出验证结果 \( z_t \in \{\text{pass}, \text{uncertain}, \text{fail}\} \)，从三方面对中间结果进行核查：① 模式有效性（字段与类型）；② 子目标一致性；③ 约束满足性（物理性、光谱性、统计合理性）。
  - 依据验证结果进行自适应控制：FAIL → 重新规划/工具修复/替代路由；UNCERTAIN → 交叉验证/替代推理路径；PASS → 提交记忆并继续。失败与恢复轨迹也写入全局记忆，使后续决策具有历史感知能力。

- **Specialist Layer（专家层）**：按遥感工作流组织为三类领域专家智能体，各配置阶段对齐的工具子集（共120个工具）：
  - **Surface Parsing Agent (SPA)** —— 图像解译、目标检测、分割、ROI生成、光谱指数（NDVI/NDWI）解析等（42个工具）。
  - **Physical Retrieval Agent (PRA)** —— 物理反演、定量产品生成、辐射定标与归一化、质量控制（18个工具）。
  - **Statistical Analytics Agent (SAA)** —— 数据聚合清洗、统计检验、相关性分析、报告级指标计算（60个工具）。

### 关键技术细节（训练策略）

- **Expert-to-Workflow Alignment Tuning（Expert-tuning，两阶段监督微调）**：
  - **Stage I：基础知识注入**。构建三级RS知识体系（3个一级主题、11个二级模块、28个三级领域），从四本权威RS教材提取知识，生成1,583个语义连贯的知识块和5,687个知识样本，以多选题（MCQ）和指令-响应对形式进行微调。
  - **Stage II：工作流对齐**。基于真实遥感流水线日志构建993个流程监督样本（684个Workflow MCQ + 309个Workflow Order），将高层任务意图与可执行的遥感处理流程对齐。

- **Verification-Guided Hierarchical RL（VG-HRL，验证引导的分层强化学习）**，基于GRPO实现：
  - **分层奖励设计**：管理层使用轨迹级奖励 \( R_{\text{mgr}} = \omega_{\text{route}}\hat{R}_{\text{route}} + \omega_{\text{final}}\hat{R}_{\text{final}} + \omega_{\text{len}}\hat{R}_{\text{len}} \)，综合衡量路由正确性、最终任务成功度和轨迹长度惩罚；专家层使用分级门控奖励 \( R_{\text{spec},k} \)——工具调用按三级分类：Tier 1为域外幻觉工具（-1.0）、Tier 2为域内但错误工具（-0.5 + 0.2R_exec）、Tier 3为正确工具（0.5 + 0.2R_exec + 0.3R_args），保留更有信息的组内方差。
  - **角色感知分组优化**：管理层按任务分组计算优势；专家层按（任务、步骤索引）分组计算优势，以对齐不同粒度的信用分配。
  - 最终通过混合损失 \( \mathcal{L}_{\text{mixed}} = \lambda\mathcal{L}_{\text{mgr}} + (1-\lambda)\mathcal{L}_{\text{spec}} \)（\(\lambda = 0.5\)）联合优化，损失层组合而非奖励层组合，保证独立归一化与稳定优化。

## 6. 论文的主要结论与发现

1. **层次化多智能体架构显著有效**：HiRS-Agent在Earth-Bench上使Qwen3-4B的Accuracy从15.73/10.08提升至43.95/45.56，Tool-Exact-Match从0.00/8.63提升至31.67/34.64（AP/IF模式）。

6. **核心洞见**：显式建模遥感工作流结构与阶段依赖（而非单纯扩大模型）对可靠长时程执行至关重要。
