## 摘要
大语言模型智能体越来越多地通过多智能体框架解决长时程任务，其中中心智能体协调专门的子智能体、工具和环境。在此类框架中训练中心策略面临两个挑战。首先，动作标签是低基数的决策，而其参数构成高维条件序列；使用共享序列级信号优化两者可能产生冲突梯度。其次，动态调度创建了具有分支、并行调用和重写上下文的相互依赖会话，无法被忠实简化为单一的扁平标记序列。我们提出Harness-RL，一种结构化强化学习框架，将冲突感知策略优化（CAPO）与接口级黑盒轨迹构建相结合。黑盒组件捕获接口调用记录，构建每会话前缀树，并将结果与过程奖励对齐到可训练标记上。CAPO利用前向激活识别与动作和参数标记相关的参数分区，然后将策略梯度路由到相应的子空间。Harness-RL支持仅中心以及联合多智能体训练。在七个多跳问答和智能体检索基准上，使用Qwen2.5-1.5B和Qwen2.5-3B分别达到平均F1分数42.93和47.79，而消融研究验证了CAPO的贡献，并在评估设置中倾向于仅中心优化。我们的代码可在https://github.com/jiangxinke/Harness-RL获取。

## Abstract
Large language model agents increasingly solve long-horizon tasks through multi-agent harnesses in which a central agent coordinates specialized sub-agents, tools, and environments. Training the central policy in such a harness raises two challenges. First, an action label is a low-cardinality decision, whereas its args form a high-dimensional conditional sequence; optimizing both with a shared sequence-level signal can produce conflicting gradients. Second, dynamic scheduling creates interdependent sessions with branches, parallel calls, and rewritten contexts, which cannot be faithfully reduced to one flat token sequence. We introduce Harness-RL, a structured reinforcement learning framework that combines Conflict-Aware Policy Optimization (CAPO) with interface-level black-box trajectory construction. The black-box component captures Interface Call Records, builds per-session prefix trees, and aligns outcome and process rewards with trainable tokens. CAPO uses forward activations to identify parameter partitions associated with action and args tokens, then routes their policy gradients to the corresponding subspaces. Harness-RL supports both central-only and joint multi-agent training. Across seven multi-hop question answering and agentic retrieval benchmarks, it reaches average F1 scores of 42.93 and 47.79 with Qwen2.5-1.5B and Qwen2.5-3B, respectively, while ablations validate the contribution of CAPO and favor central-only optimization in the evaluated setting. Our code is available at https://github.com/jiangxinke/Harness-RL.

## 2. 论文提出的方法论

**总体结构**：Harness-RL 由两大组件构成：
- **黑盒强化学习机制**（接口级黑盒轨迹构建）：负责将真实的多智能体交互转换为可训练的结构化轨迹，并实现奖励对齐。
- **冲突感知策略优化（CAPO）**：负责对 Action 与 Args 施加解耦的梯度路由，避免行为间干扰。

### 2.1 黑盒 RL 机制：三步轨迹构造与奖励分配

1. **接口调用记录捕获**
   - 对每次会话（session）中的每一次模型调用，记录：
     - Token-In：输入（消息+工具规范经模板化）。
     - Token-Out：模型采样输出。
     - 采样对数概率（rollout log-probabilities）。
   - 记录为三元组：ξ = (X, Y, ℓ_roll)。

2. **前缀匹配与树构造**
   - 将近端的完整输入输出标记拼接为 Z = X ⊕ Y。
   - 在每个 session 内构建前缀树，共享前缀被合并，非共享后缀形成独立分支。上下文重写被挂在其最长共享前缀上，原分支保留重写前的输出。
   - 每个输出跨度节点对应一个基础样本 S_n；训练集 eD_H(τ_e) 由这些样本构成。

3. **分段奖励归属**
   - 定义结果奖励：R_out = token-level F1（且需满足输出约束）。
   - 计算结果优势：组内归一化（减去组均值、除以组标准差）。
   - 对每个决策单元（Action–Args 单元集）定义过程奖励，并计算对应优势。
   - 将 rollout 级结果优势与决策级过程优势逐层对齐到 token 上，最终得到 token 级对齐的优势 A_{n,t}。

### 2.2 冲突感知策略优化（CAPO）

核心思想：通过前向激活分析寻找 Action token 与 Args token 各自对应的功能参数分区，将两类的策略梯度路由到各自的子空间，从而降低相互干扰。

1. **高质量轨迹构建**：对每个训练查询做多次 rollout，保留成功轨迹作为探针集（rejection sampling），减少失败行为对应的激活噪声。

2. **激活统计与功能分区**：
   - 统计每一层、每个结构单元的 Action token 与 Args token 的平均正向激活强度。
   - 筛选出各自响应最强的 TopK 单元，形成动作分区 U_action 和参数分区 U_args。
   - 若某单元被同时选中，则视为共享单元，按实现中的重叠规则处理。

3. **Token 特定梯度路由**：
   - 对 action 样本位置集 I_action 与 args 样本位置集 I_args，分别计算各自策略梯度：
     - ∇θ_action J_action = Σ A_{n,t} ∇θ_action ℓ_{n,t}(θ)
     - ∇θ_args J_args = Σ A_{n,t} ∇θ_args ℓ_{n,t}(θ)
   - 整体目标 J = J_action + J_args，但参数只被各自对应分区接收梯度更新。

4. **最终损失**：采用 rollout 平衡的 clip 目标（类似于 GRPO 的 clipped surrogate），对每条 rollout 独立归一化，防止分支多的 rollout 主导梯度。整体目标再按 Action 与 Args 位置拆分，分别施加上述梯度路由。

### 2.3 训练范围

- 支持仅中心智能体训练（central-only）与联合训练（joint multi-agent training，中心+子智能体）。默认实验采用 central-only，子智能体被冻结为环境的一部分。

## 3. 实验设计

### 3.1 数据与基准

- **训练数据**：来自 2WikiMultiHopQA 和 HotpotQA 的训练集，剔除无需检索或仅需单次检索的问题，保留需要多步推理与子智能体协作的样本。
- **评测基准**（共7个）：2WikiMultiHopQA、HotpotQA 为域内；Bamboogle、FRAMES、MuSiQue、Natural Questions、TriviaQA 为域外。指标采用 token-level F1。
- **智能体框架配置**：沿用 STACKPLANNER 配置。含 Search Agent（维基百科与知识图谱检索工具）和 Conclusion Agent（答案综合工具），默认冻结子智能体，仅优化中心智能体。
- **基线方法**分为四类：
  1. 无检索：Base、CoT
  2. 朴素 RAG：FS-RAG、FL-RAG
  3. 智能体 RAG：ReAct、IRCoT、TC-RAG
  4. 基于 RL：ReSearch、Search-R1、AEPO、ARPO、MEM1、AgenticRAG-R1
- **策略骨干模型**：Qwen2.5-1.5B 和 Qwen2.5-3B。
- **评测维度**：RQ1 主效果、RQ2 CAPO有效性、RQ3 训练范围影响、RQ4 定性行为分析。

### 3.2 主要对比结果（摘要）

- Qwen2.5-1.5B：Harness-RL 平均 F1 = 42.93，比最强基线 AgenticRAG-R1 高 15.28 分，在全部7个基准上排名第一。
- Qwen2.5-3B：Harness-RL 平均 F1 = 47.79，比 AgenticRAG-R1 高 14.24 分，同样在全部7个基准上排名第一。

### 3.3 消融与行为研究

- 对比 w/o CAPO（使用标准 GRPO）：有 CAPO 的完整方法平均 F1 在 1.5B 上提高 1.89，3B 上提高 1.57。
- 对比 central-only 与 all agents：central-only 在 Accuracy 上领先2.38 分（42.88 vs 40.49），F1 上领先 2.42 分（47.79 vs 45.36），说明中心协调任务下 center-only 更优。
- 可视化分析了 Action/Args 在 Qwen2.5-1.5B（28层）和 Qwen2.5-3B（36层）上的分层功能分区分布，发现两者响应层不同，佐证 CAPO 分区的合理性。

## 6. 论文的主要结论与发现

1. **主结论**：Harness-RL 能有效训练中心智能体策略，显著改善多智能体框架中的推理、调度与协调能力。在7个基准上全面超过所有基线。
2. **CAPO 有效**：动作与参数的分区梯度路由能缓解梯度冲突，带来整体平均 F1 的一致提高（两种模型尺度的消融均显示积极增益）。
3. **中心智能体解耦行为改善**：中心智能体可以保持动作决策不变、单轮内精细化参数内容，从而提升多步协同能力。
4. **训练范围结论**：在中心协调任务下，仅训练中心智能体优于联合训练所有智能体，因为联合训练可能干扰全局规划目标的一致性与参数更新稳定性。
5. CAPO 分区在实际模型中层间分布存在差异，证实 Action 与 Args 确实对应不同的功能参数子空间。

## 7. 优点

- **问题捕捉准确**：具体剖析了现有多智能体 RL 中两大隐式假设的不合理性，提出了明确的两个挑战，具有较高研究价值。
- **框架统一且可扩展**：黑盒式记录+前缀树重构提供了一个近乎设备级的统一表示，不依赖特定 harness 的内部结构，可复用到不同智能体框架。
