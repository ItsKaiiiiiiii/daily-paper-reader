## 摘要
多智能体组合优化问题因其NP-hard性质而极具挑战性。近年来的并行自回归神经求解器通过允许智能体同时做出决策来提高推理效率，但其性能在大规模实例上往往会下降。这在很大程度上归因于对局部几何结构的建模薄弱，以及冲突任务选择仅在动作生成之后才被处理。为解决这些局限性，我们提出了GeoPAR，一种几何引导的并行自回归强化学习框架，用于可扩展的多智能体组合优化。GeoPAR整合了三个关键组件：（1）投影窗口稀疏几何机制，通过多方向投影构建轻量级局部候选邻域；（2）稀疏边偏置注意力，将这些几何关系注入节点表示；（3）缓存引导的冲突感知分配，在解码过程中重用几何缓存以抑制独占任务的重复选择。在异构车辆路径问题和开放多车场取送货问题上的实验表明，GeoPAR在显著减少展开步骤并保持高效推理的同时，提升了大规模零样本泛化能力。

## Abstract
Multi-agent combinatorial optimization problems are notoriously challenging due to their NP-hard nature. Recent parallel autoregressive neural solvers improve inference efficiency by allowing agents to make decisions simultaneously, but their performance often degrades on large-scale instances. This is largely attributable to weak modeling of local geometric structures and the fact that conflicting task selections are handled only after action generation. To address these limitations, we propose GeoPAR, a geometry-guided parallel autoregressive reinforcement learning framework for scalable multi-agent combinatorial optimization. GeoPAR integrates three key components: (1) a projection-window sparse geometry mechanism that builds lightweight local candidate neighborhoods through multi-directional projections, (2) sparse edge-biased attention that injects these geometric relations into node representations, and (3) cache-guided conflict-aware assignment that reuses the geometric cache during decoding to suppress duplicate selections of exclusive tasks. Experiments on heterogeneous vehicle routing and open multi-depot pickup-and-delivery problems show that GeoPAR improves large-scale zero-shot generalization while substantially reducing rollout steps and maintaining efficient inference.

- 最近提出的并行自回归组合优化框架（PA-CO，如 PARCO）允许多个智能体在同一构造步骤中同时生成动作，显著提高推理效率；但在零样本泛化到大规规模实例时仍面临两个关键挑战：

## 2. 论文提出的方法论

- GeoPAR 整体采用“编码器—并行指针解码器—冲突感知分配”的三阶段结构，通过三个核心组件实现：
  1. **投影窗口稀疏几何机制（Projection-Window Sparse Geometry, PWin）**
     - 将每个任务节点（如客户点、取送货点）用二维归一化坐标等几何描述表示。
     - 沿多个固定单位投影方向（如 4 个方向）对节点排序，得到多个一维排列。
     - 对每个节点，在每个排列中取其前后窗口半径 w（默认 8）内的近邻，合并后取 TopK 个构成稀疏候选邻域 Npw(i)。
     - 只构建轻量级的稀疏几何候选集，避免构造完整稠密距离矩阵，兼顾局部结构覆盖与计算效率。
  2. **稀疏边偏置注意力（Sparse Edge-Biased Attention）**
     - 将 PWin 构建的几何缓存（候选索引、排名距离、候选来源类型等）作为边特征注入 Transformer 编码器。
     - 注意力分数由标准缩放点积注意力得分与三类几何偏置项（边描述子、候选来源、归一化排名距离）之和组成，并且仅在缓存邻域内进行聚合。
     - 同时，节点还会与智能体嵌入交互，融合“agent-conditioned”信息，最终得到几何感知的节点表示。
  3. **缓存引导的冲突感知分配（Cache-Guided Conflict-Aware Assignment, CA）**
     - 解码时，每个智能体构建一个紧凑候选池，包含：神经解码器高概率动作（TopK logit）、缓存中几何后继（CacheK）以及任务本原启发式候选（如 savings 候选），训练时额外加入随机可行动作。
     - 候选池中的每个候选用“神经偏好 + 几何奖励 − 软代价”的综合得分 S 来排序。
     - 在训练阶段使用冲突感知采样（Sample X）：按随机智能体顺序采样，已经被消费的独占任务被剔除。
     - 在推理阶段使用冲突感知解析（Resolve X）：对于竞争同一独占任务的多个智能体，仅分配给综合得分最高的智能体，其余智能体回退到安全动作（等待等）。
     - 通过内部消费集合 D_t 保证在同一并行步骤内不会出现独占任务的重复选择。

- 训练目标为强化学习（策略梯度），采用 action-independent baseline 的 REINFORCE 形式：

- GeoPAR 的编解码结构：
  - 初始嵌入：将智能体特征矩阵 X^A 和任务特征矩阵 X^V 分别经线性投影得到共享 d 维表示，再拼接输入编码器。

## 6. 论文的主要结论与发现

- GeoPAR 在两个大规模多智能体组合优化问题上的零样本泛化性能显著优于 PARCO、AM、2D-Ptr、DPN 等神经求解器，并在目标值和推理时间之间取得更好的平衡。
- GeoPAR 大幅降低了 rollout steps：例如 HCVRP 在 N=1000/M=20 时 rollout steps 从 PARCO 的 693 降到 215，在 N=3000/M=240 时从 1308 降到 129；N=5000/M=400 时从 1846 降到 177.8，同时目标值更低。
- 投影窗口机制能近似保留距离 KNN 的局部路径转移信息，但不需要稠密距离矩阵，构建速度快得多，为大图提供了可扩展的几何先验。
- CA 快速推进并行构造（减少 rollout steps），但单靠 CA 在大规模下会导致目标值退化；PWin 改善局部候选质量但无法缩短 rollout；二者相互补充，缺一不可。
- 内部消融表明：几何候选只有在同时被赋予几何评分（GeoScore）时才有效；在解码端完全去除几何缓存会同时伤害解质量和效率。
- 训练动态显示，GeoPAR 在训练早期就能学习到更紧凑的决策过程（rollout steps 快速下降），随后逐步收敛到更优解，即“效率优势源于机制而非后处理”。
- 在极低 agent 密度或极端 agent 密度变化下，GeoPAR 的解质量和效率提升仍不均匀，尤其 HCVRP 中车队稀疏时仍很困难。

## 7. 优点

- **创新的几何引导设计**：将投影窗口稀疏几何与神经解码器深度耦合，既保留了局部空间结构的有效性，又避免 O(N²) 的稠密距离计算，具备清晰的可扩展性逻辑。
- **冲突感知前置化**：将冲突避免从“事后修复”变为“事前引导”，直接使用几何缓存构建紧凑候选池，并综合神经偏好、几何奖励、软代价做出分配，整体设计上有很强的因果针对性。
- **训练目标与部署过程一致**：训练时采用冲突感知采样（Sample X），推理时采用冲突感知解析（Resolve X），二者共享相同的综合得分函数，减小训练-推理分布差距。
- **实验系统且细致**：
  - 覆盖两个不同约束结构的多智能体问题（容量+多车+最小最大目标 vs 取送货+优先级+开放路线）。
  - 大规模零样本测试最大到 N=20000，具有较强的说服力。
  - 消融实验通过逐项剥离验证了两大核心模块以及内部组件的独立贡献。
- **开源风格清晰**（文中提到实现结构完整），论文文字和图示（Figure 3 的架构图）能帮助读者快速理解整个流程。

- **极端 baseline 性能退化可能削弱对比公平性**：PARCO 在 HCVRP N=5000/M=400 时 Gap 高达 257%，DPN 在 N=1000/M=20 时 Gap 高达 116%，HAM 在 OMDCPDP 大规模上 Gap 高达 14744%，这些退化过于严重，可能反映了基线训练不充分、超参未适配等非算法本质原因；而 GeoPAR 方法则加入了密集的启发式候选（如 savings）和额外几何特征，这属于“加了额外诱导信息”的方法，与基线并非完全同等的策略空间复杂度。
- **小规模测试优势不明显**：GeoPAR 在训练规模（HCVRP N=60-100，OMDCPDP N=50-100）上的表现不如 PARCO 甚至不如传统 SISR / MAPDP，说明其优势主要集中在零样本迁移阶段；“迁移增强”是否以“小规模精度受损”为代价，没有被充分讨论。
- **几何启发式对特定问题的依赖**：投影方向、窗口大小、savings 候选、几何得分等参数和规则针对欧式坐标任务进行了手工设计；对于非欧式或更高维任务特征，该机制的有效性需要重新验证。
- **未探索更多大规模设定**：训练规模只用了 N≤100，没有在中等规模（如 N=500）上训练验证；所有大规模结果都是零样本，未比较 fine-tune 或自适应方法（如 active search）下的上限表现。
- **结论的普遍性有限**：仅测试了车辆路径类和取送货类路由问题；多智能体任务分配中的更一般约束（如时间窗、机器人运动学、多目标任务）并未覆盖。
- **自我局限说明**：作者也承认在极低 agent 密度或剧烈 agent 密度变化下提升不稳定，但没有给出专用的自适应机制，仅列为未来方向。
