## 摘要
现实世界中的多智能体系统（如无人机群、自动驾驶汽车、仓库机器人）必须在避免碰撞的同时满足丰富的时序任务。信号时序逻辑（STL）优雅地编码了此类目标，但当前的STL规划方法面临关键限制。最先进的基于优化的方法可以处理任意STL规范，但难以扩展，随着智能体数量的增加，计算变得不切实际。基于学习的方法能够高效处理大量智能体并实现快速规划，但当部署时的目标与训练时不同时表现不佳，并且不支持需要将不同规范分配给不同智能体（即异构性）或需要多智能体协调的团队级规范的规划任务。这种泛化性与可扩展性之间的根本权衡对在实际中实现多智能体STL规划算法提出了挑战。为了克服这一挑战，我们提出了一种新的基于扩散的STL规范多智能体规划方法。利用STL的可微近似，我们将STL梯度集成到去噪过程中，使我们的方法能够泛化到新颖的公式，这些公式的谓词位于训练期间覆盖的目标区域内的任意位置，同时实现与现有基于学习方法相同的可扩展性。我们的方法支持异构规范，并通过使用扩散模型自然地增强规划多样性，从而显著减少智能体之间的安全相关违规（如碰撞）。一项详细的评估研究证明了基于STL引导的扩散多智能体规划器在构建可泛化、可扩展和多样化规划方面的实用性。视频和代码可在https://www.jeappen.com/diff-ma-stl/和https://github.com/jeappen/diff-ma-stl获取。

## Abstract
Multi-agent systems in the real-world (e.g., drone swarms, autonomous cars, warehouse robots) must satisfy rich, temporal tasks while avoiding collisions. Signal Temporal Logic (STL) elegantly encodes such objectives, but current STL planning methods face critical limitations. State-of-the-art optimization-based approaches can handle arbitrary STL specifications but struggle with scalability, becoming computationally impractical as the number of agents grows. Learning-based methods efficiently handle a large number of agents with rapid planning times but fare poorly when deployment-time objectives differ from those used during training, and do not support planning tasks that require different specifications to be ascribed to different agents (i.e., heterogeneity) or team-level specifications requiring coordination of multiple agents. This fundamental trade-off between generalizability and scalability presents a challenge for realizing multi-agent STL planning algorithms in practice. To overcome this challenge, we introduce a new diffusion method for multi-agent planning with STL specifications. Using a differentiable approximation of STL, we integrate the STL gradient in the denoising process, making our approach generalizable to novel formulas whose predicates are placed anywhere within the goal region covered during training, while achieving the same scalability as existing learning-based methods. Our method supports heterogeneous specifications, and by using diffusion models, naturally enhances plan diversity, thereby significantly reducing safety-related violations (e.g., collisions) among agents. A detailed evaluation study justifies the utility of STL-guided diffusion-based multi-agent planners for constructing generalizable, scalable, and diverse plans. Videos and code are available at https://www.jeappen.com/diff-ma-stl/ and https://github.com/jeappen/diff-ma-stl .

## 一、论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：现实世界中的多智能体系统（如无人机群、自动驾驶车队、仓库机器人等）不仅要执行复杂时序任务，还必须保证智能体之间不发生碰撞。STL（Signal Temporal Logic, 信号时序逻辑）是一种能够表达带时间约束的复杂时序任务的规范语言，在机器人任务规划中被广泛应用。
- **核心矛盾**：现有STL多智能体规划方法在 **“可扩展性（Scalability）”** 与 **“泛化性（Generalizability）”** 之间存在根本性权衡：
  1. 基于优化的方法（如 MILP/混合整数线性规划）能处理任意STL规范，但随着智能体数量增加，计算量急剧膨胀（如碰撞约束带来 O(N²K²) 个额外决策变量），在实际中不可扩展。已有研究表明：即使是 N=5 的双积分器智能体的简单任务也可能超时。
  2. 基于学习的方法（如 GNN-ODE）扩展性好、规划时间短，但存在三方面限制：不支持异构规范（不同智能体有不同任务）、不支持团队级协作规范、且面对训练时未见过的规范无法零样本泛化，需要数小时的重新训练。
- **额外痛点**：现有的循环式生成式规划器（GNN-ODE）给不同智能体生成高度相似的计划，实际运行中会导致“扎堆死锁”（clustering-induced deadlocks）和碰撞。
- **本文目标**：设计一种同时具备 **可扩展性、泛化性、多样性（Diversity）** 的多智能体 STL 规划器。论文认为理想的规划器应具备：（1）高效扩展至大规模智能体；（2）运行时可处理不同的异构任务与目标区域内新放置的谓词组成的新公式；（3）生成多样化、分散的计划以减少拥塞。

## 二、论文提出的方法论

### 1. 核心思想

论文提出 **DIFF-MA**——一种基于扩散模型的 STL 引导式多智能体规划框架，其核心思想包括：

- **先验解耦**：仅在**单智能体轨迹**上训练扩散模型，多智能体之间的耦合不在训练阶段学习，而是在推理（denoising）阶段通过 STL 规范和可达性引导动态注入。这使得训练成本低，并天然支持异构与团队级规范。
- **STL梯度引导**：利用 STL 鲁棒性（robustness）的可微近似，计算轨迹相对于鲁棒性分数的梯度，并在扩散模型去噪的每一步施加该梯度，从而引导生成的规划逐步满足新的STL目标。
- **可接受性与闭环安全**：在引导中引入 GCBF+（Graph Control Barrier Function）控制器的闭环轨迹追踪误差作为“可实现性损失”（achievability loss），保证生成的规划能被底层安全控制器实际跟踪执行。

### 2. 训练阶段

- 在 4.0×4.0 单位空间中均匀放置 **9 个矩形谓词区域** 构成谓词集合 P。
- 使用 STLPY-SA 规划器随机采样 **10000 条**满足 seq 规范（随机取3个谓词、依序访问）的单智能体轨迹构建训练集。
- 训练一个基于 EDM（Elucidating Diffusion Model, Karras et al.）框架的 U-Net 去噪器 Dθ，以生成覆盖状态-目标分布的轨迹。

### 3. 推理阶段：STL引导去噪

核心算法如 Algorithm 1 所示，要点如下：

- 对每个去噪步 n：
  - 采样高斯噪声并按 EDM 的噪声调度进行扰动；
  - 用训练好的去噪器 Dθ 估计去噪后的轨迹（denoised trajectory）；
  - **计算引导梯度**：gn ← ∇_{τ̃_ng} f_guid(τ̃_ng)，即以 STL 鲁棒性损失和可实现性损失之和为引导函数，对去噪轨迹求梯度；
  - 沿梯度方向更新噪声轨迹（按智能体维度归一化梯度）；
  - 应用二阶欧拉修正。
- **引导函数定义**：f_guid = −λ_STL · L_STL − λ_ach · L_ach
  - **STL损失 L_STL**：MA-STL-A 规范下为各智能体鲁棒性分数负值之和，即 L_STL = Σᵢ −ρ(ϕᵢ, τ̃_ng)；CaTL+ 团队规范下则取联合轨迹的整体鲁棒性：L_STL = −ρ(Ψ, τ_ng)；
  - **可实现性损失 L_ach**：去噪轨迹与用 GCBF+ 控制器闭环采样轨迹之间的跟踪误差，仅在去噪过程的最后 k_ach（如20%）步计算以节省计算。
- **初始条件施加**：采用 inpainting，每步去噪后将第一帧规划覆盖为智能体的当前状态。
- **重采样机制**：每个智能体的规划最多重采样 N_sample=40 次，每次并行生成 B=8 条候选联合规划，保留精确鲁棒性最高者；直到 ρ(ϕᵢ, τ_g) > ε_sample 才接受。接受后的规划被冻结，保证了鲁棒性的单调不减。
- 在 MA-STL-A 规范中，采用异步执行模型——每个智能体只需在其自身时间戳序列上满足各自规范，而非要求全局同步满足。

## 六、论文的主要结论与发现

1. **主结果**：DIFF-MA 在所有任务模板上平均比 STLPY-SA 成功率高出 **20%**，在 N=32 拥挤地图上相对成功率提升达 **36%**，同时比 STLPY-SA 快 **3~200 倍**，且**无需重训练**即可泛化到新规范。
2. **可扩展性**：在 N=32 时仍保持 ≥84% 平均成功率（STLPY-SA 在 N=32 时平均成功率仅 64%）；在 2× 地图上最高支持 N=128（此时安全率下降到 42%，与 GCBF+ 基础控制器的能力边界有关）。
3. **安全性与延迟的权衡**：DIFF-MA 路径比 STLPY-SA 长约 **48%**——这是换取安全性（避开拥挤区域）的主动权衡。平均单个智能体的执行延迟为 STLPY-SA 单智能体基准的 **1.3~1.9 倍**（N=8→32）。
4. **团队级规范**：在 CaTL+ 团队任务中，DIFF-MA 无需显式任务分配（隐式分配），在 N=32 时保持约 90% 平均成功率，比具备 oracle 分配的最佳 STLPY-SA 基线高出 **30% 以上**。
5. **多样性显著增强**：DIFF-MA 生成的计划在 Path Overlap 和 Agents-per-Cluster 两项指标上接近最优水平（Path Overlap 几乎为 0，每簇约 1 个智能体），而 GNN-ODE 的聚类高达每个簇 7.74 个智能体（seq 任务）、路径重叠最高达 8.72%。
6. **消融发现**：提高可实现性损失 λ_ach 会牺牲一点规划时间（降低计算量时更慢），但在密集场景（N=32）降低 TtR 达 17.37%、成功率提升 2.37%，说明该损失确实有助于生成可控可执行的规划。低 λ_ach 的模型虽然规划时间短（最多缩短 62%），但在 N=32 时 TtR 高出 17.37%、成功率低 2.37%。

2. **引导函数的多目标设计**：同时优化 STL 鲁棒性（满足规格）与 GCBF+ 闭环可实现性（保证可跟踪），将高层时序规划与低层安全控制器有机结合。
3. **工程实现高效**：基于 JAX 的 JIT 向量化采样，并行生成多条候选联合计划，显著缓解扩散模型推理慢的瓶颈；实验平台只需单张 L4 GPU 级别的算力。
4. **机制设计仔细**：接受计划的冻结机制、单调不减的重采样策略，保证算法不会因重采样而退化。
5. **实验设计的对比逻辑清晰**：在“无法与协作式 MILP 在 N>5 对比”的约束下，选择了最公平的单智能体独立规划基线，并对无法对比的场景（GNN-ODE 不支持异构任务）做了说明并单列多样性对比。
6. **探讨了 STL 规划的多样性维度**：现有文献多关注满足率，本文明确将计划多样性作为核心指标并给出了两个可量化的度量，具有实用意义。

## 八、不足与局限

1. **模型依赖与假设**：
   - 需要**精确的系统动态模型**和时间离散化来训练 GCBF+ 控制器并计算可实现性损失；在真实世界中模型误差可能不可忽略。
   - 方法的“异步执行”语义假设用户可接受智能体到达时间的微小延迟（1.3~1.9×）；对需要严格时间同步的应用，此假设不成立。
2. **大规模场景的能力边界**：
   - 在 N=128、固定地图/谓词尺寸下成功率仅 42%，大幅退化（尽管部分归因于 GCBF+ 控制器本身在此密度下的安全局限，也与其更大的地图尺寸差异有关）；有效协调大规模智能体需要通信或分布式规划机制。
   - 扩散模型在更大谓词空间上（2×地图）的泛化仍需额外优化。
3. **规范表达范围有限**：
   - 仅支持 MA-STL-A 类型（规范可分解为每个智能体独立公式的合取）与 CaTL+ 团队规范，不支持**联合状态空间上的通用 STL 规范**（如 MA-STL 中需要在同一时间步、由多个智能体共同满足的同步时序关系）。
4. **无形式化保证**：
   - 可达性条件仅通过软引导项 L_ach 促进，并无形式化保证；安全是由底层 GCBF+ 控制器保证的，但静止障碍物存在时 GCBF+ 可能死锁（deadlock），作者在该讨论中亦承认这一点。
5. **关于碰撞与预测**：
   - 计划的接受标准只验证计划层面的 STL 满足性，不提供规划层面的无碰撞形式化保证；安全依赖执行期控制器，而 dense 情形下 GCBF+ 出现明显性能衰减。
6. **对比的局限**：
   - 未能与支持异构任务的其他学习型 STL 规划方法直接对比（因不存在这样的现有方法）；对真实机器人平台仅做了单段演示视频，未有完整的系统化真实环境实验数据统计。
7. **训练信息透明度不足**：论文未报告训练阶段的确切墙钟时间、能耗或训练收敛曲线等资源开销数据。

## 全文总结

DIFF-MA 提出了利用可微的 STL 鲁棒性梯度引导单智能体扩散先验、在去噪过程中合成多智能体计划的范式，以约 1 秒的规划时间实现了异构规范、团队规范、新公式零样本泛化和 32+ 智能体的稳健扩展，同时通过扩散模型的多样性显著降低了路径重叠与碰撞风险。其核心价值在于**将“通用”与“快速”两种原本对立的性质在同一框架内予以统一**。但方法的实际性能仍受制于底层 GCBF+ 控制器的安全极限、规范语言的表达边界，以及对精确模型参数的依赖。
