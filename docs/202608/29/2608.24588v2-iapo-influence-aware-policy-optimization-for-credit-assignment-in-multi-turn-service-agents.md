## 摘要
大语言模型（LLM）智能体越来越多地通过与用户和外部工具的多轮交互来解决长周期任务。在这些场景中，相关的任务信息往往随时间的推移而逐渐展开，而不是在初始提示中完全指定。服务智能体使这一挑战尤为具体：用户可能澄清或修改其目标，而工具响应则为后续决策提供所需信息。因此，仅凭最终奖励无法指示哪些动作有助于解决任务。近期方法依赖于来自其他轨迹或重采样续段的比较证据，或独立构建的步骤级学习信号，来细化信用分配。然而，一次完成的轨迹（rollout）已经记录了信息和错误如何在智能体动作之间流动。我们提出了影响感知策略优化（IAPO），它将每次轨迹表示为可训练智能体动作上的类型化影响依赖图，并以用户和工具的观察作为证据。IAPO 将支持使用和失败使用的结构转化为路由权重，从而重新分配相同的轨迹级优势。使用 Qwen3-4B 和 Qwen3-8B 进行的实验表明，在三个服务智能体基准测试（τ²-Bench、UserBench 和 AgentChangeBench）上，其性能优于多轮强化学习（RL）基线。BFCL-v4 Multi-Turn 进一步表明，这些收益不会损害多轮函数调用的性能。这项工作推进了对多轮用户交互中信用分配的理解，并提供了一种从稀疏结果反馈中训练服务智能体的原则性方法。

## Abstract
Large Language Model (LLM) agents increasingly solve long-horizon tasks through multi-turn interactions with users and external tools. In these settings, relevant task information often unfolds over time rather than being fully specified at the initial prompt. Service agents make this challenge especially concrete: users may clarify or revise their goals, while tool responses provide information needed for subsequent decisions. Thus, a final reward alone cannot indicate which actions contributed to resolving the task. Recent methods rely on comparative evidence from other trajectories or resampled continuations, or on separately constructed step-level learning signals, to refine credit. However, a completed rollout already records how information and errors flow between agent actions. We introduce Influence-Aware Policy Optimization (IAPO), which represents each rollout as a typed influence-dependency graph over trainable agent actions, with user and tool observations serving as evidence. IAPO converts support-use and failed-use structure into routing weights that redistribute the same trajectory-level advantage. Experiments with Qwen3-4B and Qwen3-8B demonstrate superior performance over multi-turn reinforcement learning (RL) baselines across three service-agent benchmarks: ${τ^2}$-Bench, UserBench, and AgentChangeBench. BFCL-v4 Multi-Turn further shows that these gains do not compromise multi-turn function-calling performance. This work advances the understanding of credit assignment in multi-turn user interactions and provides a principled approach to training service agents from sparse outcome feedback.

# IAPO 论文详细总结

## 1. 核心问题与研究动机

- **研究背景**：LLM 智能体已从单轮应答转向多轮交互式任务求解（调用工具、与用户对话、与环境交互）。在多轮服务场景中，任务相关信息往往**逐步展开**（如用户逐步澄清意图、工具调用暴露操作状态），而非在初始提示中一次性给出。
- **核心问题**：在"演化状态信用分配"（Evolving-state credit assignment）设定下，最终奖励无法区分中间动作的贡献。例如，一个早期澄清动作是否正确，只有等到后续用户确认或工具响应后才能判断。GRPO 等轨迹级 RL 方法将相同的组相对优势均匀分配给所有可训练 token，无法区分不同中间动作的贡献。
- **现有方法的不足**：
  - **跨轨迹比较法**（如 GiGPO、树搜索/重置法）：依赖可复现的环境状态或可重置的分支环境，而自由形式的用户-工具对话难以满足；
  - **独立步骤信号法**（如 InfoPO、教师模型、学习型 critic）：需要额外评分通道，可能偏离任务完成度这一核心目标。
- **关键洞察**：一次**已完成的 rollout** 本身就记录了信息与错误在智能体动作之间的流动结构（后续动作消费了先前动作获取的信息，或复用了先前动作产生的错误输出），这种结构可以用于信用分配，且无需额外奖励、反事实续段或跨轨迹比较。

## 2. 方法论：IAPO

### 2.1 总体框架
IAPO 沿用 GRPO 的轨迹级优势计算，但将优势按动作影响**路由（route）**到各 token 上，核心公式为：

\[
A_{i,\ell} = \hat{A}_\tau \cdot w_i
\]

其中 \(\hat{A}_\tau\) 是 GRPO 计算出的轨迹级优势，\(w_i > 0\) 是动作 \(a_i\) 的路由权重，满足长度归一化 \(\sum_i L_i w_i = L\)（\(L_i\) 为动作 token 数）。权重只改变优势在动作间的**分配方式**，不改变其总量与符号。

### 2.2 影响依赖图（Influence-Dependency Graph）
- 每条轨迹构建图 \(G_\tau = (V_\tau, E^+_\tau, E^-_\tau)\)，其中节点为可训练智能体动作，边分为两类：
  - **支持使用边**（\(i \xrightarrow{+} j\)）：动作 \(a_j\) 消费了 \(a_i\) 提供或诱导出的信息（标注类型为 input 或 success_utilization）；
  - **失败使用边**（\(i \xrightarrow{-} j\)）：动作 \(a_j\) 重复了 \(a_i\) 的可观察错误、使用了其无效输出、或因 \(a_i\) 而被迫回退（标注类型为 failed_utilization）。
- 边接受需同时满足三个条件：
  1. **必要性（Necessity）**：\(a_j\) 引用的具体信息单元（实体值、工具返回值、错误追踪）来源于 \(a_i\)，移除该信息则 \(a_j\) 的参数或决策不成立；
  2. **显式绑定（Explicit binding）**：引用信息绑定到 \(a_j\) 的具体元素（意图参数、工具参数、条件分支、错误恢复动作）；
  3. **源优先级（Source priority）**：多个前序动作提供重叠信息时，保留最全面的源；平局取最早者；不重叠信息才引用多源。
- 用户回复解析到引导它的助手动作，工具返回解析到产生它的工具调用；无引导者的用户回合记为直接输入计数 \(u^\text{dir}_i\)。

### 2.3 图特征
\[
\phi^+_i = \log(1 + d^+_i + d^\text{in}_i), \quad
\phi^-_i = \log(1 + e_i(1 + d^-_i + d^\text{in}_i))
\]
- \(d^+_i\)：支持使用出度；\(d^-_i\)：失败使用出度；\(d^\text{in}_i\)：消费的支持证据数（直接用户输入 + 入边数）；\(e_i \in \{0,1\}\) 为错误标记（工具、模式、运行时、规则失败或用户/环境显式拒绝）。

### 2.4 权重标准化
- 特征经长度加权标准化、裁剪（clip 至 \([-c, c]\)）、再归一化（使长度加权均值为 1）：
  \[
  m_i = \frac{\exp(\text{clip}(z_i, -c, c))}{\frac{1}{L}\sum_j L_j \exp(\text{clip}(z_j, -c, c))}, \quad
  z_i = \frac{\phi_i - \bar{\phi}}{\sigma_\phi + \varepsilon}
  \]
- 得到支持权重 \(m^+_i\) 与错误权重 \(m^-_i\)，每个动作内所有 token 共享同一权重。

### 2.5 符号条件路由（Sign-Conditioned Routing）
- **正优势轨迹**（\(\hat{A}_\tau > 0\)）：从支持权重出发，对"有错误但被后续步骤修复"的动作按其超额错误证据 \(\psi^-_i = \phi^-_i - \bar{\phi}^-\) 折减：
  \[
  w^+_i(\beta^+) = \frac{L m^+_i \exp(-\beta^+ \psi^-_i)}{\sum_j L_j m^+_j \exp(-\beta^+ \psi^-_j)}
  \]
  \(\beta^+=0\) 时纯粹按支持路由；\(\beta^+\) 越大，修复错误的步骤获得的信用越少。
- **负优势轨迹**（\(\hat{A}_\tau < 0\)）：保守地将责任集中在错误证据上：\(w^-_i = m^-_i\)（仅在可观察错误后激活，避免错误归因不明确时误伤支持性步骤）。投影支持先验变体作为消融在附录中评估。

### 2.6 理论性质
四条保障（均附证明）：
1. **质量守恒**：\(\sum_i \sum_{\ell \in a_i} A_{i,\ell} = L \hat{A}_\tau\)，不改变轨迹优势总量；
2. **均匀回退**：图特征恒定时退化为均匀分配；
3. **符号保持**：所有权重乘子为正，token 优势符号与轨迹优势一致；
4. **优化接口保持**：保留原奖励、组归一化、提示、工具、采样与优化接口，仅改变 token 级策略梯度估计器。

## 7. 局限性与讨论

### 7.1 方法层面的局限
- **依赖标注器依赖**：IAPO 的训练流程需要一个冻结的强标注器（论文默认 Qwen3-32B，温度 0）来构建影响依赖图。虽然标注器审计表明结果对标注器选择基本稳健（Gemma4-31B 替换后性能差异在 1 pp 以内），但这仍然引入了额外的推理成本与外部模型依赖，且标注质量的上界决定了图结构的质量。
- **信息流动结构的假设**：IAPO 的核心前提是“已完成的 rollout 中记录了动作间的信息依赖与错误传播结构”。这在用户-工具对话场景中成立，但对**无信息性失败轨迹**（例如动作随机、完全没有可识别的信息流动）图可能退化，此时 IAPO 近似退化为均匀路由。
- **无状态环境可迁移性未验证**：对于需要显式重置分支或可复现状态的非对话型 RL 环境（如代码执行沙箱、具身控制），该方法与 GiGPO 类方法的优劣边界未被探讨。

### 7.2 实验层面的局限
- **模型规模受限**：仅验证了 Qwen3-4B/8B，未在更大模型（如 32B/72B）上验证方法的可扩展性。更大的模型通常有更长的轨迹，图的规模与标注负担都会上升。
- **训练域单一**：全部训练数据来自 τ²-Bench 三个域（航空/零售/电信），未评估在更广泛的多域数据集上共同训练时的行为。
- **缺乏对训练不稳定性的报告**：论文未给出训练曲线、优势分布随时间的变化或梯度范数等训练动态指标。
- **标注成本未量化**：虽然提到“计算预算在 Appendix F”，但正文与提取文本中未给出端到端训练所需的具体 GPU 小时数，使该方法的工程落地成本难以精确评估。

## 8. 未来研究方向

1. **图构建的自动化**：用可学习的分层模型替代冻结标注器，或利用弱监督信号自动发现信息依赖，减少对强外部模型的依赖。
2. **扩展到更大规模模型与更长轨迹**：验证在 32B 以上模型、30 轮以上长轨迹中，图规模增大时路由权重的稳定性与收益。
3. **更细粒度的信用分配**：目前的权重在动作内所有 token 间共享，未来可结合 token 级显著性（如注意力权重）进一步细化。
4. **与其他 RL 技术正交组合**：将 IAPO 与束搜索、流程奖励模型、风险敏感 RL 结合，探索叠加收益。
5. **跨环境适配**：将路由思想推广到代码生成、游戏、具身智能等可部分恢复状态的场景，并与重置类方法做系统对比。

## 9. 综合评价

### 9.1 主要贡献
- 提出了一种**不依赖额外奖励信号、不需要环境重置或跨轨迹同状态比较**的新型信用分配机制，解决了演化状态场景下 GRPO 均匀优势分配的核心缺陷；
- 构建了完整的影响依赖图框架，并将图特征以理论上有保障（质量守恒、均匀回退、符号保持）的方式路由到 token 级优势；
- 实验设计严谨，在 3 个服务智能体基准上取得一致且显著的提升，同时通过 BFCL-MT 证明函数调用能力无退化，消融与标注器稳定性审计增强了结论的可信度。

### 9.2 不足与风险
- **外部依赖**：冻结标注器的使用使方法不是完全自包含的，在开源可复现性上低于纯 GRPO；
- **泛化证据尚窄**：域外评估全部集中于服务型对话智能体，方法的普适性仍有待更多任务类型检验；
- **报告完整度**：部分消融仅单次运行，缺少显着性检验，计算预算的具体量化信息不完整。

总体而言，IAPO 提出了一个**概念上简洁、理论上干净、实证上有效**的改进：信息流图是轨迹本身固有的“免费”结构，利用它来分配信用与训练 LLM 智能体的任务高度契合。在 τ²-Bench 上 12.57 pp 的绝对提升（8B，29.61% → 42.18%）极具说服力，且与 GRPO 的受控对比明确指出了改进来源。尽管存在标注器依赖与规模验证限制，该方法为多轮交互式智能体的 RL 训练提供了一个清晰且可复用的新方向，有望成为未来服务智能体 RL 训练的默认选择之一。
