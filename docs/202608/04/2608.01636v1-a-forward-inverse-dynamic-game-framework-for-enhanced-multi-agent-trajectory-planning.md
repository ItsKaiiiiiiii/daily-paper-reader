## 摘要
本文研究非线性动态系统中多智能体轨迹规划的反馈纳什均衡（FBNE）求解问题，其中智能体目标未知且智能体间耦合依赖于状态。尽管动态博弈理论为这类问题提供了原则性框架，但现有方法通常假设智能体完全理性且目标已知，或依赖固定正则化，限制了其捕捉安全关键场景中有界理性和空间变化交互强度的能力。为此，我们提出一种具有状态依赖权重的KL正则化动态博弈，该权重自适应地平衡最优性与行为先验。为从演示行为中推断未知成本参数，我们开发了一个基于上下文感知的逆向博弈模块，该模块基于最大熵逆向强化学习并引入物理信息正则化，确保与前向博弈的结构一致性。我们建立了正则化局部博弈在每次迭代中的良定性，并证明自适应加权函数在有界标称轨迹更新下保持Lipschitz连续性。在协作导航和汇合场景上的数值模拟与多机器人实验验证了所提框架的有效性。

## Abstract
This paper studies feedback Nash equilibrium (FBNE) seeking for multi-agent trajectory planning in nonlinear dynamical systems with unknown agents' objectives and state-dependent inter-agent coupling. While dynamic game theory provides a principled framework for such problems, existing approaches typically assume fully rational agents with known objectives or rely on fixed regularization, limiting their ability to capture bounded rationality and spatially varying interaction intensity in safety-critical settings. To this end, we propose a KL-regularized dynamic game with a state-dependent weight that adaptively balances optimality and behavioral priors. To infer unknown cost parameters from demonstrated behaviors, we develop a context-aware inverse game module based on maximum-entropy inverse reinforcement learning with physics-informed regularization, ensuring structural consistency with the forward game. We establish per-iteration well-posedness of the regularized local game and show that the adaptive weighting function remains Lipschitz continuous under bounded nominal-trajectory updates. Numerical simulations and multi-robot experiments on cooperative navigation and merging scenarios validate the effectiveness of the proposed framework.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在安全攸关的多智能体系统中，如何在高动态、强耦合的物理环境中进行鲁棒的轨迹规划。传统“先预测后规划”（prediction-then-planning）方法忽略智能体间的交互耦合，易产生保守或危险行为；而动态博弈理论虽能显式建模耦合，但现有方法普遍存在两大缺陷：
  1. **假设智能体完全理性且目标已知**——现实中智能体目标（代价函数权重）通常是私有的、未知的，受观测噪声与不可预测行为影响；
  2. **正则化系数固定不变**——如 KLGame 方法采用固定 λi，无法依据空间交互强度动态调整最优性与数据先验之间的平衡，难以刻画有界理性。

- **整体含义**：本文提出一种前向–逆向动态博弈统一框架（forward–inverse dynamic game framework），将博弈论建模与专家示范学习结合，使多智能体在未知目标、状态相关耦合和非线性动力学下仍能获得行为真实、符合安全约束的反馈纳什均衡（FBNE）策略。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：构建“前向博弈求解 + 逆向目标推断”的双层闭环框架：
  - 前向博弈：求解带 KL 正则化的非零和动态博弈，获得反馈纳什均衡策略；
  - 逆向博弈：从专家演示轨迹中学习智能体代价函数权重，为前向博弈提供行为先验。

- **关键技术细节**：

  **(1) 前向博弈——KL 正则化动态博弈（KLGame+）**
  - 代价函数中加入 KL 散度项：`Ji(πi) = Eπ[Σ cit(xt,ut,ωi)] + Σ λi·D_KL(πit ∥ π̃it)`，通过 KL 散度使策略贴近数据驱动的参考策略（行为先验），建模有界理性；
  - **状态依赖自适应权重**：λi 从常数推广为状态依赖函数 `λi(xt) = λi_min + (λi_max − λi_min)·ρi(xt)`，其中 ρi(xt) 由障碍物距离与智能体间距离共同决定的高斯函数，实现“高风险区域增强参考策略约束、低风险区域放松约束”的自适应调控；
  - **迭代线性化求解**：对非线性动力学与代价函数在标称轨迹 ηk 周围做线性-二次近似（LQ 化），将 FBNE 求解转化为递归的耦合线性方程组（Riccati 递归）；
  - **高斯参考策略**：通过拉普拉斯近似将参考策略 π̃it 构造为高斯分布，使 KL 正则化后的最优策略保持高斯闭式形式（均值与协方差可解析计算）。

  **(2) 逆向博弈——最大熵 IRL 与场景感知神经网络**
  - 代价函数建模为“代价基元线性加权”：`cit = ωi⊤ f_i(xt,ut)`，其中基元包含到达目标、防碰撞（对数势垒）、车道边界惩罚和控制能耗；
  - 用**场景感知神经网络** φθi 直接输出代价权重 ωi：GRU 编码轨迹历史，MLP 嵌入矢量化地图，交叉注意力融合主车、邻车与地图信息，Softplus 输出保证权重为正；
  - **训练损失** = 最大熵 IRL 损失（最大化专家轨迹似然）+ 规则惩罚项（对碰撞、越界等物理规则违反施加二次惩罚），保证学习策略的物理可行性和结构一致性。

- **算法流程概述**：
  - 前向求解器（Algorithm 1）：以专家轨迹为初始标称轨迹 → 线性化/二次化系统 → 计算状态依赖 λi(xt) → 调用 KLGame+ 求解器获得高斯反馈策略（均值 μi*，协方差 Σi*）→ 沿策略方向更新标称轨迹 → 迭代至收敛。
  - 逆向求解器（Algorithm 2）：从专家演示集 D 出发，用场景感知网络输出权重 ωi → 计算轨迹奖励 → 用最大熵 IRL 损失 + 规则损失更新网络参数 → 直至收敛，返回估计的代价权重。

- 状态依赖的自适应 λi(xt) 是安全性的关键机制：在 RM 场景中，固定 λ 时存在 1~2 次碰撞，而定全模型实现**零碰撞**；在大规模 20 智能体场景中，自适应 λ 将碰撞从 6~7 次降至 4 次，验证了“高风险区域更强参考策略约束”的有效性；
