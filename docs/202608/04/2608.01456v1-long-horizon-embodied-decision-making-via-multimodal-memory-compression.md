## 摘要
智能体日益被期望不仅作为任务执行者，还作为人类用户的决策者。这种转变要求智能体在长时域内积累证据、解读隐式用户偏好，并在部分观察下比较多个候选方案。在此工作中，我们提出了DunphyBench，一个用于评估智能体在长时域人类中心具身决策上的基准，其中智能体必须穿越多个具身居住环境，并做出与多维人类偏好一致的决策。与通常侧重于程序性规划或即时目标完成的具身推理任务不同，我们的设置要求智能体将多模态、多源输入整合为连贯的知识，以支持跨长时域的复杂推理。评估结果显示，当前智能体与人类表现之间存在显著差距。此外，我们对最先进的VLM驱动智能体的诊断揭示，记忆管理是瓶颈之一，其中原始多模态历史引入的噪声阻碍了决策质量。受此发现启发，我们设计了MeMento，一种偏好条件下的多模态记忆压缩器，它基于用户偏好，利用固定数量的记忆令牌，从长时域历史中选择性地压缩与决策相关的信息。实验表明，与最强基线相比，MeMento帮助VLM驱动智能体将准确率提高了7.18%，同时将记忆使用量减少了85.38%。

## Abstract
Agents are increasingly expected to act not only as task executors, but also as decision-makers on behalf of human users. This shift requires agents to accumulate evidence over long horizons, interpret implicit user preferences, and compare multiple candidates under partial observations. In this work, we propose DunphyBench, a new benchmark for evaluating agents on long-horizon human-centered embodied decision-making, where the agent must navigate through multiple embodied housing environments and make decisions that align with multi-dimensional human preferences. Unlike standard embodied reasoning tasks that often focus on procedural planning or immediate goal completion, our setting requires agents to integrate multimodal, multi-source input into coherent knowledge that supports complex reasoning across long horizon. The evaluation results reveal that there is a substantial gap between current agents and human performance. Furthermore, our diagnosis of state-of-the-art VLM-driven agents reveals that memory management is one of the bottlenecks, where raw multimodal history introduces noise that hinders decision quality. Motivated by this finding, we design MeMento, a preference-conditioned multimodal memory compressor that selectively compresses decision-relevant information from long-horizon history based on user preferences with a fixed set of memory tokens. Experiments show that MeMento helps VLM-driven agents improve accuracy by 7.18%, while reducing memory usage by 85.38% compared to the strongest baseline.

### 2. 方法论

#### 2.1 DunphyBench 基准构建

- **任务设定**：以“房屋选择”为具体实例。每个实例包含 N 条用户偏好（分为 7 个语义类别：房间数量/类型、房间尺寸/面积、窗户/采光、物体存在性、物体数量、空间连通性、材料/装饰），以及 1+3M 个候选环境（1 个黄金环境 + 3M 个干扰项，分易/中/难三档）。
- **环境表示**：基于 ProcTHOR 程序化生成的具身住宅环境，转换为结构化特征向量（全局布局、房间属性、物体清单、空间邻接关系），并定义确定性谓词作为自然语言偏好与环境验证之间的接口。
- **偏好设计**：分离两条独立轨道：
  - **显式轨道**：偏好直接表示为结构化约束（如“至少三间卧室”），映射到可验证谓词。
  - **隐式轨道**：偏好以自然语言人物式陈述呈现（如“我经常为朋友做饭”），要求模型推断底层结构需求。
- **数据生成流水线**：特征提取 → 黄金环境采样 → 偏好生成 → 干扰项构造（按满足率分组）→ 质量控制（保证黄金唯一满足、干扰项不满足、偏好均衡、冗余过滤）。
- **关键统计**：默认配置 N=7、M=19，最大探索步数 1500。

#### 2.2 MeMento 记忆压缩器

- **核心思想**：将长时域多模态历史压缩为一组**固定大小的偏好相关记忆令牌**，以软提示形式注入冻结的 VLM，既保留决策相关信息，又消除噪声干扰。
- **技术细节（四步流程）**：
  1. **偏好编码**：用冻结 VLM 将用户需求转化为关键词，取其文本嵌入池化为单一偏好向量 z̄_r。
  2. **多模态步骤编码**：将每个探索步骤（自我视角图像、地图图像、观察文本、动作文本）编码为步骤表示 e_t，并加上步骤时间戳和所属环境的身份嵌入。
  3. **偏好条件化压缩**：用可学习的查询集 Q₀，通过投影网络注入偏好向量得到 Q_r = Q₀ + φ(z̄_r)。每个环境独立压缩（防止不同候选环境证据混合），通过交叉注意力（查询关注步骤表示）加自注意力获得环境级记忆令牌。
  4. **记忆注入**：将全局记忆令牌经适配器投影到冻结 VLM 的嵌入空间，与当前步骤的提示令牌拼接，作为软提示指导下一步行动预测。

- **两阶段训练**：
  - **阶段一（偏好引导压缩训练）**：训练压缩器用分类头预测步骤级偏好相关性（四类标签：正、负、未知、不相关），并对齐交叉注意力权重与相关性标签。损失函数：L_stage1 = L_rel + λL_attn。
  - **阶段二（对齐训练）**：训练压缩器和投影适配器，使压缩记忆可被冻结 VLM 读取，通过偏好相关问答任务优化答案令牌上的语言建模损失。VLM 保持冻结，梯度只回传到可训练部分。

- **推理**：丢弃预测头，仅保留压缩与注入流程。

### 6. 主要结论与发现

- **人类与智能体差距显著**：最佳智能体准确率 58.3%，人类达 83.3%，差距约 25 个百分点。
- **性能随任务复杂度急剧下降**：从 Easy 到 Hard，显式准确率从 49.1% 降至 25.0%，隐式从 26.7% 降至 16.1%；干扰项从 M=4 增至 M=19 时准确率从 42.6% 降至 15.3%。
- **隐式偏好推理是关键瓶颈**：所有配置下隐式性能显著低于显式（如 Easy 档 26.7% vs. 49.1%），揭示模型难以推断未明说的用户意图。
- **记忆对性能贡献显著，但存在“非单调”特征**：添加记忆可将准确率提升近一倍（如 GPT-5.4 从 25% → 58.3%），但历史窗口过长（超过约 15 轮）反而使性能下降——**原始多模态历史引入噪声，损害决策质量**。
- **工具（Sketchpad/Retriever）增益有限且不稳定**：无法独立解决长时域挑战。
- **探索效率与决策质量难以兼顾**：部分智能体过早停止探索，证据收集不足；人类在两者间平衡最佳。
- **MeMento 的有效性**：准确率提升 7.18%（相对提升 15.74%），记忆使用量减少 85.38%（仅 ~3.8K 令牌 vs. 最强基线 ~26K），并在记忆探针任务中取得最佳非 oracle F1（0.719，距离 oracle 上界仅 0.097），在 Web 任务上也展现泛化能力（83% vs. 最强基线 72%）。

### 7. 优点

1. **基准设计新颖且富有现实意义**：首次系统性地将“长时域 + 多环境 + 隐式偏好”纳入具身决策评测，更贴近真实人类中心决策场景。
2. **偏好双轨设计**：显式/隐式轨道分离，有效隔离并量化了“约束检查”与“偏好推断”两种不同能力，诊断价值高。
3. **数据可控且可自动验证**：基于结构化特征和确定性谓词，保证了偏好的可验证性，避免了注释歧义；干扰项按满足率分层，难度可控。
4. **记忆瓶颈的发现具有启发性**：通过系统的消融与预算分析，清晰论证了“记忆缩放非单调”这一核心洞见，为社区指明关键研究方向。
5. **MeMento 方法设计精巧**：偏好条件化查询、环境独立压缩、两阶段训练（相关性引导 + VLM 对齐）环环相扣；固定令牌数提供了可控的记忆预算。
6. **记忆探针实验设计巧妙**：通过事后问答任务直接评估记忆保留质量，为记忆系统评估提供了可借鉴的范式。
7. **领域迁移验证增强了结论的普适性**：在 Web Agent 任务上的表现证明方法并非只能用于具身场景。
