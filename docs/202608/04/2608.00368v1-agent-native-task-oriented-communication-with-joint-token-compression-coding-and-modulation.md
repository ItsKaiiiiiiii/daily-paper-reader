## 摘要
随着大型基础模型赋能智能体在各行各业普及，并成为智能系统中的核心角色，在后香农时代，对通信范式进行根本性反思，转向AI原生、以智能体为中心的设计已不可避免。一个关键转变是，令牌作为大型语言模型（LLMs）原生处理的最小语义单元，应取代比特成为通信的基本单元。然而，LLMs领域的现有工作假设通过高速有线链路进行无损令牌传输，在很大程度上忽略了无线环境中的空口开销和信道失真，缺乏针对无线令牌通信系统的原生设计。为弥合这一差距，我们提出了一种创新的令牌发射器-接收器架构设计，以促进面向任务的令牌传输。具体而言，我们提出了JTCM（联合令牌编码与调制），这是一种AI原生的语义通信框架，它联合优化令牌表示、信道编码和调制，直接最大化下游任务性能。相应地，我们提出了一种两阶段训练方案。在第一阶段，预训练令牌编码器-解码器对，以实现语义保持的压缩和重建。在第二阶段，在特定下游任务下，与多模态基础模型进行端到端微调，以实现任务感知优化。大量实验表明，在带宽受限和信噪比受限的无线信道中，与最先进的基线相比，JTCM显著减少了传输开销，同时提高了任务准确性和鲁棒性。

## Abstract
As large foundation models empower agents to become pervasive across industries and emerge as central actors in intelligent systems, a fundamental rethinking of communication paradigms toward AI-native, agent-centric designs in the post-Shannon era becomes inevitable. One essential shift is that tokens, which are the minimal semantic units natively processed by large language models (LLMs), should replace bits as the fundamental unit of communication. However, existing works in the LLMs field assume lossless token transmission over high-speed wired links and largely neglect the air-interface overhead and channel distortions inherent in wireless environments, lacking a native design for wireless token communication systems. To bridge this gap, we propose an innovative design for a token transmitter-receiver architecture that facilitates task-oriented token transmission. Specifically, we propose JTCM (Joint Token Coding and Modulation), an AI-native semantic communication framework that jointly optimizes token representation, channel coding, and modulation to maximize downstream task performance directly. Correspondingly, we propose a two-stage training scheme. In the first stage, the token encoder-decoder pair is pre-trained to enable semantic-preserving compression and reconstruction. In the second stage, it is fine-tuned end-to-end with a multi-modal foundation model under specific downstream tasks to achieve task-aware optimization. Extensive experiments demonstrate that JTCM significantly reduces transmission overhead while enhancing task accuracy and robustness compared to state-of-the-art baselines in bandwidth- and SNR-constrained wireless channels.

## 2. 方法论：核心思想、技术与算法流程

### 2.1 系统架构（Token发射器-接收器）

- **Token发射器**：
  - 使用**冻结的预训练图像编码器**（对比学习训练）将输入图像映射为视觉令牌序列 `V ∈ R^{N×d}`；
  - 将**任务意图提示**（task intention prompt）前置拼接形成联合输入 `Zin = [P_intention, V]`，该提示作为动态前缀，条件化后续压缩与调制过程；
  - JTCM编码器 `f_θ` 将 `Zin` 映射为复数符号序列 `s ∈ C^L`（实值向量长度2L再整形为L个复数符号），并进行平均功率归一化。
- **Token接收器**：
  - JTCM解码器 `g_φ` 将受损符号 `ŝ` 映射回重建的视觉令牌序列 `V̂ ∈ R^{N×d}`；
  - 将任务描述的文本令牌嵌入 `P_task` 与重建视觉令牌拼接，输入经**LoRA微调的LLM骨干网络**；
  - 支持两种输出策略：保留原语言建模头生成自由文本，或替换为任务专用头（如分类器）以适配结构化任务。

### 2.2 JTCM编解码模块设计

- 基于**对称的Mixture-of-Experts（MoE）Transformer**架构，MoE层替代标准FFN，每个令牌仅激活top-k专家；
- 引入**SNR感知门控路由**：路由器以瞬时信道SNR γ为输入输出门控权重 `w = Gate(γ)`，使模型无需重训即可适配不同散射环境和宽SNR范围；
- 发射器在序列末尾附加**可学习CLS令牌**用于全局语义聚合，编解码器均使用**RoPE旋转位置编码**；
- 编码器输出CLS令牌经线性投影得到2L维实向量，再整形为L个复数符号（`s_l = u_{2l−1} + j·u_{2l}`）；
- 解码器将受损复数符号的实部虚部拼接、投影回令牌空间，再经MoE解码器重建令牌序列。

### 2.3 两阶段训练方案

- **第一阶段：预训练（语义保持的令牌压缩/重建）**：
  - 原始令牌序列与重建令牌序列分别与意图提示拼接，输入同一个冻结LLM骨干；
  - 选取**中间若干层作为语义评估（SE）层**，对每层隐藏状态做均值池化得到全局语义向量；
  - 计算**语义余弦相似度（SeCS）**并加权求和为语义损失：`L_sem = Σ ω_k(1 − SeCS^(k))`；
  - 无线信道建模为**可微代理**（Sionna/MIMO-OFDM），噪声在反向传播中从计算图分离以保证梯度稳定。
- **第二阶段：端到端微调（任务感知优化）**：
  - 对LLM使用**LoRA（低秩适配）**高效微调（仅训练query/value投影的适配器模块）；
  - 计算教师强制的**标准交叉熵损失**，梯度通过整个网络反向传播，联合优化令牌压缩、传输与任务执行（Θ_LoRA与Θ_JTCM同时更新）；
  - 重建令牌 `V̂` 和任务描述提示 `P_task` 共同输入LoRA增强的LLM进行自回归生成。

## 6. 主要结论与发现

- **压缩效率**：JTCM的传输开销仅为原始图像传输的约0.52%，显著优于JPEG（10.90%）、DeepJSCC（2.14%）和文本描述方案（0.76%）；
- **任务精度**：在所有SNR水平上，JTCM在两个数据集上的任务精度均优于所有基线和SOTA方法，实现直接最大化下游任务性能；
- **鲁棒性**：在高达80%符号丢失的情况下，JTCM仍保持较高任务精度；JPEG逐符号退化近乎线性，DeepJSCC在符号丢失下发生严重性能崩溃；
- **关键洞察**：DeepJSCC等面向图像重建的方案仅在低SNR区有相对优势，而通过文本传递视觉推理任务的信息容量不足，验证了以令牌为通信单元、以任务为导向的范式优越性。

## 7. 方法亮点

- **AI原生设计**：以令牌为通信基本单元，与LLM的表示空间天然对齐，多模态输入自然融合，无需架构重构即可支持多任务；
- **真正的端到端联合优化**：从令牌调制、信道传输到任务执行全程可微，直接以任务目标驱动而非中间保真度指标；
- **SNR自适应MoE路由**：门控网络以信道状态为输入动态选择专家，实现无需重训的全SNR范围自适应，兼具鲁棒性与计算效率；
- **两阶段训练策略**：先语义预训练（稳定收敛）再任务微调（任务对齐），解决端到端直接训练的收敛困难；
- **轻量化部署**：发射端保持轻量（冻结图像编码器），接收端采用LoRA高效微调，适配资源受限智能体场景；
- **真实信道评估**：采用Sionna射线追踪的城市信道模型，比简单的AWGN/衰落假设更具实用性。
