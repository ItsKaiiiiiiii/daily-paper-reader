## 摘要
通信受限的分布式多智能体系统中的协作任务调度具有挑战性，因为每个智能体必须在满足复杂实际约束的同时，根据部分且动态的观测做出决策。现有启发式方法依赖于手工设计的投标规则和重复共识，而许多基于学习的方法假设全局观测，缺乏基于显式通信的协调。为解决这些局限性，本文提出了一种用于分布式多机器人任务分配（MRTA）的神经调度框架，由多解码器图注意力模型（MDGAM）策略模型和无评论家的组相对多智能体策略梯度（GRMAPG）训练算法组成。MDGAM使用扩展的图注意力机制联合更新节点和边特征，并采用多个解码器生成任务选择决策和通信消息。GRMAPG从等价任务规划实例中构建组相对优势，以取代传统MARL算法中使用的评论家网络，从而降低训练难度并提高收敛性能。在不同问题规模和通信范围下的实验表明，所提方法在任务完成性能上优于现有启发式和基于学习的方法，同时消融、复杂性和泛化测试进一步验证了所提出的创新点。

## Abstract
Cooperative task scheduling in communication-constrained distributed multi-agent systems is challenging because each agent must make decisions from partial and dynamic observations while satisfying complex practical constraints. Existing heuristics rely on handcrafted bidding rules and repeated consensus, whereas many learning-based methods assume global observations and lack explicit communication-based coordination. To address these limitations, this paper proposes a neural scheduling framework for distributed multi-robot task allocation (MRTA), consisting of a multi-decoder graph attention model (MDGAM) policy model and a critic-free group relative multi-agent policy gradient (GRMAPG) training algorithm. MDGAM uses an extended graph attention mechanism to jointly update node and edge features, and employs multiple decoders to generate task-selection decisions and communication messages. GRMAPG constructs group-relative advantages from equivalent task-planning instances to replace the critic network used in conventional MARL algorithms, thereby reducing training difficulty and improving convergence performance. Experiments under different problem scales and communication ranges show that the proposed method improves task-completion performance over existing heuristic and learning-based methods, while ablation, complexity, and generalization tests further validate the proposed innovations.

- **研究背景**：分布式多智能体系统（机器人、无人机、车辆等）在智能交通、物联网、应急响应等场景中广泛部署，需要协作完成空间分布的任务。多机器人任务分配（MRTA）本质是组合优化问题，相关于 MVRP，一般 NP-hard。

- **现有方法局限**：
  - 启发式方法（CBBA、PI-maxAss、EEPI 等）依赖手工设计的投标或性能影响函数，需要反复共识和重规划，通信与计算开销大。

- **研究意义**：本文旨在设计一种可扩展的神经调度框架，使智能体在部分可观测、通信受限的条件下，通过显式通信协作与本地规划，最大化总完成任务数。

## 2. 方法论

### 2.1 问题建模
- 将分布式任务规划过程建模为 **Dec-POMDP**（去中心化部分可观测马尔可夫决策过程）。
- 全局目标函数为最大化所有智能体完成的任务总数：
  - `max Σ_m |σ_m|`
  - 约束包括：任务时间窗、智能体能力匹配、任务无冲突、最晚返回时间。
- 决策过程为事件触发的异步过程：智能体到达并完成当前任务后才触发新的任务选择；每个决策事件中，智能体通过与当前通信连通分量内的邻居交换信息获得局部观测。

### 2.2 MDGAM 策略网络架构
- **输入**：图结构局部观测，节点包括当前智能体、其仓库、候选任务、可达邻居智能体；边表示距离等成对关系。
- **扩展图注意力机制**：
  - **Node-Node Attention**：聚合节点间上下文信息。
  - **Edge-Node Attention**：用边表示作为 query，对其两个端点做带方向编码（PE）的注意力，更新边特征。
  - **Node-Edge Attention**：将边信息传播回节点表示。
  - 通过这一块机制，节点和边特征双向更新，支持非欧氏或不对称代价。
- **编码器**：类型相关初始嵌入 → 多层编码器（L=4）→ 残差 + 层归一化 + 前馈网络，得到最终节点/边嵌入。
- **任务解码器**：以当前智能体嵌入为初始上下文，通过若干 MHA 层和单头注意力打分，输出各候选节点的选择概率；不可行节点通过 mask 屏蔽。训练时采样，测试时贪心解码。
- **通信解码器**：与任务解码器结构类似，但输出连续的消息向量（维度 dcom=128），供后续可达智能体在局部观测中使用。

### 2.3 GRMAPG 训练算法
- 核心思想：**无评论家的组相对策略梯度**。
- 对每个问题实例 g，通过等价变换（坐标旋转、任务类型与能力交换、时间与速度同步缩放等）构造 K 个等价实例组成组 `G(g)`。
- 对组内每个实例采样轨迹，得到奖励 `R_k`。
- 使用留一法（leave-one-out）计算基线：
  - `b_k = (1/(K-1)) Σ_{j≠k} R_j`
  - 组相对优势 `A_k = R_k - b_k`
- 梯度估计：
  - `∇_θ L ≈ (1/K) Σ_k A_k ∇_θ log P_θ(σ_k|g_k)`
- 优点：
  - 不引入额外评论家网络，减少可训练参数量；
  - 直接优化终端奖励，避免手工步进奖励分解；
  - 在保留梯度无偏性的同时降低方差，改善收敛性。
