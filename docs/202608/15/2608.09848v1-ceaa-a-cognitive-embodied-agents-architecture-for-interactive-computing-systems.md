## 摘要
在实时交互虚拟环境中开发具备认知能力的具身智能虚拟代理（IVA）即便在当今技术进步的情况下，仍是一项挑战。现有架构往往要么专注于实现受商业游戏引擎限制的低级反应控制系统，要么专注于在虚拟世界中难以实现的高级推理模型表示。本文基于这一理念，提出了一种用于部署具身IVA的模块化认知架构。该架构建立在既有框架之上，如感知-思考-行动范式和信念-愿望-意图认知模型等，旨在提供一个可复用的、面向实现的框架，作为在交互式3D计算系统中部署IVA“大脑”的模板。所提出的架构通过提供一个模块化、面向实现的框架，用于部署具备认知能力的具身IVA，并弥合了高层智能体推理模型与实时具身执行之间的鸿沟，从而在复杂的交互式虚拟环境中实现可扩展、自适应且可解释的智能体。

## Abstract
The development of embodied Intelligent Virtual Agents (IVAs) that have cognitive capabilities in real-time interactive virtual environments remains a challenge, even with today's advancements in technology. Existing architectures are often focused on either the implementation of low-level reactive control systems that are constrained by commercial game engines, or high-level representations of reasoning models that can be difficult to implement in virtual worlds. This paper builds on that notion and proposes a modular cognitive architecture for deploying embodied IVAs. This architecture builds on existing, pre-established frameworks such as the Sense-Think-Act paradigm and the Belief-Desire-Intention cognitive model, among others, and aims to provide a reusable implementation-oriented framework as a template for deploying IVA "brains" in interactive 3D computing systems. The proposed architecture contributes by providing a modular, implementation-oriented framework for the deployment of embodied, cognitive-capable IVAs and bridges the gap between high-level agent reasoning models with real-time embodied execution, for scalable, adaptive, and explainable agents in complex interactive virtual environments.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在实时交互式三维虚拟环境中，部署具有认知能力的具身智能虚拟代理（IVA）仍面临重大挑战。现有架构呈现两极分化：
  - 一类是**底层反应式控制**（如状态机、行为树、规则系统），它们与商业游戏引擎（Unity、Unreal）紧密耦合，运行效率高，但缺乏高层推理、适应性、可解释性和个性化能力；
  - 另一类是**高层认知模型**（如 BDI、SOAR、ACT-R），它们提供了丰富的推理和记忆理论基础，但往往难以集成到实时 3D 环境中，实现复杂度高。
  - 这两者之间存在明显的“鸿沟”，导致缺乏一种既能支持高层认知推理、又能满足实时具身执行需求的、面向实现的统一架构。

- **整体含义**：本文提出 **CEAA（Cognitive Embodied Agents Architecture）**，作为部署具身 IVA“大脑”的模块化、可复用、面向实现的架构模板。它融合多个既有框架（Sense-Think-Act、BDI、黑板模型、记忆处理等），旨在弥合高层智能体推理与实时具身执行之间的差距，为复杂交互式虚拟环境（VR、Metaverse、严肃游戏、CPSS 等）提供可扩展、自适应、可解释的智能体开发基础。

## 2. 提出的方法论：核心思想、关键技术细节、算法流程

- **总体思想**：CEAA 扩展了经典的感–思–行（Sense-Think-Act）范式，将 BDI 认知模型整合其中，并显式加入共享知识表示、记忆管理、规划、行为映射等模块，从而将认知状态、推理、规划与具身动作明确分离。

- **三层架构**：
  1. **用户与环境层（User & Environment Layer）**：包含用户、代理以及环境中的虚拟对象和事件；
  2. **知识层（Knowledge Layer）**：维护环境状态与事件日志的共享结构化表示，基于黑板（Blackboard）架构；
  3. **代理层（Agent Layer）**：负责推理、决策与动作执行，实现类似人类的推理行为。

- **十二个互联组件**：
  - **Environment**：外部虚拟世界，产生事件但不进行推理；
  - **Knowledge Base**：共享黑板，集中记录环境事件和状态，供多个代理协作访问；
  - **Sense**：选择性感知组件，基于代理的兴趣（角色、信念、欲望、意图等）从黑板上筛选相关事件，防止过载；可结合规则过滤或“喧哗模型”（pandemonium）算法；
  - **Memory**：存储代理的过往经验（情景记忆）和语义知识（事实、概念、用户模型），并维护当前世界理解，支持基于相似性、上下文匹配、案例推理等检索算法；
  - **Memory Processor**：与 Memory 协作管理经验，检索历史行为并形成新知识；
  - **Think**：中央认知协调器，负责整合记忆、调用推理器和规划器，决定合适行动；本身不实现具体推理算法，而是编排信息流；
  - **Cognitive Construct**：包含 Beliefs（信念）、Desires（愿望）、Intentions（意图）三个子组件，构成代理的内心状态，支持符号、概率或加权置信度表示；
  - **Reasoner**：基于认知结构（BDI）进行推断，评估欲望、选择意图、处理意图修订，可运用规则推理、逻辑推理或约束满足算法；
  - **Planner**：将 BDI 结构转化为有序或部分有序的抽象动作序列；
  - **Act**：从 Think 接收决定，与 Behavior Mapper 协作，最终在环境中执行动画、语音、导航等动作，需满足实时性能约束；
  - **Behavior Mapper**：将抽象计划映射为具体可执行行为（动画选择、对话动作、手势变体等）；
  - **Agent Capabilities**：代理具身能力数据库（动画、表情、动作、语音、注视等），支持搜索算法供 Behavior Mapper 查询。

- **算法/机制**：文中提及可使用状态机、规则系统、案例推理、搜索算法、约束满足、事件驱动发布-订阅等实现各组件，但未给出严格数学公式或伪代码，整体属于架构设计层面的方法论。

## 3. 实验设计：数据集/场景、基准、对比方法

## 6. 主要结论与发现

- CEAA 能够作为实现导向的“大脑”模板，支持具身 IVA 在实时交互三维环境中运行，实现感知、记忆、推理、规划和具身动作的分离与协同。
- 原型系统（虚拟博物馆教学代理）在两个版本（桌面 3D 和 VR）中都显著促进了知识获取：前后测成绩均有统计显著提升；两组之间的学习效果差异不显著，说明同一代理支持的指导设计在两种模式下同样有效。
- 技术接受度调查显示，参与者认为系统易用、有用，并愿意在未来使用；VR 组在努力期望和行为意向的中位数上略高，绩效期望和使用态度两组相近。
- 焦点小组结果支持 VR 体验带来互动性、沉浸感、参与感和信息保持优势。
- 总体结论：CEAA 弥合了高层认知模型与实时具身执行之间的鸿沟，提供了一种可复用、模块化、可解释的架构，但仍需进一步技术评估。
