## 摘要
基于大语言模型的多智能体系统通常以文本形式进行通信，即使用离散词元。然而，文本引入了离散瓶颈。将发送方的连续隐藏状态转换为离散词元会丢弃仅凭词元身份无法捕获的信息。近期工作提出了潜在通信作为替代方案，即智能体直接传输隐藏表示，而不将其转换为文本。然而，现有的潜在通信方法要么跨Transformer逐层注入工作记忆，要么需要训练投影器从而限制了可移植性。我们提出StateBridge，一种免训练的潜在通信方法，通过闭式正交变换将发送方的最后一层隐藏状态对齐到接收方的输入空间。轻量级范数校准和词汇锚定确保与预训练输入分布的兼容性。对齐后的状态作为连续前缀添加到接收方智能体的输入之前。我们在数学推理、代码生成和问答任务上，使用来自两个系列的四个模型对StateBridge进行评估。StateBridge在26个模型-任务组合中的22个上取得最佳或并列最佳分数，持续优于最强基线。

## Abstract
Large language model based multi-agent systems usually communicate in text, i.e., using discrete tokens. However, text introduces a discrete bottleneck. Converting the sender's continuous hidden states into discrete tokens discards information that token identities alone cannot capture. Recent work proposes latent communication as an alternative, where agents transmit hidden representations directly without converting them to text. However, existing latent methods either inject working memory layer by layer across the transformers, or require trained projectors that limit portability. We propose StateBridge, a training-free latent communication approach that aligns the sender's final-layer hidden states to the receiver's input space via a closed-form orthogonal transformation. Lightweight norm calibration and vocabulary anchoring ensure compatibility with the pretrained input distribution. The aligned states are prepended to the input of the receiver agent as a continuous prefix. We evaluate StateBridge on math reasoning, code generation, and question answering with four models from two families. StateBridge achieves the best or tied-best score on 22 out of 26 model-task pairs, consistently outperforming the strongest baseline.

# StateBridge 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **文本通信的离散瓶颈**：基于 LLM 的多智能体（MA）系统通常通过自然语言（离散 token）通信。发送方需将连续的隐藏状态压缩为 token，这一过程会丢弃 token 身份无法捕获的连续信息，导致信息损失，进而损害智能体间的协调与协作效果。
- **现有潜在通信方案的不足**：近年提出的潜在通信（latent communication）直接传输隐藏表示，但已有方法存在两类缺陷：
  - KV-cache 转移方法（如 LatentMAS、Cache-to-Cache）需跨 Transformer 各层注入工作记忆，传输的是内部处理状态而非完整消息的紧凑表示，且对模型架构敏感；
  - 基于嵌入的方法（如 Interlat、ThoughtComm）依赖训练好的投影器（projector），可移植性差，更换模型或任务需重新训练。
- **核心研究问题**：能否仅通过对齐（alignment）解决最终层隐藏状态与输入嵌入空间之间的表示失配，从而在不训练、不修改架构的前提下，实现开箱即用 LLM 智能体之间的高效潜在通信？
- **答案**：论文提出 StateBridge，一种免训练的通信接口，通过闭式正交变换将发送方最终层隐藏状态对齐到接收方输入嵌入空间，并在多任务上验证了其有效性和跨模型适用性。

## 2. 方法论

### 2.1 核心思想

- 潜在通信要有效，传输的状态必须同时满足两个条件：**信息丰富**（保留发送方隐藏状态的几何关系）和**兼容接收方**（与接收方预训练输入嵌入空间对齐）。
- StateBridge 在发送方与接收方之间构建一个“对齐接口”，将消息隐藏状态转换为可被接收方直接读取的连续前缀，而不是离散文本或跨层注入的 KV 状态。

### 2.2 关键技术细节

1. **消息提取**：
   - 仅保留生成消息的最后 K 个 token 的最终层隐藏状态，记为 S ∈ ℝ^{K×d}。
   - 从共享的 token 嵌入矩阵 W_emb 中取出这些 token 对应的嵌入，作为参考嵌入 R（用于对齐目标）。
   - 对带中间推理（如 Qwen3 的 think 段）的模型，丢弃推理段隐藏状态，只保留真正传给接收方的消息段。

2. **对齐接口（三步骤）**：
   - **Procrustes 对齐**：
     - 对 S 和 R 分别进行中心化（centering），再白化（whitening），消除全局偏移和各主方向方差差异；
     - 求解正交 Procrustes 问题，即在正交约束下寻找旋转矩阵 Q*，使白化后的发送方状态尽可能接近白化后的参考嵌入；解为闭式 SVD 解 Q* = UVᵀ；
     - 逆向重建参考嵌入的尺度与位置，得到初步对齐结果 S̃。
     - 正交旋转保持白化空间中两两距离与夹角，从而保留语义几何结构。
   - **范数校准**：将每个对齐向量缩放到词嵌入的平均 ℓ2 范数，避免最终层隐藏状态范数过大（如 Qwen3-4B 上约为输入嵌入的 140 倍）主导注意力分数。
   - **词汇锚定**：将每个校准向量按余弦相似度向最近的词嵌入方向移动一个小比例 α，使其靠近预训练阶段见过的输入嵌入区域，同时保持连续性、不硬截断为离散 token。

3. **前缀注入**：
   - 将最终对齐前缀 S̄ 直接拼接到接收方 prompt 的嵌入序列之前，位置编码按顺序生成，接收方无需任何架构或注意力掩码修改。

### 2.3 公式与算法（文字说明）

- 中心化：S_c = S − 行均值，R_c = R − 行均值。
- 白化：用协方差矩阵的逆平方根缩放主方向。
- 正交 Procrustes：min ||S_w Q − R_w||²_F，约束 QᵀQ = I，最优解为 S_wᵀR_w 的 SVD 中的 U Vᵀ。
- 范数校准：ŝᵢ = s̃ᵢ · (n̄ / ||s̃ᵢ||)。
- 词汇锚定：s̄ᵢ = (1−α)·ŝᵢ + α·W_emb[v*]，v* 为最近词嵌入（余弦相似度）。
- 计算复杂度：对齐过程为 O(d³) + O(KVd)，远低于一次自回归生成 O(TLd²)；空间上只需存储 O(Kd) 的最终层隐藏状态，远小于 KV-cache 方法的 O(TLd)。

## 6. 主要结论与发现

- StateBridge 在 26 个模型–任务对中的 **22 个**上取得最佳或并列最佳分数，并在全部 4 个模型设置中取得平均分最高，较最强基线提升 2.4–2.9 个百分点。
- **跨模型适应性显著优于 KV-cache 方法**：OLMo3-7B-Think 上 LatentMAS 平均分仅 55.1%，远低于 TextMAS，而 StateBridge 达到 76.7%，说明只作用于输入嵌入层比逐层注入更通用。
- **在更具挑战性的任务上增益更大**：如 GPQA（最高 +7.0）、AIME24（+6.6）、MedQA、代码生成等，符合“文本交接更易丢失信息”的假设。
- 消融表明：**正交 Procrustes 对齐（几何保持）贡献最大**，替换为 Ridge 回归后平均分下降 7.5；范数校准和词汇锚定分别贡献 2.9 和 2.2；随机噪声前缀几乎无效（48.8%），排除“仅凭额外连续向量有效”的干扰。
- 案例研究显示：对齐前缀携带超出可见后缀 token 的语义信息（如恢复出“koilonychia”等未出现在后缀中的术语），证明连续通信确实比文本传递更多信息。

## 7. 优点

- **免训练、即插即用**：无需训练 projection、无需微调、无需修改模型架构，可直接用于现有开源 LLM。
- **理论支撑扎实**：附录给出文本通信的信息论下界、Ridge 对齐的跨度限制证明、Procrustes 等距保持证明，解释了方法有效性的几何原因。
- **计算与存储开销低**：对齐开销 O(d³)+O(KVd)，远低于一次生成；内存仅 O(Kd)，显著优于 KV-cache 方法。
- **跨模型普适性强**：仅在输入嵌入层操作，不依赖特定层结构，在 Qwen3 和 OLMo3 上均有效。
- **组件可解释、可调**：Procrustes、范数校准、词汇锚定各有明确作用，超参数（K、α）敏感性分析清晰，默认值通用性好。
- **实验验证全面**：多任务、多模型、多基线、多消融，结论一致性强。

## 8. 不足与局限

- **同构模型假设**：方法要求所有智能体共享同一模型（至少共享词汇表与维度），尚未扩展到异构模型场景。
- **前缀长度固定**：K 设为固定值 64；K 过小失去信息、过大则因全局旋转拟合不同质点的群体而降低对齐质量，缺乏自适应机制。
- **部分任务性能回退**：在 Qwen3 的 GSM8K 上低于最佳基线，论文推测与精确匹配评估下连续前缀影响输出格式有关，但未提供深入解决方案。
- **潜在表征可解释性不足**：连续前缀无法像自然语言一样被人类直接阅读和检验，实际部署中可能难以调试或审计。
- **评估范围有限**：任务类型虽多，但均为英文、单轮、短上下文设置；未测试长对话、多模态或更多模型家族；计算资源细节披露不足。
- **超参数仍需人工设定**：虽然默认值在多个基准上表现稳定，但 K 与 α 的选择缺少理论指导或自动选择机制。
