## 摘要
本文在模型预测控制（MPC）框架下研究了约束异构多智能体系统的分布式最优一致性控制问题。在所提出的MPC框架中，控制输入序列和动态可行的共识平衡点被同时优化以提升一致性性能，从而在每个预测时刻产生一个耦合的约束优化问题。开发了一种分布式原始-对偶算法来求解由此产生的优化问题，并推导了局部可验证的条件以保证其收敛性。此外，为所提出的MPC框架建立了充分的终端条件，以保证闭环异构多智能体系统的递归可行性和渐近一致性。最后，数值仿真验证了所提方法的有效性。

## Abstract
This paper investigates the distributed optimal consensus control problem of constrained heterogeneous multi-agent systems within a model predictive control (MPC) scheme. Both the control input sequence and the dynamically feasible consensus equilibrium are optimized simultaneously within the proposed MPC framework to improve consensus performance, yielding a coupled constrained optimization problem at each prediction time. A distributed primal--dual algorithm is developed to solve the resulting optimization problem, and locally verifiable conditions are derived to guarantee its convergence. Furthermore, sufficient terminal conditions are established for the proposed MPC framework to guarantee the recursive feasibility and asymptotic consensus of the closed-loop heterogeneous multi-agent systems. Finally, numerical simulations verify the effectiveness of the proposed approach.

## 1. 核心问题与研究动机

- **研究对象**：约束异构多智能体系统（即各智能体的动态矩阵 \(A_i, B_i\) 可不同），状态与输入均受凸约束。
- **问题**：分布式最优一致性控制（optimal consensus control），即让异构智能体在满足自身约束的前提下，收敛到一个“动态可行”的共识平衡点，同时优化整体控制性能。
- **现有方法不足**：
  - 经典一致性控制仅保证“达成一致”，未指定目标状态或最优性；
  - 线性二次最优一致通常预设共识平衡点（如原点），限制了优化空间；
  - 现有MPC方法多将目标或平衡点固定，或仅以软惩罚促使局部目标接近，不能保证其构成共同且可维持的可行平衡；
  - 最新工作[28]引入硬共识约束并联合优化目标，但未保证目标对异构智能体动态可行，递归可行性与渐近一致性无法推广到一般异构线性系统。
- **核心目标**：在MPC框架中同时优化控制输入序列与共识平衡点，并保证：
  1. 优化出的共识平衡点必须落于每个智能体的可行平衡集 \(E_i\)（动态可维持）；
  2. 求解由局部耦合与全局共识耦合构成的优化问题；
  3. 保证闭环递归可行性与渐近一致性。

## 2. 方法论与关键技术

### 2.1 MPC问题建模

- 每个智能体采用离散时间线性动态：
  \[
  x_i(k+1)=A_i x_i(k)+B_i u_i(k), \quad x_i\in\mathcal X_i,\ u_i\in\mathcal U_i
  \]
- 定义可行平衡集：
  \[
  E_i=\{(z_i,u_{ei})\ |\ z_i\in\mathcal X_i,\ u_{ei}\in\mathcal U_i,\ z_i=A_iz_i+B_iu_{ei}\}
  \]
- 由于 \(B_i\) 列满秩，平衡输入可写成 \(u_{ei}=D_iz_i\)，其中 \(D_i=(B_i^\top B_i)^{-1}B_i^\top(I_n-A_i)\)，于是成本函数可视为 \((u_i,z_i)\) 的函数。

- 构建 **Problem 1**：在每个预测时刻 \(t_k\)，求解
  \[
  \min_{U(t_k),Z(t_k)}\sum_{i=1}^N J_i(u_i(t_k),z_i(t_k))
  \]
  约束包括：
  - 系统动态（4a）；
  - 共识约束 \(\tilde L Z(t_k)=0\)（全局耦合）；
  - 局部可行平衡约束 \(z_i(t_k)\in\tilde{\mathcal Z}_i\)；
  - 状态/输入约束与终端约束 \(x_i(T|t_k)\in\mathcal X_{iT}\)。

- 与已有公式的关键差异：
  1. \(z_i(t_k)\) 被显式限定在每个智能体的可行平衡集内，保证共识平衡点对异构动态可行；
  2. 成本函数加入 \(\|u_i(l|t_k)-u_{ei}(t_k)\|^2_{R_i}\)，将平衡信息嵌入目标，连接暂态性能与稳态可行性。

### 2.2 分布式求解器（Algorithm 2）

- 采用增广拉格朗日方法，而非常规 \(\|\tilde L Z\|^2\) 罚项，改用 \(\frac{\rho}{2}\|Z\|^2_{\tilde L}\)，保持等价性的同时便于分布式分解。
- 整体更新结构为“投影梯度 + 原始-对偶”：
  - **u 更新**：\(u_i^{q+1}=\mathcal P_{\tilde{\mathcal U}_i}\{u_i^q-g_{ui}\nabla_{u_i}J_i(u_i^q,z_i^q)\}\)
  - **z 更新**：\(z_i^{q+1}=\mathcal P_{\tilde{\mathcal Z}_i}\{z_i^q-g_{zi}[\nabla_{z_i}J_i(u_i^q,z_i^q)+\sum_{j\in\mathcal N_i}(\lambda_i^q-\lambda_j^q)+\rho\sum_{j\in\mathcal N_i}(z_i^q-z_j^q)]\}\)
  - **乘子更新**：\(\lambda_i^{q+1}=\lambda_i^q+\rho z_i^{q+1}\)
  - 每一步只需邻居的 \(z,\lambda\) 信息，实现并行分布式计算。
- **收敛条件**（Theorem 1）：通过调节步长参数 \(g_{ui},g_{zi}\) 使得
  \[
  G_{ui}>0,\quad G_{ui}^{-1}-L_{\delta i}I_{mT}>0,\quad G_{zi}>0,\quad G_{zi}^{-1}-(L_{\delta i}+2\rho L_{ii})I_n>0
  \]
  每个智能体可仅凭局部信息验证，因此算法可完全分布式部署。

- **收敛率**（Corollary 1）：给出加权平均迭代的 \(O(1/t)\) 次优性界和共识约束违逆界。

### 2.3 闭环分析（Theorem 2）

- 建立终端条件：
  1. 存在控制增益 \(K_i\)，使
     \[
     \sum_{h=0}^{\Delta t-1}\|(A_i+B_iK_i)^h\|^2_{Q_i+K_i^\top R_iK_i}+\|(A_i+B_iK_i)^{\Delta t}\|^2_{P_i}-P_i\le 0
     \]
  2. 终端集与平衡集满足：
     \[
     K_i\mathcal X_{iT}\oplus(D_i-K_i)\tilde{\mathcal Z}_i\subseteq\mathcal U_i
     \]
     \[
     (A_i+B_iK_i)\mathcal X_{iT}\oplus(I-(A_i+B_iK_i))\tilde{\mathcal Z}_i\subseteq\mathcal X_{iT}
     \]
- 在可行初始解下，这两组条件保证：
  - **递归可行性**：每步MPC优化均有可行解；
  - **渐近一致性**：闭环系统状态最终趋向一致，且状态/输入约束始终满足。

### 2.4 算法流程

- Algorithm 1（外部MPC循环）：
  1. 给定当前状态 \(x_i(t_k)\)，求解 Problem 1 获得最优输入序列 \(u_i^\star(t_k)\) 与共识平衡点 \(z_i^\star(t_k)\)；
  2. 应用前 \(\Delta t\) 步控制量作为真实输入；
  3. 更新时间 \(t_{k+1}=t_k+\Delta t\) 并重复。

- Algorithm 2（内层分布式求解器）：在每次MPC更新中，各智能体并行执行 u/z 投影梯度更新、乘子更新、邻居通信与分布式终止检测。

## 6. 主要结论与发现

1. **同时优化输入与平衡点可行且有效**：将共识平衡点视为决策变量并限制在可行平衡集内，可以提升一致性能并确保动态可行性。
2. **分布式原始-对偶算法有效**：Algorithm 2 可并行求解带耦合约束的MPC优化问题，收敛条件为局部可验证，适合分布式部署。
3. **闭环保证成立**：在合适的终端条件下，MPC框架可保证递归可行性与渐近一致性。
4. **数值验证**：两套不同系统的仿真显示智能体快速收敛到共同平衡点且全程满足约束；大规摸对比证明提出方法在收敛速度与性能成本上优于 STMPC/STBC/AFGC，并与 OCMPC 性能相当，但适用范围更广（异构、可行平衡显式保证）。
