## 摘要
由大型语言模型驱动的多智能体系统（MAS）在复杂任务中展现出潜力，但失败率很高。当前针对MAS的自我反思方法要求所有智能体对失败进行反思，忽略了一个关键现实：失败通常源于某个特定的智能体将任务引向歧途，即决定性错误智能体，而其他智能体只是履行其常规职责。强迫行为正常的智能体进行反思会用错误的见解污染其记忆。因此，我们提出DoCtOR（诊断-纠正-强化学习增强反思），一种新颖的反思框架，用于增强多智能体协作。DoCtOR首先通过自动故障归因识别决定性错误步骤和决定性错误智能体，然后使用反事实推理生成纠正后的决定性错误步骤，最后仅让决定性错误智能体进行有针对性的反思。实验结果表明，在HotPotQA、ChartQAPro和Mind2Web数据集上，DoCtOR相比初始成功率分别提高了22%、26%和27%，优于Reflexion、Retroformer和COPPER。我们进一步验证了我们'先诊断后纠正'范式的泛化性，并证明在低资源设置下，将对决定性错误步骤之后的推理步骤的反思聚焦到与对整个失败轨迹的反思达到相当的质量。

## Abstract
Multi-agent systems (MAS) powered by large language models have shown promise for complex tasks but suffer from high failure rates. Current self-reflection methods for MAS require all agents to reflect upon failure, overlooking a critical reality: failures typically stem from a specific agent leading the task astray, namely the decisive error agent, while others merely fulfill their regular duties. Forcing regular-behaving agents to reflect contaminates their memory with wrong insights. Hence, we propose DoCtOR (Diagnose-then-Correct PPO-enhanced Reflection), a novel reflection framework that enhances multi-agent collaboration. DoCtOR first identifies the decisive error step and decisive error agent through automated failure attribution, then employs counterfactual reasoning to generate a corrected decisive error step, and finally engages only the decisive error agent to produce targeted reflections. Experimental results show DoCtOR achieves 22%, 26%, and 27% improvements over initial success rates on HotPotQA, ChartQAPro, and Mind2Web datasets, outperforming Reflexion, Retroformer, and COPPER. We further establish the generalizability of our diagnose-then-correct paradigm and demonstrate that in low-resource settings, focusing reflection on reasoning steps after the decisive error step achieves comparable quality to reflecting on the complete failure trajectory.

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

#### 核心思想
提出 **DoCtOR（Diagnose-then-Correct PPO-enhanced Reflection）** 框架，采用“先诊断、后纠正、再针对性反思”的三阶段范式：

1. **诊断（Diagnose）**：通过自动故障归因定位决定性错误步骤（decisive error step）和决定性错误智能体（decisive error agent）。
2. **纠正（Correct）**：使用反事实推理生成纠正后的决定性错误步骤。
3. **反思（Reflect）**：仅让决定性错误智能体基于上述信息进行针对性反思，并通过 PPO 优化反思生成质量。

#### 关键技术细节

**(1) 诊断子模块：ProFA（Process reward-based Automated Failure Attribution）**

- 受 Process Reward Model (PRM) 启发，为轨迹中每个推理步骤分配正确性分数：
  \[
  c_t = \text{ProFA}_\phi(s_t, a_t, \tau_{<t})
  \]
- 通过阈值 \(\gamma=0.5\) 将分数转为二元正确性指示：
  \[
  B_t = \mathbb{I}(c_t > \gamma)
  \]
- 决定性错误步骤 \(t^*\) 定义为第一个 \(B_t=0\) 的步骤：
  \[
  t^* = \min\{t \mid B_t = 0, 0 \le t \le T\}
  \]
- 模型基于 Qwen3-1.7B 全参数微调，使用 BCE 损失：
  \[
  \mathcal{L}_{\text{ProFA}} = -\frac{1}{M}\sum_{j=1}^M \sum_{t=0}^{T_j} \text{BCE}(c_t^{(j)}, l_t^{(j)})
  \]

**(2) 纠正子模块：反事实推理**

- 给定决定性错误步骤 \(t^*\) 和错误智能体 \(i^*\)，生成纠正后的动作：
  \[
  \tilde{a}_{t^*} = \text{CR}(s_{t^*}, \tau_{<t^*}, p_{i^*})
  \]
- 用 ProFA 验证纠正动作的正确性：
  \[
  \tilde{c}_{t^*} = \text{ProFA}_\phi(s_{t^*}, \tilde{a}_{t^*}, \tau_{<t^*})
  \]
- 若 \(\tilde{c}_{t^*} > \gamma\) 则接受，否则重新生成，直到通过验证。

**(3) 反思器（Reflector）**

- 输入为失败轨迹 \(\tau\)、错误智能体画像 \(p_{i^*}\)、决定性错误步骤 \(a_{t^*}\)、纠正后的步骤 \(\tilde{a}_{t^*}\)，输出针对性反思 \(y_{i^*}\)。
- 反思质量评分：用下一轮回报与当前轮回报之差作为评分：
  \[
  r(y_{i^*}^{k,e}) = G_{k,e+1} - G_{k,e}
  \]
- 优化采用三阶段 RLHF 流程：
  - **SFT**：先用正例监督微调（最大似然估计）；
  - **Reward Model**：用回归模型（GPT-2）预测评分，MSE 损失；
  - **PPO**：用 KL 正则化约束与 SFT 模型的距离：
    \[
    \mathcal{L}_{\text{PPO}}(\theta) = -\mathbb{E}\left[ R_\phi(x,y) - \beta \log \frac{\pi_{\text{RL}}^\theta(y_{i^*} \mid x)}{\pi_{\text{SFT}}(y_{i^*} \mid x)} \right]
    \]
- 反思器基座为 Llama-3.1-8B-Instruct（LoRA 微调）。
