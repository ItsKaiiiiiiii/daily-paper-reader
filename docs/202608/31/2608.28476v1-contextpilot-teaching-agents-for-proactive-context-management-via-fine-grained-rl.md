## 摘要
长视野智能体任务要求大型语言模型（LLMs）在多轮交互中迭代地检索、整合和维护分散的信息，但保留所有交互历史会导致工作上下文持续增长。最近的主动上下文管理方法允许模型使用专门工具编辑其自身的工作上下文，但仍面临三个关键限制：（1）工具集有限，仅限于搜索、删除和摘要，不支持全局规划、长期记忆和自适应压缩；（2）探索效率低下，将上下文管理操作一视同仁，尽管它们对最终结果的影响各异；（3）粗粒度的信用分配，在强化学习期间将最终的轨迹级奖励分配给所有中间的上下文编辑动作。为弥补这些差距，我们引入了ContextPilot，一个用于长视野智能体推理的主动上下文管理框架。我们的方法系统地扩展了工具集，增加了规划、长期记忆和软上下文卸载工具。我们进一步提出了一种针对上下文管理量身定制的强化学习方法，该方法利用上下文和熵变化来识别关键编辑决策以进行分支采样，并从所有通过相应上下文编辑动作的分支轨迹中估计动作级优势。在长上下文问答和深度搜索任务上的实验表明，ContextPilot以更紧凑的工作上下文实现了更强的性能，在各种基础模型和基准测试上持续优于现有基线。代码可在https://github.com/Tencent/ContextPilot获取。

## Abstract
Long-horizon agentic tasks require large language models (LLMs) to iteratively retrieve, integrate, and maintain dispersed information across multi-turn interactions, but preserving all interaction histories leads to a continuously growing working context. Recent proactive context management methods allow models to edit their own working context with specialized tools, yet they still face three key limitations: (1) a limited toolset restricted to search, deletion, and summarization, with no support for global planning, long-term memory, and adaptive compression; (2) inefficient exploration that treats context management actions uniformly despite their heterogeneous impacts on final outcomes; and (3) coarse-grained credit assignment that assigns the final trajectory-level reward to all intermediate context editing actions during RL. To bridge these gaps, we introduce ContextPilot, a proactive context management framework for long-horizon agentic reasoning. Our approach systematically augments the toolset with planning, long-term memory, and soft context offloading tools. We further propose an RL method tailored for context management, which uses context and entropy variation to identify critical editing decisions for branch sampling and estimates action-level advantages from all branched trajectories that pass through the corresponding context editing action. Experiments on long-context QA and deep search tasks show that ContextPilot achieves stronger performance with a more compact working context, consistently outperforming existing baselines across various base models and benchmarks. Code is available at https://github.com/Tencent/ContextPilot.

## 1. 核心问题与整体含义

- **研究动机**：长视野（long-horizon）智能体任务中，LLM 需要多轮交互检索、整合和维护分散信息；但若保留全部交互历史，工作上下文会持续膨胀，导致计算成本上升与信息过载。
- **既有方法不足**：虽然已有“主动上下文管理”方法（如 StateLM）允许模型用工具编辑自身上下文，但仍存在三大关键局限：
  1. **工具集受限**：仅支持搜索、删除、摘要，缺乏全局规划、长期记忆与自适应压缩能力；
  2. **探索低效**：训练时将所有上下文管理操作同等对待，忽略了不同操作对最终结果影响差异巨大；
  3. **信用分配粗糙**：RL 中将最终轨迹级奖励直接赋给所有中间上下文编辑动作，无法区分好坏决策。
- **整体含义**：ContextPilot 通过更丰富的工具集与针对上下文管理定制的细粒度 RL 训练，使模型能够主动、紧凑地管理自身工作上下文，从而在长上下文 QA 和深度搜索任务上取得更强性能。

## 2. 方法论

- **核心思想**：扩展上下文管理工具集，并设计专门适配上下文管理的 RL 训练流程，包括“上下文感知部分展开”（context-aware partial rollout）和“细粒度信用分配”（fine-grained credit assignment）。

### 2.1 工具集设计

- 在 StateLM 基础工具之上新增三类工具：
  - **规划与感知**：`plan`（提出简明计划）、`analyzeText`、`checkBudget`；
  - **长期记忆**：`memorize`（提取实体/时间戳/事件脚本并建边）、`updateMemory`、`readMemory`；
  - **软上下文卸载**：`summarizeContext`（摘要）、`compressContext`（基于 LLMLingua-2 压缩）、`foldHistory`（折叠历史并构建可搜索索引）。
- 将上下文卸载、记忆写入/更新等视为上下文编辑动作，用于在训练时切分轨迹快照（trajectory snapshots）。

### 2.2 SFT 数据合成

- 使用教师模型（Qwen3.5-397B-A17B）在“上下文管理 harness”引导下生成轨迹；harness 提供动态工具可用性约束、错误提示和重试机制，但这些提示只在生成时使用，不进入最终 SFT 轨迹。
- 经结果过滤（允许两次重试）、基于 GPT-OSS 的过程过滤、峰值 token 过滤后，得到 3,068 条合格轨迹，并按上下文编辑动作切分为 51,469 个快照。

### 2.3 RL 训练

- **上下文感知部分展开**：
  - 对每个上下文管理动作计算上下文变化量：
    \[
    \Delta C^{cm}_t = \frac{\text{len}(c^{cm}_{t+1}) - \text{len}(c^{cm}_t)}{\text{len}(c^{cm}_t)}
    \]
  - 计算熵变化量：
    \[
    \Delta H^{cm}_t = H^{cm}_t - H_{\text{initial}}
    \]
  - 定义敏感度分数 \(S = \alpha \Delta C + \beta \Delta H\)，选择分数最高的动作作为分支点，从父节点采样额外子轨迹，从而对影响大的关键决策分配更多探索预算。
- **细粒度信用分配**：
  - 对每个轨迹快照 \(S_i\)，其奖励定义为所有以 \(S_i\) 为前缀的终止轨迹奖励的平均值：
    \[
    R(S_i) = \frac{1}{|\mathcal{T}(S_i)|} \sum_{T \in \mathcal{T}(S_i)} R(T)
    \]
  - 在同 query 组内计算 advantage（均值/标准差），并以 GRPO 目标优化策略。
  - 附录给出理论证明：该估计器无偏且方差为轨迹级估计的 \(1/n_S\)，可显著降低优势信号方差。
