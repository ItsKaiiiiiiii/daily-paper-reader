## 摘要
多智能体推理（MAR）通过迭代式的方案交换与优化来提高推理可靠性。现有的自适应MAR方法通常从查询级标签或轨迹级回报中学习路由决策，但这种粗粒度的监督无法准确估计多步协作中单个操作符的状态条件效用。我们提出了TreeCredit，一种用于高效自适应MAR的共享前缀信用分配框架。其核心见解是通过状态匹配的下游比较来估计操作符效用，而不是将轨迹级结果直接归因于先前的决策。TreeCredit通过从同一中间状态扩展候选操作符来构建共享前缀协作树，并根据其完整后续的终端正确性和累计额外成本，为每个状态-操作符对分配一个正确性优先的后缀信用。这些结构化的信用被转换为状态局部的操作符偏好，用于训练一个轻量级的成对状态路由器，该路由器在推理过程中动态选择下一个可行的操作符。在六个推理基准上的实验表明，TreeCredit在显著降低推理成本的同时适度提高了准确率，实现了比代表性MAR方法更好的准确率-成本权衡。

## Abstract
Multi-agent reasoning (MAR) improves reasoning reliability through iterative solution exchange and refinement. Existing adaptive MAR methods typically learn routing decisions from query-level labels or trajectory-level returns, but such coarse supervision cannot accurately estimate the state-conditioned utility of individual operators in multi-step collaboration. We propose TreeCredit, a shared-prefix credit assignment framework for efficient adaptive MAR. Its core insight is to estimate operator utility through state-matched downstream comparisons, rather than directly attributing trajectory-level outcomes to preceding decisions. TreeCredit constructs shared-prefix collaboration trees by expanding candidate operators from the same intermediate state and assigns each state--operator pair a correctness-prioritized suffix credit based on the terminal correctness and cumulative additional cost of its complete continuation. These structured credits are converted into state-local operator preferences to train a lightweight pairwise state router, which dynamically selects the next admissible operator during inference. Experiments on six reasoning benchmarks show that TreeCredit modestly improves accuracy while substantially reducing inference cost, achieving a better accuracy--cost trade-off than representative MAR methods.

## 1. 论文的核心问题与整体含义（研究动机和背景）

多智能体推理（Multi-Agent Reasoning, MAR）通过多个智能体之间迭代交换方案、相互修正与聚合意见，能够显著提高复杂推理任务的可靠性与答案质量。然而，这种性能提升往往伴随着高昂的推理开销——更多模型调用、更多消息交换和更复杂的协调机制。

**核心矛盾**：如何在保持甚至提升推理质量的同时，有效控制协作成本。

近年来，自适应路由与编排方法（如 MasRouter、DAAO、BAMAS 等）试图根据查询特征或估计难度动态配置协作模式，以改善精度-成本权衡。然而，这些方法存在一个关键的**信用分配问题**：

- 现有方法通常使用查询级标签或轨迹级回报来监督路由决策；
- 这类粗粒度监督无法准确估计多步协作中**单个状态-操作符对**（state–operator pair）的真实效用；
- 成功的轨迹可能包含冗余甚至有害的决策，失败的轨迹也可能包含局部有益的步骤。

**论文的核心洞见**在于：应该通过**状态匹配的下游比较**（state-matched downstream comparisons）来估计操作符效用，而非直接将轨迹级结果归因于先前的路由决策——即在同一中间状态下并列比较不同操作符的完整后续表现。

## 2. 论文提出的方法论

### 2.1 整体框架

TreeCredit 是一个共享前缀信用分配框架，包含四个核心模块：

### 2.2 共享前缀树扩展（Shared-Prefix Tree Expansion）

- 对每个带标签样本 $(q_i, y_i)$，构建 $K$ 棵独立采样的协作树；
- 在每个非终止节点 $v$，从**同一状态** $s_v$ 扩展所有可行操作符作为兄弟分支；
- 操作符目录为 $\mathcal{O} = \{o_{acc}, o_{deb}, o_{vote}\}$：
  - $o_{acc}$：接受当前答案并终止；
  - $o_{deb}$：执行另一轮异构辩论；
  - $o_{vote}$：聚合当前候选答案并终止；
- 关键性质：同一节点的兄弟分支共享相同的前缀 $P(v)$（查询 + 交互历史 + 计算前缀），因此下游差异完全归因于操作符选择。

### 2.3 正确性优先后缀信用（Correctness-Prioritized Suffix Credit）

对每个状态-操作符对 $(s_v, o)$ 定义结构化后缀信用：

$$G(s_v, o) = (Z(s_v, o),\; -C_{suf}(s_v, o))$$

其中 $Z \in \{0,1\}$ 为终端预测的正确性，$C_{suf}$ 为从 $s_v$ 经 $o$ 到终止的累计额外成本。采用**字典序比较**：

$$(z, -c) \succ_{lex} (z', -c') \iff [z > z'] \lor [z = z' \land c < c']$$

- 正确性优先：防止低成本但错误的路径压制正确路径；
- 同等正确性下偏好更低成本；
- 对 $o_{deb}$ 的信用从其后续状态的最佳可达后缀通过**最大值备份**（optimal-continuation backup）获得。

### 2.4 状态局部偏好提取（State-Local Preference Extraction）

- 对同一状态下任意两个具有严格信用排序的操作符，构造偏好 $o_a \succ_{s_v} o_b$；
- 聚合所有独立采样状态、树和样本，得到偏好数据集 $\mathcal{D}_{pref}$；
- 权重 $w_j$ 强调正确性变化的比较，并平衡无序操作符对内相反方向的偏好。

### 2.5 成对状态路由（Pairwise State Routing）

- 状态表示：398 维特征 = 384 维 MiniLM 查询嵌入 + 14 维协作状态特征（答案一致性、交互稳定性、剩余预算等）；
- 使用两层 MLP（隐藏层 128 维）将状态映射为操作符 logits；
- 通过**加权 Bradley–Terry 损失**训练路由器：

$$\mathcal{L}_{pref}(\theta) = \frac{\sum_{j=1}^{J} w_j \log(1 + \exp(-\Delta_{\theta,j}))}{\sum_{j=1}^{J} w_j}$$

- 推理时，路由器选择最高分操作符，采用**单条自适应轨迹**，无需构建树。
