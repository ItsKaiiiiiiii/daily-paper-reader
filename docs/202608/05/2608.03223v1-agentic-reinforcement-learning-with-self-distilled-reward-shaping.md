## 摘要
智能体强化学习使大型语言模型（LLM）智能体能够通过交互进行学习，但稀疏的轨迹级奖励仅能揭示成功与否，而无法识别哪些中间决策应获得信用。仅训练阶段可用的特权技能可以通过允许相同的冻结策略快照在基于任务匹配的程序性技能条件下对来自无技能轨迹的固定 token 进行重新评分，从而提供更密集的监督。然而，现有方法并未在交互步骤间联合校准教师分数、将教师置信度与实际回报相关联，并将所得信号整合到原生奖励到优势（reward-to-advantage）的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个为多轮语言智能体构建与回报相关的 token 级信用的框架。ADRS 在每一步内对特权 token 分数进行中心化和归一化，通过基于组内置信度-回报关联的、与回报相关的教师价值优势（TVA）门控对其进行调制，并将门控后的 token 信号纳入原生强化学习信用构建中。这些组件共同决定了教师偏好什么、该偏好何时与回报相关，以及它如何进入原生强化学习信用路径，同时保持 rollout 和推理过程的无技能性。最后，在三个交互基准上的实验表明，ADRS 在长视界任务上持续提升了性能，且增益在多种强化学习主干、数据减少设置、未见任务和扩展训练中均得以保持。为便于匿名评审，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 2. 论文提出的方法论

论文提出 **ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping）**，将特权技能转换为 token 级训练奖励，同时保持 rollout 和推理阶段完全无技能输入。核心架构由三个模块组成：

### 2.1 模块一：步内相对特权评分（Within-Step Relative Privileged Scoring）

- **目标**：解决教师原始 log-probability 在不同交互步骤之间偏移和尺度不一致的问题。
- **做法**：同一冻结策略快照在普通上下文和特权上下文（技能⊕历史）对同一批 token 重新打分，然后在每个交互步内进行中心化和归一化：

  $$b_s = \frac{1}{|\mathcal{V}_s|} \sum_{j\in \mathcal{V}_s} \ell^T_{s,j}, \quad q_{s,j} = \ell^T_{s,j} - b_s, \quad \hat{q}_{s,j} = \frac{q_{s,j}}{\sigma_q + \epsilon}$$

- **关键性质**：每步内 $\sum_{j\in \mathcal{V}_s} \hat{q}_{s,j} = 0$，即零和结构，保证轨迹级别的奖励总量不因教师信号而发生偏移。

### 2.2 模块二：回报关联的 TVA 可靠性门控（Return-Associated TVA Gate）

- **目标**：判断教师信心是否与实际回报一致——教师高分偏好并不一定意味着高回报。
- **做法**：在选定分组内比较"高置信单元"和"低置信单元"的平均回报差异，即计算：
  $$d_g = \mu_g^+ - \mu_g^-$$
  其中 $\mu_g^+$ 与 $\mu_g^-$ 分别是置信度加权后的高/低置信单元的平均回报。随后用 sigmoid 映射为门控 $m_u = \sigma(\tau \tilde{d}_g)$。
- **理论保证**：Proposition 1 证明 TVA 门控的符号与组内置信度-回报协方差一致（$d_g = \mathrm{Cov}_g(\alpha, R) / (\bar{\alpha}_g(1 - \bar{\alpha}_g))$）。
- **支持多粒度**：完成级 TVA（L2，GRPO 风格）和步级 TVA（L3，GiGPO 风格）。

### 2.3 模块三：教师引导的逐 Token 优势调制（Teacher-Guided Per-Token Advantage Modulation）

- **目标**：将门控后的教师信号注入原生 RL 信用构造，而非独立辅助损失。
- **做法**：
  - 教师奖励：$r^T_{s,j} = \eta m_{s,j} \hat{q}_{s,j}$
  - 塑形奖励：$\tilde{r}_{s,j} = r^{base}_{s,j} + r^T_{s,j}$
  - 轨迹路径（trajectory path）：塑形奖励经过标准 GRPO/GiGPO 计算轨迹优势（由于步内零和性质，轨迹得分与基线一致）
  - Token 路径（token path）：独立保存教师 reward 并按 prompt 组进行标准化（$Z^T_t$），叠加到轨迹优势上，得到最终 token 级优势：
  $$A^{ADRS}_{i,k,t} = A^{traj}_{i,k} + \eta Z^T_{i,k,t}$$
- **理论性质**：
  - Proposition 2：教师奖励在步级具有零和表示，可写成势函数差分形式。
  - Proposition 3：ADRS 与 detached token 辅助系数在局部一阶梯度上等价，证明其优化合理性。

**整体流程**：行为策略生成无技能轨迹 → 冻结快照对 token 重打分（普通+特权上下文）→ 步内归一化 → TVA 门控 → 与基奖励合并 → 生成 token 级优势 → 标准策略更新。特权文本不进入 rollout 与推理。

## 6. 论文的主要结论与发现

1. **ADRS 在三个基准上刷新 SOTA**：
   - ALFWorld（Qwen2.5-3B）：94.5% 成功率，比最强基线高 +10.1 个百分点；

2. **跨模型家族与规模稳定生效**：Qwen2.5-3B、Qwen2.5-7B、Qwen3-1.7B 上均取得最佳 ALFWorld 结果。
3. **300 步长训练后增益保持**：ALFWorld 最终 checkpoint 达 96.1%，比 GRPO 高 9.4 个百分点；WebShop 峰值 84.4%。
4. **TVA 门控在原生 RL 骨干上带来增量**：在 GiGPO 骨干上，ADRS 从 82.8% 提升到 87.5%，加 TVA 后进一步到 89.8%。
5. **机制诊断显示**：ADRS 将更新对比聚焦于任务关键 token（action/object），而风格 token 的教师-学生差距趋近于零（action/style 比值达到 95.3）。
6. **数据效率高**：使用 60% 数据即超过完整数据 GRPO 的效果。
7. **未见任务泛化**：平均 +11.9 个百分点，6 类任务中 5 类提升。

## 8. 不足与局限

- **算力信息透明度低**：论文没有报告具体 GPU 数量和训练耗时，难以评估 ADRS 相对于基线方法的计算开销增幅，也影响其他研究者的复现成本评估。
- **Search QA 上的优势不显著**：ADRS 在此任务上仅比最佳基线高 0.4 个百分点（45.0 vs 44.6），且并非所有数据集（如 Bamboogle、2WikiMultihopQA）都获得提升；这可能意味着 token 级信用注入对短视界、固定行为的搜索任务增益有限。
- **配置有选择偏差风险**：主表使用"基准特定"的归一化设置（global vs per-sequence），虽然附录有说明，但仍存在为每个基准选择最优配置后再报告结果的偏差风险。
- **未统一比较所有 300 步配置**：300 步扩展只包含代表性配置（如 ALFWorld 用 GRPO 骨干，WebShop 用 per-seq），没有对全模型 × 全基准 × 全配置进行统一 300 步扫描，长训练结果的全面性有限。
- **TVA 门控有效性依赖分组质量**：如果组内样本太少（L2/L3 少于 2 个单元），门控退回 0.5；而 L1 回退不包含回报信息，这与 TVA 设计意图不一致。
- **理论保证为局部性质**：三个 Proposition 均限定在"行为策略点、采样批次、未截断分支"等局部条件下，不保证整个训练动态的全局收敛优势。
- **数据效率实验存在边界**：20% 和 40% 数据下 ADRS 仍低于完整数据 GRPO，说明 token 级信用并不能完全弥补数据量严重不足的问题。
- **隐私与安全性考虑缺失**：特权技能使用场景是否涉及额外外部知识/敏感信息处理，论文未做讨论。
