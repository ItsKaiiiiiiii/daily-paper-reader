## 摘要
现有的搜索增强型LLM智能体通过强化学习训练以提升其推理能力。然而，这些方法主要依赖结果级奖励，对搜索行为的监督很少，并且忽略了智能体正确分解复杂查询的能力。为解决这一问题，我们提出PROGRESS，利用教师引导的覆盖率奖励来显式塑造策略模型的分解查询生成。在训练过程中，冻结的教师模型用于将复杂查询分解为必要的搜索查询，这些必要的搜索查询用于引导策略模型的搜索行为。我们的方法集成到R1式训练框架中，在无需密集过程级监督的情况下，对查询分解决策提供轻量级引导。实验表明，覆盖率引导的强化学习提升了整体任务性能，突显了在智能体LLM中显式监督搜索策略的重要性。

## Abstract
Existing search-augmented LLM agents are trained using Reinforcement Learning to boost its reasoning capabilities. However, these approaches primarily rely on outcome-level rewards, which provide little supervision over search behavior and overlook agent's ability to decompose complex queries properly. To mitigate this issue, we propose PROGRESS which utilizes teacher-guided coverage reward to explicitly shape decomposed query generation of the policy model. During training, frozen teacher models are used to decompose complex queries into essential search queries. These essential search queries are utilized to guide the search behavior of the policy model. Integrated into an R1-style training framework, our approach provides lightweight guidance over query decomposition decisions without dense process-level supervision. Experiments show that coverage-guided RL improves overall task performance, highlighting the importance of explicitly supervising search strategies in agentic LLMs.

### 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：搜索增强型 LLM 智能体可以通过与外部搜索引擎交互，实现复杂的多跳推理。训练此类智能体通常采用强化学习（RL），例如现有工作 Search-R1 已证明 RL 可以显著提升模型在检索与思考之间交替的能力。
- **核心问题**：现有 RL 训练方法大多依赖**结果级奖励**（如精确匹配 Exact Match），只关注最终答案是否正确，而忽略了：
  - 对**搜索行为本身**的监督（即"搜什么、何时搜、怎么搜"）；
  - 对**复杂查询分解能力**的显式指导。这会导致小模型倾向于直接使用复杂查询进行整段检索，或生成粒度不当的复合搜索查询，从而降低检索效率与推理表现。
- **整体含义**：论文指出，**显式监督搜索策略**是训练稳健的 agentic LLM 的关键要素。若能让模型在训练过程中学会"覆盖一组必要的信息需求"，即使没有逐步骤的人工密集监督，也能显著改善多跳问答的表现。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想
利用**冻结的教师模型**预先生成关键搜索查询（essential search queries），作为策略模型搜索行为的"锚点"。通过在 RL 训练中加入一个**覆盖率奖励（coverage reward）**，显式鼓励策略模型生成的搜索查询在**语义**和**粒度**上与教师查询重叠，从而实现轻量级的查询分解监督。

#### 关键技术细节

- **教师查询生成**：使用 Qwen2.5-72B-Instruct 作为冻结教师模型，针对每个复杂问题 x 预先离线生成一组关键搜索查询集合：QT(x) = {qT₁, qT₂, …, qT_K}。这些查询近似代表任务所需的潜在信息需求。
- **策略查询提取**：策略模型 πθ 在 rollout 中生成搜索轨迹，提取其中所有搜索查询，得到 QP(x, y) = {qP₁, qP₂, …, qP_M}。
- **查询匹配**：利用 LLM judge（同样为 Qwen2.5-72B-Instruct）基于**语义等价性**与**粒度一致性**两个准则，识别匹配集合 I(x, y) = QP ∩ QT。
- **覆盖率指标**：计算精确率（Precision）与召回率（Recall），并取**F1 分数（调和平均）**作为覆盖率奖励：

```
Precision = |I| / |QP|
Recall    = |I| / |QT|
r_cov     = 2 * Precision * Recall / (Precision + Recall)
```

- **总奖励函数**：

```
r(x, y) = r_ans(x, y) + r_format(y) + λ_cov * r_cov(x, y)
```

其中 r_ans 为答案精确匹配奖励，r_format 为格式奖励（要求正确使用 `<search>`、`<think>`、`<answer>` 等特殊标记），λ_cov 设为 0.2。

- **训练框架**：基于 Search-R1 的 RL 范式，采用 PPO 进行策略优化，并包含检索词掩码（retrieved-token masking）与 KL 正则化以保持训练稳定性。优化仅作用于策略模型生成的 token，教师模型全程不更新。

#### 算法流程概述
1. 离线阶段：教师模型生成所有训练样本的关键搜索查询。
2. 在线 rollout：策略模型与环境交互，生成搜索轨迹与多轮搜索查询。
3. 奖励计算：通过 LLM judge 匹配策略与教师查询，结合答案正确性、格式合规性计算总奖励。
4. PPO 更新：在 KL 约束下优化策略，逐步提升搜索查询对关键信息需求的覆盖率。

### 6. 主要结论与发现

1. **覆盖率奖励有效提升多跳 QA 表现**：PROGRESS 在多跳数据集上相较 Search-R1 获得 2–5% 的绝对 EM 提升，其中 MuSiQue 上提升约 5%。
2. **仅用多跳数据训练时优势更明显**：在 HotpotQA-only 训练设置下，PROGRESS 在 2wiki 与 MuSiQue 上分别比基线高约 4.2% 和 5.6%。
3. **搜索查询质量显著改善**：Completeness 与 Granularity 两个维度上均优于 Search-R1，说明覆盖率奖励确实塑造了更好的查询分解行为。
4. **检索准确率提升**：在三种多跳数据集上，PROGRESS 的检索命中率显著高于基线（平均约 6–9 个百分点）。
5. **具备跨模型规模泛化能力**：在 1.5B 模型上同样获得一致提升。
6. **核心论断**：在 agentic LLM 的训练中，**干预中间搜索行为比只看最终结果更有效**，覆盖率奖励提供了一种轻量、无需过程级人工标注的解决方案。

### 7. 优点

- **轻量级监督**：仅使用离线预生成的教师查询与 trajectory 级 F1 奖励，不需要逐推理步骤的人工标注，实用性强。
- **同时兼顾精确率与召回率**：F1 式的覆盖率奖励避免模型走极端——既防止生成大量不相关查询刷覆盖率，也防止只搜少量关键查询的偷懒策略。
- **与现有框架无缝集成**：可直接融入 Search-R1 风格的 PPO 框架，无需改动环境或推理协议。
- **多维度实验验证**：除 EM 外，还分析了对检索质量、查询分解质量的真实影响，并有跨模型泛化验证，说服力较强。
