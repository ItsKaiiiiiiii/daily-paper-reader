## 摘要
自主网络作战（ACO）对于防御企业网络日益重要，因为网络威胁的复杂性不断提升。ACO应用通常采用强化学习（RL）智能体，通过与环境的交互学习防御行为。然而，RL智能体在训练中通常需要大量探索，往往在收敛到有效防御策略之前，表现出不稳定的行为和较差的初始决策能力。在本工作中，我们研究了在ACO环境中使用大型语言模型（LLM）来改进自主防御决策。通过提示工程而非微调，我们证明了一个在网络安全数据上预训练的80亿参数LLM，在改进的CybORG CAGE Challenge 2环境中能够优于基线RL智能体。然后，我们提出了一种在线策略蒸馏框架，将LLM的防御策略转移到仅包含64,910个参数的轻量级RL智能体中，在保持有效防御能力的同时，将模型大小减少了几个数量级。这为在轻量级、可部署的智能体中落地前沿网络安全模型提供了一条途径。为了评估可迁移性，我们构建了主机数量从4到12不等的CybORG场景，并在不同网络配置下评估了该方法。我们还评估了教师引导的RL稳定化策略，观察到没有一种策略能持续超越优化后的教师策略，这表明奖励驱动的RL优化与教师引导的防御策略之间存在策略对齐限制。我们的结果证明了聚焦网络安全的LLM作为自主网络防御专业知识来源的潜力，同时策略蒸馏为在高效、可扩展的智能体中落地前沿网络安全模型提供了一条实用路径。

## Abstract
Autonomous Cyber Operations (ACO) are increasingly important for defending enterprise networks as cyber threats continue to evolve in sophistication. ACO applications commonly employ Reinforcement Learning (RL) agents to learn defensive behaviors through interaction with environments. However, RL agents typically require extensive exploration during training, often resulting in unstable behavior and poor initial decision-making before converging toward effective defense strategies.   In this work, we investigate the use of a Large Language Model (LLM) to improve autonomous defensive decision-making within an ACO environment. Through prompt engineering rather than fine-tuning, we demonstrate that an 8-billion parameter LLM pretrained on cybersecurity data can outperform a baseline RL agent in a modified CybORG CAGE Challenge 2 environment. We then propose an online policy distillation framework that transfers the LLM's defensive policy into a lightweight RL agent containing only 64,910 parameters, reducing model size by several orders of magnitude while maintaining effective defensive capabilities. This provides a pathway toward operationalizing frontier cybersecurity models within lightweight, deployable agents.   To evaluate transferability, we construct CybORG scenarios ranging from 4 to 12 hosts and assess the approach across varying network configurations. We also evaluate teacher-guided RL stabilization strategies and observe that none consistently surpass the optimized teacher policy, suggesting policy-alignment limitations between reward-driven RL optimization and teacher-guided defense strategies.   Our results demonstrate the potential of cybersecurity-focused LLMs as sources of expertise for autonomous cyber defense, while policy distillation provides a practical path toward operationalizing frontier cybersecurity models within efficient, scalable agents.

## 2. 论文提出的方法论

### 核心思想
直接学习教师策略而非联合使用环境奖励与教师引导，即通过在线策略蒸馏，将 LLM 的防御策略转移至轻量级 RL 智能体，避免了教师策略与环境奖励信号之间的潜在对齐冲突。

### 关键技术细节
- **在线策略蒸馏框架**：
  - **动作掩码（Action Masking）**：将教师未推荐动作的概率设为 0，确保学生智能体始终执行教师建议的动作，公式为：
    \[
    \pi_{\text{masked}}(a_t) = \frac{M_t(a_t)}{\sum_{a'}M_t(a')}
    \]
    其中 \(M_t(a_t)\) 为掩码矩阵（推荐动作置 1，其余置 0），用于保证概率分布的合法性。
  - **教师引导损失**：使用负对数似然作为损失信号：
    \[
    L_{\text{teacher}}(\theta) = -\log(\pi_\theta(a_t^{\text{teacher}}|s_t))
    \]
    即最大化当前策略选择教师推荐动作的概率，使学生策略逐渐与教师策略对齐。
  - 蒸馏过程持续约 240 个 episodes，之后切换到仅由 RL 智能体独立决策。

- **提示工程（Prompt Engineering）**：
  - 不进行环境特定的 LLM 微调，而是采用**角色设定、零样本学习、规则语义、约束链式思维（constrained chain-of-thought scaffolding）**等手段优化提示词。
  - 提示中的信息被刻意限定为现实中防御者可获取的信息（排除特权模拟器状态和具体攻击 TTP）。
  - 使用正则表达式匹配动作，失败时用语义相似度兜底提取 LLM 推荐动作。

- **可迁移性评估**：
  - 构建 4 到 12 个主机的多种 CybORG 场景，只有蒸馏截止时间随网络规模调节，其余超参数和提示保持一致。

## 6. 主要结论与发现

- 经**提示工程优化的 LLM** 平均奖励约 70，比先前标准提示提升约 35%，且方差更小。
- **蒸馏后轻量 RL 智能体**在 2,000 episodes 内显著优于基线 PPO 和教师引导 RL；即便基线在 50,000 episodes 后偶有超越，也无法保持稳定，而蒸馏智能体始终表现稳定。
- 蒸馏智能体**跨场景迁移性较好**，在 4-12 主机规模下均保持稳定、低方差，仅 7 主机场中基线在约 700 episodes 后均值反超，但蒸馏智能体的方差始终更低，防御行为更稳健。
- **教师引导 RL 稳定化策略**（共 7 种）均无法持续超越优化后的教师策略，表明 CybORG 的环境奖励信号与教师防御策略之间存在**策略对齐限制**——即奖励驱动 RR 优化可能引导出与专家策略不同（竞争性/更脆弱）的防御行为。
- 总体证明：LLM 可作为 ACO 中防御策略的专家来源，策略蒸馏是将大型模型的防御能力实用化、轻量化、可扩展化的一条有效路径。

## 7. 优点

- **方法新颖且实用**：提出"提示工程 + 在线蒸馏"的完整流程，避免对环境进行繁重微调，同时达到显著的模型压缩效果（约 0.0008% 教师规模）。
- **系统化的可迁移性评估**：覆盖 4-12 个主机的多样网络拓扑，且所有场景中蒸馏智能体的标准误差远低于基线，说明方法鲁棒。
- **对教师-学生策略对齐问题进行了深入而系统的探讨**：通过 7 种稳定化策略的系统对比，提供了针对"为什么教师引导 RL 难以超越教师"的证据性分析。
- **完全可复现**：作者公开源代码、提示词、配置和实验设置于 GitHub 仓库。
- **推理效率优势明显**：蒸馏后模型仅为几万参数，适合资源受限环境部署，且初始阶段用动作掩码保证不因探索造成灾难性失败。

## 8. 不足与局限

- **环境真实性有限**：CybORG 仍是对真实网络的高度简化，未涵盖完整的企业网络噪声、网络延迟、误报、多变攻击模式等现实复杂性。
- **评价指标单一**：主要依据 CybORG 给出的标量奖励判断防御性能，未在攻击成功率、检测率、误报率、业务影响等操作指标上评估。
- **依赖单一教师**：框架从固定 LLM 策略中蒸馏，教师本身若存在幻觉或错误偏好，这些缺陷会传染给轻量学生智能体。
- **实验中存在冷特例**：7 主机场景中基线 PPO 在后期均值上超越蒸馏智能体，说明蒸馏策略并非所有拓扑上均最优，可能存在容量/拓扑不适配的情形。
- **对抗鲁棒性缺失**：未考虑对教师或学生智能体的对抗性攻击（如提示注入、观察扰动、毒化攻击），也未评估策略在对抗条件下的鲁棒性。
- **缺少算力细节**：未说明 LLM 推理和 RL 训练的部署环境与资源开销，难以评估实际工程落地成本。
- **教师引导稳定化实验揭示了限制而非解决方案**：作者承认未能通过任何策略实现超越教师，说明该方法体系距离"教师+自主优化"的高效闭环仍有差距。
