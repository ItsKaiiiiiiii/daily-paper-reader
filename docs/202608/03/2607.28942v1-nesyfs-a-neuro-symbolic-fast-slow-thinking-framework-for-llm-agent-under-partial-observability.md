## 摘要
近期，大语言模型（LLMs）越来越多地被部署为自主智能体，应用于自我反思、检索增强生成和科学发现等场景。在这些场景中，智能体必须基于有限的观察而非完整的环境状态进行决策，由此导致部分可观测性。这引入了几个关键挑战：信念状态推断、任务目标错位以及不确定性下的规划。现有方法通常基于完整或摘要式的动作-观察历史来决定动作，其中冗余和不相关的信息可能会误导LLM智能体的决策。受人类认知启发，我们提出了一种新颖的神经符号快慢思考（NeSyFS）框架，用于LLM智能体，以统一的方式解决部分可观测性带来的挑战。我们使用知识图谱（KG）来表示信念状态，为NeSyFS的每个模块提供三元组作为上下文。快思考模块执行反应式动作，而慢思考模块遵循扭转序列蒙特卡洛（TSMC）算法的高级结构，进行新的不确定性感知规划。为缓解任务目标错位问题，我们使用反思模块来反思快思考动作，并且在反应式动作反复失败时切换到慢思考模块。在三个代表性基准（即ALFWorld、Webshop和ScienceWorld）上的实验表明，我们相比现有方法具有显著优势。

## Abstract
Recently Large Language Models (LLMs) have been increasingly deployed as autonomous agents in applications such as self-reflection, retrieval-augmented generation, and scientific discovery. In these settings, agents must act based on limited observations rather than full environmental states, leading to partial observability. This introduces several key challenges: belief state inference, task objective misalignment, and planning under uncertainty. Prior approaches typically condition actions on full or summarized action-observation histories whose redundant and irrelevant information can mislead the decision making of LLM agent. Inspired by human cognition, we propose a novel neuro-symbolic fast-slow thinking (NeSyFS) framework for LLM agent, addressing the challenges introduced by partial observability in a unified approach. We use a knowledge graph (KG) to represent the belief state, providing triplets as context for every module of NeSyFS. The fast-thinking module performs reactive action, while slow-thinking conducts a new uncertainty-aware planning by following the high-level structure of twisted sequential Monte Carlo (TSMC) algorithm. To mitigate the misalignment of task objective, a reflection module is used to reflect fast-thinking actions, and also switches to the slow-thinking module whenever reactive actions repeatedly fail. Experiments on three representative benchmarks, i.e. ALFWorld, Webshop, and ScienceWorld, demonstrate significant advantages over previous methods.

### 2. 论文提出的方法论

#### 核心思想
NeSyFS 框架由**知识图谱（KG）记忆**、**快思考模块**、**反思模块**和**慢思考模块**四部分协同组成。KG作为环境潜在状态的结构化代理，为所有模块提供基于三元组的精简上下文。

#### 模块与技术细节

##### （1）记忆知识图谱（KG）
- 以三元组形式（实体-关系-实体、实体-属性-值/布尔、实体-过去时动词-实体）编码环境事实；
- 每步通过 `G_{t+1} = Update(G_t, o_t, a_t)` 进行更新，加入新三元组并剪除过时三元组，保持对隐状态的动态一致表征；
- 通过 `τ_t = R(G_t, η)` 按任务描述 η 检索相关三元组，作为各模块的上下文。

##### （2）快思考模块（Fast Thinking）
- 使用检索到的KG三元组 + 当前观察 + 任务描述，调用`P_fast`提示模板生成下一步反应式动作，公式为：
  `a_t = LLM(P_fast; R(G_t), o_t, η)`；
- 采用链式思维（CoT）推理，流程上与ReAct类似，但以结构化KG替代原始历史作为上下文。

##### （3）反思模块（Reflection）
- 采用**第三人称视角**验证快思考动作是否与任务目标一致，输出为二值 `Y_ref ∈ {Yes, No}`：
  `Y_ref = LLM(P_ref; a_t, o_t, R(G_t), η)`；
- 使用**自一致性（Self-consistency）**策略，采样 n=5 个结果，当80%以上为"Yes"才批准动作；
- 若被拒绝，将反思意见反馈给快思考模块重新生成动作；若连续 K=3 次被拒，则启动慢思考模块；
- 创新点：利用KG三元组实现**逐步（stepwise）粒度反思**，与传统的轨迹级反思相比更高效、更稳健。

##### （4）慢思考模块（Slow Thinking）——TSMC风格规划
- 这是论文的**核心创新算法**，将扭转序列蒙特卡洛（TSMC）框架引入LLM规划；
- 维持 N 个粒子，每个粒子表示为 `p_τ^i = (ô^i_{1:τ}, Ĝ^i_{1:τ}, â^i_{1:τ}, ω_τ^i)`（预测观察序列、KG状态序列、动作序列、权重）；
- 初始化：所有粒子从实际状态 `t_0` 出发，复制真实观察、KG和动作，权重设为1；
- **传播（Propagation）**：每个粒子依次预测下一步动作 `â_{τ+1} = LLM(P_fast; R(Ĝ_τ), ô_τ, η)`，预测观察 `ô_{τ+1} = LLM(P_obs; R(Ĝ_τ), â_{τ+1})`，进而更新KG得到 `Ĝ_{τ+1} = Update(Ĝ_τ, ô_{τ+1}, â_{τ+1})`；
- **权重更新（Weight Update）**：`ω_{τ+1} ← ω_τ · exp(λδ_{τ+1})`，其中 `δ_{τ+1} ∈ {0,1}` 由LLM基于二元反馈判断该状态转移是否有助于任务推进（`P_prog`提示模板）；
- **重采样（Resampling）**：按粒子权重比例概率性保留优质粒子、丢弃劣质粒子；
- 规划到达 H 步后，均匀随机抽取一个粒子的首个动作应用到真实环境；
- 优势：与MCTS等树搜索相比，能更好地处理状态不确定性，且被丢弃的粒子不会被进一步扩展，有效降低计算复杂度；重采样机制还能容忍LLM在任务进度判断上的偶发错误。

### 7. 优点

1. **统一框架**：以单一思想（神经符号 + 快慢系统）同时处置部分可观测性的三大挑战（信念推断、目标错位、不确定性规划）；
2. **知识图谱作为记忆的独创性**：以三元的结构化记忆替代完整历史或LLM摘要，在信息保留和去冗之间取得更好平衡，且适用于各类模块；
3. **TSMC引入LLM规划的创新性**：首次将扭转序列蒙特卡洛应用于LLM智能体规划，规避了MCTS类方法在状态不确定性下的脆弱性和高计算复杂度；
4. **LLM二元进度的容错设计**：不依赖LLM输出的对数概率，使用二进制反馈 + 重采样，使规划对LLM判断错误具有鲁棒性；
5. **高效反射机制**：反射仅以KG三元组为上下文，避免了引入长历史带来的噪声与成本；通过自一致性增强判断可靠性；
6. **计算效率控制**：仅在快思考连续失败时触发慢思考，避免过度规划开销；
7. **实验覆盖面较广**：涵盖三种不同性质的LLM、三大类文本环境、多种方法和消融组合，证据链较为完整。
