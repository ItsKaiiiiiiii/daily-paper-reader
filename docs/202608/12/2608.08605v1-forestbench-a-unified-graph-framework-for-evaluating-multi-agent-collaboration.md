## 摘要
基于大型语言模型（LLM）的多智能体系统（MAS）正在迅速普及，但其异构执行轨迹为跨方法评估提供了共同基础。仅基于结果的基准测试忽略了协作，而LLM作为评判者的评估需要额外的、依赖模型的推理，并且可能随LLM和评分标准而变化。我们引入了一个可推广的评估框架，将原生MAS轨迹映射到统一协作图的共享空间，使不同方法能够在相同的表示、参考集和指标面板下进行评估。候选图与查询特定的参考森林进行比较。每个森林是基准提供的已验证成功图的集合：它记录了代表性MAS方法完成任务的多种方式，而不是规定唯一的最优过程。将该框架实例化为ForestBench，我们从七个公共数据集中筛选出844个需要协作的查询，为每个查询预计算十个成功的、以目标为条件的参考图，并评估六个代表性的MAS框架。受控骨干网、参考构建和扰动研究测试了评估的稳定性和范围。一旦构建了基准森林，ForestBench即可在毫秒内对轨迹进行评分，无需进一步进行LLM推理，为比较不同的MAS协作轨迹提供了可复用的结构基础。

## Abstract
Multi-agent systems (MAS) built on Large Language Models (LLMs) are proliferating rapidly, but their heterogeneous execution traces provide no common basis for evaluation across methods. Outcome-only benchmarks discard collaborations, whereas LLM-as-Judge evaluation requires additional, model-dependent inference and can vary with the LLM and rubric. We introduce a generalizable evaluation framework that maps native MAS traces into a shared space of unified collaboration graphs, enabling different methods to be evaluated under the same representation, reference set, and metric panel. Candidate graphs are compared with a query-specific reference forest. Each forest is a benchmark-provided collection of verified-success graphs: it records diverse ways in which representative MAS methods can complete the task, rather than prescribing a unique optimal process. Instantiating the framework as ForestBench, we filter $844$ collaboration-necessary queries from seven public datasets, precompute ten successful target-conditioned reference graphs per query, and evaluate six representative MAS frameworks. Controlled backbone, reference-construction, and perturbation studies test the stability and scope of evaluation. Once the benchmark forests are built, ForestBench scores a trace in milliseconds without further LLM inference, providing a reusable structural basis for comparing diverse MAS collaboration traces.

- **研究背景**：基于大语言模型（LLM）的多智能体系统（MAS）发展迅速，成为复杂推理、软件工程和科学工作流的重要设计范式；但新框架层出不穷，评估能力严重滞后。
- **核心问题**：
  - **结果导向基准**（如 GSM8K、MMLU、HumanEval）只评分最终答案，丢掉了 MAS 最本质的“协作过程”；
  - **LLM-as-Judge** 需要额外的、模型相关的推理，成本高、结果随模型和评分标准变化，可复现性差；
  - 不同 MAS 的原生执行轨迹异构（事件模式、角色命名、通信协议不同），缺乏共同的“过程级”比较基础。
- **整体含义**：论文提出一种可泛化的评估框架，将所有 MAS 执行轨迹映射为统一的有向无环协作图，并与“查询特定的参考森林”对比，从而在统一的表示、参考集和指标面板下，对不同方法进行确定性、低成本、协作感知的水平评估。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 图抽象（Graph Abstraction）
- 每个 MAS 轨迹被投影为协作图：

  \[
  G(\tau) = (V, E, \phi)
  \]

  - \(V\)：每个原子动作一个节点；
  - \(E\)：动作之间的信息传递依赖边；
  - \(\phi\)：给节点标注执行者、标准角色（来自共享角色词汇表）和文本内容。
- 图天然是有向无环图（DAG），因为边只能指向时间上之后的信息消费节点。
- 该抽象刻意“有损”：丢弃框架特定的运行状态和精确墙钟交错，保留角色、动作和信息流；因此不同框架的轨迹可在同一结构空间内比较，且对动作重命名、并行动作顺序置换不变。

### 2.2 参考森林（Reference Forest）
- 一个任务可以有多种成功协作模式（辩论、流水线、peer swarm），因此参考不应是单一“金标准”树，而是一个**森林**：

  \[
  F(q) = \{(G_k, q_k)\}_{k=1}^{K(q)}
  \]

  - 每个 \(G_k\) 是从代表性范式采样到的“已验证成功”参考图；
  - 每棵参考树附带分数 \(q_k\)，结合正确性、结构简洁性和 token 成本；
  - 森林是基准发布的“参考资产”：新轨迹只与固定森林比较，无需重新生成参考。

### 2.3 评估度量（Graph-based Evaluation）
- **两图相似度**：

  \[
  \text{sim}(G, G') = \alpha s_{\text{node}} + \beta s_{\text{edge}} + \gamma s_{\text{topo}}
  \]

  - 默认权重 \((0.4, 0.4, 0.2)\)；
  - \(s_{\text{node}}\)：规范角色多重集合的 Jaccard 相似度；
  - \(s_{\text{edge}}\)：角色类型化边指纹集合的 Jaccard 相似度；
  - \(s_{\text{topo}}\)：图规模匹配度（节点数和边数的比值综合）。
- **Forest Match（FM）**：对候选图与森林中各参考图的相似度做加权平均，权重为归一化的参考质量分数，衡量候选图与整个成功结构集合的“森林级对齐”。
- **Best Similarity**：与森林中最接近单棵参考树的最大相似度。
- **辅助指标面板**：
  - **Node Validity**：被下游行动消费的节点比例；
  - **Mean Uptake**：下游内容对上游内容的语义采纳比例（基于 embedding 余弦相似度阈值）；
  - **Content Redundancy**：内容去重后的重复率；
  - **Tokens**：总消耗 token 数；
  - **Efficiency**：拓扑效率（每个活跃智能体的并行度）。
- 所有指标都是图结构的确定性函数，**不需要额外 LLM 推理**，单条轨迹毫秒级评出。

### 2.4 算法流程
- **数据收集**：从七个公开数据集汇集原始查询池 \(Q_0\)。
- **查询过滤（TSP）**：对每个查询用强 LLM 按三个维度打分：
  - 深度 \(d(q)\)：至少需要的推理步数；
  - 宽度 \(w(q)\)：所需能力的多样性（8 种能力的归一化熵）；
  - 可分解性 \(\delta(q)\)：是否可拆成独立子任务；
  - 阈值为 \((\theta_d, \theta_w, \theta_\delta) = (5, 0.5, 0.5)\)，保留 844 个查询。
- **参考森林构建**：用六种代表性 MAS 框架（Debate、Swarm、AutoGen、MetaGPT、MAS-GPT、AFlow）对每个查询采样、以目标答案 \(a^*\) 为条件生成成功轨迹，每个查询保留 10 个已验证成功的参考图，共 8,440 个参考图。
- **新候选评估**：运行候选方法 → 适配器把原生轨迹解析为统一事件流（agent_message、tool_call、decision）→ 投影为协作图 → 映射角色到共享词表 → 与预计算参考森林计算指标。

## 6. 主要结论与发现

- **纯准确率区分度很弱**：六个框架准确率仅 0.531–0.569（跨度 0.038），但 Forest Match 范围 0.316–0.421，结构信号明显更有区分度。
- **结构面板揭示结果掩盖的差异**：Debate 准确率最高但 Forest Match/Best Similarity 最低；AFlow 内容冗余高；Swarm 是唯一 Node Validity < 1 的框架。
- **参考森林具有稳定性**：跨骨干排序完全一致（Kendall/Spearman = 1.00）；held-out 生成器消融中 Top-3 在 6/7 设置保留；开放条件构建基本保持 Top-3 顺序。
- **指标分工明确**：结构扰动稳健地降低 Forest Match；重复内容注入不改变 Forest Match、但被 Content Redundancy 捕捉；拓扑单独权重会破坏角色/通信语义，导致排序变化。
- **失败模式可分离**：失败可分为“结构失效”（角色缺失、固定模式不匹配任务）和“内容错误”（求解器/验证器引入错误内容），对应不同修复方向。
- **编排收益取决于骨干**：相对于单智能体 CoT 基线，平均编排增益在 DeepSeek-V4 约 -0.002，GPT-5.5 约 -0.039，Claude-S4.6 约 -0.069；更强骨干下平均增益为负，说明“加智能体”并非普遍有益。
- **领域专业化存在**：Debate 在全局最差，但在 SWE-bench-Verified 上反而最好（因为其 review-and-revise 模式更匹配代码补丁任务），说明应结合源级分析做方法选择。
- **成本优势显著**：构建完成后评估新轨迹无需额外 LLM 推理，毫秒级完成，比 LLM-as-Judge 快约三个数量级。

## 7. 优点

- **统一的图表示**：把异构 MAS 轨迹规范成共享的 DAG 结构，真正支持跨框架、跨骨干的水平比较。
- **参考森林而非单一参考**：允许多种成功协作范式共存，避免“单模板偏爱”，更贴合实际任务多样性。
- **完全确定性的评估指标**：不依赖额外 LLM 推理，可复现、可扩展，且支持毫秒级在线评估。
- **基准资产可复用**：预计算并发布 844 个查询的参考森林（8,440 个参考图）与适配器，新方法可直接使用，避免重复构建。
- **严谨的受控实验**：跨骨干、held-out 生成器、阈值网格、扰动注入、权重敏感性等设计系统性地验证了指标的稳定性和行为边界。
- **结果与过程解耦**：保留 Accuracy 作为结果度量，同时用结构指标刻画“如何完成”，互补性强。
- **面向实用诊断**：通过结构 vs 内容失败拆分，为不同框架给出具体修复方向，而非仅仅给出排名。

## 8. 不足与局限

- **参考森林构建成本高**：一次性 token 消耗约 20.5M，虽可摊销，但对小团队仍是门槛。
- **评价范围受限**：Forest Match 度量的是与参考森林的结构对齐，而非“绝对协作质量”；参考森林基于特定骨干和生成器，可能偏向某些范式。
- **条件化参考构建可能引入偏差**：以目标答案 \(a^*\) 为条件生成参考轨迹，虽保证正确性，但可能忽略未采样到的其他成功路径。
- **辅助指标依赖角色/内容语义**：角色规范化依赖逐框架 alias 表；Mean Uptake 使用固定 embedding 阈值，跨领域语义可能有差异。
- **LLM 诊断标签脆弱**：论文承认 LLM-as-judge 的 fine-grained 标签对 rubric 和法官模型敏感，因此只用于粗粒度修复方向，不适合直接作为评分。
- **论文未提供具体 GPU 算力信息**（型号、数量、训练时长），复现时资源评估存在不便。
- **框架覆盖有限**：只评估了六个 MAS 框架，未覆盖所有最新范式；查询池也仅为 844 条，且部分数据集的原始题目因过滤被大量删减。
- **同源 LOO 虽降低偏差，但无法完全消除**：候选框架的训练/架构差异与参考生成器的耦合仍可能影响比较公平性。
