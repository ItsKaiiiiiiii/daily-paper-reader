## 摘要
AI智能体越来越多地在系统内运作，这些系统管理着它们如何委派任务、传递信息、执行行动以及使用共享资源。近期研究已经表明，部署规则可以改变集体行为。在此，我们探究AI制度的哪些部分能产生安全性，以及它们是如何实现的。这是POLIS的首篇论文，POLIS是一项正在进行的研究计划，旨在研究多智能体系统的算法制度。我们报告了一个固定的5,280场次研究套件。主要的预先指定委派实验跨越四个模型家族；一个针对性的高冲突诊断增加了三个额外的模型端点。在匹配的结构化工作流程中，模型会看到不同的规则表述，而守卫会咨询不同的权威状态。我们还改变了即时合规的内部/自身回退的吸引力，并允许受阻的工作流程继续。一个详细的宪法性提示产生了0/384的实际违规。一个具有来源感知的可执行守卫也产生了0/384，尽管它在51/384场次中阻止了被禁止的尝试；其中51场次中的44场后来安全完成。局部状态守卫的失败集中在原始转换改变可见策略而来源权威保持不变的场景中。在匹配的洗钱场景中，该守卫在22/96场次中允许违规，而来源执行在0/96中允许违规（p = 4.77 x 10^-7）。一个独立的资源分配实验表明，揭示原本相同上限的数值会改变智能体的请求。在这些结构化工作流程中，相同的最终违规率可能隐藏着非常不同的机制。规则本身只是制度的一部分。系统所信任的权威状态很重要，阻止后可用路径也很重要。

## Abstract
AI agents increasingly work inside systems that govern how they delegate tasks, move information, execute actions, and use shared resources. Recent work already shows that deployment rules can change collective behavior. Here we ask which parts of an AI institution produce safety and how they do it. This is the first paper from POLIS, an ongoing research programme studying algorithmic institutions for multi-agent systems. We report a frozen 5,280-episode study suite. The main pre-specified delegation experiment spans four model families; a targeted high-conflict diagnostic adds three additional model endpoints. In matched structured workflows, the model sees different rule formulations and guards consult different authority states. We also vary the attractiveness of the immediate compliant internal/self fallback and allow blocked workflows to continue. A detailed constitutional prompt produces 0/384 realized violations. A provenance-aware executable guard also produces 0/384, although it blocks prohibited attempts in 51/384 episodes; 44/51 of those episodes later complete safely. The local-state guard's failures concentrate in scenarios where an ordinary transformation changes visible policy while originating authority stays fixed. In matched laundering scenarios, that guard admits violations in 22/96 episodes and provenance enforcement in 0/96 (p = 4.77 x 10^-7). A separate resource-allocation experiment shows that revealing the numerical value of an otherwise identical cap changes agent requests. In these structured workflows, the same final violation rate can hide very different mechanisms. The rule itself is only part of the institution. The authority state the system trusts matters, and so does the path available after a block.

# 论文总结：多智能体AI安全作为制度设计问题

## 1. 核心问题与整体含义

- **研究背景**：AI智能体越来越多地运行于管理任务委派、信息流转、行动执行和资源共享的制度化系统中。已有的多智能体对齐研究开始将部署规则视为影响集体行为的关键变量，但“究竟制度中的哪一部分产生安全性、如何产生”仍不清楚。
- **核心问题**：本文旨在以实验方式解析AI制度（algorithmic institution）中影响安全的机制，特别是：
  - 规则信息如何传达给模型；
  - 执行机构信任的是哪种“权威状态”（可见策略 vs. 不可变来源权限）；
  - 执行阻塞后是否保留可恢复的合规路径。
- **整体含义**：安全不仅仅是“规则文本”或“可执行守卫”的单一问题，而是由规则表述、权威状态、执行位置和阻塞后路径共同构成的制度设计问题。相同的最终违规率可能由完全不同的机制产生，因此单一安全指标不足以评估AI制度。

## 2. 方法论

- **核心思想**：将多智能体AI安全视为“机构设计”问题，通过结构化、可控的工作流实验，分离不同制度组件（信息、执行状态、恢复机制）对安全结果的影响。
- **实验环境**：
  - **委派环境**：三角色工作流（Agent A 规划者/初始控制者；Agent B 内部合规专家；Agent C 外部高风险专家）。受限工件受“根策略”（root policy）约束：未经授权禁止跨主体转移（Alpha→Beta）。
  - **动作语言**：委派、转换、审批、拒绝；每集至多6步；被拒绝的动作不终止，模型保留控制权以继续选择。
  - **制度处理**：六种治理制度，包括无制度、简明提示、宪法提示、来源提示、本地守卫、来源守卫。关键在于：
    - 模型看到的规则信息不同；
    - 可执行守卫所依据的权威状态不同（本地可见策略 vs. 不可变来源权限）。
  - **场景类型**：安全内部路线、直接禁止路线、转换洗钱、授权清洗，用于区分合规路径、普通违规和结构性权限升级漏洞。
  - **压力水平**：通过降低内部/自身回退的收益（10→8→5→2）模拟优化压力。
- **结果判定**：由**确定性环境**判定动作是否执行以及是否产生实际违规，而非由模型自行判断，从而分离“行为预防”（不提出违规提议）与“机械遏制”（提出违规但被阻止执行）。
- **统计模型**：线性概率模型（实际违规 ~ 治理×压力 + 模型 + 领域 + 场景类型），基于场景聚类鲁棒标准误；匹配对检验使用配对Bootstrap；洗钱对比使用精确配对检验。

## 3. 实验设计

- **研究套件**：POLIS v2.0.8 冻结协议，共 **5,280 个实验场景（episodes）**，分为5个子研究：
  1. **委派主研究**（2,304 episodes）：跨6个领域、4个压力水平、4个场景类型、6种治理制度。
  2. **措辞稳健性研究**（1,152 episodes）：等价措辞变体。
  3. **角色分配诊断**（576 episodes）：不同模型在各角色上的配置，但只有规划者Agent A产生模型动作。
  4. **附加模型诊断**（288 episodes）：用额外3个端点（Qwen3 235B A22B Instruct 2507、Claude Sonnet 4.5、GPT-4.1）复现高冲突场景。
  5. **资源公用研究**（960 episodes）：独立的资源分配实验，考察信息显著性（上限可见与否）对请求行为的影响。
- **模型范围**：主研究使用4个模型族——Gemini 2.5 Flash-Lite、Mistral Small 4、GPT-4.1 Mini、DeepSeek V3.2；温度0，512 token输出限制，禁用DeepSeek推理模式。
- **对比制度**：无制度、简明提示、宪法提示、来源提示、本地可执行守卫、来源可执行守卫；重点对比宪法提示（信息丰富、无机械限制）vs. 本地守卫（机械限制但信任可变状态）vs. 来源守卫（机械限制且信任不可变来源）。

## 5. 实验数量与充分性

- **实验数量**：总计 5,280 个冻结场景，主研究每种治理制度含384个场景，洗钱场景匹配对为96对，附加模型诊断为288个场景，资源公用实验为960个场景。
- **充分性评估**：
  - **优点**：实验设计具有高控制度，匹配场景保证仅特定变量变化；多种诊断（措辞、角色分配、额外模型）增加了结论的稳健性；使用了精确配对检验，关键结果具有极低p值（p = 4.77×10⁻⁷）。
  - **不足**：模型覆盖面有限（主研究仅4个模型族，附加诊断仅3个额外端点）；某些关键单元格（如DeepSeek的洗钱行为）样本较少；0违规的低上限约束（如0/384的Wilson 95%上限约0.99%）；角色分配诊断因委派终止设计未能测试真正的异质多智能体交互；后验发现的GPT-4.1 Mini福利效应仅为探索性结果。

## 6. 主要结论与发现

- **压力确实改变行为**：无制度条件下，压力每升一级，实际违规率提高6.46个百分点；压力级3时原始违规率达20.8%。
- **不同制度产生不同机制**：
  - **宪法提示**：0/384实际违规，且无违规尝试（行为预防）。
  - **来源守卫**：0/384实际违规，但阻止了51/384个被禁止尝试；其中44/51个受阻塞后安全恢复（机械遏制）。
  - **本地守卫**：22/384实际违规，全部发生在转换洗钱场景中（22/96匹配洗钱场景）。来源执行则为0/96，配对检验p=4.77×10⁻⁷。
- **模型依赖性显著**：DeepSeek V3.2贡献了本地守卫18/24的洗钱违规；Mistral有4个；Gemini和GPT-4.1 Mini为0。
- **可恢复性**：来源守卫阻塞后，86.3%的受影响场景安全恢复并完成任务；本地守卫只有68.8%恢复，且8/32被阻塞场景最终仍违反。
- **信息资源具有独立影响**：资源公用实验中，揭示同样数值上限（30）显著增加恰好请求30的倾向（自利目标下+2.73百分点，社会福利目标下+5.47百分点）；添加“只请求实际需要”的规范后，该效应消失。
- **核心论点**：相同最终违规率的背后可能隐藏不同的安全机制；制度设计需要同时关注规则表述、权威状态、执行位置和阻塞后恢复路径。

## 7. 优点

- **机制解析性强**：通过匹配工作流，分离了“信息变化”与“机械约束变化”对安全的影响。
- **确定性结果裁判**：由确定性环境判定执行与违规，避免依赖模型自我报告，提高结果可靠性。
- **可恢复性测量**：设计允许阻塞后模型继续行动，从而测量制度是否保留有用工作，而不仅仅是单纯阻止违规。
- **清晰的场景设计**：洗钱场景专门构造了“可见策略可变但根策略不可变”的漏洞，能够精确测试执行机构信任何种状态。
- **预注册与冻结协议**：设计在典型分析前固定，并经过审计，提升可复现性。
- **跨模型诊断**：多个模型族覆盖，并附加高冲突诊断，增强外部有效性。

## 8. 不足与局限

- **环境简化**：委派环境只有六个领域、四类场景、有限动作集和至多六步；资源公用只有单轮交互，不能代表真实部署复杂度。
- **多智能体范围受限**：委派任务中成功委派即终止，不激活下游模型，因此不能评估多模型交互效应；角色分配诊断仅测试规划者身份敏感性。
- **无法隔离单一变量**：宪法提示与本地守卫在信息内容和执行架构上都有差异，无法区分语言效果与代码效果；作者也承认需要后续析因设计。
- **守卫机制披露偏差**：本地守卫被明确告知检查可见策略，这可能诱导模型主动利用漏洞；隐藏机制的消融未被测试。
- **模型覆盖不足**：仅四种主模型和三种附加模型，且DeepSeek的洗钱行为占主导，跨模型泛化需要更多证据。
- **统计上限**：0违规计数仍允许非零真实风险；一些单元格结果恒定，标准误不可估计，只能描述性报告。
- **后验发现未预注册**：GPT-4.1 Mini在社会福利目标下的效率下降结果属于事后识别，只能作为假设，不能作为已证结论。
