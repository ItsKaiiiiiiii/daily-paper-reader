## 摘要
基于LLM的多智能体系统（MAS）通过协调多个智能体在复杂推理任务上取得了强劲性能，但代价是大量的令牌消耗。最近关于自动拓扑设计的工作ARG-Designer将此问题重新表述为自回归图生成。然而，其训练目标没有为模型生成稀疏且高效的拓扑提供明确激励。我们通过引入受人类反馈强化学习（RLHF）启发的奖励引导自回归图生成（RGA-Designer）来解决这一限制。我们训练了一个奖励模型，联合捕捉任务正确性和结构紧凑性，然后使用奖励模型作为反馈对预训练图生成器进行微调。我们的方法在保持ARG-Designer水平上的任务准确性的同时，平均减少了20.5%的令牌消耗。

## Abstract
LLM-based Multi-Agent Systems (MAS) achieve strong performance on complex reasoning tasks by coordinating multiple agents, but at the cost of substantial token consumption. Recent work on automatic topology design, ARG-Designer, has reframed this problem as autoregressive graph generation. However, its training objective provides no explicit incentive for the model to generate sparse and efficient topologies. We address this limitation by introducing a Reward-Guided Autoregressive Graph Generation (RGA-Designer) inspired by Reinforcement Learning from Human Feedback (RLHF). We train a reward model that jointly captures task correctness and structural compactness, and then fine-tune the pretrained graph generator using the reward model as feedback. Our method preserves task accuracy at the level of ARG-Designer while reducing token consumption by an average of 20.5%.

## 2. 方法论

### 2.1 核心思想

提出 **RGA-Designer（Reward-Guided Autoregressive Graph Generation）**，受 RLHF 启发，构建一个**图级奖励模型**，联合评估生成图的两个维度——**任务是否正确完成**、**结构是否紧凑**——并以此奖励信号微调预训练的自回归图生成器，使其倾向生成稀疏但功能完整的拓扑。由于图质量可通过程序化执行验证，作者用规则化的自动奖励替代人工标注，属于**RLVR（Reinforcement Learning with Verifiable Rewards）** 框架。

### 2.2 整体流程（三阶段，外加预训练前置阶段）

1. **阶段 0：预训练生成器**——继承 ARG-Designer 的自回归图生成器，该生成器逐步采样节点角色和边。
2. **阶段 1：数据集收集**：
   - 使用预训练 ARG-Designer 以不同采样温度生成候选图，并执行验证其任务完成情况；同时融入 ARG-Designer 训练过程中已有的图/查询对（零额外成本）。
   - 样本表示为三元组 \((G_i^{(n)}, q^{(n)}, r_i^{(n)})\)，其中奖励 \(r\) 由公式 (8) 计算：
     \[
     r = \lambda_c c + \lambda_V \max(0, \frac{V_{\max} - |V|}{V_{\max} - 1}) + \lambda_E \text{clip}\left[0,1\right]\left(\frac{E_{\max} - |E|}{E_{\max} - E_{\min}}\right)
     \]
   - 权重设为 \(\lambda_c = 0.6\)（正确性优先）、\(\lambda_V = 0.3\)、\(\lambda_E = 0.1\)，保证**正确性优先于稀疏性**。
   - 构造偏好对：每对必须至少有一个成功样本，且奖励差 > 阈值 δ=0.05。
3. **阶段 2：奖励模型训练**：
   - 奖励模型为 **GraphSAGE** 图神经网络，节点特征由角色嵌入、查询嵌入（均为 384 维，来自 MiniLM）和 5 维结构特征拼接而成。
   - 图编码经两层 GraphSAGE + 残差 + LayerNorm，全局平均池化后经 MLP 输出标量奖励。
   - 使用 **Bradley-Terry 成对排序损失**训练；对 pass/pass 对设置较低权重（0.1），pass/fail 对权重为 1.0，以平衡信息量。
4. **阶段 3：策略优化**：
   - 采用 **GRPO（Group Relative Policy Optimization）** 的 on-policy 变体。
   - 每组内奖励归一化得到优势函数 \(\hat{A}_i\)（公式 14）。
   - 优化目标（公式 15）包含两个项：最大化优势信号 + KL 正则（与参考模型 \(\pi_{\text{ref}}\) 保持接近，β=0.2）。

### 2.3 关键优势

- 奖励模型在**嵌入空间**打分，可跨数据集复用，支持**未见过的角色**；而 ARG-Designer 的节点生成器对新角色需扩展分类头并重新训练。
- 推理时采用 **Best-of-N（N=5）** 选择奖励最高的拓扑，采样与评分均由轻量图模型完成，开销可忽略。

## 6. 主要结论与发现

- **token 消耗显著降低**：相比 ARG-Designer，RGA-Designer 平均减少 **20.5%** token 消耗（3815 → 3032 tokens），在 6 个基准中 **5 个显著降低**（p < 0.05）。
- **准确率保持**：与 ARG-Designer 相比，准确率无统计显著的下降；在 GSM8K、HumanEval 上略有提升。
- **MultiArith 例外**：token 减少未达显著水平。原因：MultiArith 为模板化数据集，问题结构简单，本就可用小拓扑解决，缺乏冗余可压缩。
- **消融验证**：完整方法 token 消耗最低；移除奖励模型或 BoN 均导致 token 增加（如 MMLU 上 w/o BoN 比 Full 多 30.5% token）。
- **额外收益**：全局奖励模型可跨数据集共享，支持新角色，无需重新训练生成器。

## 7. 优点
