## 摘要
我们提出了Eureka，一种任务条件化的元智能体架构，它将长时程任务编译为具有显式接受语义的动态义务图。在执行过程中，Eureka通过滚动时域规划、架构提升和最小充分编译，形成具有专门化状态、记忆、算子、工具、验证器和局部拓扑的宏智能体。当瓶颈重复出现时，成本效益门控的演化在约束条件下更新局部架构。理论上，我们建立了关于遗憾、规划失效、摊销、子树接口、可串行化和验证的结果。实验上，Eureka完成了170/170个递归任务，并生成了3,948个证书，且无错误接受。主动上下文将中位输入从9,490个token压缩至4,005个token；增量处理在12,000个任务中避免了65.38%的重复计算；16,000个并发执行保持一致的可串行化。同一个元智能体实例化了一个理论发现智能体和一个数学/猜想智能体。前者在量子过程和时空理论方面产生了结构性结果。后者识别了黎曼猜想研究中的瓶颈，并将Suzuki局部Weil二次型的正性证书推进到0 < a <= 69/200 = 0.345，达到(log 2)/2的约99.55%。这些结果表明，科学智能体的能力不仅取决于基础模型，还取决于能否形成与任务认知结构相匹配的架构。

## Abstract
We present Eureka, a task-conditioned Meta-Agent architecture that compiles long-horizon tasks into dynamic obligation graphs with explicit acceptance semantics. During execution, Eureka forms Macro-Agents with specialized state, memory, operators, tools, verifiers, and local topology via receding-horizon planning, architecture promotion, and minimal-sufficient compilation. When bottlenecks recur, cost-benefit-gated evolution updates the local architecture under constraints. Theoretically, we establish results on regret, planning invalidation, amortization, subtree interfaces, serializability, and verification. Experimentally, Eureka completes 170/170 recursive tasks and generates 3,948 certificates with no false acceptances. Active context compresses median input from 9,490 to 4,005 tokens; incremental processing avoids 65.38% recomputation across 12,000 tasks; 16,000 concurrent executions serialize consistently. The same Meta-Agent instantiates a Theory-Discovery Agent and a Math/Conjecture Agent. The former yields structural results in quantum-process and spacetime theory. The latter identifies bottlenecks in Riemann Hypothesis research and advances a positivity certificate for Suzuki's localized Weil quadratic form to 0 < a <= 69/200 = 0.345, reaching ~99.55% of (log 2)/2. These results suggest that scientific-agent capability depends not only on the base model but on whether an architecture can be formed to match the task's cognitive structure.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心架构：任务条件化元智能体（Task-Conditioned Meta-Agent）

Eureka 将长时程任务编译为**动态义务图（Dynamic Obligation Graph）**，并在此基础上动态形成、运行和演化任务专用的宏智能体（Macro-Agent）。其核心流程为：

1. **动态义务图编译**：任务被编译为节点（义务）和边（依赖）构成的图，每个节点携带五类信息：目标语义、前置依赖、持久状态读集、状态写集和接受契约（Acceptance Contract）。
2. **滚动时域规划（Receding-Horizon Planning）**：只展开当前信息能够可靠确定的任务图部分；未解决的未来工作以延迟义务的形式保留，并带有明确的信息边界。规划由"就绪前沿"（ready frontier）的**反压**（backpressure）机制驱动：当可执行工作充足时暂停规划，枯竭时重新激活。
3. **宏智能体提升（Architecture Promotion）**：当执行轨迹暴露出"架构热点"（持续状态共享、高依赖密度、算子/验证器复用等）时，Eureka 评估本地自主性是否能降低长期协调和状态重建成本，并基于**摊销阈值**（推广成本 < 单次服务节省 × 预期服务次数）决定是否提升。
4. **最小充分架构编译（Minimal Sufficient Architecture Compilation）**：将提升的子图编译为组件选择问题，在满足需求覆盖、前置约束和不兼容约束的前提下最小化组件安装成本。
5. **子树 ABI 接口**：宏智能体内部复杂度被封装在本地子树中，父编排器仅通过类型化的子树接口观察导出的产物、显式假设、未解决债务和重开条件。论文证明了若压缩满足**决策充分性**条件，父级可以看到完整轨迹与只看到 ABI 时的最优决策值相同。
6. **有治理的演化（Governed Evolution）**：当遥测数据表明反复出现的瓶颈在剩余时间范围内足以摊销诊断、评估和迁移成本时，Eureka 在显式约束下对局部架构进行受控修改。演化被建模为一种规划动作，需要满足成本-收益门控条件 $\mathcal{C}_{m}^{\mathrm{evo}} < \gamma_m \mathbb{E}[N_S | \mathcal{F}_t]$。
7. **并发与验证语义**：并发租约通过完整的读写集冲突检测实现乐观可串行化；证书以追加式账本形式保存，依赖失效时通过显式传播机制撤销，不会被未经验证的自然语言输出静默覆盖；验证采用三值语义（PASS / FAIL / INCONCLUSIVE）。

### 关键理论结果（节选）

- **Theorem 1（固定架构遗憾下界）**：若两个任务的近最优架构集合不相交，则任何固定架构在至少一个任务上有正的平均超额成本。
- **Theorem 3（递归分解可靠性）**：在每个非叶节点满足组合可靠性条件、叶验证器可靠的前提下，自底向上的组合确保根工件满足根语义。
- **Theorem 4（宏智能体推广摊销阈值）**：推广条件为 $\mathcal{F}_S < \delta_S \mathbb{E}[N_S | \mathcal{F}_t]$，即在相同可靠性约束下，推广后的期望总成本严格更低。

- **架构-任务认知结构匹配是关键变量**：同一 Eureka 元智能体在两种截然不同的认知结构下形成了两个结构相异的专用科学智能体——Theory-Discovery Agent（围绕假设-证据交互、独立证伪、理论一致性）和 Math/Conjecture Agent（围绕事实-断⸻证明依赖、持久证明状态、精确验证路由）。这验证了"智能体能力不仅取决于底层模型，还取决于能否形成和维持与任务认知结构匹配的架构"这一核心论点。
- **系统级可靠性**：Eureka 在所有递归长时程任务上零失败，无未认证接受和假终结态；并发执行全部与合法串行执行一致；增量依赖处理避免了 65.38% 的重复计算；编译后的主动上下文将模型输入 token 从 9,490 压缩至 4,005（降低 57.8%）且不改变成功率。
- **有治理演化优于无条件演化**：Governed Evolution 在四种演化策略中同时取得最低中位总成本（2525.4）和最高成功率（60.55%）。EvolutionLease 将演化往返次数从 12 次降至 4 次（减少 66.7%）。
- **成本感知的延迟推广优于复杂度驱动推广**：Eureka 推广策略的假推广率仅 0.04%，中位执行成本与成本最优参考仅差 0.64%。
- **数学前沿推进**：在黎曼猜想方向上，将 Suzuki 局部 Weil 二次型的正性证书候选从 $a \le 1/4$ 扩展至 $0 < a \le 69/200 = 0.345$（1.38 倍范围扩展，达到首个素数阈值的 99.55%）；跨过首个素数阈值的边界交换吸收条件约为 $a \le 0.3871392153$。作者明确声明这不是黎曼猜想的证明，也不构成临界线上零点比例的新纪录。
- **理论结构发现**：产生了五个结构性结果，其中 QSOST 全秩胶合候选具有明确的参数（$t=1/2$、$65/16 > 4$ 严格间隙），但需要外部或正式审查。
- **理论预测与实验一致**：滚动时域规划、推广摊销、信息充分上下文、增量重建、安全并行合并、有治理演化、接受保持递归和结构驱动专业化等理论结果均获得实验支撑。

## 7. 优点

- **理论先行且严谨**：论文建立了大量可验证的形式化定理（固定架构遗憾下界、规划失效阈值、递归分解可靠性、推广/演化摊销条件、子树接口决策充分性、并发可串行化、评估信息隔离等），且明确列出了每个定理的适用条件和失败模式——这一点在现有智能体系统论文中不常见。
- **"架构即优化对象"的视角**：将智能体架构设计从预先固定的人工选择提升为执行期间动态发现和治理的对象。这与近期 ADAS、AFlow、MaAS 等工作一致，但 Eureka 将架构形成嵌入长时程义务执行轨迹中，统一了任务分解、边界发现和智能体合成。
- **统一的验证基础设施**：两个结构不同的科学智能体通过相同的类型化义务、本地接受收据和合并契约与父层交互，既保持架构差异，又不碎片化验证体系。
- **多层次的实验设计**：从系统效率、架构消融、鲁棒性到科学发现输出逐层递进；每个消融都保持任务目标与接受契约不变，排除了"降低验证标准换取效率"的混淆。
- **诚实的边界声明**：论文明确区分"经过独立形式验证的数学声明"与"方向正确的证书候选"；对黎曼猜想结果明确声明不是证明、不是零点比例新纪录；对理论发现成果声明需要外部审查。
- **可证伪的理论预测**：论文给出了一系列可直接实验检验的推论（如匿名化保持架构输出不变、密封评估器变更不改变冻结前轨迹哈希、迟滞宽度增大降低切换次数等）。

## 8. 不足与局限

- **算力与模型信息缺失**：未披露 GPU 规格、数量、训练/推理耗时、总 token 消耗等关键资源信息，导致成本可复现性和效率比较的基准不完整。
- **科学结果未经独立验证**：黎曼猜想方向的 Weil 正性证书和理论发现方向的 QSOST 胶合候选均未经过独立的形式化证明重放或外部专家审查；后者还是"开放问题的解决方案候选"而非已确立结论。
- **理论发现结果的深度问题**：五组理论结构结果中，除 QSOST 胶合候选外，其余（零扇形解耦、作用集正规形式、等价分离、操作签名）更多是"结构重构和元理论进展"，其物理普遍性和理论深度需要后续验证。
- **基线覆盖面有限**：系统层面与单点基线（如 LLMCompiler、ADaPT、AgentSquare 等）进行了概念对比，但缺乏在统一实现框架下的直接数值基准对比；实验以自建任务为主，没有在标准多智能体基准（如 GAIA 或类似任务集）上与现有系统进行横向比较。
- **重命名不变性证据的潜在局限**：5,000 个实体重命名测试证明了 Eureka 在结构保持条件下不依赖任务名，但现实任务中"结构等价"通常被表面命名差异掩盖，实际映射何时成立仍有模糊空间。
- **规划策略的 k 数局限**：虽然 Eureka 的滚动时域规划取得了最低规划成本，但其外层往返次数（9 次）相比 Streaming without Backpressure（6 次）更多，说明其优势来自"避免无效计划"而非"减少控制调用"；这一权衡需要更广泛的任务分布才能充分验证。
- **推理成本与并发增益的权衡**：论文报告了并发执行对处理延迟的改善，但没有报告并发租约串行化/重试开销、锁竞争或死锁恢复等潜在成本。
- **单机构建与独立复现门槛**：Eureka 涉及大量运行时组件（动态义务图、遥测、演化预算、证书账本、并发验证等），实现复杂度高，外部复现成本大。
