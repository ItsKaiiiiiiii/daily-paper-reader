## 摘要
共享自主性需要原则性机制来分配和转移人类与自主代理之间的控制权。现有方法通常依赖于混合控制输入或启发式切换规则，这些方法缺乏理论保证，且未能考虑权威转移的动态特性。本文开发了一个用于共享自主性中权威切换的合作博弈论框架。我们将控制切换问题建模为一个同利益动态博弈，其中权威转移被嵌入系统动态中，从而产生最优切换策略而非临时规则。我们在随机人类干预下建立了纯策略团队最优策略的存在性和特征化，并考虑了人类保留干预能力的不对称权威。对于线性二次系统，我们推导了最优切换策略和值函数的闭式递推关系，使得计算能够独立于连续状态高效进行。我们在标量和多维线性系统上验证了该框架，展示了最优切换如何适应变化的系统动态、成本结构和干预概率。结果揭示了人类适应性与自主效率之间的基本权衡，说明了将共享自主性植根于合作博弈论的实际益处。

## Abstract
Shared autonomy requires principled mechanisms for allocating and transferring control between a human and an autonomous agent. Existing approaches often rely on blending control inputs or heuristic switching rules, which lack theoretical guarantees and fail to account for the dynamics of authority transfer. This paper develops a cooperative game-theoretic framework for authority switching in shared autonomy. We formulate the control switching problem as an identical-interest dynamic game in which authority transitions are embedded into the system dynamics, yielding optimal switching policies rather than ad hoc rules. We establish the existence and characterization of team-optimal policies in pure strategies under stochastic human override, accounting for asymmetric authority where humans retain override capability. For linear-quadratic systems, we derive closed-form recursions for the optimal switching policies and value functions, enabling efficient computation independent of the continuous state. We validate the framework on scalar and multi-dimensional linear systems, demonstrating how optimal switching adapts to varying system dynamics, cost structures, and override probabilities. The results reveal fundamental trade-offs between human adaptability and autonomous efficiency, illustrating the practical benefits of grounding shared autonomy in cooperative game theory.

## 1. 论文的核心问题与整体含义

### 研究动机与背景

- **问题定位**：共享自主性（Shared Autonomy）是人机协作中的核心范式，即人类与自主代理动态共享控制权，广泛存在于自动驾驶、辅助机器人、远程操作等安全关键系统中。
- **现状不足**：现有方法主要分为两类——**控制输入混合（Blending）** 和 **启发式切换规则（Heuristic Switching）**。前者需要人类在每个时间步持续输入，认知负担高，且依赖精确意图预测与手工调参；后者缺乏理论保证，无法量化何时切换才是最优的。
- **核心痛点**：已有方法未充分考虑 **人类越权（Override）决策的非确定性**（即人类是否真的会干预，受信任度、认知负荷、任务关键性等影响），也缺乏可泛化的最优性准则。实际中因接管协调失败导致的事故（如航空自动驾驶脱接、自动驾驶汽车碰撞）凸显了这一问题的紧迫性。
- **本文核心问题**：如何设计一个**原则性的权威切换框架**，使得在人类保留更高权威（可随时越权）的前提下，控制权在人类与自主代理之间的转移是**团队最优的**，而非临时性的启发式规则。

## 2. 论文提出的方法论

### 核心思想

- **合作博弈建模**：将权威切换问题形式化为**相同利益动态博弈（Identical-Interest Dynamic Game）**，人类与自主代理组成团队，共同最小化一个统一代价函数。
- **权威状态嵌入系统动态**：引入二值 **FlipDyn 状态** αₖ ∈ {H, A}（H=人类，A=自主），代表当前控制权的持有者，并构建考虑人类越权概率 pₖ 的权威状态转移律。
- **不对称权威设计**：人类拥有更高的控制层级——当自主代理未请求交接时，人类以概率 pₖ 可单方面接管；自主代理无法在人类不同意的情况下强制接管（人类持有时切换是确定性的）。

### 关键技术细节

- **两类动力学**：人类控制 xₖ₊₁ = Fₖᴴ(xₖ, uₖ) 与自主控制 xₖ₊₁ = Fₖᴬ(xₖ, wₖ)。
- **代价函数**：总代价包含状态代价 gₖ(xₖ, αₖ)、人类切换代价 hₖ(xₖ)、自主切换代价 aₖ(xₖ)，以及终端代价。
- **线性二次（LQ）框架**：在线性动力学与二次代价假设下，值函数保持二次型 Vₖ(x) = xᵀPₖx，从而可推导出**闭式最优切换策略**（Theorem 1）：
  - **αₖ = H（人类持有时）**：若代价优势与切换成本之和为正（P̃ₖ₊₁ + Hₖ + Aₖ ≻ 0），人类保留控制；否则双方协商移交给自主代理。
  - **αₖ = A（自主持有时）**：根据 P̃ₖ₊₁ 与 Hₖ/pₖ、Aₖ/(1−pₖ) 的比较关系，分为三种策略：**保留自主控制**、**人类越权**、**协调交接**。越权概率 pₖ 直接决定切换阈值。
- **临界越权阈值**（Theorem 2）：推导出人类干预具有成本效益的最小越权概率 pₖ* = xᵀHₖx / xᵀ(Hₖ + Aₖ)x。对于**各向同性切换成本**（Hₖ = hₖI, Aₖ = aₖI），阈值简化为与状态无关的常数：p* = hₖ/(hₖ + aₖ)。
- **在线估计 pₖ**：利用多次重复任务中的观测干预数据，通过频率估计（公式24）或指数平滑（公式25）在线学习人类越权倾向，无需先验标定。

### Agent 控制器设计

- **自主控制器**：低状态代价 + 高控制代价 → 收敛慢但成本低。
- **切换成本**：各向同性 Hₖ = 0.3·I₂, Aₖ = 0.2·I₂，故临界阈值 p* = 0.6（状态无关）。

### 对比方法（Benchmark）

3. **Performance-threshold**：启发式切换——跟踪误差超过阈值 ε=1.0 时切换给人，低于 ε 时切回自主
4. **Flip-Team**：本文提出的基于 Theorem 1 的最优切换策略（已知 pₖ）

## 6. 论文的主要结论与发现

- **Flip-Team 实现最低总代价**：总代价 40.5，比 always-human（43.2）低 6%，比 always-autonomous（45.6）低 11%，且切换次数仅 1.8 次，人类控制时间占比 56%，体现了**高效权威分配**。
- **启发式切换策略失效**：Performance-threshold 策略总代价高达 55.3，高于任何单代理基线，表明**仅基于跟踪误差的响应式切换**在未考虑越权倾向和切换成本时会引入大量无效切换，反而降低性能。
- **权威切换阈值受 pₖ 动态调控**：当 pₖ 高（人类积极），自动越权发生的成本优势阈值降低（Hₖ/pₖ 变小），框架会预期人类更早介入；当 pₖ 低（人类不积极），阈值提高，系统更倾向于保持自主。
- **各向同性切换成本给出可解释设计法则**：p* = h/(h + a)，若人类切换成本高，则需要更高的人类参与倾向才值得干预；反之亦然。该法则为系统设计者提供了**定量指导**。
- **在线估计可行性**：提出的基于频率估计和指数平滑的方法框架无需先验标定，为实际部署提供路径（评估细节见技术报告 [19]）。

## 7. 优点

- **坚实的理论根基**：将共享自主的权威切换问题建立于合作博弈论之上，获得团队最优策略，而非启发式规则；团队最优解同时也是纳什均衡，保证无单方面偏离动机。
- **闭式解高效可算**：对 LQ 系统推导出矩阵形式的闭式递归，计算与状态维度解耦，适合嵌入实时控制管线。
- **不对称权威建模新颖且符合实际**：人类持有“概率性越权”能力，更真实地刻画了人在回路的控制层级结构。
- **阈值分析提供可操作洞见**：临界越权概率 p* 的推导和各向同性假设下的简化（p* = h/(h+a)）为交互方式和界面设计提供了量化依据。
- **在线自适应能力**：提出的 pₖ 在线估计方法让系统无需预先校准即可适应不同操作者和不同任务阶段。
