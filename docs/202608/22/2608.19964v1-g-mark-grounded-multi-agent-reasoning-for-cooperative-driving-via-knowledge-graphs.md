## 摘要
自动驾驶系统必须在部分可观测性条件下运行，其中安全关键的物体可能被遮挡，或仅对邻近的联网车辆可见。车对车协作可以减少这种不确定性，但现有的协同驾驶方法通常将多智能体证据压缩为潜在特征或隐藏的多模态状态。因此，它们模糊了哪个智能体观察到每个物体、该物体对自车是否可见，以及冲突证据如何影响下游决策。我们提出G-MARK，一种接地多智能体推理框架，将协作的以物体为中心的观测转换为显式的、具有来源感知的知识图谱（KGs）。生成的KGs保留了物体假设及其来源归属、自车与伙伴可见性、不确定性、冲突、空间关系和规划相关上下文。G-MARK随后从这些KGs中推导出共享特征表示，使得轻量级任务头能够支持物体推理、运动预测、控制选择和轨迹预测。与最先进的基线相比，G-MARK在遮挡推理准确率上提高了42.2%，控制选择误差降低了13.1%，并以25.6倍更小的结构化通信负载实现了相当的轨迹规划准确率。我们的代码可在 https://github.com/bhavyagupta98/g-mark 获取。

## Abstract
Autonomous driving systems must operate under partial observability, where safety-critical objects may be occluded or visible only to neighboring connected vehicles. Vehicle-to-vehicle cooperation can reduce this uncertainty, but existing cooperative driving methods often compress multi-agent evidence into latent features or hidden multimodal states. As a result, they obscure which agent observed each object, whether the object is visible to the ego vehicle, and how conflicting evidence affects downstream decisions. We propose G-MARK, a grounded multi-agent reasoning framework that converts cooperative object-centric observations into explicit provenance-aware knowledge graphs (KGs). The resulting KGs preserve object hypotheses together with their source attribution, ego-versus-partner visibility, uncertainty, conflicts, spatial relations, and planning-relevant context. G-MARK then derives a shared feature representation from these KGs, enabling lightweight task heads to support object reasoning, motion prediction, control selection, and trajectory forecasting. Compared with the state-of-the-art baseline, GMARK improves occlusion reasoning accuracy by 42.2%, reduces control-selection error by 13.1%, and achieves comparable trajectory-planning accuracy with a 25.6x smaller structured communication payload. Our code is available at https://github.com/bhavyagupta98/g-mark.

- **核心研究问题**：如何在协同驾驶中保留并显式建模多智能体证据的来源、可见性、不确定性、冲突等关键信息，并支持多个下游推理任务？

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- **延迟证据融合（Delayed Evidence Fusion）**：不预先将所有智能体观测压缩为单一融合物体列表，而是先构建图谱结构，**等待下游任务明确后再决定如何融合**。这使得各任务可以查询同一份协同证据，但侧重点不同。
- **来源感知（Provenance-aware）**：每个物体假设都记录其支持观测来自哪些智能体，保证证据可追溯。
- **候选保留（Candidate Retention）**：没有匹配到其他观测的弱观测不会被丢弃，而是保留为**弱候选假设**，供下游任务自行判断其相关性。

### 2.2 技术步骤

G-MARK 共分四个阶段：

#### 阶段一：协同 KG 生成（Cooperative KG Generation）
- 每个 CAV 的处理后感知输出被实例化为本地证据 KG，包含三类节点：
  - **智能体节点（Agent Node）**：存储身份、位姿、时间戳、自车/伙伴角色；
  - **观测节点（Observation Node）**：表示单个本地物体观测，记为 o(i)t,j = (x, τ, c, a_i, t, η)；
  - **物体假设节点（Object-Hypothesis Node）**：表示来自通信证据或关联后的共享物体假设。
- 节点之间通过类型化关系连接：
  - **source** 关系：智能体 → 观测；
  - **support** 关系：观测 → 物体假设；
  - **空间关系**：front-of、behind、left-of、right-of、near；
  - **规划上下文关系**：near-trajectory、path-relevant；
  - **证据一致性关系**：cooperatively-supported、low-conflict。
- 每个物体假设表示为：h = (x_h, τ_h, c_h, π_h, S(h), u_h, γ_h, r_h)，其中：
  - π_h 为来源记录（provenance），即支持该假设的智能体与观测；
  - S(h) 为支持观测集；
  - u_h 表示不确定性；γ_h 表示智能体间分歧；r_h 表示规划相关性。

#### 阶段二：保守关联（Conservative Association）
- 使用确定性门控规则判断哪些本地观测对可以关联，以**避免将不同物体过度合并**：

  δ_t(v_p^O, v_q^O) = 1 ⟺ type_match(τ_p, τ_q) ∧ d(x_p, x_q) < ε_{τ_p, τ_q}

  - 要求语义类别完全匹配（保守设计，防止行人-车辆误合并）；
  - ε 为类别相关的关联阈值。
- 门控匹配的观测对分配可解释的距离亲和度得分：

  α_{t,pq} = 1 − d(x_p, x_q) / ε_{τ_p, τ_q}（若 δ=1），否则为 0。

- 融合位置 x_h 为支持观测位置的置信度加权平均；
- 假设置信度采用有界 noisy-or 聚合：c_h = 1 − ∏(1 − c(v_O))；
- **未匹配观测保留为弱候选**，具有较低支持度和较高不确定性。

#### 阶段三：协同上下文丰富（Cooperative Context Enrichment）
- 对每个物体假设生成增强向量：

  φ(h) = [φ_prov(h), φ_vis(h), φ_unc(h), φ_dis(h), φ_plan(h)]

  - φ_prov：来源支持与置信度摘要；
  - φ_vis：自车相对可见性（visible / occluded / uncertain）；
  - φ_unc：不确定性摘要；
  - φ_dis：跨智能体不一致性；
  - φ_plan：到自车规划轨迹的距离。
- 最终 KG 特征向量 ψ(h) 为物体状态属性（位置、类型、置信度、运动线索）与 φ(h) 的拼接。

#### 阶段四：统一 KG 任务头（Unified KG Task Heads）
- 三类任务头家族：
  1. **选择与可见性推理**（Q1–Q4）：使用共享逻辑回归排序器；
  2. **运动与交互预测**（Q5/Q7/Q9）：使用正则化回归头；
  3. **控制与轨迹规划**（Q6/Q8）：使用轻量级分类器。
- 推理表示为：y_k = R_k(G_t, {ψ(h): h ∈ V_H^t})；
- 设计原则：**每个场景构建一个来源感知的协同 KG**，每个任务头自行选择所需证据。

## 6. 主要结论与发现

1. **显式协同证据显著提升可见性敏感推理**：
   - 遮挡推理（Occlusion Reasoning）F1 从 0.301 → 0.428，提高 **42.2%**；
   - 隐藏物体发现（Hidden-object Discovery）F1 从 0.440 → 0.494，提高 **12.3%**；
   - 物体运动预测 L2 误差降低约 **50%**（Q5: 8.050 → 3.822；Q7: 7.610 → 3.822）；
   - 控制选择误差降低 **13.1%**（Action L1: 0.088 → 0.076）。

2. **G-MARK 在 9 个任务中 8 个超过基线**；唯一略逊的是未来轨迹预测（L2: 2.710 vs 2.620，即 -3.4%），显示 KG 表示在长时域规划中仍有一定信息损失。

3. **通信效率大幅提升**：
   - G-MARK：0.0159 MB/样本；
   - 中间融合方法：约 0.4008–0.4068 MB/样本；
   - 相比中间融合低约 **25.2×**，相比 V2V-GoT 低约 **25.6×**。

4. **消融实验结论**：
   - 去除伙伴证据后，隐藏物体发现 F1 从 0.494 降至 **0.000**，证明隐藏物体发现完全依赖协作证据；
   - 去除来源信息后，隐藏物体 F1 降至 0.396，控制误差升至 0.152，说明来源归属对推理和控制均重要；
   - 将 KG 替换为平面非结构化表示后，性能下降（F1: 0.494 → 0.443；Action L1: 0.076 → 0.089），说明显式 KG 结构提供了额外价值。

5. **运行效率**：KG 推理层不是系统瓶颈，端到端 CPU 延迟保持毫秒级。

## 7. 优点
