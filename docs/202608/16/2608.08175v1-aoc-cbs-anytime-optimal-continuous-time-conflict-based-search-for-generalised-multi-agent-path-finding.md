## 摘要
许多研究领域共享一个共同的结构：一组智能体，每个智能体追求自己的目标，其行动必须协调以避免任何两个智能体冲突。多智能体路径寻找（MAPF）是该结构的一个具体实例，其应用涵盖仓库、道路交通和机场。许多MAPF研究假设离散时间、圆形智能体共享一个空间图、每个智能体只有一个目标，并且智能体一旦到达目标就必须停留在那里，这排除了异构车队、非几何冲突、任务序列以及完成这些任务后继续移动的智能体。我们推广了MAPF公式以解除这些假设，并提出了AOC-CBS（任意时间最优连续时间冲突搜索），这是针对该问题的精确且解完备的求解器。AOC-CBS保证最终返回最优解，同时在其运行过程中报告具有已知最优性间隙上界的当前最优解；它可配置一组修复函数组合（我们引入了其中之一：分层优先安全间隔路径规划），并可利用多个处理器核心。我们在混合的非凸智能体车队上演示了AOC-CBS，这些智能体沿着平滑、运动动力学可行轨迹移动。在著名基准测试和从其中采样的路标图上，与精确求解器OC-CBS进行的初步实验表明，AOC-CBS在寻找最优解方面与OC-CBS相当，同时在接受有界最优性间隙时将可扩展性从数十个智能体扩展到数百个智能体。

## Abstract
Many research fields share a common structure: a set of agents, each pursuing its own goal, whose actions must be coordinated so that no two of them conflict. Multi-Agent Path Finding (MAPF) is a concrete instance of this structure, with applications from warehouses to road traffic and airports. Much of MAPF research assumes discrete time, circular agents sharing one spatial graph, a single goal per agent, and that an agent must remain at its goal once reached, precluding heterogeneous fleets, non-geometric conflicts, task sequences, and agents that move on after completing them. We generalise the MAPF formulation to lift these assumptions, and present Anytime-Optimal Continuous-time Conflict-Based Search (AOC-CBS), an exact and solution-complete solver for it. AOC-CBS guarantees the eventual return of an optimal solution, while reporting an incumbent with a known optimality gap upper bound throughout its runtime; it is configurable with a portfolio of repair functions, one of which we introduce (Tier-Prioritized Safe Interval Path Planning), and can exploit multiple processor cores. We demonstrate AOC-CBS on a mixed fleet of non-convex agents moving along smooth, kinodynamically feasible trajectories. Preliminary experiments against the exact solver OC-CBS, on well-known benchmarks and roadmaps we sample from them, show AOC-CBS is comparable at finding optimal solutions while extending scalability from the tens to the hundreds of agents when a bounded optimality gap is accepted.

## 1. 论文的核心问题与整体含义

多智能体路径寻找（MAPF）在仓储物流、道路交通、机场调度、视频游戏等众多领域具有核心地位。然而，绝大多数现有 MAPF 研究建立在若干强假设之上：

- **离散时间**：智能体只在整数时间步移动，动作时长固定。
- **同构空间图**：所有智能体共享同一个图，隐含要求它们具有相同运动模型。
- **目标单一且终点固定**：每个智能体只有一个目标顶点，且到达目标后必须永久停在那里。
- **冲突仅指几何碰撞**：两个智能体无法在共享空间状态同时出现，且通常忽略体积或只处理圆形智能体。
- **任务结构简单**：不涉及任务序列、边遍历任务、服务时间、空闲智能体或不可等待状态（如固定翼飞机不可在空中悬停）。

这些假设极大地限制了模型的表达能力和实际适用性。本文作者将 MAPF 形式化地推广为更一般的连续时间、异构智能体、抽象冲突定义、任意任务序列的协同规划问题，并提出了求解器 **AOC-CBS（Anytime-Optimal Continuous-time Conflict-Based Search）**。AOC-CBS 的关键价值在于：**它是一种精确且解完备的求解器，保证最终返回最优解，同时在运行过程中始终提供一个带“已知最优性差距上界”的可行解**，即具备“任意时间最优”（anytime-optimal）特性。这使得它既能作为快速启发式求解器使用，也能在时间充裕时收敛到最优解。

## 2. 论文提出的方法论

### 2.1 对 MAPF 问题的推广

作者将经典 MAPF 推广为如下模型：

- 每个智能体在自己的状态空间 `S_a` 上拥有独立的图 `G_a`，图中顶点对应于状态，边对应从源状态到目标状态的轨迹。这样，异构智能体（如移动机器人、机械臂、固定翼无人机）可共存于同一问题。
- 时间是连续的，边遍历和顶点等待可以取任意实数时长。
- 冲突通过抽象函数 `InConflict(i, s_i, j, s_j)` 定义，不限于几何体积碰撞，可建模如无人机下洗流干扰等非几何冲突。
- 任务序列由顶点任务（带服务时间）和边任务组成；智能体完成所有任务后可以继续移动，而非必须停留在某个最终目标。
- 顶点不必是可等待的；只有计划的最后一个动作为无限等待动作，需位于可等待顶点。
- 成本函数可采用 Sum-of-Costs（SOC）或 makespan 等，要求可分解且对单个计划成本非递减。

### 2.2 AOC-CBS 框架

AOC-CBS 基于 OC-CBS（Optimal Continuous-time Conflict-Based Search）扩展而来。其核心结构仍然是**两层搜索**：高层的约束树（CT）搜索和低层的单智能体路径规划。但 AOC-CBS 与 OC-CBS 的主要区别在于：

1. **每次展开后立即检查子节点是否形成可行解**：若子节点是解，且成本低于当前 incumbment，则更新 incumbent，从而提早获得可行解及最优性差距上界。
2. **引入可配置的策略组合（portfolio）**：每个策略包含一个“节点选择策略”和一组“修复函数”。多个策略可以并行地在不同处理器核心上同时展开 CT 节点，提高扩展能力。
3. **支持多种节点选择策略**：默认的策略是按最小成本下界 `LB(N)` 选择以维持最优性保证；也允许随机选择、按最小冲突数选择、按最小累计冲突时间选择等。
4. **修复函数**：对当前 CT 节点的联合计划进行局部修复，尝试快速生成无冲突的解。论文中提出了 TP-SIPP 作为新的修复函数。

### 2.3 关键组件：MG-CSIPP 和 TP-SIPP

- **MG-CSIPP（Multi-Goal CSIPP）**：这是低层单智能体路径规划器，扩展自 CSIPP/SIPP，在状态中加入“下一个任务索引”，能处理多目标任务序列、空闲智能体、边/顶点服务时长等，并使用安全间隔分解和可采纳启发式保证返回最优单智能体计划。
- **TP-SIPP（Tier-Prioritized Safe Interval Path Planning）**：一种分层优先的修复函数。它将未规划智能体按“截止时间”分为三级（严重受限、受限、不受限），逐层规划。与现有 PSIPP 不同，TP-SIPP 允许智能体在完成顶点任务后离开该顶点，而不是永久占据，从而避免因优先级不当导致不必要的失败。它还引入随机顺序，使修复在不同调用间具有多样性。

### 2.4 理论保证

论文证明了 AOC-CBS 满足如下性质：

- **不变量**：每次迭代开始时，要么仍有一个未展开节点可以到达某个最优解，要么已经找到最优解。
- **终止性**：若节点队列为空，则 incumbent 一定是最优解。
- **界正确性**：`LB_k ≤ σ* ≤ UB_k`，因此 `ΔUB = UB/LB - 1` 是真实的最优性差异上界。
- 如果已经找到一个可行解，或者至少有一个策略始终选择最小下界节点进行展开，则 AOC-CBS 保证在有限迭代内终止并返回最优解。

## 6. 论文的主要结论与发现

- **最优解能力相当**：在网格图上，AOC-CBS 能证明 3414 个实例的最优解，OC-CBS 为 3269；路标图上为 616 vs 592。差距约 4%，基本持平，考虑到 Python/C++ 差异，AOC-CBS 的优化设计有效。
- **接受有界次优带来显著规模提升**：在相同 30 秒预算下，AOC-CBS 找到可行解的数量约为 OC-CBS 最优解数量的 5–6 倍（网格图 19078 vs 3269，路标图 3220 vs 592）；最大可解智能体数从数十扩展到数百。
- **“找解”和“证明最优”是不同负载**：修复函数 TP-SIPP 能显著扩展松次优差距下的可解智能体数，但在追求最优解时会拖慢下界提升；静态配置无法同时兼顾两端，而动态 gap-cadence 配置 C6 可以。
- **多策略并行主要提升覆盖能力**，而不是简单加速：对难实例可带来 2–3 倍以上加速，并且能解决单核无法解决的 67 个实例，覆盖从 92.0% 提升到 96.3%；但并行开销在容易实例上反而降低性能。
- **冲突选择策略的有效性**：基于“cardinality ranking”的 Best-of-n 选择显著优于 Arbitrary；较小的候选样本（n=8 或 16）已接近穷尽搜索（n=∞）的效果，并且代价更低。Semi-/Cardinal 由于只“满足于第一个可提高成本的冲突”，效果不稳定，取决于地图。
- **方法是通用框架**：预处理将领域知识（几何、形状、冲突定义）转化为领域无关的冲突时间区间，因此 AOC-CBS 可以扩展至任意智能体类型和非几何冲突。

## 7. 优点

- **问题建模非常泛化**：允许异构智能体、独立图、非几何冲突、边任务/顶点任务序列、服务时间、空闲智能体、非可等待顶点，几乎覆盖了现有 MAPF 变体的多数扩展方向，并保持统一的形式化。
- **创新性地结合精确与次优**：在同一个算法框架内做到“任意时间最优”，既有精确搜索的下界保证，又有修复函数提供上界，并提供可验证的最优性差距。
- **模块化设计**：策略组合、修复函数、节点选择策略均可替换，便于扩展；动态组合策略展示了对搜索阶段自适应的潜力。
- **多核并行不影响理论保证**：通过定理证明，在给定条件下仍能有限步收敛到最优。
- **详细且严谨的理论分析**：给出了不变量、终止性、界正确性和两条终止充分条件的证明。
- **实验呈现细致**：既有整体成功率统计，也有配对实例级 speedup/throughput/overhead 分析，还进行了冲突选择的消融，信息量大。

## 8. 不足与局限

- **实验仍属初步**：缺少多次运行的平均/方差、统计显著性检验，也没有在更多类型地图或场景中验证泛化性。
- **公平性隐患**：主要对比是 Python 版 AOC-CBS 对 C++ 版 OC-CBS，性能差异可能受实现语言影响，作者也认为未来需要 C++ 版本来确认算法层面的优势。
- **多核并行效率有限**：实测节点扩展率达到单核的 4.77 倍，仅为理想 11 倍的 43% 左右，且并行开销会导致容易实例反而变慢；“随核数扩展的饱和点”仍是开放问题。
- **预处理代价与可扩展性**：冲突信息预处理虽然是一次性成本，但复杂度随图规模和智能体类型增加；非凸多边形智能体的预处理耗时明显更长（演示中约 11 分钟），论文未系统评估大数据集上的预处理可扩展性。
- **现有三维模型缺失**：论文当前只提供二维实现，3D 扩展仍为“进行中工作”。
- **冲突检测的保守近似**：Lipschitz 界方法在有限精度下会将部分无冲突区域判定为冲突，可能引入保守性；且要求冲突持续时间远高于机器精度，某些极端场景（超短冲突）可能无法正确处理。
- **最优性差距是上界而非精确值**：返回的次优解的真实差距可能远小于报告值，但论文没有进行后续测量或校准。
- **TP-SIPP 的失败模式不保证完备**：虽然作为修复函数使用，但 TP-SIPP 本身是启发式方法，可能因随机顺序或分级策略仍找不到一个实际存在的解，因此不承担整体完备性责任。
