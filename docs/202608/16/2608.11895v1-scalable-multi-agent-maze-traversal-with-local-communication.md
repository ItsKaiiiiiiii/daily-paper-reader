## 摘要
洞穴网络、管道系统以及类似的迷宫环境对未知环境中有限通信下的多智能体导航提出了重大挑战。我们提出了一种分布式算法，使智能体能够集体遍历未知的、可能循环的图。智能体在指定的起始节点依次进入，任务是在避免碰撞的同时定位并到达未公开的目标。它们通过局部通信，利用领导者-跟随者关系和领导者切换进行协调。在任何时刻，仅由其中一个智能体执行探索，该智能体运行单智能体迷宫求解器。我们证明了该算法的完备性，其完工时间（就智能体数量而言）渐近等价于最优全知策略，并推导出其时间和空间复杂度。多达625个智能体的仿真表明，随着智能体数量的增加，平均总燃料消耗减少，并证明了所提出的方法优于所有智能体独立执行单智能体求解器的朴素基线。

## Abstract
Cave networks, pipe systems, and similar maze-like environments pose significant challenges for multi-agent navigation in unknown settings with limited communication. We propose a distributed algorithm that enables agents to collectively traverse an unknown, possibly cyclic graph. Agents enter sequentially at a designated start node and are tasked to localize and reach an undisclosed goal while avoiding collisions. They coordinate via local communication using leader-follower relationships and leader switching. At any moment in time, exploration is performed by only one of the agents, which runs a single-agent maze solver. We prove that the algorithm is complete, that its makespan is asymptotically equivalent (in the number of agents) to that of an optimal full-knowledge strategy, and derive its time and space complexity. Simulations with up to $625$ agents show a decreasing average sum-of-fuels as the number of agents increases and demonstrate that the proposed approach outperforms a naïve baseline in which all agents independently execute the single-agent solver.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 论文研究的是**未知、可能循环的迷宫环境下的多智能体协作遍历问题**（Multi-Agent Maze Traversal, MAMT）。这类环境常见于管道网络、洞穴系统、地下设施等，智能体需要在没有全局地图、通信受限且需避免碰撞的条件下，从共同的起始节点出发，找到并到达一个未公开的目标节点。
- 与经典 MAPF（多智能体路径规划）不同，MAMT 假设环境图**事先完全未知**，只能通过局部感知逐步揭示；同时通信被限制在局部范围（两跳以内、且不能穿过被占用的节点），这比全局通信更加现实。
- 已有工作主要存在两个缺口：一是仅适用于树形图（acyclic graphs），无法处理一般带环图；二是缺乏理论保证，如完备性和最优性分析。论文的目标是**设计一种仅依赖局部通信、可扩展至大规模智能体、且具备理论保证的分布式算法**。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想：**
- 任意时刻**只有一个“头”（head）智能体**负责执行探索，它运行一个单智能体迷宫求解器（如 Trémaux 算法、BFS 或随机游走）来决定下一步移动。
- 其余所有活跃智能体通过选择“领导者”（leader）形成一棵以头智能体为根的**跟随树**（in-tree），间接或直接跟随头智能体移动。
- 当移动可能引发冲突时，头智能体通过**领导者切换**将探索角色移交给占用目标节点的智能体，从而避免碰撞并保持通信连通性。

**关键技术细节：**
- 智能体在每个时间步内执行同步的“感知–决策–移动–通讯”循环。
- 通信方式包括：
  - **定向投递（directed cast）**：沿指定边发送，可到达特定范围内的智能体；
  - **本地广播（broadcast）**：沿所有出边发送。
- 定义了三种消息类型：
  1. **状态消息**：包含智能体 ID、是否在目标节点、领导者指针；
  2. **竞争消息**：用于非头智能体之间竞争原本领导者所占用的节点；
  3. **头消息**：由头智能体广播，包含单智能体求解器状态、是否转移头角色等信息。
- 冲突避免：通过**顶点冲突**和**跟随冲突**的定义，算法确保任意非目标节点至多被一个活跃智能体占据，且不会发生“一个离开、另一个同时进入”的情况。
- 竞争机制：所有竞争同一节点的智能体共享相同信息（通过局部通信和消息交换），使用确定性选择器选出唯一胜者；胜者移动到该节点，败者选择胜者作为新领导者。

**关键定理：**
- **Lemma 1**：任意时刻恰好存在一个头智能体，且头智能体的轨迹与单智能体求解器一致。
- **Lemma 2**：每个非起始节点的首次访问均由头智能体完成；所有智能体最终通过同一个与目标相邻的节点到达目标。
- **Lemma 3**：任意非目标节点至多被一个活跃智能体占据，竞争同一节点的智能体具有相同的领导者。
- **Lemma 5**：领导图始终是以头智能体为根的入树（in-tree）。
- **Theorem 1**：如果单智能体求解器在时间步 \(k_g-1\) 首次到达目标相邻节点，则 \(n\) 个智能体在至多 \(k_g + 2(n-1)\) 步内全部到达目标。
- **Theorem 2**：与全知最优策略相比，算法的 makespan 要么相等，要么随智能体数量增长渐近等价（\(\lim_{n\to\infty} R(n)=1\)）。

**复杂度：**
- 空间复杂度：\(O(d \min(n, d^2))\)，其中 \(d\) 为图的最大度数；若考虑单智能体求解器附加需求，Trémaux 为 \(O(E + d\min(n,d^2))\)，BFS 为 \(O(V + d\min(n,d^2))\)。
- 时间复杂度（总迭代次数乘以单步开销）：
  - Trémaux：\(O((E+n)\min(n,d^2))\)
  - BFS：\(O(((V+E)^2 + n)\min(n,d^2))\)
  - 随机游走：期望 \(O((V^3+n)\min(n,d^2))\)

  - **Makespan**：所有智能体到达目标所需的总时间步；
  - **平均 sum-of-fuels**：所有智能体到达目标所经过边的平均数。
