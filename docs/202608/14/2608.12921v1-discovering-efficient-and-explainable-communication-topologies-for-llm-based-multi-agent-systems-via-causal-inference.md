## 摘要
大型语言模型（LLM）为基础的多智能体系统（MAS）的性能在很大程度上取决于有效的通信拓扑。然而，现有的拓扑生成方法通常仅通过任务级奖励驱动的黑盒优化来学习通信拓扑。虽然有效，但此类优化对于为何选择特定通信边提供了很少的见解，使得难以识别负责成功协作的关键通信子图。为了解决这一局限性，我们提出了E2-Explainer，一个模型无关的框架，用于为任意拓扑生成器产生的通信拓扑提供可解释的解释。具体来说，我们将拓扑解释表述为一个因果归因问题，该问题识别由任务保留的边级证据支持的紧凑通信子图。我们通过一个格兰杰风格的目标获得这一证据，该目标衡量屏蔽每个通信通道如何改变任务结果和最终响应的稳定性。然后将所得的预算子图提炼到一个摊销解释器中，从而在部署时无需重复边级评估即可实现高效的事后解释。在多个推理和编码基准上的大量实验表明，E2-Explainer识别出保持成功协作的关键通信子图。这些子图也可以直接执行以修剪冗余通信边，在保持竞争性任务性能的同时大幅降低通信成本。

## Abstract
The performance of large language model (LLM)-based multi-agent systems (MAS) largely depends on effective communication topologies. Existing topology generation methods, however, typically learn communication topologies through black-box optimization driven solely by task-level rewards. While effective, such optimization provides little insight into why particular communication edges are selected, making it difficult to identify the critical communication subgraphs responsible for successful collaboration. To address this limitation, we propose E2-Explainer, a model-agnostic framework for providing interpretable explanations of communication topologies produced by arbitrary topology generators. Specifically, we formulate topology explanation as a causal attribution problem that identifies compact communication subgraphs supported by edge-level evidence of task preservation. We obtain this evidence with a Granger-style objective that measures how masking each communication channel changes the task outcome and the stability of the final response. The resulting budgeted subgraphs are then distilled into an amortized explainer, enabling efficient post-hoc explanation without repeated edge-level evaluations at deployment. Extensive experiments on multiple reasoning and coding benchmarks demonstrate that E2-Explainer identifies critical communication subgraphs that preserve successful collaboration. These subgraphs can also be executed directly to prune redundant communication edges, substantially reducing communication costs while maintaining competitive task performance.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：LLM基础的多智能体系统已广泛应用于数学推理、代码生成、知识问答等任务。系统的协作性能很大程度上取决于智能体之间的**通信拓扑**（即智能体如何连接、如何传递信息）。早期的拓扑生成方法依赖手工设计的固定结构（如链式、星型、完全图），缺乏对任务的自适应性。
- **核心问题**：现有的可学习拓扑生成方法（如基于剪枝和基于生成的方法）虽然能够实现更好的性能，但它们**完全依赖黑盒优化**——仅以任务级奖励（如准确率）作为优化目标，而不关心“为什么某条通信边被选择”。这使得生成的拓扑中往往包含大量**冗余边**，甚至存在“仅与成功协作相关、并非因果必要”的边，难以被随机剪枝发现，也无法为协作成功提供可解释性。
- **研究目标**：提出一个**模型无关的事后解释框架**，能够从任意拓扑生成器输出的通信图中，识别出**紧凑的、任务保持的因果关键子图**——既能解释协作成功的关键通信路径，又能作为可执行子图直接剪枝冗余通信，降低推理成本。

### 2. 论文提出的方法论

#### 核心思想

论文将拓扑解释形式化为一个**因果归因问题**。核心思想源自**Granger因果**：如果一条边传递的信息能提升任务结果的预测能力，则该边对协作具有因果重要性。据此，论文逐边进行“屏蔽干预”（edge masking），观察任务结果和响应稳定性的变化，以此评估各边的因果贡献。

#### 方法框架：E2-Explainer

该方法包含三个阶段：

- **第一阶段：候选拓扑构建（Candidate Topology Construction）**
  - 使用现有拓扑生成器（如G-Designer、AgentPrune、OFA-MAS、ARG-Designer等）对查询q生成候选通信拓扑 G = (V, E)。

- **第二阶段：Granger式因果子图发现（Causal Subgraph Discovery）**
  - **边级因果归因**：对每条边 e = (u, v)，将其从图中移除，得到干预图 G−e，并重新执行LLM-MAS系统，比较任务分数：
    - **任务级因果贡献**：Δtask_e = Q(x, G) − Q(x, G−e)，取非负部分作为保留贡献 u_task_e。
    - **辅助语义熵信号**：使用**语义熵**（Semantic Entropy）衡量最终响应的不确定性。若屏蔽该边后，多次随机采样的最终响应语义熵增加（响应更不稳定），则提供额外证据表明该边有助于保持原图行为。
  - **统一边效用**：将两个信号归一化并加权融合：u_e = clip[0,1](α·ûtask_e + β·ûsem_e)，默认权重 (α, β) = (0.8, 0.2)。
  - **预算感知子图选取**：根据边效用排序 πG，使用TopK选取高效用边；然后通过**可执行性约束投影** R_valid 将选取的边集合转化为可执行的子图 H_b*——该投影只保留原图中的边、保留必需输入和最终聚合节点、删除与排除节点相连的边和孤立的可选节点。
  - 对预算集合 B = {E25+N0, E50+N0, E75+N0, E25+N20, E50+N20, E25+N40} 分别生成子图，形成**预算化的解释家族**。

- **第三阶段：摊销解释器（Amortized Explainer）**
  - 由于因果归因需要大量重复执行LLM-MAS（逐个屏蔽边并重新运行），在线部署代价过高。因此，将因果发现得到的子图作为**监督信号**（graph-to-subgraph supervision），训练一个**摊销解释器** Fθ：(x, G, b) → Ĥ_b。
  - 该解释器采用共享的节点编码器和边/节点预测头，预测每条边的保留概率和每个节点的保留概率，再通过TopK和可执行性投影输出最终子图。训练损失为边和节点的二元交叉熵（BCE）之和，加上权重衰减。
  - 部署时，解释器只需一次前向传播即可预测子图，**无需任务标签、无需重复边干预**。

### 6. 论文的主要结论与发现

- **E2-Explainer能有效降低通信成本并保持/提升性能**：对4种拓扑生成器，平均减少token消耗 20.1%–25.6%，同时平均准确率在4个生成器上分别提升 0.44、0.53、0.58 和 1.09 个百分点。性能最好的是 G-Designer + E2-Explainer，平均准确率 90.71，token比原G-Designer少25.1%。
- **跨生成器泛化能力强**：仅在G-Designer图上校准，直接应用到未见的ARG-Designer、OFA-MAS、AgentPrune上，精度同样提升、token全面下降，说明学到的是跨拓扑生成器的可迁移的通信路径选择模式。
- **跨智能体规模可迁移**：5-agent训练的解释器直接应用到6-agent图，在MMLU上精度从79.43提升至81.70，HumanEval上从89.26提升至90.08，同时token减少10.16%和19.38%。
- **因果信号是主要驱动力，语义熵信号提供补充**：移除因果信号导致MMLU精度下降3.92点、HumanEval下降3.81点；移除语义熵信号（仅用因果信号）性能和完整模型仍有差距，说明语义熵作为稀疏奖励下的稠密化信号具有补充价值。
- **冗余边并非随机可剪**：随机屏蔽分析表明，大部分随机掩码降低性能，只有极少数保留或提升精度，说明任务保持的紧凑子图存在但难以通过随机剪枝发现，需要因果引导。
- **节点剪枝比边剪枝更能节省token**：边剪枝（E75+N0）只减少约5.27% token，而加入节点剪枝（E25+N20）可达25.1%的token减少。但过度节点剪枝（E25+N40）在HumanEval上精度损失较大（-6.52点），说明代码生成任务对角色多样性敏感性高。

### 7. 优点

- **问题定义新颖且实用**：将拓扑优化从“生成/剪枝”扩展到“事后的可解释子图发现”，定位精准、切入实际痛点。
- **方法设计巧妙**：将Granger因果从个体变量推广到通信子图；将无法枚举的组合性子图搜索分解为上界因果排序+预算化TopK+可执行性投影，具有理论合理性和计算可行性。
- **双信号融合增强鲁棒性**：任务级因果信号在稀疏奖励下可能区分度不够，语义熵提供了稠密、稳定的辅助信号，两者互补。
- **摊销化设计解决了部署瓶颈**：将昂贵的离线因果评估蒸馏为轻量级在线预测模型，训练后仅需一次前向传播，非常实用。
- **模型无关且跨生成器/跨规模泛化验证充分**：不访问生成器内部参数，仅在一种生成器上校准、冻结后应用到其他三类生成器和手工拓扑，验证了方法的通用性。
- **可执行性约束保障了实际可用性**：R_valid投影确保提取的子图不引入新边、保持DAG性质、保留必要节点，可直接在真实MAS中执行。
- **定性案例丰富**：提供了4个完整执行轨迹案例，直观展示了剪枝前后各智能体的输入输出变化，有助于理解为何拓扑修改会改变协作结果。

### 8. 不足与局限

- **骨干LLM单一性**：所有实验仅使用Qwen3-8B，未验证在其他规模或类型的LLM（如更大的模型或不同供应商的模型）上是否依然有效。不同LLM的推理能力和对拓扑变化的敏感度可能不同。
- **校准规模有限**：每个数据集仅使用40个校准查询构建监督信号，在数据量较大、拓扑多样性高的场景下，解释器学习的覆盖度可能不足。
- **跨规模泛化测试幅度有限**：仅从5-agent扩展到6-agent，未测试更大差异（如5→8、5→10个智能体）下的迁移能力。
- **不确定性量化缺失**：主结果报告了三次独立运行的均值，但没有报告方差或置信区间，无法判断精度提升或下降在统计上是否显著。
- **任务类型覆盖有限**：基准测试集中在推理（数学、知识、代码），未覆盖多智能体系统常用的更复杂交互任务（如具身智能、网页代理、数据库操作等），其结论是否能推广到更复杂任务尚不明确。
- **对共享错误的无能为力**：定性案例2表明，若所有保留的智能体共享相同的领域误解（如对囊性纤维化酶功能的理解偏差），拓扑剪枝无法修复错误——剪枝只能去除冗余，不能纠正认知误区。这是一个本质性的方法边界。
- **方法依赖重复LLM调用的规模随图大小线性增长**：离线构造监督需要每条边至少M次额外的LLM执行，虽然部署端高效，但校准成本随图增大而上升。
- **潜在评估偏差**：采用单一固定预算（E25+N20）统一评估所有生成器，虽然保证了公平性，但不同生成器的最优预算很可能不同，这可能导致对某些生成器的改善被低估。
