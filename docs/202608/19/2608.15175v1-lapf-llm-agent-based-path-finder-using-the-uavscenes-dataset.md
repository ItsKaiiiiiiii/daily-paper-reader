## 摘要
无人驾驶航空器（UAV）越来越多地部署在复杂户外环境中的自主导航，其中动态条件和任务要求需要智能自适应决策。现有的基于优化的、机器学习（ML）和强化学习（RL）方法通常依赖预定义模型或特定任务训练，限制了它们在不确定场景中的泛化性和适应性。最近的大语言模型（LLM）辅助方法提供了有前景的推理能力，但仍受限于有限的代理功能，包括记忆、规划和工具交互机制不足。本文提出了一种基于LLM代理的路径查找器（LAPF）框架，用于城镇规模户外环境中的自主UAV导航。LAPF通过将感知、记忆、规划和行动模块集成到闭环认知架构中，扩展了LLM辅助导航。所提出的代理利用先前的导航经验，执行思维链（CoT）推理，将每个检测到的危险与有界校正动作耦合，并根据环境反馈动态细化航点决策。每种方法的三次独立试验表明，LAPF的平均路径长度分别为512.83米和506.37米，而直线最优为497.33米，相对于CoT提示，路径长度分别减少了17.2%和15.6%，在开放场地和障碍注入场景中的绝对路径效率分别为97.1%和98.1%。此外，LAPF是唯一一种将每个检测到的危险与有界、度量中性的校正动作耦合，同时保持近目标稳定性，在两种场景中均零钳位事件的方法，而CoT提示从9.7次增加到14.0次。

## Abstract
Uncrewed aerial vehicles (UAVs) are increasingly deployed for autonomous navigation in complex outdoor environments, where dynamic conditions and mission requirements require intelligent adaptive decision-making. Existing optimization-based, Machine Learning (ML), and Reinforcement Learning (RL) approaches often rely on predefined models or task-specific training, limiting their generalization and adaptability in uncertain scenarios. Recent Large Language Model (LLM)-assisted approaches offer promising reasoning capabilities but remain constrained by limited agentic functionality, including insufficient memory, planning, and tool interaction mechanisms.This paper proposes an LLM-Agent-Based Path Finder (LAPF) framework for autonomous UAV navigation in town-scale outdoor environments. LAPF extends LLM-assisted navigation by integrating perception, memory, planning, and action modules into a closed-loop cognitive architecture. The proposed agent leverages prior navigation experiences, performs Chain-of-Thought (CoT) reasoning, couples each detected hazard to a bounded corrective action, and dynamically refines waypoint decisions based on environmental feedback.The three independent trials per method demonstrate that LAPF achieves mean path lengths of 512.83 m and 506.37 m, compared to the straight-line optimum of 497.33 m, corresponding to path length reductions of 17.2% and 15.6% relative to CoT prompting and absolute path efficiencies of 97.1% and 98.1% in open-field and obstacle-injected scenarios, respectively. Furthermore, LAPF is the only evaluated approach that couples every detected hazard to a bounded, metric-neutral corrective action while maintaining near-goal stability, with zero clamp events in both scenarios, whereas CoT prompting increases from 9.7 to 14.0 events.

## 2. 论文提出的方法论

### 2.1 总体架构
LAPF是一个五阶段闭环智能体框架（每决策步t执行）：
- **感知（Perception）**：生成观察 \(O_t = \{I_t, \sigma_t, L_t\}\)，RGB图像以原生图像形式传入VLM；LiDAR点云被压缩为摘要统计 \(\sigma_t\)；6-DoF位姿以符号化状态输入。双通道设计——视觉通道与符号通道在骨干网络内部推理时融合。
- **记忆（Memory）**：检索最近 \(k=3\) 个导航片段（含执行的航点、执行结果、反思），支持时间连续性与长期空间认知。
- **规划（Planning）**：执行策略 \(\pi: (P_{sys}, G, O_t, M_t, \phi_t) \mapsto (cwp_t, Tools_t)\)，利用CoT推理生成候选航点和工具调用。
- **行动（Action）**：两层级屏蔽策略——第一层为**保证层**，逐决策步评估危险指标 \(h_t = \mathbb{1}[c_t \leq d_{safe}]\)，触发时以确定性收缩算子 \(R(wp_{t-1}) = wp_{t-1} + \kappa(p_{goal} - wp_{t-1})\) 覆盖模型输出（\(\kappa=0.5\)）；第二层为**可选项层**，如WaypointAdjust工具触发保持位置算子 \(H(w)\)；另设近目标稳定性算子 \(C(w)\) 限制末段步长。
- **反馈（Feedback）**：记录结果、更新性能信号 \(\phi_t\)、生成反思并写回记忆，构成闭环。

### 2.2 关键公式与机制
- **LiDAR摘要统计**：\(\sigma_t = (n_t, r^{min}_t, r^{max}_t, b^{min}_t, b^{max}_t, c_t)\)，其中 \(c_t\) 为最小轴向净空坐标；由于 \(c_t \leq \|p_i\|\)，安全检测天然保守。
- **危险检测**：\(h_t = \mathbb{1}[c_t \leq d_{safe}]\)，\(d_{safe}=5.0\)m，每步保证调用。
- **屏蔽策略复合式**：\(wp_t = H^{\mathbb{1}[\text{WaypointAdjust} \in Tools_t]}( h_t R(wp_{t-1}) + (1-h_t)C(cwp_t) )\)。
- **效率指标**：投影任务长度 \(\tilde{L}_t = L_t + \|p_{goal} - wp_t\|\)，路径效率 \(\eta_t = L^\star / \tilde{L}_t\)，绕路比 \(\varrho_t = \eta_t^{-1}\)。
- **Property 1（度量中性）**：通过三角不等式证明纠偏算子 \(R\) 对路径效率指标贡献精确为零，仅在航点位于起点-目标连线上时等号成立。安全执行与轨迹质量评价完全解耦——这是设计核心。

### 2.3 提示模板
采用固定七字段结构化模板（系统提示、任务、图像块、符号化状态、检索记忆、性能反馈、推理指令），输出为单一JSON对象（含situation_analysis、thought、waypoint、tool_calls字段），在保证CoT推理可用的同时确保机器可解析性。

## 3. 实验设计

### 3.1 数据集与场景
- **数据集**：UAVScenes的AMtown03序列（城镇规模户外场景），UAVScenes是多模态无人机感知基准，包含RGB图像、LiDAR、6-DoF位姿、语义标签和3D地图。
- **传感器**：Livox Avia LiDAR + 2448×2048@10Hz RGB相机 + GNSS/IMU/RTK，硬件同步。
- **两种评估场景**：
  1. **开放场地**（无注入障碍）：验证无约束导航效率；
  2. **障碍注入**（注入5个净空违例，其中4个低于 \(d_{safe}=5\)m）：验证安全机制正确性与应对环境复杂度提升的鲁棒性。

### 3.2 对比方法
- **Pure LLM**：非智能体基线，直接生成决策，无反馈/记忆/修正。
- **CoT LLM**：推理增强但非智能体，提示逐步推理后生成动作。
- **LAPF**：完整智能体框架。

### 3.3 公平性保障（关键设计）
- 三者使用**相同Qwen2-VL-7B骨干**、相同解码设置；
- 接收**字节级别相同的观察**（RGB以图像传入，符号字段完全一致）；
- 都施加相同的稳定算子 \(C\) 和保持算子 \(H\)；
- 障碍注入作用于观察流而非指令状态，确保共同观察控制；
- 所有方法在110步相同预算内评分。

### 3.4 评估指标
路径长度、路径效率、绕路比、钳位事件数（近目标步长截断）、不安全事件数。

## 6. 论文的主要结论与发现

1. **路径效率显著提升**：LAPF在开放场地和障碍注入场景中平均路径长度为512.83m和506.37m（直线最优497.33m），相比CoT LLM减少17.2%和15.6%，路径效率达97.05%和98.09%。
2. **零钳位事件**：LAPF在两种场景中均保持零钳位事件（近目标步长截断）；CoT LLM从9.7增至14.0，Pure LLM从0.0增至2.3——LAPF的优势随环境复杂度增加而保持，而非退化。
3. **危险响应保证**：LAPF是唯一将每次检测到的危险（全部4次不安全事件）耦合到有界、可复现的确定性纠偏动作（通过公式15）的方法；提示型基线记录了相同4次危险但无执行路径。
4. **归因分析**：性能优势主要归于**记忆和反馈通道**（基线是 \(M_t=\emptyset, \phi_t=\emptyset\) 的特例），而非推理深度；CoT LLM的深度推理缺乏反馈校准，反而导致更大的绕行和降级。
5. **度量中立设计验证**：通过Property 1的精确分解，安全盾对 \(\eta_t\) 贡献精确为零，使效率指标纯反映决策策略本身——LAPF的评价优势是真实的决策质量提升，而非安全机制的掩盖。
6. **消费级可部署**：完全在MacBook Air上运行，无需微调，证明智能体架构而非专有骨干驱动性能增益。

## 8. 不足与局限

- **实验覆盖狭窄**：仅一个场景（AMtown03）和一个骨干模型（Qwen2-VL-7B）；UAVScenes不包含密集城市区域（高楼、窄街、行人），无法验证复杂城市场景的适应能力。
- **人为障碍构造**：原始序列净空始终 >15m，注入的净空违例是人工构造的，建立的是机制正确性而非自然危险场景的真实性能，存在外部效度风险。
- **传感器通道利用不完整**：深度图 \(D_t\) 和语义分割 \(S_t\) 虽在数据集中可用但未融合（列为未来工作），制约了感知丰富度。
- **安全层粒度有限**：仅基于标量轴向净空 \(c_t\)（仅测距、无方位），不构成3D碰撞模型，不能直接保证水平方向避障或完整几何碰撞安全。
- **缺乏消融实验**：未隔离记忆、反馈、工具各自的贡献，也未做图像通道消融，因果归因主要依赖架构推理而非实证验证。
- **缺乏位移全局约束**：未设全局步长上限 \(\Delta_{max}\)，路径效率指标鼓励几何直接性但未联合验证运动学可实现性（作者建议列为未来工作）。
- **统计功效有限**：每种配置仅3次独立试验，未进行多次重复的显著性检验，统计分析基础偏薄弱。
- **评估为离线重放**：记录流固定，执行航点不反哺后续观测，未覆盖真实闭环物理系统的交互动态。
- **未来方向**：需扩展至交互式闭环仿真、真实世界无人机部署、大规模多场景、端到端实时验证。
