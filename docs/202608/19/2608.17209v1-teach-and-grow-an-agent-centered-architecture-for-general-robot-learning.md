## 摘要
端到端的视觉-语言-动作（VLA）模型与世界-动作模型为通用机器人技术提供了一条优雅的路径，但其可靠性受限于经过验证的物理覆盖范围。当陌生的物体、传感器、具身形态或接触超出该覆盖范围，且不存在经过验证的备选方案时，纠正失败需要新的机器人数据、策略更新以及回归测试。这种反复出现的负担就是“再训练税”。与文本不同，具身数据通常必须通过操作机器来产生。我们提出了“教导与成长学习”（Teach-and-Grow Learning, TGL），一种面向通用机器人学习的智能体中心架构。在其一般形式中，多模态智能体将少量成功的示范转化为可复用的技能块（Skill Blocks）：用于有意义的子目标闭环控制行为。在新场景中，智能体对这些技能块进行落地（grounding）与组合，选择学习到的或几何工具，观察物理结果，并在执行偏离意图时修正路径。技能库（Skill Library）存储可执行行为，而结构化经验记忆（Experience Memory）则保留成功、失败与修复经验。新任务的获取无需针对特定任务的策略再训练。我们的LIBERO评估达到了最先进的性能；受控研究揭示了技能归纳、持续复用和智能体导向的自适应。最后，我们提出了“教导与成长”缩放律假说：若X表示有效的可复用经验，则未来任务的错误率和教学需求应遵循以X为变量的幂律，趋近于不可再约的底线。因此，该架构将部署视为持续学习的阶段，在此阶段中，一项任务可以使下一项任务变得更加容易。

## Abstract
End-to-end vision-language-action (VLA) and world-action models offer an elegant route to general-purpose robotics, but their reliability is bounded by validated physical coverage. When an unfamiliar object, sensor, embodiment, or contact falls outside that coverage and no validated fallback exists, correcting the failure requires new robot data, a policy update, and regression testing. This recurring burden is the retraining tax. Unlike text, embodied data must often be created by operating machines. We present Teach-and-Grow Learning (TGL), an agent-centered architecture for general robot learning. In its general form, a multimodal agent turns a few successful demonstrations into reusable Skill Blocks: closed-loop behaviors for meaningful subgoals. In a new scene, the agent grounds and composes these blocks, selects learned or geometric tools, observes the physical outcome, and revises the route when execution departs from intent. A Skill Library stores executable behavior, while structured Experience Memory carries forward success, failure, and repair. New tasks are acquired without task-specific policy retraining. Our LIBERO evaluation attains state-of-the-art performance; controlled studies expose skill induction, persistent reuse, and agent-directed adaptation. Finally, we propose the Teach-and-Grow scaling-law hypothesis: if X denotes effective reusable experience, future-task error and teaching demand should approach irreducible floors as power laws in X. The architecture therefore treats deployment as a period of continued learning, in which one task can make the next easier.

### 2. 论文提出的方法论（核心思想、关键技术细节、公式或算法流程）

**核心思想**：多模态 AI 智能体（Agent）将少量成功演示转化为可复用的闭环行为模块——**Skill Blocks（技能块）**，并通过物理反馈动态组合这些模块以完成任务。学习发生在显式的技能库和经验记忆中，而非模型权重中。

**关键技术细节与算法流程**：

- **固定权重学习（Learning with Fixed Model Weights）**：面对任务序列 \(\{T_n\}\)，预训练参数 \(\theta\) 始终不变。系统的更新仅作用于技能库 \(B\) 和经验记忆 \(M\)：
  \[
  \theta_{n+1} = \theta_n = \theta, \quad (B_{n+1}, M_{n+1}) = U(B_n, M_n, D_n, \Delta H_n)
  \]
  新行为进入技能库，上下文与失败经验进入经验记忆。学习不依赖任务特定的策略再训练。

- **Skill Block 的结构化表示**：
  \[
  b_i := \langle g_i, S_i, \rho_i, \gamma_i, \Pi_i, v_i, R_i \rangle
  \]
  其中 \(g_i\) 为子目标，\(S_i\) 为适用场景范围，\(\rho_i\) 为可复用策略，\(\gamma_i\) 为观测落地函数（grounding），\(\Pi_i\) 为兼容执行器集合，\(v_i\) 为效果验证器（pass/fail/inconclusive），\(R_i\) 为有界恢复选项。技能块是"语义层级"的构建单元，而非不可分割的原子动作。

- **动态任务组合**：在决策步骤 \(t\)，智能体维护一个有序工作计划：
  \[
  \tau_t = \langle b_{i_{t,1}}, b_{i_{t,2}}, \dots, b_{i_{t,L_t}} \rangle
  \]
  执行完一个块后，智能体根据物理结果更新剩余计划——继续、缩短、替换或请求教学。

- **结构化经验记忆**：
  \[
  \mu_j = \langle \text{task}, \text{context}, \text{blocks}, \text{outcome}, \text{diagnosis}, \text{repair}, \text{evidence} \rangle
  \]
  记忆存储"发生了什么、为什么、以及什么修复有效"，与技能库的"如何行动"形成互补。

- **Teach-and-Grow 缩放律假说（核心理论贡献）**：
  \[
  E_{\text{future}}(X) = E_\infty + AX^{-\alpha}, \quad D_{\text{teach}}(X) = D_\infty + BX^{-\beta}
  \]
  其中 \(X\) 为"有效可复用经验"，定义为：
  \[
  X_n = \sum_{h\in H_n} \omega(h; B_n, M_n)
  \]
  \(\omega \in [0,1]\) 是根据证据可靠性、覆盖增量、可检索性、落地有效性和与已有块的兼容性计算的无量纲分数。该假说预测：随着 \(X\) 增长，未来任务错误率和所需教学时间将按幂律趋近于不可约的下限。

- **跨演示抽象（Cross-Demonstration Abstraction）**：智能体将每条演示分割为围绕语义状态变化的有序片段 \(d^{(j)} = (s_1^{(j)}, \dots, s_{K_j}^{(j)})\)，以"实现了什么效果"为标准对齐片段（而非对齐运动坐标），然后合成共享策略 \(\rho_k = \text{Synthesize}(A_k)\)。

- **执行反馈循环**：每个块执行后返回 \((o_{t+1}, \varepsilon_t) = \text{Run}(b_{i_{t,1}}, \pi_{i_{t,1},t}, o_t)\)；智能体根据证据 \(\varepsilon_t\) 决定下一步动作。反馈可触发重新规划、重新观察或定向教学。

- **慢教师与快学生（Slow Teacher / Fast Student）**：验证后的轨迹可蒸馏为快速策略（VLA/WAM/扩散策略等），实现低延迟执行；当快路径不确定时，控制返回给智能体进行诊断扩展。感知、规划、控制、经典算法与学习策略在架构中平等地作为"能力"而非"竞争者"。

### 6. 论文的主要结论与发现

- **TGL 架构可行性**：少量演示可被转化为可复用的、闭环的、可验证的技能块，并在未见状态中成功完成任务。
- **反馈驱动自适应**：物理执行反馈（成功/失败/不确定）可以且应当改变智能体后续的任务级规划，而不仅是调整动作参数。
- **局部增长有效性**：向技能库添加两个学习块即可让同一执行器从 0/6 提升到 4/6，验证了"局部能力增长改变整体行为"的架构动机。
- **范围感知（Scope Awareness）**：技能块能够在超出其学习范围时停止并报告，而不是盲目继续执行导致错误传播。
- **缩放律假说**：提出"有效可复用经验" \(X\) 作为机器人终身学习的新缩放资源，预测未来任务错误和教学需求随 \(X\) 按幂律下降。这是对传统"数据/参数/算力"缩放资源的重要视角扩展。

### 7. 优点（方法或实验设计上的亮点）

- **架构创新**：将"智能体决策层"与"物理执行层"明确分离——语言级计划不直接获得电机控制权，物理反馈却能改变计划。这种不对称设计兼具灵活性与安全性。
- **局部性修复全局问题**：技能库与经验记忆作为显式、可版本化、可人工干预的对象，使系统能以局部更新应对局部知识缺口，避免全局模型重训。
- **少样本高效**：仅需极少成功演示（2~3 条）即可获取新任务结构，大幅降低数据采集成本。
- **技能块的语义抽象**：块存储"策略性契约"而非轨迹片段，当前场景中的几何与控制目标均重新计算，因而具备跨场景、跨具身形态复用的潜力。
- **记忆与技能分离**：经验记忆（诊断与修复）与技能库（可执行行为）功能互补，结构性文本记录可被人检查和修正，增加了系统的可解释性。
- **缩放律提出**：TGL 缩放律假说将"有效可复用经验"定义为一个可操作的、随生命周期增长的资源，为机器人终身学习的理论化提供了可测试的目标。
- **经典与学习方法的统一**：经典视觉伺服、运动规划、学习型 VLA 等均可作为技能块的执行器，体现了架构的开放性和兼容性。
