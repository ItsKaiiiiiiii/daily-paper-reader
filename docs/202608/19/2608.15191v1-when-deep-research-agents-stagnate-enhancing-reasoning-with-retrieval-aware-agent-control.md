## 摘要
在本文中，我们分析了多种深度研究智能体（DRA）的推理轨迹，并表明现有智能体常常遭受推理停滞的困扰：大多数迭代对最终性能几乎没有贡献或毫无贡献，而智能体缺乏对其轨迹的感知，因此无法有效调整其搜索策略或确定何时终止。为了解决这个问题，我们引入了一组无监督信号和一个检索感知的智能体控制器（RAAC），该控制器帮助智能体在研究过程的每个阶段选择最优动作。RAAC融合了关键的信息检索原则，即搜索新颖性和信息覆盖度，从而产生更有效的推理轨迹，在减少不必要迭代（进而降低成本与延迟）的同时提升整体性能。具体而言，在BrowseComp-Plus上，跨大量DRA，加入RAAC平均减少了14次搜索调用，显著提升了表现最佳的DRA在召回率和准确率上的性能，并实现了高达10%的准确率提升（平均3%）。

## Abstract
In this paper, we analyze the reasoning trajectories of a variety of DRAs and show that existing agents often suffer from reasoning stagnation: the majority of iterations contribute little or no improvement to final performance, while agents lack awareness of their trajectories and are therefore ineffective at adapting their search strategies or determining when to terminate. To address this issue, we introduce a set of unsupervised signals and a Retrieval-Aware Agent Controller (RAAC), which assists the agent in selecting optimal actions at each stage of the research process. RAAC incorporates key information retrieval principles, namely search novelty and information coverage, resulting in more effective reasoning trajectories that improve overall performance while reducing unnecessary iterations, and consequently cost and latency. Specifically on BrowseComp-Plus and across a large set of DRAs, adding RAAC reduces the number of search calls by an average of 14, significantly improves the best-performing DRA on recall and accuracy, and achieves an accuracy gain of up to 10% (3% on average).

## 1. 核心问题与整体含义（研究动机与背景）

**研究动机：**
- 检索增强生成（RAG）已成为将 LLM 输出与外部知识结合的主流范式，而深度研究智能体（Deep Research Agents, DRAs）通过将工具使用（如搜索引擎）与多步推理相结合，进一步扩展了 RAG 的能力。
- 现有 DRA 研究大多聚焦于**组件级改进**（如检索重排、查询改写、推理增强等），但**忽略了组件在长推理轨迹中如何协同工作以达成最终目标**这一关键问题。

**核心问题——"推理停滞"（Reasoning Stagnation）：**
- 作者对七种不同架构的 DRA 进行了逐迭代的系统性分析，发现一个一致模式：**大多数迭代对最终性能几乎没有贡献**。
- 在初始几步之后，信息发现能力迅速饱和，后续迭代仅带来微乎其微的改进。例如在 BrowseComp-Plus 上，许多智能体在几次迭代后就已达到接近最终的性能，却仍继续执行数十次冗余搜索。
- 智能体**缺乏对自身轨迹的感知**——不清楚已收集了什么信息、哪些查询条件已被满足、是否已得到正确答案，因此既无法有效调整搜索方向，也无法决定恰当的终止时机。
- 检索文档类型分析表明：随着迭代推进，智能体检索到的新文档（无论相关与否）逐渐减少，转而反复回看已见过的文档；新相关文档的数量稳步下降直至消失，说明智能体难以探索新的搜索空间、容易陷入由早期相关证据定义的局部最优。

**整体含义：**
- 该问题导致计算成本与延迟的浪费，制约了 DRA 在实际场景中的实用性与可扩展性。论文主张：DRA 应保持对轨迹的全局视角，尤其是"已覆盖哪些信息"以及"后续步骤是否在探索新区域"，并以此决定继续、重定向/反思或停止。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

作者提出 **检索感知智能体控制器（Retrieval-Aware Agent Controller, RAAC）**——一个与具体智能体架构无关（agent-agnostic）的轻量级决策控制器。RAAC 在每轮推理后计算轨迹级检索感知信号，据此从预设动作集合中选取最优动作，从而引导智能体走向更高效、更有效的推理轨迹。

### 2.2 四个无监督轨迹信号

1. **准则覆盖度（Criteria Coverage, Cov_t）**
   - 衡量查询所关联的信息准则 C = [c₁, ..., c_M] 在研究过程中被满足的程度。
   - 公式：**Cov_t = (1/|C|) Σ_{c∈C} W(c, t)**
   - 权重 W(c,t)：完全覆盖=1.0，部分覆盖=0.5，未覆盖=0。
   - 在 BrowseComp-Plus 中准则由数据集显式提供；在其他数据集上由 LLM 组件生成并动态更新。

2. **文档新颖性（Document Novelty, Nov_t）**
   - 衡量当前迭代中新检索到的、此前从未出现过的文档比例。
   - 公式：**Nov_t = |D_t \ D_{1:t-1}| / |D_t|**
   - 这是最主要的信号，因为新（相关）文档的检索在轨迹后期会持续下降。

3. **连续查询多样性（Successive Query Diversity, Div_t）**
   - 衡量当前搜索查询与上一轮查询之间的不相似度。
   - 公式：**Div_t = 1 − cos(e_t, e_{t-1})**，其中 e_t 为查询 q_t 的归一化嵌入。

4. **原始问题相似度（Original Question Similarity, Sim_t）**
   - 作为"护栏"（guardrail）信号，确保新颖性探索不偏离用户问题主题。
   - 公式：**Sim_t = cos(e_t, e_x)**，e_x 为用户查询 x 的归一化嵌入。该值过低时提示搜索发生主题漂移。

### 2.3 控制器动作集

RAAC 在每个迭代 t 计算上述信号，并从预定义动作集 A = {continue, intervene, stop} 中选择动作：

- **Continue（继续）**：轨迹产出正常，不做干预，让智能体按默认方式继续。
- **Intervene（干预）**：轨迹停滞但可恢复时触发。控制器调用"批判性反思器"（critical re-thinker）：(1) 批判性评估当前轨迹停滞的原因；(2) 生成一个本质不同、更具创造性的新搜索查询以跳出循环。新查询检索的文档被追加到交互历史：**H_{t+1} = H_t ⊕ (τ^{cr}_{t+1}, q^{cr}_{t+1}, D^{cr}_{t+1})**。
- **Stop（停止）**：轨迹已耗尽、进一步迭代不太可能产生新信息时触发。此时智能体基于 H_t 生成最终答案：**(τ'_T, r_T) ∼ π(·|f(H_t))**。

### 2.4 分析方法的两个关键指标

- **中间准确率（Intermediate Accuracy, Acc_t）**：在第 t 轮从主轨迹分支出一个概念性思维链，让智能体生成中间答案 r_t（允许输出 "no candidate"），与真实答案 r* 比较。
- **中间召回率（Intermediate Recall, R_t）**：**R_t = |D_g ∩ D_{1:t}| / |D_g|**，即截至第 t 步已检索到的金标准文档比例。
- **新条目召回率（New-item Recall, NiR_t）**：**NiR_t = |(D_t ∩ D_g) \ D_{1:t-1}| / |D_g|**，用于评估信号与有效检索之间的相关性。

## 6. 主要结论与发现

1. **推理停滞是跨架构的普遍现象**：所有 7 种智能体在 3 个数据集上均表现出"前期快速饱和、后期无意义迭代"的模式，新相关文档的检索随迭代持续下降，已见文档（相关与非相关）的重复检索比例不断上升。

2. **RAAC 有效缓解推理停滞**：
   - 在 **BrowseComp-Plus** 上平均减少 14 次搜索调用（最多 44 次），召回率与准确率均有提升，准确率最高提升 **10%**，平均提升 **3%**。
   - 在 **NeuCLIR** 上平均减少 4 次搜索调用，在 **LegalSearch** 上平均减少 5.5 次。
   - 最佳结果由 WebWeaver+RAAC（BrowseComp-Plus，准确率 67.2%，搜索调用减少 33%）和 Tongyi-DR+RAAC（NeuCLIR 召回率 55.6%、LegalSearch 召回率 56.5%）取得。
   - RAAC 具有**自适应行为**：在智能体过早终止时（如 CPM-Report）会增加迭代以积累更多证据，在智能体冗余循环时则减少迭代——两方面都带来性能提升。

3. **信号有效性排序**：消融与 AUROC 相关性分析一致表明 **文档新颖性（Nov）是最有效的信号**，其次为准则覆盖度（Cov）；连续查询多样性（Div）相关性最低。Cov 在有人工标注准则的 BrowseComp-Plus 上作用明显，在 LLM 生成准则的数据集上作用不稳定（作为补充信号而非主信号使用）。

4. **控制器动作的正面效果**：在 Has Stop 和 Intervene Only 两组中，Win 比例均稳定超过 Loss（如 BrowseComp-Plus 上 34%-36% vs 18%），说明干预能有效重定向轨迹、停止不会过早切断有效迭代。约 61.5% 的 BrowseComp-Plus 查询-智能体对触发了 Stop，而 NeuCLIR/LegalSearch 上 Intervene 占主导。

## 7. 优点

1. **首次系统性中间行为分析**：据作者所述，这是第一个基于中间迭代行为对 DRA 进行系统分析的工作，揭示了"推理停滞"这一此前未被关注的问题。
2. **智能体无关（Agent-agnostic）设计**：RAAC 不依赖特定智能体的内部设计，可即插即用地应用于 4 类不同架构，工程适用性强。
3. **纯无监督信号**：所有信号无需训练数据或监督标签，成本低、可解释性强，避免了训练-推理分布漂移问题。
4. **丰富的动作空间**：相比现有方法（多为二值决策），RAAC 支持 continue/intervene/stop 三动作，并通过批判性反思器提供更丰富的干预机制。
5. **实验设计全面**：涵盖了效果（Recall/Accuracy）、效率（#S）、信号消融、信号判别力（AUROC）、动作贡献（Win/Tie/Loss）和定性案例分析，多角度验证了方法的有效性。
6. **详细的案例可视化**：通过 4 个端到端案例分析直观展示了 RAAC 如何改变具体查询的推理轨迹，增强了结果的可理解性。

## 8. 不足与局限

1. **基于提示

接上文第 8 节，从中断处继续：

---

1. **基于提示词的控制器设计**：RAAC 的动作决策（continue/intervene/stop）是通过将轨迹信号以文本形式输入给 LLM（Claude Sonnet 4.5）并让其输出结构化动作来实现的，本质上仍是一种基于提示词（prompt-based）的启发式方法。这意味着：(a) 决策质量受主干 LLM 的指令遵循能力影响，可能存在随机性；(b) 控制器本身的推理延迟虽然仅占约 10%，但仍引入了额外的 LLM 调用开销；(c) 没有与更形式化的决策机制（如基于强化学习的停时策略、阈值化规则等）进行对比。

2. **信号计算对嵌入模型的依赖**：查询多样性（Div）和问题相似度（Sim）均依赖嵌入模型的语义质量。对于跨语言场景（如 NeuCLIR 的中文/波斯文查询翻译为英文后），嵌入空间中的余弦相似度可能无法完全捕捉细粒度的语义差异，导致信号判别力下降（实验中也证实 Div 是最不有效的信号）。

3. **准则（Criteria）的获取与更新成本**：在无显式准则的数据集（NeuCLIR、LegalSearch）上，准则需要由 LLM 从查询中动态生成并逐轮更新。如果初始准则生成不完整或更新不及时，准则覆盖度（Cov）信号会失真——这也解释了为何消融实验中 Cov 在非 BrowseComp-Plus 数据集上作用不稳定。

4. **缺少与其他自适应检索控制方法的直接基线对比**：论文只对比了"无控制器的原始智能体"，未与 FLARE、Adaptive-RAG、Self-RAG、Stop-RAG 等现有多步推理控制方法进行公平对比，因此无法确定 RAAC 相对于同类方案的相对优势有多大。

5. **阈值与触发机制的敏感性未充分讨论**：控制器对轨迹信号的解读完全依赖 LLM 的自由裁量（prompt 中并未使用硬性阈值），不同 prompt 措辞、不同主干 LLM 对"停滞"的判定标准可能不同，论文未对此做敏感性分析。

6. **数据集规模与多样性限制**：NeuCLIR（74 条查询）和 LegalSearch（100 条查询）的测试规模较小，统计功效有限；且三个数据集均属于"多跳信息检索"类型，未覆盖对话式研究、多模态检索、流式知识更新等更复杂的实际深度研究场景。

7. **未报告多次运行的方差**：论文未说明不同随机种子或 LLM 采样温度下的结果方差，对于基于 LLM 的智能体而言，同一查询多次运行的轨迹可能差异显著，结果的稳定性存疑。

## 9. 对未来工作的启示与开放问题

1. **从"减少停滞"到"主动规划"**：RAAC 目前是对停滞的被动响应（在问题发生后检测并干预）。未来可探索**前瞻性（proactive）控制**——即在每轮开始前预测本轮检索的信息增益，从而提前规划搜索策略，而非事后补救。

2. **学习型控制器的可行性**：既然论文已证明文档新颖性等信号与迭代有效性高度相关（AUROC 分析），未来可用这些信号构造标注数据，训练一个轻量级二元/三元分类器替代 LLM 决策，可进一步降低延迟并提高决策稳定性。

3. **更细粒度的表征空间**：当前信号是轨迹级的标量汇总。未来可探索**文档级或句子级的检索感知表征**（如已覆盖子主题的多维向量），实现对搜索空间覆盖率的精确建模，进而支持更细粒度的动作（如"针对未覆盖子主题定向检索"）。

4. **多智能体协作场景下的停滞检测**：在并行多智能体深度研究中，"搜索空间耗尽"与"智能体彼此信息冗余"是两种不同的停滞模式，需要区分处理。RAAC 的轨迹级信号可扩展为多智能体间的共享信号。

5. **与强化学习训练的结合**：论文发现 RL 训练的智能体（如 GLM-4.7、AgentCPM-Explore）仍然存在推理停滞，说明当前 RL 训练目标（如最终答案正确率）未能充分鼓励**信息探索效率**。未来可在 RL 奖励中引入中间过程的检索新颖性/覆盖度奖励，从根本上训练出"检索感知"的智能体。

6. **用户可解释性与控制权**：RAAC 的干预可以更透明——例如向用户展示"当前已覆盖 3/5 个准则，正在针对剩余 2 个切换搜索方向"，让用户能手动批准或否决控制器的动作，提升人机协同深度研究的信任度。

## 10. 文章的检索感知结论总结（一条主线）

> **核心逻辑链**：深度研究智能体在长推理轨迹中普遍存在"推理停滞"（信息发现早期饱和、后期低效循环）→ 停滞的根源是智能体缺乏对自身轨迹的检索感知（不知道已覆盖了什么）→ 通过引入轻量级、智能体无关的检索感知控制器（RAAC），以文档新颖性为主的四个无监督信号实时监测轨迹质量，并采取 continue/intervene/stop 三动作 → 在 7 种架构 × 3 个数据集上系统验证了该方法能以更少的搜索调用获得同等或更好的检索与回答质量。

## 11. 论文基本信息（补充）

- **标题**：When Deep Research Agents Stuck: Enhancing Reasoning with Retrieval-Aware Agent Control
- **核心贡献**：① 首次系统性揭示 DRA 的"推理停滞"现象并给出量化分析方法（中间召回率、新条目召回率、文档类型分布）；② 提出可即插即用的 RAAC 控制器，仅需四个无监督信号即可有效控制任意 DRA 的推理轨迹；③ 通过大规模跨架构、跨数据集实验（含消融、相关性分析、案例分析）验证了方法的有效性与可解释性。
- **适用场景**：任何以"多轮搜索 + 多步推理"为范式的检索增强智能体系统，尤其适用于对延迟与成本敏感的产品化深度研究场景。
