## 摘要
现有的智能体推理系统通常依赖中心化协议。这种设计引入了路由瓶颈和静态角色分配，在处理复杂多模态查询时往往失效。我们提出DeAR（去中心化智能体推理），一种从中心控制转向自主点对点协作的框架。DeAR基于三种机制：(1) 用于查询相关智能体特化的去中心化能力锚定，(2) 用于定向智能体交互的思想地图导航，以及(3) 用于自适应错误修正的拓扑更新。在9个多样化的多模态推理和基于文本的问答基准上的评估表明，DeAR一致优于最近的基线方法，验证了智能体间的去中心化与自适应协作能提升知识密集型推理任务的准确性。源代码将在 https://open_upon_acceptance 提供。

## Abstract
Existing agentic reasoning systems typically rely on centralized protocols. This design introduces routing bottlenecks and static role allocations that often fail when handling complex multimodal queries. We propose DeAR (Decentralized Agentic Reasoning), a framework that shifts from central control to autonomous peer-to-peer collaboration. DeAR is built on three mechanisms: (1) decentralized capability grounding for query-dependent agent specialization, (2) thought map navigation for targeted peer interactions, and (3) topology update for adaptive error correction. Evaluations across 9 diverse multimodal reasoning and text-based QA benchmarks indicate that DeAR consistently outperforms recent baseline methods, validating that decentralized and adaptive collaboration among agents enhances accuracy in knowledge-intensive reasoning tasks. The source code will be available at https://open_upon_acceptance.

## 1. 核心问题与研究动机

本论文针对**现有智能体推理系统过度依赖中心化协议的固有缺陷**展开研究。作者指出，当前主流的智能体推理框架（如 AutoGen、AgentVerse、DyLAN 等）在架构上均采用中心化控制范式，存在两大核心弊端：

- **路由瓶颈**：一个中心协调者（Coordinator）或裁判（Judge）垄断了所有任务的分配、路由与结果聚合。在复杂多模态查询中，若中间智能体产生错误或幻觉，中心节点会盲目聚合这些有缺陷的中间结果，且缺乏对等验证机制，导致错误沿流水线逐级传播。
- **静态角色分配**：基于预定义标签（如"视觉提取 Agent"、"数学 Agent"）的角色分工只是真实能力的弱代理。在开放域任务中，协调者容易对标签产生能力幻觉，将不匹配的任务错误路由给不擅长的智能体，导致推理失败。

作者以"图像中有多少人出生于二战后"这一复合查询为例，说明单智能体无法同时完成细粒度视觉识别与历史知识检索，而中心化多智能体框架中的裁判节点则可能因盲目聚合错误结果而输出错误答案。其核心观点是：**这些失败源于中心化协作协议的结构性缺陷，而非模型本身能力不足。**

## 2. 方法论：DeAR 框架

DeAR（**De**centralized **A**gentic **R**easoning）将智能体协作从中心化控制转向**自主对等协作**，核心思想是让智能体像现实世界的跨学科专家一样，自主决定何时、与谁协作，不依赖全局调度器。系统形式化定义为 S = (Q, A, C, K)，即问题、智能体集合、协作倾向矩阵 C ∈ R^(N×N)，与知识状态序列 K。框架包含三大核心机制：

### 2.1 去中心化能力锚定（Decentralized Capability Grounding）

针对静态标签问题，智能体不再被赋予固定角色名，而是基于自身官方技术报告或模型卡中的**可验证基准数据**，在多维认知维度上建立自身的连续能力画像：τ_i = (τ_cr, τ_ea, τ_nc, τ_fr, τ_cm)，分别对应常识推理、解释能力、数值计算、事实可靠性与自然语言理解。

- **锚定机制**：将各维度对应的标准基准分数（如 GSM8K → 数值计算、MMLU → 常识推理、TruthfulQA → 事实可靠性）按如下公式进行 Softmax 跨智能体归一化：

  τ_i^d = exp(s_i^d) / Σ_{k=1}^{N} exp(s_k^d)

  这确保了所有智能体的能力值在相同尺度上严格可比且具有数值稳定性。

- **查询动态化**：当收到查询 q 时，智能体调用内部推理算子 Φ_i 将查询需求、技术报告与内在画像结合，形成查询相关能力状态 τ_i(q)，再以此条件化生成中间知识 K_i = Θ_i(q | τ_i(q))。

### 2.2 自组织协作与思想地图导航（Self-Organized Collaboration & Thought Map Navigation）

- 每个智能体 a_i 自主计算对其他智能体 a_j 的**协作倾向向量** c_i = [c_i,1, ..., c_i,N]，通过温度缩放 Softmax 计算：

  c_i,j = exp(τ_j^d / T) / Σ_{k≠i} exp(τ_k^d / T)

  其中 τ_j^d 是目标智能体在查询映射的认知维度 d 上的锚定能力，T 控制路由锐度，自协作被禁止（c_i,i = 0）。所有向量聚合形成协作倾向矩阵 C。

- **本地图遍历**：推理从随机种子节点开始，当前激活智能体作为本地导航器，选择使增量效用 u_i(a_j) 最大的未访问智能体：a_{i+1} = arg max u_i(a_j)，被选中的智能体基于累积知识上下文生成新知识。该过程逐步构建起一条自组织的推理链，无需中央裁判。

- **动态终止**：当所有未访问智能体的协作倾向低于阈值，或全部节点已遍历时终止，终止节点直接输出最终答案。

### 2.3 渐进式精炼的拓扑更新（Topology Update with Progressive Refinement）

当终止节点无法生成有效答案（即推理路径走入死胡同）时，系统不丢弃整个推理轨迹，而是采用**局部化、逐步回退**的纠错策略：

- 失败边缘集合 E_fail 仅包含当前终止边，若局部路由选择耗尽则逐步回溯至前序邻居。
- 对失败连接施加衰减因子 α（如 α = 0.5）：c_i,j ← α · c_i,j（仅对失败边）。

更新后的矩阵 C 引导智能体在修正后的拓扑上重新导航，实现渐进收敛到有效推理路径，避免了中心化系统"全链丢弃重启"的无效开销。

## 6. 主要结论与发现

1. **去中心化优越性**：DeAR 在 MathVista（59.41）、ChartQA（89.43）和 ScienceQA（62.45）上取得最高分，MMMU 达 55.58，一致超越包括中心化平台（AutoGen/AgentVerse/DyLAN）在内的所有基线。
2. **架构增益大于参数规模**：DeAR 的总参数量低于 Qwen2-VL-72B，但在 MathVista 上高出 18.07 分，证明收益来自结构化架构而非参数扩展。
3. **三个机制均不可或缺**：固定角色导致 MMMU 下降 5.76 分；移除思想地图导航使 MathVista 仅 51.68（降幅显著）；移除拓扑更新导致各数据集均有不同程度性能下滑。
4. **动态导航收益显著**：思想地图导航在统计推理（STA）上提升 18 个点、逻辑推理（LOG）提升 11.4 个点。
5. **效率自适应**：62.5% 的 MathVista 查询无需全部 4 个智能体即可解决，验证了按需激活的资源效率。
6. **中度衰减最优**：α ∈ [0.5, 0.8] 时性能最佳，过小导致过度修正，过大则无法有效剪枝。
7. **纯文本任务适用性**：在 NQ 上取得最优 EM，HotpotQA 上取得最高分，证明该范式可推广至纯 NLP 域。

## 7. 方法优点

- **范式创新**：首次系统性地将去中心化协作范式引入智能体推理，突破了对中心协调器的普遍依赖，对智能体架构设计具有启发意义。
- **能力锚定可验证性**：用定量基准数据替代主观标签，通过 Softmax 归一化保证跨模型能力可比，逻辑自洽且数值稳定。
- **局部图遍历而非全局路由**：将协作选择建模为动态邻接矩阵上的本地最优决策，既保留选择性协作又消除全局瓶颈。
- **渐进式纠错设计精巧**：局部回溯 + 按层扩展的策略精准剪枝失败边，避免了中心化系统全链重启的算力浪费，设计优雅且直觉合理。
- **动态终止机制**：基于实时能力评估而非固定步数终止路径，兼顾性能与资源利用。
- **有效的消融设计**："DeAR (Fixed Role)" 和 "w/o Topology Update" 等变体有效区分了架构优势与模型集成效应。
- **异构智能体组合**：选用 4 个不同厂商、不同类型的模型，避免同质化偏差，更贴近实际应用。

## 8. 不足与局限

- **基准覆盖有限**：虽横跨多模态与文本域，但未覆盖如多轮对话、工具使用、代码生成等更多智能体应用场景；每类任务仅一个指标，难以全面刻画多维性能。
- **算力信息缺失**：未报告 GPU 类型/数量、推理耗时、token 开销等关键工程指标，难以准确评估其相对于基线的实际成本效益。
- **统计显著性缺失**：未报告多次实验的方差或显著性检验结果，性能差异是否在统计意义上可靠尚不明确。
- **能力锚定的映射简化**：将复杂能力简化为五个维度的连续值可能失之粗糙，不同模型在基准上的分数也未必能完全反映真实场景中的表现。
- **协作矩阵依赖基准分数**：协作倾向完全由公开基准分数驱动，这些分数可能存在数据污染或评测偏差，从而影响路由质量。
- **最终答案缺乏独立验证**：虽然拓扑更新能纠正失败路径，但"生成最终答案的终止节点"同时充当验证者，缺少真正的外部监督或对等验证环节。
- **α 参数需人工调节**：衰减因子在不同数据集上需手动调优（0.1 与 0.9 均表现不佳），这本身仍带有一定中心化调参的色彩。
