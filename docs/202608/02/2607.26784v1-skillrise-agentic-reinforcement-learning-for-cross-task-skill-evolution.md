## 摘要
大语言模型智能体经常遇到相关但不同的任务，这些任务共享可复用的解决方案模式。然而，标准的智能体强化学习将任务视为独立的事件，而现有的技能学习方法要么专注于对单一任务的重复尝试，要么使用多阶段流水线，将抽取、检索和执行纠缠在一起。我们提出了SkillRise，一个用于跨任务学习技能的统一强化学习框架。SkillRise将相关实例组织成逐步具有挑战性的序列，并使用单一策略在任务解决和整理不断演进的技能文档之间交替，该文档直接传递给下一个任务。跨任务的解耦信用分配使用当前任务结果监督解决过程，并使用折扣后的下游结果监督整理过程。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在比较方法中取得了最强的Pass@1性能，比最强基线的提升幅度在2.3到8.5个百分点之间。尽管在不同任务上进行训练，其学到的整理策略对于同一任务的重复尝试仍然有效。进一步分析揭示了测试时跨任务的扩展性：即使每个任务只尝试一次，性能也会随着相关任务序列的延长而提升。这一趋势表明，SkillRise跨任务重用可迁移技能，而不是从对同一任务的重复采样中获益。SkillRise在显著降低多阶段技能学习流水线运行时开销的同时，保持了强大的性能。总之，这些结果为LLM智能体提供了一种简单高效的训练范式，使其能够跨任务提取、改进和重用可迁移技能。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 2. 论文提出的方法论

### 2.1 核心思想
SkillRise 将跨任务技能学习形式化为一个统一的强化学习问题：给定一组**有序的相关任务序列**，单一策略交替执行两种角色——
- **任务解决（Task Solving）**：利用当前技能文档完成当前任务；
- **技能整理（Skill Curation）**：根据刚结束的任务轨迹更新技能文档，传递给下一个任务。

技能文档是唯一跨任务的信息通道，后续任务的表现天然成为衡量技能迁移质量的信号。

### 2.2 关键技术细节

**（1）跨任务序列构建**
- 利用环境提供的任务族元数据（family metadata），将同一任务族内不同实例分组；
- 按难度从简到繁排列任务（如 WebShop 按产品类别分组、按所需属性和选项数量排序）；
- 每个训练序列含 K 个不同实例，构成渐进式学习路径。

**（2）跨任务滚动（Rollout with Skill Evolution）**
- 每个 trial 从空技能文档 S₀ = ∅ 开始；
- 对第 i 个任务：策略先利用 Sᵢ₋₁ 生成解决轨迹 τᵢ，获得任务奖励 rᵢ = R(τᵢ)；
- 对前 K-1 个任务：策略切换为"技能整理"角色，基于 Sᵢ₋₁、τᵢ 和 rᵢ 生成修订后的完整文档 Sᵢ；
- 只有修订后的文档传递给下一任务，早期轨迹不进入后续任务上下文，确保 Sᵢ 是唯一的跨任务信息通道。

**（3）解耦信用分配（Decoupled Credit Assignment）**

论文提出了按时间角色分离的奖励分配方案：
- **任务解决**：仅由**当前任务奖励** rᵢ 监督；
- **技能整理**：由**后续任务的折扣累积奖励** Σγʲ⁻ⁱ·rⱼ（j > i）监督，γ ∈ [0,1] 为跨任务折扣因子（实验中取 0.6）。

这样避免了将序列级回报同时归于两个阶段而混淆"解决质量"与"技能迁移性"的问题。

**（4）角色感知的组相对优化（Role-Aware Group-Relative Optimization）**
- 对固定序列、固定位置 i、固定角色 z，在 N 个独立 trials 之间计算组相对优势：A = G⁽ⁿ⁾ − mean(G)；
- 按"任务位置 × 角色"分组，确保解决与整理的回报互不作为对方的基线；
- 使用 PPO 风格的裁剪目标（clipped objective）联合优化两类响应中的所有 token。

**（5）训练设置**
- 每批次 16 个序列，每个序列 K=3 个任务，每任务 N=8 个独立 trials；
- 学习率 1×10⁻⁶，mini-batch 128，最大响应长度 1024 tokens，最多 150 次更新；
- 评估用温度 0.7 采样。

## 6. 论文的主要结论与发现

1. **SOTA 性能**：SkillRise 在三个 benchmark 上均获得最强 Pass@1——ALFWorld 85.9%、WebShop 84.4%、ScienceWorld 54.6%，超最强基线 GiGPO 分别达 2.3、7.1、8.5 个百分点；
2. **跨任务确为迁移而非重复采样**：Pass@2/Pass@3 也全面领先，表明跨任务训练学到的技能整理策略可泛化到同任务重复尝试，甚至超过专门训练于同任务重复的 LaMer；
3. **测试时跨任务扩展性**：在 ALFWorld 上，随着相关任务序列从 K=2 增至 K=6，SkillRise 性能单调提升（83.6%→87.5%），而对比方法无此趋势；由于每任务只尝试一次，该增益纯粹来自技能跨任务迁移；
4. **模型规模增益更大**：从 1.7B 扩到 4B 时，SkillRise 提升 7.8 个百分点，大于 GRPO（+4.7）和 LaMer（+3.3），说明更大容量对"任务执行+跨任务抽象"的双重学习目标更为有利；
5. **端到端范式效率优势**：在匹配甚至超越 RetroAgent 性能的同时，SkillRise 只需其 1/6 的运行时间，验证了"直接以后续任务结果监督技能整理"比多阶段流水线更清晰高效。

## 7. 优点

- **统一优雅的问题形式化**：将技能提取与技能使用纳入同一策略、同一优化目标，避免了多阶段流水线的工程复杂性和归因困难；
- **解耦信用分配设计精巧**：按时间角色区分解决与整理的监督信号，符合两类行为在时间上的因果关系，是一个具有较强普适性的方法论贡献；
- **"以文档作为唯一跨任务通道"的设计**：实验设计干净，能严谨证明性能增益确实来自技能迁移而非其他信息泄露；
- **测试时扩展性证据有力**：通过"每任务仅尝试一次 + 序列长度变化"的实验设计，清晰排除重复采样混淆，证明技能确实跨任务迁移；
- **角色感知的组相对优势**：考虑了序列位置和阶段的差异，比朴素 GRPO 更精细；
- **训练效率显著**：在相同计算预算下达到最优性能，且无需外部教师模型、记忆库或检索模块。

## 8. 不足与局限

- **依赖任务族元数据**：当前序列构建需要环境提供任务族标签（如"同一产品类别"），在开放式无标注任务流中自动发现任务关联性仍是未解决的问题；
- **模型规模受限**：实验仅在 Qwen3-1.7B/4B 上进行，结论在更大模型（如 7B、70B 级）上的外推性未知；
- **环境覆盖面有限**：三个基准均为文本交互环境，且奖励均为可验证的二元结果；在更泛化的多模态、真实世界、奖励信号模糊的任务上尚需验证；
- **统计严谨性不足**：未报告多次运行的标准差或显著性检验，结果存在一定随机波动风险（如 ALFWorld 内部各子任务族波动明显）；
- **消融覆盖不完整**：折扣因子敏感性和无整理消融仅在 ALFWorld 上评估；未消融序列长度 K 的选择、任务难度排序策略的贡献；
- **多阶段管线复现公平性**：SkillRL 的复现使用较大教师模型（Gemini-2.5-Pro），可能放大其训练开销，但对多阶段管线的性能对比仍有改进空间；
- **γ 的选取依据**：论文指出 γ=0.6 对结果不敏感，但未讨论 γ 与序列长度 K 之间的交互关系（更长的序列可能需要不同的折扣策略）。
