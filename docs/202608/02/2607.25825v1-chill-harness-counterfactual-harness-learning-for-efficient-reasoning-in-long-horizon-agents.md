## 摘要
智能体harness已成为现代大语言模型智能体的运行基础设施，协调上下文、工具、验证和执行控制，将潜在模型能力转化为可靠的长时程行为。然而，可靠的长时程行为要求harness控制适应任务需求、执行环境和不断变化的执行状态，而当前harness主要依赖手工设计或全局固定的策略；这种不匹配表现为不必要的计算开销，在不利情况下还会降低任务成功率。为解决这一局限，我们将harness系统中实现自适应编排的任务表述为一个因果学习问题，并提出用于长时程智能体的反事实Harness干预学习（CHILL-Harness）。CHILL-Harness在编排层进行干预，以实现优势引导的工作流自适应，从而在保持任务性能的同时提高推理与执行效率。具体而言，我们开发了因果干预效应学习作为CHILL-Harness的效应估计组件，从置信度加权的执行证据中估计与干预相关的工作流优势，并识别有利的工作流调整。我们进一步引入优势实现的因果编排作为其实现组件，以自适应地分配反事实推理，仅实现具有足够预期优势支持的工作流调整。最后，我们在CHILL-Harness中加入成功保持目标与优势边际授权约束，以促进可靠的自适应。在涵盖信息检索、软件工程和终端交互的异构长时程任务上的大量实验表明，CHILL-Harness在显著降低令牌消耗和执行时间的同时，持续保持或提升任务成功率。

## Abstract
Agent harnesses have become the operational infrastructure of modern large language model agents, coordinating context, tools, verification, and execution control to translate latent model capability into reliable long-horizon behavior. However, reliable long-horizon behavior requires harness control to adapt to task demands, execution environments, and evolving execution states, whereas current harnesses predominantly rely on hand-crafted or globally fixed policies; this mismatch manifests as unnecessary computational overhead and, in adverse cases, reduced task success. To address this limitation, we formulate the task of enabling adaptive orchestration in harness systems as a causal learning problem and propose Counterfactual Harness Intervention Learning for Long-Horizon Agents (CHILL-Harness). CHILL-Harness intervenes at the orchestration layer to enable advantage-guided workflow adaptation, thereby improving reasoning and execution efficiency while preserving task performance. Specifically, we develop causal intervention effect learning as the effect-estimation component of CHILL-Harness to estimate intervention-relative workflow advantage from confidence-weighted execution evidence and identify advantageous workflow adaptations. We further introduce advantage-realizing causal orchestration as its realization component to adaptively allocate counterfactual reasoning and realize only workflow adjustments supported by sufficient expected advantage. Finally, we incorporate a success-preserving objective and advantage-margin authorization constraints into CHILL-Harness to promote reliable adaptation. Extensive experiments on heterogeneous long-horizon tasks spanning information seeking, software engineering, and terminal interaction show that CHILL-Harness consistently preserves or improves task success while substantially reducing token consumption and execution time.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型智能体（LLM Agent）在长时程任务（如信息检索、软件工程、终端交互）中需要持续管理上下文、调用外部工具、进行中间验证、实现失败恢复和执行控制。Agent Harness（智能体框架/运行基础设施）负责协调这些环节，将模型潜在能力转化为可靠行为。
- **核心问题**：现有 Harness 的编排策略大多依赖 **手工规则、固定阈值或全局配置的工作流**，无法根据任务需求、执行环境和实时执行状态动态调整。这种"静态控制 vs 动态环境"的不匹配导致：
  - 冗余推理（过度深思/过度规划）
  - 延迟纠正（发现问题过晚）
  - 不必要的工作流中断
  - 计算成本上升，甚至任务成功率下降
- **核心洞见**：作者将"Harness 是否应该干预当前工作流"这一问题形式化为 **因果学习问题**——当前工作流是事实参照（factual reference），可行替代方案是在同一执行上下文中的 **反事实干预**（counterfactual interventions）。通过因果干预，可以隔离"工作流调整"本身对任务表现的因果贡献，而非被上下文混杂所混淆。

## 2. 方法论：CHILL-Harness

### 2.1 总体框架
CHILL-Harness 将因果 Harness 编排分解为两个耦合的子问题：
- **Harness 干预效应问题**：评估某个可行替代工作流在同一上下文下是否比事实工作流更优（"是否该干预"）。
- **Harness 干预实现问题**：确定估计收益是否足以证明替换事实工作流的合理性（"如何实现干预"）。

### 2.2 核心组件一：CIEL（Causal Intervention Effect Learning，因果干预效应学习）

- **统一因果干预归纳（Unified Causal Intervention Induction）**：将 Harness 的重复性适应行为抽象为统一干预空间：
  - `Keep`（保留事实工作流）
  - `Deliberate`（追加推理）
  - `Revise(r)`，r ∈ {Inspect, Verify, Visual}（获取证据、验证中间状态、视觉检查）
  - `Stabilize(q)`，q ∈ {Dedup, NoOpRecovery}（抑制重复操作、恢复无效执行）
  - `AnswerSynthesis`（非终止性的答案构建）
  - 每个干预通过实现映射 `G_t(ι)` 对应到一组可执行工作流。
- **工作流效应估计**：学习上下文条件化的工作流效果 `Γ_t(ω) = E[U_t(ω) − U_t(ω⁰_t) | χ_t]`，以事实工作流为零效应参考。训练数据来自**离线检查点配对回放**（checkpointed paired replay）——从相同上下文恢复，分别执行事实与候选工作流，比较其效用差 `Γ̃_pair(ω)`。
- **三因子决策学习（Factorized Intervention Decision Learning）**：
  - **CDE（Counterfactual Deliberation Effect）**：预测深思路线 `z_t ∈ {Skip, Light, Full}`，控制额外推理的计算量——解决**过度深思**问题。
  - **CRE（Counterfactual Revision Effect）**：预测是否支持用候选工作流替换事实工作流 `y_chg ∈ {Keep, Change}`——解决**工作流惯性**与**有害替换**的双重问题。
  - **CAE（Completion Attribution Effect）**：预测完成支持 `b_t ∈ {0,1}`——防止**任务已成功仍继续执行**和**仅因无望而提前终止**。
- **理论保证**：论文证明了干预选择遗憾（selection regret）受效应估计误差和摊销预测误差联合控制：`V_int(ι†) − V_int(ι̂) ≤ 2ε_t + ρ_t`（命题 A.1）。

### 2.3 核心组件二：ARCO（Advantage-Realizing Causal Orchestration，优势实现因果编排）

ARCO 将 CIEL 学到的决策落地为具体执行：

1. **路线先于生成（Route-before-generation）**：先用 CDE 选出深思路线（Skip/Light/Full），Skip 直接保留事实工作流；否则只暴露该路线允许的候选工作流集合 `Ω_t ⊆ A_t`——在**生成候选之前**就抑制低价值深思，避免规划器开销。
2. **因果-操作联合估值（Causal–Operational Valuation）**：对每个暴露的候选工作流计算组合效用 `Û_ARCO = Û_op + η_Γ·Γ̂_φ`，其中 `Û_op` 聚合进展、成本、风险、信息增益、鲁棒性和安全性信号。
3. **保守授权（Conservative Authorization）**：选择最高价值候选 `ω⁺_t` 后，要求 **同时满足**：
   - CRE 输出 `Change`（学习支持替换）；
   - 估计优势 `Δ_cf ≥ δ_{ι̂_t}`（干预相关的授权边际）；
   - 通过可采性过滤（安全、模式有效、任务兼容、预算内、非重复）。
   - 任一条件不满足则保留事实工作流 `ω⁰_t`。
4. **证据约束的终止（Evidence-Grounded Completion）**：终止需要 **双重要求**：CAE 预测 `b̂_t = 1` **且** 显式任务验证器输出 `e_comp = 1`。`AnswerSynthesis ≠ Complete`——合成答案是非终止性适应，不等于终止。

### 2.4 成功保持目标（Success-Preserving Objective）

- 全局优化目标为最小化轨迹资源成本，同时约束 `PassRate(π_CHILL) ≥ PassRate(π_ref) − ε_pass`（允许的通过率退化上限）。
- 轨迹级损失 `L_traj = J_eff + λ_fail(1−Y_τ) + λ_break·I[Y_ref=1 ∧ Y_τ=0]`——第三项专门惩罚"将参考成功转化为失败"的适应行为（break-aware supervision）。
- 由于环境执行不可微，通过**结果条件化的弱监督**而非轨迹级反向传播实现。

## 6. 主要结论与发现

- **RQ1（有效性）**：在匹配参考设置下，CHILL-Harness 在**所有三个基准**上保持或提升任务成功率。它在 GAIA（71.3%）和 SWE-bench Verified（65.6%）上取得最高成功率；Terminal-Bench 2.0 上为 56.1%，超过 Terminus-KIRA 和 Meta-Harness，接近 LemonHarness（57.4%）。
- **RQ2（效率）**：CHILL-Harness 在每个基准组中取得**最高的每百万 token 解决任务数**。相对最低 token 基线，token 消耗降低 **28.4%（GAIA）、13.1%（SWE-bench）、23.1%（Terminal-Bench）**；相对最快基线，运行时间降低 **46.6%、25.9%、2.6%**。
- **RQ3（泛化性）**：在信息检索、软件修复、终端交互三个异构环境中，效率和有效性的提升均保持一致模式。
- **消融结论**：强制全量深思（Always-Full）在 GAIA 上导致严重过度干预（成功率从 71.3% 暴跌至 27.7%），在 SWE-bench 上同时增加成本并降低成功率，在 Terminal-Bench 上产生大量规划开销但几乎无收益——验证了 CDE 选择性深思和"路线先于生成"设计的必要性。

## 7. 优点（亮点）

- **新颖的因果视角**：将 Harness 编排决策形式化为"事实 vs 反事实"的因果效应估计问题，与已有方法（工程化 Harness、协作结构优化、组件级适应）形成本质区别——现有方法不评估具体编排干预是否因果性地改善当前工作流。
- **干预效应与实现决策分离**：CIEL 负责"什么适应是有益的"（效应估计），ARCO 负责"如何实现适应"（路线选择、估值、授权），且两者通过理论边界（命题 A.1/A.2）建立联系。
- **保守性设计原则**：多种机制共同防止效率优化破坏成功率——成功保持目标、优势边际授权（δ）、CRE 双闸门、CAE+验证器的双重完成确认、Skip 保守平局决策（无正效应时保持事实工作流）。
- **理论保障扎实**：提供干预选择遗憾界、配对回放识别与集中界、插入-中间界（插值错误、配对回放误差、摊销误差三者联合控制选择质量）。
- **最保守的指标口径**：token 统计包含所有反事实深思和候选估值的模型调用，没有隐藏开销；对照实验使用匹配参考运行确保公平性。

## 8. 不足与局限

- **实验覆盖的局限**：
  - 仅使用 deepseek-v4 系列模型，未验证方法在不同模型家族上的通用性；
  - 未报告多次运行的方差/置信区间，难以判断成功率差异的统计显著性；
  - 消融仅覆盖 CDE 一个组件，CIEL 其他决策头（CRE、CAE）和授权机制的独立贡献未被验证。
- **偏差风险**：
  - CIEL 训练依赖离线配对回放数据（从相同检查点执行事实与候选分支），该数据构造成本较高，且论文未报告其总量与收集效率；
  - 授权边际 `δ`、估值系数 `α`、`η_Γ` 等超参需要针对基准进行校准，可能存在对特定基准过拟合的风险；
  - 轨迹弱监督标签（`z*, y*, b*`）由"成功保持"条件倒推生成，若参考 Harness 本身成功率有限，弱监督信号的质量可能受限。
- **应用限制**：
  - Terminal-Bench 上的时间增益较小（2.6%），说明在部分环境下编排开销的减少并未完全转化为端到端延迟收益；
  - 框架引入了多个预测头（干预、路线、修订、完成）和复杂的授权链，部署复杂度高于单一策略的 Harness；
  - 论文未讨论方法在实时性要求更高、或上下文窗口极长的场景下的扩展性。

**总体评价**：CHILL-Harness 是首个将 Harness 自适应编排系统性地建模为因果学习问题的工作，兼具理论深度与实证说服力。其"选择性干预 + 成功保持"的核心思想，为长时程智能体的高效可靠部署提供了有价值的新范式，但训练成本透明度、跨模型泛化验证和组件级消融仍需进一步完善。
