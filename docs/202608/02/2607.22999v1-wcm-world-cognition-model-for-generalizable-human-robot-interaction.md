## 摘要
语言代理如今能够在软件环境中与用户流畅交互，但机器人在物理任务中仍难以实现同等水平的交互。当前的机器人控制范式，包括视觉-语言-动作策略和基于世界模型的规划器，主要针对指令执行进行优化，导致用户难以理解为何选择某个动作，也缺乏通过交互来引导、纠正或教授机器人的机制。为解决这一问题，我们提出了世界认知模型（WCM），一种基于SLAK架构（感知、逻辑、动作与知识）和异步运行时的人本具身代理。SLAK将感知、推理、控制与记忆分离，而运行时允许推理、对话与执行并行进行。WCM进一步引入了人在回路的教学模式，使用户能够交互式地教授机器人完成困难或长视界任务。教学片段和自主任务执行被提炼为思维链监督，以持续改进模型。在九项真实世界人机交互任务中，WCM实现了73.8%的平均成功率，包括从思维链微调中留出的任务以及一项通过教学习得的长视界任务。

## Abstract
Language agents can now interact fluently with users in software, but robots still struggle to bring comparable interaction to physical tasks. Current robot-control paradigms, including vision-language-action policies and world-model-based planners, are mainly optimized for instruction execution, leaving users with little visibility into why an action is chosen and few mechanisms to redirect, correct, or teach the robot through interaction. To solve this problem, we present the World-Cognition Model (WCM), a human-centered embodied agent built on the SLAK architecture (Sensing, Logic, Action, and Knowledge) and an asynchronous runtime. SLAK separates perception, reasoning, control, and memory, while the runtime allows reasoning, dialogue, and execution to proceed concurrently. WCM further introduces a human-in-the-loop teaching mode that enables users to interactively teach the robot difficult or long-horizon tasks. Teaching episodes and autonomous task rollouts are refined into chain-of-thought supervision to continually improve the model. WCM achieves a 73.8% average success rate across nine real-world human-robot interaction tasks, including tasks held out from CoT fine-tuning and a long-horizon task learned through teaching.

**研究动机与背景**：
- 语言代理（Language Agents）已能在纯软件环境中与用户进行流畅交互，但机器人在物理任务中仍难以实现同等水平的交互。

  - **视觉-语言-动作（VLA）策略**：直接从视觉与语言输入映射到动作；

  - **不可交互**：用户缺乏机制去引导、纠正或教授机器人，难以将人类知识注入系统。

**整体含义**：
本文提出 **世界认知模型（WCM，World-Cognition Model）**——一个以人为中心的具身智能代理。其核心目标是将**可解释性**与**可交互性**纳入机器人控制的基础架构中，而不只是追求任务成功率。通过分离感知、逻辑、控制与记忆，以及引入人类在环教学机制，WCM 试图建立一种更通用、更自然的人-机器人协作范式。

## 2. 方法论

**核心思想**：
WCM 的核心在于对机器人认知架构的重新设计：模仿人类认知模块分工，将**感知、推理、控制与记忆**解耦，并让它们**异步并发运行**，从而在实时执行任务的同时支持对话与推理。

**关键技术细节（SLAK 架构）**：
- **S（Sensing，感知）**：负责环境状态感知与多模态输入处理；
- **L（Logic，逻辑）**：负责任务推理、规划与决策；
- **A（Action，动作）**：负责将高层决策转化为具体物理动作并执行；
- **K（Knowledge，知识）**：负责经验存储、长期记忆与可迁移知识的管理。

**异步运行时（Asynchronous Runtime）**：
- 允许**推理、对话与执行**三者并行进行，而不是串行阻塞；
- 这使得机器人在执行动作的同时，还能响应用户提问、接受指令修正，实现真正的"边做边聊"。

**人在回路教学（Human-in-the-Loop Teaching）**：
- 用户可交互式地教授机器人完成**困难或长视界（long-horizon）任务**；
- 教学过程中，用户的示范与自然语言指导被记录为教学片段（teaching episodes）；
- 教学片段与机器人自主任务回放（autonomous rollouts）被进一步**提炼为思维链（Chain-of-Thought, CoT）监督信号**，用于持续微调和改进模型。

**算法流程（文字说明）**：
1. **教师教学阶段**：用户通过语言指令、动作示范等方式教授机器人完成任务，系统记录完整教学轨迹。
2. **自主执行阶段**：机器人在环境中自主回放/执行所学任务，收集执行数据。
3. **CoT 监督提炼**：从教学轨迹与自主回放中提取结构化推理链，作为监督信号。
4. **模型更新**：利用提炼出的 CoT 数据对模型进行持续微调，逐步提升泛化能力与交互质量。
