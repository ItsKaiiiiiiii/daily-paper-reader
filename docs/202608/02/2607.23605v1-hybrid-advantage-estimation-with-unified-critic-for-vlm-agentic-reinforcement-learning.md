## 摘要
大型视觉语言模型（VLM）现在作为智能体在交互环境中运作，其成功需要在多轮交互中进行连贯的推理和决策。尽管在智能体环境中进行端到端训练能够提升这种多轮决策能力，但当前方法主要依赖于对拼接的令牌轨迹进行逐词优化，或采用轮级统一信用分配进行逐轮优化。在本工作中，我们为这两个优化层级建立了理论公式，并推导出一种混合优势，同时服务于这两个目标。此外，通过适当选择折扣因子和学习目标，我们证明了一个统一的评论家模型能够同时估计轮级和令牌级的值。因此，我们提出了HyGAE，一个演员-评论家框架，通过混合优势和统一评论家联合优化令牌级和轮级目标。我们在五个多轮决策环境中对HyGAE进行了广泛评估，其平均成功率达到91%，相较于其他方法显著提升了10%。此外，我们进行了深入分析，表明混合优势和回报的精确解析形式对优化至关重要。项目页面：https://wx-zhang.github.io/hygae-web/。

## Abstract
Large Vision-Language Models (VLMs) now act as agents in interactive environments, where success requires coherent reasoning and decision-making across turns. Although end-to-end training in agentic environments can improve such multi-turn decision-making abilities, current methods mainly rely on either token-wise optimization over concatenated token trajectories or turn-wise optimization with uniform within-turn credit. In this work, we establish theoretical formulations for the two levels of optimization and derive a hybrid advantage that serves both objectives. Furthermore, with an appropriate choice of discount factor and learning target, we prove that a unified critic model can estimate values for both turn-wise and token-wise. As such, we propose HyGAE, an actor-critic framework that jointly optimizes token- and turn-level objectives with the hybrid advantage and unified critic. We conduct extensive evaluations of HyGAE across five multi-turn decision-making environments, where it achieves an average success rate of 91% and a significant improvement of 10% over other methods. Furthermore, we provide an in-depth analysis showing that the exact analytic form of the hybrid advantage and return is crucial for optimization. Project Page: https://wx-zhang.github.io/hygae-web/.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大型视觉语言模型（VLM）已从单轮视觉问答扩展到多轮、交互式的智能体决策任务。在这类任务中，模型需要持续感知环境、基于历史信息推理、生成动作，并根据环境反馈调整后续行为。
- **核心问题**：当前 VLM 在多轮决策中存在"短视"问题——模型往往只根据最近的观测做决策，忽略过去的动作和反馈，导致重复无效动作、缺乏系统性规划。作者认为根本原因在于**传统单轮训练范式与多轮交互需求不匹配**。
- **现有方法的局限**：
  - **Token 级优化**：将每个 token 视为动作，提供细粒度的生成指导，但过度折扣中间推理 token 的奖励。
  - **Turn 级优化**：将整轮生成视为一个宏动作，更好地利用中间反馈，但回合内信用分配均匀，缺乏 token 级细粒度指导。
  - 现有方法要么只使用单一层级，要么引入复杂的分层模型，缺乏统一的理论框架。
- **研究目标**：从理论上厘清两种优化层级的内在关系，设计一个**同时兼顾 token 级和 turn 级信用分配**的强化学习算法，提升 VLM 在多轮决策中的表现。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

- 将 VLM 多轮交互建模为 **POMDP**（部分可观测马尔可夫决策过程）。
- 从理论上证明：**turn-wise 和 token-wise 两种 RL 建模方式的策略梯度在本质上等价**，唯一区别在于优势函数（advantage）的选择。
- 因此无需构建复杂的分层模型，只需将两种优势函数进行**线性混合**，即可同时优化两个层级的目标。
- 进一步证明：在合适的折扣因子设置下（\(\gamma_t = \gamma^{I_t}\)，其中 \(I_t\) 为第 \(t\) 轮的 token 数），**轮级价值函数与 token 级价值函数在轮末 token 处相等**，从而可以用**一个统一的评论家（critic）模型**同时估计两个层级的价值，避免训练两个独立价值模型的额外开销。

### 2.2 关键技术细节

**（1）两种 POMDP 公式化：**
- **Token-wise POMDP**：每个 token 被视为动作，token 级奖励仅在回合末 token 处获得环境奖励，其余中间 token 奖励为 0。其替代目标为：
  \[
  L_{\text{token}}(\theta) = \mathbb{E}\left[\sum_{t=0}^{T-1}\sum_{i=0}^{I_t-1} \log \pi_\theta(a_t^i|\tau_t^i) A^{\pi_\theta}(\tau_t^i, a_t^i)\right]
  \]
- **Turn-wise POMDP**：整轮生成的 token 序列被视为一个宏动作。由于
  \[
  \log \pi_\theta(a_t|\tau_t) = \sum_{i=0}^{I_t-1}\log \pi_\theta(a_t^i|\tau_t^i)
  \]
  turn-wise 替代目标可展开为逐 token 求和形式：
  \[
  L_{\text{turn}}(\theta) = \mathbb{E}\left[\sum_{t=0}^{T-1}\sum_{i=0}^{I_t-1} \log \pi_\theta(a_t^i|\tau_t^i) A^{\pi_\theta}(\tau_t, a_t)\right]
  \]
- 两种目标形式完全相同，仅优势函数不同。

**（2）混合优势函数（Hybrid Advantage）：**
\[
\hat{A}_t^i = \alpha \hat{A}_t + (1-\alpha) \hat{A}_t^i,\quad \alpha \in [0,1]
\]
- \(\hat{A}_t\)：turn-wise GAE 优势，在整轮内保持恒定，保留回合级奖励信号。
- \(\hat{A}_t^i\)：token-wise GAE 优势，提供逐 token 的细粒度信用分配。
- 理论保证：**定理 1** 证明混合替代目标的梯度与原始目标梯度一致，即 \(\nabla J(\theta) = \nabla L_{\text{hybrid}}(\theta) = \nabla L_{\text{turn}}(\theta) = \nabla L_{\text{token}}(\theta)\)，说明混合优化在梯度层面无偏。

**（3）统一评论家（Unified Critic）：**
- **定理 2** 证明在折扣因子满足 \(\gamma_t = \gamma^{I_t}\) 时，轮级价值函数与 token 级价值函数在轮末 token 处完全相等：
  \[
  V^\pi(\tau_t) = V^\pi(\tau_t^{I_t})
  \]
- 因此只需训练一个共享价值模型 \(V_\psi\)，在轮末提供轮级价值，在中间 token 位置提供 token 级价值，避免了双价值模型的计算和内存开销。

**（4）混合回报（Hybrid Return）：**
- Token-wise 回报：\(\hat{G}_t^i = \hat{A}_t^i + V_\psi(\tau_t^i)\)
- Turn-wise 回报向中间 token 广播：\(\hat{G}_t^i = \hat{A}_t + \sum_{k=i+1}^{I_t}\gamma^{k-i}r^k + V_\psi(\tau_t)\)
- 混合回报：\(\hat{G}_t^i = \alpha \hat{G}_t^i + (1-\alpha)\hat{G}_t^i\)

**（5）训练流程（Algorithm 1）：**
1. 与环境交互收集轨迹；
2. 分别计算轮级 GAE 和 token 级 GAE 的优势与回报；
3. 按公式混合得到混合优势 \(\hat{A}_t^i\) 和混合回报 \(\hat{G}_t^i\)；
4. 使用 PPO 裁剪目标更新策略网络，用 TD 损失更新统一价值模型。

**（6）理论分析（定理 3 和 4）：**
- **偏差对比**：轮级估计器偏差上界为 \(b_{\text{turn}} \leq b_{\text{token}}\)，即轮级优势偏差更小；
- **方差对比**：轮级估计器方差上界 \(v_{\text{turn}} > v_{\text{token}}\)，即 token 级优势方差更小；
- 这揭示了两种估计器之间存在**偏差-方差权衡**，混合优势可达到更好的平衡。

## 6. 论文的主要结论与发现

1. **理论层面**：turn-wise 和 token-wise 两种 RL 建模方式在梯度层面等价，差异仅在优势函数；混合优势函数的梯度与原始目标一致，因此在理论上可以采用线性混合。
2. **方法层面**：统一评论家模型能够同时为两个层级提供价值估计，显著降低计算和内存开销；混合优势在偏差-方差权衡上优于任一单一层级估计器。
3. **实验层面**：
   - HyGAE 在**所有五个基准上取得 SOTA**，平均成功率达到 **0.91**，比第二好的 Token-PPO（0.81）提升 10 个百分点；
   - 专有模型整体优于开源模型，但开源冻结模型表现极差（平均 < 0.1），说明**多轮 RL 训练对于赋予 VLM 决策能力至关重要**；
   - 混合回报的**精确解析形式**对训练稳定性至关重要，简化替代方案（如均匀广播、REINFORCE）会导致训练崩溃；
   - HyGAE 显著降低训练方差（±0.071 vs ±0.210），优化更稳定；
   - 定性分析表明，HyGAE 训练的模型能够基于失败反馈调整策略，避免重复无效动作，而冻结模型陷入重复循环。

## 7. 优点

- **理论贡献完整**：从 POMDP 的两种形式化出发，给出等价性定理、价值一致性定理、偏差-方差上界定理，推导严谨且自成体系。
- **方法简洁高效**：通过理论分析避免了复杂的分层 RL 模型，仅用一个统一的评论家模型即可实现两个层级的联合优化，计算效率和内存效率高。
- **实验覆盖广泛**：5 个基准涵盖不同复杂度和模态的决策任务，对比对象包括专有模型、开源模型和多种主流 RL 算法，证明方法的普适性。
- **消融和分析深入**：不仅报告了最终性能，还分析了混合回报公式、奖励聚合、价值基线选择等关键设计因素，以及偏差-方差的数值验证，实证支撑充分。
- **性能提升显著**：平均成功率 0.91，较现有方法提升 10%，并在所有环境中都达到 SOTA。

## 8. 不足与局限

- **计算资源信息不透明**：未报告具体 GPU 数量、总训练时长、FLOPs 等关键算力指标，影响复现和成本评估。
- **消融实验范围有限**：关键设计选择的消融只在 Sokoban 上进行，缺乏在其他四个环境上的验证；α 消融也未覆盖所有任务。
- **骨干模型单一**：所有 RL 实验仅基于 Qwen2.5-VL-3B，未验证方法在更大规模 VLM（如 7B、13B 或 70B）上的效果，结论的泛化性有限。
- **可复现性信息不足**：未提供多次随机种子的完整方差报告，除 Sokoban 的数值分析外，缺乏统计显著性检验。
- **环境规模相对较小**：Sokoban 和 FrozenLake 的测试集仅 128 个 episode，存在评估噪声风险；VIRL 的 OOD 测试集仅有 18 个样本，统计功效可能不足。
- **理论的简化假设**：定理条件（如 \(\gamma_t = \gamma^{I_t}\)）要求回合长度与折扣因子之间存在特定耦合，实践中回合长度 \(I_t\) 通常变化，该假设的适用性需要进一步讨论。
- **KL 惩罚处理方式较为启发式**：论文发现不将 token 级 KL 惩罚聚合到回合奖励效果更好，但这一发现缺乏理论解释，属于经验性处理。
- **应用限制**：方法主要面向可解析为文本动作的决策环境，对于更复杂的连续控制、多智能体交互或真实物理世界部署，其直接适用性尚未验证。
