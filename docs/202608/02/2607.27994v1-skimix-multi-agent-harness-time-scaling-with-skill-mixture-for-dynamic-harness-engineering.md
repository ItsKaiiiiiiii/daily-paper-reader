## 摘要
AI智能体日益依赖大型技能库，但选择、组合和维护技能仍然困难。我们提出了SKIMIX，一种多智能体框架，其中具有不同技能组合的智能体通过迭代细化进行协作。SKIMIX结合了基于嵌入的技能检索、子模块防稀释路由和自适应技能进化。在六个推理基准测试中，多智能体协作显著改善了开放式数学推理，但在多项选择任务上的改善有限甚至为负。智能体数量扩展是非单调的，大多数改进出现在第一轮细化中。这些结果表明，任务特征决定了技能级集成是否有帮助，并为可扩展智能体设计提供了实用指导。

## Abstract
AI agents increasingly rely on large skill libraries, but selecting, combining, and maintaining skills remains difficult. We propose SKIMIX, a multi-agent framework in which agents with different skill portfolios collaborate through iterative refinement. SKIMIX combines embedding-based skill retrieval, submodular anti-dilution routing, and adaptive skill evolution. Across six reasoning benchmarks, multi-agent collaboration substantially improves open-ended mathematical reasoning but offers limited or negative gains on multiple-choice tasks. Agent-count scaling is non-monotonic, and most improvements arise during the first refinement round. These results show that task characteristics determine whether skill-level ensembles help and provide practical guidance for scalable agent design.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现代AI智能体（Agent）依赖大型技能库（skill library）来执行复杂任务，但面临两大挑战：
  - **技能组合难**：对于任意给定查询，事先无法知道最佳的技能组合方式；技能组合空间庞大，穷举搜索不可行，现有系统要么使用固定单一流水线，要么依赖用户手动选择技能，导致大部分技能库未被利用。
  - **技能稀释（Skill Dilution）**：随着技能库不断扩大，冗余技能增加噪声、加大路由难度，并拉低整体性能。
- **研究意义**：现有研究聚焦于模型多样性（如MoA）或工具多样性（如TUMIX），而SKIMIX首次系统性地聚焦于**技能组合多样性**，致力于在大规模技能库条件下实现动态技能选择、组合与管理，并抑制技能稀释问题。

### 2. 论文提出的方法论：核心思想与关键技术细节

#### 核心思想
- **Skill Mixture (SKIMIX)**：并行运行多个智能体，每个智能体配备**不同的技能组合（Skill Portfolio）**，通过多轮迭代共享和精炼答案，最终通过多数投票聚合结果。
- 核心假设：技能比模型或工具**更廉价、更易混合、与任务性能的直接关联更强**，因此技能级集成具有独特的价值。

#### 三大关键技术机制

1. **动态技能注册表（Dynamic Skill Registry, DSR）**
   - 每个技能通过嵌入向量 \(e_i \in \mathbb{R}^d\) 编码其能力特征、调用模式和成功统计信息。
   - 使用基于余弦相似度的k-NN索引进行技能检索，替代硬编码规则。
   - 通过对比学习目标更新嵌入：\(e_i^{(t+1)} = e_i^{(t)} + \eta \cdot \nabla_{e_i} \mathcal{L}_{\text{align}}(q, e_i, y)\)。

2. **抗稀释路由（Anti-Dilution Routing, ADR）**
   - 将技能路由形式化为**子模最大化问题**：\(P^* = \arg\max_{P \subseteq S, |P| \le k} \sum_{s \in P} \text{rel}(s,q) + \gamma \cdot \log\det(I + K_P)\)
   - 其中第一项最大化技能与查询的相关性，第二项（对数行列式）最小化技能间的相似性（即提升多样性），直接抑制技能稀释。
   - 使用贪心算法求解，达到 \((1 - 1/e)\) 近似保证；边际增益低于阈值 \(\tau_{\min}\) 的技能被降权或归档。

3. **自适应技能进化（Adaptive Skill Evolution, ASE）**
   - 持续考核技能近期性能，过时技能被弃用（deprecated）。
   - 当使用模式暴露技能缺口时，从推理轨迹中**综合生成新技能**。

#### 形式化目标与流程
- 目标函数：\(\max_\pi P\{\hat{a}_\pi = a^\star\} - \lambda \cdot \text{Cost}_\pi\)，即最大化准确率与计算成本的平衡。
- 多轮精炼（Refinement）被建模为**消息传递**过程：每轮每个智能体根据原始查询和上一轮所有智能体的响应生成新解答。
- 终止条件：当边际收益 \(\Delta_r \le \lambda \cdot\) 边际成本时停止（LLM-as-Judge辅助判断，最少2轮）。
- 最终答案通过多数投票选择。

### 6. 论文的主要结论与发现

1. **任务类型决定多智能体协作的有效性**：
   - **开放式数学推理**：SKIMIX大幅优于自精炼。AIME上自精炼40.0% → SKIMIX-3达73.3%（+33.3%绝对值）；SKIMIX-15达76.7%（相对基线的0.0%提升了76.7个百分点）。
   - **多项选择任务（MCQ）**：单智能体自精炼最佳（GPQA达88.0%），添加更多智能体导致单调退化（SKIMIX-3=78.0%、SKIMIX-5=74.0%、SKIMIX-15=72.0%）。
   - **混合任务**：收益居中或微弱（HLE从43.0%升至51.0%）。

2. **智能体数量扩展非单调**：
   - AIME上3个智能体（73.3%）优于5个（70.0%），但15个（76.7%）又更好。
   - GPQA上每增加智能体都使性能下降。
   - 结论：**“更多智能体=更好性能”的默认假设不成立**，最优智能体数量是任务相关的。

3. **第二轮精炼是关键拐点**：
   - 几乎所有方法和基准的最大精度提升发生在Round 1→Round 2之间。
   - Round 3收益递减甚至为负（多智能体配置下，冲突响应引入噪声，正确候选答案可能被丢弃）。

4. **覆盖−准确率差距显著**：
   - 多智能体配置的覆盖率（≥1个正确候选）始终超过最终准确率。
   - 如HLE上SKIMIX-15达到72.0%覆盖率但仅51.0%最终准确率（21个百分点差距）。
   - 结论：**答案聚合是当前瓶颈**，而非候选生成，多数投票可能不是最优聚合策略。
