## 摘要
多流机器人操作策略通过相对于环境参考坐标系对动作进行建模，实现了无与伦比的样本效率和泛化能力。然而，现有方法通常假设这些坐标系是严格外生的。这种因果假设在动态环境中会失效，例如当单个机械臂操作移动物体或双臂协调时，每条手臂实际上都成为另一条手臂动态环境的一部分。我们提出DynaMAC，一个轻量级、策略无关的框架，在保留多流策略的样本效率、计算速度和灵活性的同时解决了这一因果局限性。DynaMAC将另一条手臂视为动态任务参数，从而为动态操作和双臂协调提供统一的表述，而无需显式的领导者-跟随者关系。为了严格评估这些能力，我们引入了DynaBench，一个面向动态环境中机器人操作的新基准。在动态环境和双臂操作任务中，DynaMAC在样本量减少20倍的情况下，仍比领先的概率和生成式基线高出超过35个百分点。关键在于，DynaMAC能从静态演示零样本泛化到动态环境，大大简化了数据收集，并为人类-机器人协作建立了优雅的桥梁。

## Abstract
Multi-stream robot manipulation policies achieve unparalleled sample efficiency and generalization by modeling actions relative to environmental reference frames. However, existing approaches typically assume these frames to be strictly exogenous. This causal assumption collapses in dynamic settings, such as when a single robot arm manipulates a moving object or when two arms coordinate, where each arm effectively becomes part of the dynamic environment of the other. We propose DynaMAC, a lightweight, policy-agnostic framework that resolves this causal limitation while preserving the sample efficiency, computational speed, and flexibility of multi-stream policies, DynaMAC treats the opposite arm as a dynamic task parameter, thereby providing a unified formulation for dynamic manipulation and bimanual coordination without requiring an explicit leader-follower relationship. To rigorously evaluate these capabilities, we introduce DynaBench, a novel benchmark for robot manipulation in dynamic environments. Across both dynamic environments and bimanual manipulation tasks, DynaMAC outperforms leading probabilistic and generative baselines by over 35 percentage points while requiring 20 times fewer samples. Crucially, DynaMAC generalizes zero-shot from static demonstrations to dynamic environments, substantially simplifying data collection and establishing an elegant bridge toward human-robot collaboration.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：真实世界的机器人不能假设环境是静态的，必须应对移动物体和其他智能体（如人类协作）的动态变化。模仿学习（IL）虽然已成为机器人操作的主流范式，但面临严重的数据瓶颈——高质量演示数据收集昂贵，尤其在动态环境中更为稀缺。
- **现有方法的不足**：多流（Multi-Stream）策略通过将动作建模在多个物体中心坐标系中，实现了卓越的样本效率。但其**根本性因果假设**——参考坐标系必须是严格外生的（即不受机器人自身行为影响）——在以下三类场景中崩溃：
  - **动态环境**：如从运动的传送带上拾取工件，物体一旦被抓住，其坐标系就从外生变为与机器人刚性耦合，导致流融合不一致和策略失败。
  - **多智能体协作**：另一智能体的行为不断改变相关任务坐标系（如交接、协作搬运）。
  - **双臂操作**：大多数多流策略仅面向单臂操作，而许多日常任务需要双臂协同。
- **核心含义**：本文旨在统一解决动态环境操作、多智能体协作与双臂操作这三个问题，通过消除对严格外生参考系的依赖，保留多流策略的样本效率优势，同时大幅简化动态场景下的数据收集。

### 2. 方法论：DynaMAC 框架

- **核心思想**：动态多流学习（Dynamic Multi-Stream Learning）——从策略流本身推断机器人与任务物体间的**运动学链接**，据此指导策略流选择，恢复多流学习的因果假设。
- **关键流程（Algorithm 1）**：包含四个主要步骤：
  1. **技能分割（Skill Segmentation）**：使用 TAPAS 将长时程演示分割为更短的技能片段。
  2. **运动学链接分析（Kinematic Link Analysis）**：当物体被机器人抓取后，对应流的方法精度急剧增加、方差趋近于零。通过几何平均标准差 M(f)t = |det(Λ(f)t)|^(−1/2d) 来识别链接，低于阈值 τM 即判定存在运动学链接。
  3. **虚拟帧补充（Virtual Frame Supplementation）**：为补偿因运动学链接而移除的动态物体帧，在每个技能边界记录末端执行器姿态并添加为静态虚拟帧，提供后抓取行为和空间记忆。
  4. **任务参数选择（Task-Parameter Selection）**：通过精度加权 ω(f) 评估候选帧并筛选相关帧。
- **双臂操作的统一表述**：将双臂操作视作多智能体协作问题，每个臂独立运行一个 DynaMAC 实例，并将对侧手臂的末端执行器添加为候选动态任务参数。无需显式领导者-跟随者关系或专门的协调模块，主导/跟随角色从任务参数选择中自然涌现。
- **理论联系**：建立了多流学习与信息论的联系——条件熵 H(ξee|f) ∝ log det(Σt)，互信息随运动学链接而激增，从理论上解释了 TAPAS 选择和 DynaMAC 过滤的合理性。

### 3. 实验设计

- **DynaBench 基准**：基于 RLBench 构建的动态环境操作基准，采用"采样-验证"机制最大化任务实例多样性。通过采样并验证两个独立有效的静态配置，从一个配置向另一个插值（平滑移动或瞬时传送），保证运动学可行性同时最大化实例多样性。
- **单臂任务（4个）**：StackWine、PlaceCups、OpenMicrowave、WipeDesk。各有三种变体：静态、平滑动态、瞬间传送。
- **静态双臂任务（4个）**：StoreBottle、HandOver、SweepDust、LiftTray（来自 RLBench2）。
- **动态双臂任务**：对四任务应用动态增强以及修改的 HandOver（随机交接位置+推理时扰动手臂预测轨迹）。
- **真实世界实验**：在双 Franka Emika 机器人 + RealSense D405 摄像头上进行四个任务（StoreItem、HandOver、LiftJointly、SweepBlocks），每个任务仅用5个演示，静态和动态条件下各进行25轮。
- **对比方法**：Diffusion Policy（100和5个演示）、ARP（Auto-Regressive Policy）、TAPAS-GMM、MiDiGaP、ACT、PerAct2、RVT-LF 等。

### 6. 主要结论与发现

- 在单臂静态任务中，DynaMAC 保持了与 MiDiGaP 相当的高性能（平均成功率 1.00 vs 0.99）。
- 在零样本动态场景中，DynaMAC 平均成功率 0.94，而 MiDiGaP 和 TAPAS-GMM 完全失败（0.00），Diffusion Policy（100个演示）仅 0.59——DynaMAC 以 **20倍更少的样本取得35个百分点以上的优势**。
- 在静态双臂任务中，DynaMAC 与 MiDiGaP 持平（0.95），远超其他基线。
- 在动态双臂协调中，MiDiGaP 大幅退步（0.26），而 DynaMAC 保持 0.96 的高成功率，包括对任一手臂扰动的动态重协调。
- 真实世界实验验证了仿真结果：DynaMAC 在静态任务中与 MiDiGaP 相当，但在动态和协调任务中显著更优（0.95 vs 0.41）。
- 初步验证了人类-机器人交接的零样本泛化潜力，但严重依赖于物体可见性。
- **核心发现**：从静态演示训练的 DynaMAC 可零样本迁移到动态环境与交互扰动，大幅简化数据收集流程。

### 7. 优点

- **轻量且策略无关**：作为包裹层可直接加在任意多流策略之上，保留原生优势（样本效率、泛化、可解释性、推理速度）。
- **统一框架**：动态环境操作、多智能体协作、双臂操作被统一为同一个动态多流学习问题，无需显式领导-跟随关系或协调模块。
- **零样本动态泛化**：静态演示直接部署到动态环境，极大降低动态场景数据采集成本。
- **理论深度**：首次将多流学习与信息论（互信息、条件熵）形式化连接，为任务参数选择提供了更坚实的理论基础。
- **DynaBench 开源基准**：为动态操作研究提供标准化、可扩展的评估平台，兼容 RLBench 生态。

### 8. 不足与局限

- **继承性局限**：依赖技能分割质量（使用 TAPAS 自动分割），若任务无法清晰分割则受限；依赖外部视觉编码器模块（在实机实验中基于 DINO 特征估计）。
- **感知脆弱性**：在遮挡条件下性能大幅下降（如手部交接时物体被遮挡），虽有对侧手臂运动学补偿但仍有限。
- **视觉依赖**：大多数剩余失败案例归因于感知错误（尤其是深度测量错误）。
- **基准范围有限**：DynaBench 当前仅实现了位置插值和瞬间传送两种动态模式，相比并发工作 DOMINO 的多样化物体动态模型（线性 vs. 突变）覆盖较少。
- **人机协作验证深度有限**：仅做了初步的单侧替换为人类的实验，未涉及人类行为的更大变异性和不可预测性。
- **运动学链接阈值的设置**：τM 和 τω 需要人工调节，对高度精确的预抓取存在短暂误报（虽有规避策略但不保证完全鲁棒）。
