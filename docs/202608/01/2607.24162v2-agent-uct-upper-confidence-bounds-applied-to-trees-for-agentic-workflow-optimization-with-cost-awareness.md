## 摘要
优化智能体工作流（例如检索增强生成（RAG）流水线）需要在紧凑的评估预算下，在离散组件的组合空间中进行导航。现有方法——启发式搜索、黑盒优化和标准树搜索方法——并未显式利用这些工作流的组合结构，导致冗余计算和低效的预算分配。我们提出Agent-UCT（基于智能体的成本感知树置信上界应用），一种树搜索算法，它通过从二分前缀复用图推导出的复用感知正则化项扩展了UCT。Agent-UCT将选择偏向于利用先前已物化配置前缀的分支，在保持有效探索的同时减少冗余执行。我们的框架RAGSpace将来自LongRAG、LightRAG和Self-RAG的异构RAG组件统一到一个五维配置空间中，实现跨框架的系统性重组。WTB（工作流测试台）提供确定性重放、内容寻址缓存和事务一致性，确保中间状态被物化一次并在搜索中复用。在HotpotQA和UltraDomain上的实验表明，Agent-UCT在评估的固定框架预设中识别出具有最高样本外性能的配置。在全池评估下，相对于无前缀共享的成本上界，二分前缀复用将逻辑搜索成本降低了73.6%。与全池评估相比，基于采样的评估进一步实现了4.2倍的墙钟加速。Agent-UCT、RAGSpace和WTB共同提供了一个用于成本感知、可复现和组合高效的智能体工作流优化的统一框架。

## Abstract
Optimizing agentic workflows, such as retrieval-augmented generation (RAG) pipelines, requires navigating a combinatorial space of discrete component choices under tight evaluation budgets. Existing approaches - heuristic search, black-box optimization, and standard tree search methods - do not explicitly exploit the compositional structure of these workflows, leading to redundant computation and inefficient budget allocation. We introduce Agent-UCT (Agent-based Cost-Aware Upper Confidence Bounds Applied to Trees), a tree search algorithm that extends UCT with a reuse-aware regularization term derived from a bipartite prefix reuse graph. Agent-UCT biases selection toward branches that leverage previously materialized configuration prefixes, reducing redundant execution while maintaining effective exploration. Our framework, RAGSpace, unifies heterogeneous RAG components from LongRAG, LightRAG, and Self-RAG into a five-dimensional configuration space, enabling systematic cross-framework recombination. WTB (Workflow Test Bench) provides deterministic replay, content-addressable caching, and transactional consistency, ensuring that intermediate states are materialized once and reused across the search. Experiments on HotpotQA and UltraDomain demonstrate that Agent-UCT identifies configurations with the highest out-of-sample performance among the evaluated fixed framework presets. Under full-pool evaluation, bipartite prefix reuse reduces logical search cost by 73.6% relative to the no-prefix-sharing cost upper bound. Compared with full-pool evaluation, sampling-based evaluation further achieves a 4.2x wall-clock speedup. Agent-UCT, RAGSpace, and WTB together provide a unified framework for cost-aware, reproducible, and compositionally efficient agentic workflow optimization.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在固定的、有限的评估预算下，如何高效地优化智能体工作流（如 RAG 流水线）中离散组件的组合选择。这类问题的搜索空间随组件数量指数级增长（例如 5 个组件、每个 3–5 个选项即可产生数百至上万个候选配置），而每次完整评估都需要执行昂贵的 LLM 推理、检索和工具调用。
- **现有方法的不足**：
  - 启发式网格搜索/随机采样忽略组合结构，浪费预算在无前景区域；
  - 黑盒优化（如贝叶斯优化、强化学习）将工作流视为整体黑盒，无法利用前缀复用；
  - 多臂老虎机假设各臂独立，不适用于结构化依赖；
  - 标准 UCT/MCTS 面向游戏规划等低成本模拟场景，不适用于“评估代价路径依赖 + 前缀可复用”的智能体工作流优化。
- **关键洞察**：智能体工作流具有**组合结构**和**状态化执行**特征——两个配置若共享相同前缀（如相同的分块策略和嵌入模型），重复执行该前缀会产生大量冗余计算。现有方法未显式利用这一特性。
- **整体含义**：论文提出一套“算法 + 配置空间 + 执行基础设施”三位一体的统一框架（Agent-UCT + RAGSpace + WTB），实现成本感知、可复现、组合高效的智能体工作流优化。

## 2. 方法论

### 核心思想

将组件选择构建为一棵搜索树（节点 = 部分配置前缀，叶节点 = 完整配置），在标准 UCT 选择分数中引入一个**基于二分前缀复用图推导的边际执行成本正则化项**，使搜索优先选择能复用已物化前缀的分支，从而在保持有效探索的同时减少冗余执行。

### 关键公式

Agent-UCT 的选择分数定义为：

\[
\text{Agent-UCT}_t(s,a) = \hat{Q}_t(s,a) + c_{\text{UCT}}\sqrt{\frac{\log(N_t(s)+1)}{N_t(s,a)+1}} - \lambda_t \widehat{\Delta C}_t(s,a)
\]

- \(\hat{Q}_t(s,a)\)：经验奖励估计；
- 第二项：标准 UCT 探索项；
- 第三项：成本正则化项，其中 \(\lambda_t = \lambda_0/\sqrt{t}\) 随时间衰减，\(\widehat{\Delta C}_t(s,a)\) 为基于二分复用图估计的边际执行成本。

### 技术细节

- **双级二分前缀复用图**：
  - **簇级图** \(G^Z_t = (\mathcal{S}, \mathcal{Z}, E^Z_t)\)：连接配置前缀与 benchmark 簇，用于全池评估下的成本估计；
  - **条目级图** \(G^Q_t = (\mathcal{S}, \mathcal{I}, E^Q_t)\)：追踪单个问题级别的物化状态，用于采样评估下的细粒度复用跟踪。
- **边际成本定义**：\(\Delta C_t(s,a;z) = c_{d+1}(s,a,z)\cdot \mathbb{1}[(Child(s,a), z) \notin E^Z_t]\)——仅当子节点前缀尚未物化时才计费。
- **算法流程（采样模式）**：
  1. 初始化搜索树和二分复用图；
  2. 每轮迭代：采样问题批次 → 从根节点按 Agent-UCT 分数选择子树（若节点已完全展开）→ 对未尝试动作进行扩展 → 补全配置 → 评估奖励 → 更新复用图和树统计量（回传奖励）；
  3. 返回观测到最高奖励的配置。
- **系统组件**：
  - **RAGSpace**：将 LongRAG、LightRAG、Self-RAG 统一为五维配置空间（分块、查询、检索、检索后处理、生成），缺失阶段用恒等直通表示；
  - **WTB（Workflow Test Bench）**：基于 AgentGit 构建，提供确定性重放、内容寻址缓存、事务一致性，确保中间状态只物化一次。

## 3. 实验设计

### 数据集与 Benchmark

- **HotpotQA**：多跳问答，按难度分为 easy / medium / hard 三个谱系；
- **UltraDomain**：领域特定长文问答，覆盖 agriculture / computer science / legal / mixed 四个领域；
- 两个数据集各按 70/30 划分：搜索集 350 条（供 Agent-UCT 搜索）、测试集 150 条（用于样本外评估）。

### 搜索空间与对比方法

- 五维 RAGSpace 的原始笛卡尔积定义 **384 个候选配置**；
- 对比基线：**LongRAG、LightRAG、Self-RAG 三种固定框架预设**（每种仅对应配置空间中一个固定点）；
- Agent-UCT 可在 384 点空间中自由组合跨框架组件。

### 评估指标

- HotpotQA：EM 和 token-overlap F1（F1 作为搜索奖励，EM 作为辅助指标）；
- UltraDomain：token 级 F1；
- 联合目标 HQ+UD：HQ F1 与 UD F1 的算术平均（Combined F1）。

### 主要实验组

三个搜索目标下的配置发现（HQ-only、UD-only、HQ+UD），每组均进行样本外评估、效率对比、前缀复用消融、组件归因分析。

## 6. 主要结论与发现

- Agent-UCT 在不同目标下找到的最优配置不同，说明**不存在单一固定流水线在所有设定下占优**；
- 样本外结果：HotpotQA 上 Agent-UCT 与 LongRAG 相当（\(p=0.27\)），显著优于 Self-RAG 和 LightRAG；UltraDomain 上显著优于全部三个基线（\(p < 0.0001\)）；
- 联合目标下，Agent-UCT 选择的配置获得最高 Combined F1（0.4542），显著优于 LightRAG 和 Self-RAG；
- **效率收益**：采样评估较全池评估快 **4.2 倍**，减少 LLM token 消耗 5.73 倍、Chat API 调用 7.86 倍；二分前缀复用使逻辑搜索成本从 10,920 降至 2,878，降低 **73.6%**；
- **归因分析**：生成组件（generation）对奖励变化贡献最大（ANOVA \(\eta^2\) 为 0.769–0.831），其次为检索（retrieval），其余组件影响有限。

## 7. 优点

- **方法创新性强**：首次将“复用感知的成本正则化”引入 UCT，将工作流的组合结构与状态物化特点显式建模为二分图，属方法层面的新贡献；
- **三位一体设计**：算法（Agent-UCT）、搜索空间（RAGSpace）、执行基础设施（WTB）形成完整闭环，兼顾搜索效率与可复现性；
- **系统性成本控制**：簇级 + 条目级双层复用图支持全池与采样两种评估协议，提供了从粗到细的成本估计；衰减正则化系数使搜索前期偏向低成本分支、后期更依赖奖励估计；
- **实验设计严谨**：使用分离的搜索集（350 条）与测试集（150 条）验证样本外泛化；使用置换检验报告显著性；全池与采样两种评估对照；
- **归因分析具有实践价值**：通过 ANOVA 和随机森林联合归因，揭示生成与检索组件的主导地位，为后续优化方向提供参考。

## 8. 不足与局限

- **实验规模受限**：使用数据集的子集（350/150），未在完整基准上验证；搜索空间限于三个框架（LongRAG、LightRAG、Self-RAG）的组件，未覆盖更广泛的 RAG 设计空间；
- **单一 backbone 模型**：所有实验仅使用 `openai/gpt-5.4-nano`，无法说明不同模型容量下的行为差异和泛化性；
- **评估指标局限**：UltraDomain 为长文生成，但自动评估仅用 token 级 F1，可能对答案长度和词汇重叠敏感，不能充分反映事实性与完整性；
- **WTB 的复杂特性未被充分测试**：论文承认未充分利用 WTB 对文件系统级执行结构的支持（如目录级、工件级缓存），当前实验主要在 RAG 工作流层面进行；
- **部分对比差异不显著**：HotpotQA 上相对 LongRAG 的提升未达到统计显著（\(p=0.27\)），说明在部分设定下优势有限；
- **算力信息披露不足**：未报告硬件配置（GPU 型号/数量），影响结果的可复现性和成本评估透明度。
