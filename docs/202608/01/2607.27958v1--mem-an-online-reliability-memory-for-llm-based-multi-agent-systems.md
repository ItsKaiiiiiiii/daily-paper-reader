## 摘要
记忆对于长时程大语言模型智能体至关重要，然而现有记忆系统主要保存交互内容，而非建模哪些智能体可被信任及其在何种条件下可信。这一局限在多智能体系统中尤为突出，因为中央模型可能无法直接验证看似合理或相互关联的同伴响应。我们提出 $Σ$-Mem，一种在线可靠性记忆，它记录个体同伴的历史能力证据以及跨同伴集合的同伴关系证据。这两类证据均以实对称状态形式维护，并根据决策后的正确性反馈进行更新。借助 Weyl 不等式，每次事件级更新引起的谱变化是有界的，从而无需重新训练底层模型即可实现稳定的在线自适应。$Σ$-Mem 提供通用的读写接口：同一记忆可用于中央模型的残差引导、无响应同伴路由或可靠性加权投票。在五个 Qwen 系列模型上，$Σ$-Mem 能够适应反事实的可靠性变化，并泛化到未见过的同伴和任务领域。在完整的域外评估集上，直接记忆读取也优于多数投票和最佳固定同伴。此外，随着可获得更多正确性反馈，性能持续提升，这表明 $Σ$-Mem 逐步积累了可操作的可靠性信息。这些结果确立了可靠性记忆作为基于大语言模型多智能体系统中自适应协调的可复用基础。

## Abstract
Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $Σ$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set. Both forms of evidence are maintained as real symmetric states and updated from post-decision correctness feedback. By Weyl's inequality, the spectral change caused by each event-level update is bounded, enabling stable online adaptation without retraining the underlying models. $Σ$-Mem provides a general write-and-read interface: the same memory can be used for residual steering of a central model, response-free peer routing, or reliability-weighted voting. Across five Qwen-family models, $Σ$-Mem adapts to counterfactual reliability shifts and generalizes to unseen peers and task domains. Direct memory readouts also outperform majority voting and the best fixed peer over the full OOD evaluation set. Moreover, performance improves consistently as more correctness feedback becomes available, indicating that $Σ$-Mem progressively accumulates actionable reliability information. These results establish reliability memory as a reusable foundation for adaptive coordination in LLM-based multi-agent systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有记忆系统的局限**：当前LLM智能体记忆系统主要关注**内容记忆**（存储、检索和总结历史交互），但无法回答一个关键问题——**“哪个智能体在何种条件下值得信任”**。
- **多智能体系统的独特挑战**：在多智能体系统中，中央协调模型往往无法直接验证同伴（peer）响应的正确性，尤其是在以下场景中：
  - 支持性证据不可获取（如RAG任务中上下文被隐藏）；
  - 判断答案的难度与生成答案相当；
  - 多个同伴给出看似一致但可能存在**相关错误**或**共同偏误**的响应。
- **可靠性记忆的必要性**：内容记忆回答“发生了什么”，而可靠性记忆回答“谁能被信任、何时被信任”。当直接验证不可行或代价高昂时，系统的性能取决于是否将注意力分配给正确的同伴。
- **核心贡献定位**：论文提出Σ-Mem，一种**在线可靠性记忆**机制，将信任建模作为多智能体协调的一等公民，而非仅作为响应聚合的辅助信号。

## 2. 方法论

### 2.1 核心思想

- Σ-Mem记录两种互补的可靠性证据：
  1. **历史能力证据（Historical Competence Evidence）**：记录每个同伴在不同任务条件下的历史可信度，存储于同伴特定的实对称矩阵$M_p \in \mathbb{R}^{r \times r}$；
  2. **同伴关系证据（Peer Relationship Evidence）**：建模同伴之间通过正确性模式体现的关系（相互支持或相互对立），存储于对称关系矩阵$G \in \mathbb{R}^{P \times P}$。

### 2.2 关键技术细节

- **事件级更新规则**：对于事件$t$，先计算能力方向$\boldsymbol{\phi}(x_t)$（$\|\boldsymbol{\phi}(x_t)\|_2 = 1$），获得外部正确性标签$c_{p,t} \in \{+1, -1\}$，更新公式为：
  $$M_p^{(t+1)} = \gamma M_p^{(t)} + \eta c_{p,t} \boldsymbol{\phi}(x_t)\boldsymbol{\phi}(x_t)^\top$$
  其中$\gamma$为衰减因子，$\eta$为更新因子。秩一更新项保持矩阵对称性。
  
- **关系矩阵更新**：先将正确性向量中心化$q_{p,t} = c_{p,t} - \frac{1}{P}\sum_j c_{j,t}$，更新$G^{(t+1)} = \gamma_G G^{(t)} + \eta_G q_t q_t^\top$，并保持对角线为1。$G_{p,q} > 0$表示同伴间正确性相互支持，$G_{p,q} < 0$表示相互对立。

- **稳定性保证（Weyl不等式）**：每个事件级更新视为有界对称扰动。根据Weyl不等式$\lambda_i(M+E) - \lambda_i(M) \leq \|E\|_2$，单个事件对特征值的改变受谱范数控制，防止记忆状态被异常事件扭曲。

- **定理1（持久证据主导噪声）**：若同伴$p$在固定能力方向$\boldsymbol{\phi}^*$上具有持久期望能力$\mu_p$，则其最大特征值以高概率满足：
  $$\lambda_{\max}(M_p^{(T)}) \geq \eta\mu_p\frac{1-\gamma^T}{1-\gamma} - \eta\sqrt{\frac{8\log(2/\delta)}{1-\gamma^2}}$$
  噪声项不随$T$增长，信号项趋于饱和$\eta\mu_p/(1-\gamma)$，信噪比$\mu_p\sqrt{(1+\gamma)/(1-\gamma)}$随$\gamma$单调递增。

- **记忆读取与残差引导**：决策时计算读取向量$r_{p,t} = M_p^{(t)}\boldsymbol{\phi}(x_t)$，通过投影$P$和增益$g$转换为残差引导向量$\boldsymbol{\delta}_{p,t}(x_t) = gPr_{p,t}$，仅注入中央模型的上半部分解码器块（$\ell \in \{\lfloor L/2\rfloor, \ldots, L-1\}$），实现同伴条件化的注意力计算。

- **效用评估与同伴选择**：中央模型在同伴特定引导下评估答案，效用分数为：
  $$U_{p,t} = \log P_{CM}("Yes"|x_t, a_{p,t}; \boldsymbol{\delta}_{p,t}) - \log P_{CM}("No"|x_t, a_{p,t}; \boldsymbol{\delta}_{p,t})$$
  结合同伴关系矩阵$G$和后验分布$P(y_t | x_t, M^{(t)}, G^{(t)})$，选择后验期望最大的同伴。选择与记忆写入分离：选择基于效用判断和历史引导，更新基于外部反馈。

- **直接读取机制**：无需中央模型参与决策时，计算历史可靠性分数$s_{p,t} = \boldsymbol{\phi}(x_t)^\top M_p^{(t)} \boldsymbol{\phi}(x_t)$，支持两种规则：
  - **M-route**：选择分数最高的同伴（响应无关路由）；
  - **M-vote**：将分数作为投票权重进行答案聚合。

## 6. 主要结论与发现

- **Σ-Mem显著提升弱中央模型的应对反事实变化的能力**：Qwen3-0.6B在CF@90下从46.22%提升至71.10%（Σ w/ G），提升幅度约25个百分点。
- **同伴关系证据互补个体历史**：Σ w/ G普遍优于Σ w/o G，说明关系证据提供了个体历史之外的有用信息。
- **可泛化到未见同伴**：训练时仅3个同伴，扩展到4-5个同伴（含未见模型）时整体仍保持改进趋势（CF@50除外）。
- **OOD泛化性能良好**：在27/30个OOD案例上超过基础模型，BBH上提升显著（如Qwen3-8B从19.29%至28.17%）。
- **记忆作为可复用协调状态**：直接读取（M-route、M-vote）在OOD全数据集上优于多数投票（59.12%）和最佳固定同伴（57.52%），接近Oracle reputation（60.79%）。
- **反馈越多性能越好**：随着正确性反馈比例从5%增至100%，记忆方法性能持续提升，表明记忆状态有效积累了可操作的可靠性信息。
- **强中央模型与记忆互补**：Qwen3.5系列中Σ w/G优于M-route，说明较强的中央模型能更好地结合当前响应证据与历史可靠性指导。

## 7. 优点

- **理论与机制结合紧密**：Weyl不等式和定理1为稳定性提供了严格的数学基础，证明持久证据在谱中积累而噪声有界，理论不再是“装饰”而是设计核心。
- **统一且优雅的记忆接口**：同一记忆状态支持三种不同的消费方式（残差引导、无响应路由、加权投票），展示出记忆的可复用性。
- **稳定性与适应性兼顾**：通过衰减因子$\gamma$控制历史与当前证据的平衡，单事件扰动有界，避免异常反馈造成记忆崩溃。
- **广泛而系统的实验覆盖**：涵盖5个模型大小、3个训练域、6个OOD域、多个反事实条件，验证了跨模型、跨任务、跨同伴池的泛化能力。
- **公平的决策时间限制**：记忆更新仅使用外部正确性标签，不泄漏当前事件的答案信息到决策过程。
- **对失败案例的诚实分析**：论文明确讨论CF@50下的性能下降，指出这是“忠实记忆”的必然结果，而非机制缺陷，并据此提出未来研究方向。

## 8. 不足与局限

- **对模糊历史证据的敏感性**：CF@50情景中（一半历史支持原偏好、一半支持反事实转变），Σ-Mem性能明显下降，M-route最严重（降至56.20%-57.91%）。论文承认需要设计自适应读取机制来平衡历史与当前证据，但这在现版本中尚未解决。
- **依赖外部正确性标签**：Σ-Mem的更新完全依赖外部反馈，在真实部署中获取可靠标签的成本可能很高。论文未讨论无标签或弱标签情况下的降级策略（仅做了反馈比率消融，未解决标签来源问题）。
- **算力信息缺失**：论文未报告训练和推理的具体计算成本，难以评估Σ-Mem在实际应用中的资源开销。
- **同伴数量有限**：训练时仅3个同伴，测试最多5个，距离真实大规模多智能体系统（数十至数百个智能体）仍有距离。关系矩阵$G$的规模随$P$二次增长，大规模场景下的可扩展性未得到验证。
- **能力方向$\boldsymbol{\phi}(x_t)$的依赖性**：记忆效果依赖于中央模型对任务映射到能力方向的质量，较弱模型（如Qwen3-0.6B）在部分场景下需要直接读取而非残差引导来弥补判断力不足，说明方法对中央模型质量存在隐含依赖。
- **潜在的社会性偏差问题**：关系证据$G$可能编码同伴间的系统性关联错误（如共同训练数据导致的共有偏见），论文对此的讨论不够深入。
- **缺少与近期LLM路由/集成方法（如RouteLLM、FrugalGPT、GPTSwarm等）的直接全面比较**：尽管提及相关工作，但实验对比仅包含多数投票和固定同伴基线，缺少与这些强基线在相同条件下的系统对比。
