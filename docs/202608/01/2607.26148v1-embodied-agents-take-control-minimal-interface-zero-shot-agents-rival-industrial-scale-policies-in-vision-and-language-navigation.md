## 摘要
自主具身智能体必须维持一个长期决策循环，涉及感知、行动、验证和多次自我修正。当前系统通过任务专用工作流或具身策略来维持这一循环。我们研究第三种形态——智能体具身控制，即由通用智能体自身承担这一循环。以零样本导航作为受控测试平台，我们在仅提供单目RGB相机和离散动作的条件下，评估了三种软件工程智能体框架。在这种严格最小条件下，复现的默认努力配置达到70.7±3.5%的成功率（opus-5，三次运行的平均值），而fable-5在最大努力下达到78%。当将训练好的路径点工具作为可选能力与原始动作一同暴露时，混合型fable-5智能体在默认努力下达到76.7±0.6%的成功率，使用的环境步数减半，耗时不到最大努力原始运行的四分之一。受控干预表明，能力主要集中于模型：模型选择显著改变成功率，框架效应是描述性的，而强制路径点接口有助于较弱的模型，但可能阻碍较强的模型。然而，在长时程任务上性能急剧下降，同时延迟和上下文增长限制了持续运行。这些结果表明，智能体控制在零样本导航中已具备竞争力，模型、框架和接口为自主具身智能体提供了互补的路径。

## Abstract
Autonomous embodied agents must sustain a long decision-making loop that involves perceiving, acting, verifying, and self-correcting over many steps. Current systems sustain this loop through task-specific workflows or embodied policies. We study a third form, agentic embodied control, in which a general-purpose agent holds the loop itself. Using zero-shot navigation as a controlled testbed, we evaluate three software-engineering agent harnesses given only a monocular RGB camera and discrete actions. Under this strictly minimal condition, replicated default-effort configurations reach 70.7$\pm$3.5% success (opus-5, mean over three runs), and fable-5 reaches 78% at maximum effort. When a trained waypoint tool is exposed alongside primitives as an optional capability, the hybrid fable-5 agent reaches 76.7$\pm$0.6% at default effort, using half the environment steps and less than one quarter of the wall time of the maximum-effort primitive run. Controlled interventions show that capability is primarily model-centered: model choice strongly changes success, harness effects are descriptive, and a forced waypoint interface helps weaker models but can hinder stronger ones. Performance nevertheless falls sharply on longer-horizon tasks, while latency and context growth limit sustained operation. These results show that agentic control is already competitive in zero-shot navigation and that models, harnesses, and interfaces offer complementary paths toward autonomous embodied agents.

## 2. 论文提出的方法论

### 2.1 核心思想
- 用通用软件工程智能体框架替换导航专用脚手架。模型在每回合观察环境、推理下一步动作、执行工具调用，并在整个会话中承担高层控制权。
- 刻意采用**最小接口**（Minimal-Interface）作为诊断性基线：仅暴露两个工具，不提供任何导航特定的辅助信息（无深度、位姿、全景、地图、路径点、碰撞反馈等）。
  - `observe()`：返回单张 512×512 前视 RGB 帧，不推进环境；
  - `step(actions)`：执行由四个 Habitat 原始动作组成的序列——`FORWARD`（前进 0.25 m）、`LEFT`/`RIGHT`（旋转 15°）、`STOP`（终止情节）。
- 为隔离变量，作者将系统拆分为三个可独立操作的轴：
  - **模型（Model）**：被冻结的通用 VLM，提供决策能力；
  - **框架（Harness）**：维持会话、执行工具调用、传递提示的通用 agent 环；
  - **接口（Interface）**：模型可观察和表达的行动空间边界。

### 2.2 实验范式（Agentic Loop 的实现）
- 每个情节从全新的会话开始，不跨情节传递任何状态或经验。
- 框架（harness）不预设交互顺序，只负责输送提示、执行工具调用、返回结果、维持会话。
- 系统提示词仅包含任务说明、工具定义和行动预算，不含任何导航提示模板或领域演示。

### 2.3 混合接口（Hybrid Interface）
- 将训练好的基于深度的路径点预测器作为一个可选工具，与原始动作同时暴露给模型。
- 智能体自行决定何时使用路径点（覆盖距离、定位路线）何时改用原始动作（精细调整终点），由此形成粗到细的自组织策略。

## 6. 论文的主要结论与发现

1. **最小接口下零样本智能体已具竞争力**：
   - fable-5（mini-swe-agent）达 72 SR；Claude SDK 默认努力下 opus-5 复现均值 **70.7±3.5 SR**、fable-5 为 **68.3±1.5 SR**；
   - fable-5 最大努力达 **78 SR / 65.27 SPL**——优于同子集上带地图、记忆和搜索的 AgenticNav（55 SR），接近 ABot-N1（71 SR）等工业级训练模型水平。
2. **能力以模型为中心**：模型轴跨度为 5–72 SR（同框架同接口），是研究中最大的变异来源；推理努力的影响是模型特定的，仅 fable-5 有明显增益（+9.7 SR）。
3. **框架效应是描述性的**：不同 harness 之间差异约 2–7 SR 点，无一致方向。
4. **接口的作用是补偿性的而非普惠的**：强制路径点接口对弱模型提升显著（小 Qwen 模型 +37–38 SR），对强模型增益微小（fable-5 仅 +0.7，opus-5 仅 +1.3），在 VLNVerse 上甚至反向（SR −4~−6，碰撞率上升 4–6 倍）。
5. **混合接口最优**：将路径点作为可选工具而非强制路径时，fable-5 默认努力达 **76.7±0.6 SR**，超过两种固定接口，接近最大努力原始结果（78），但环境步数减半、时间仅四分之一，NE 也是全组最佳——证明"脚手架在智能体控制下而非强加时最有效"。
6. **长时程是明确瓶颈**：RxR-CE 上原始 SR 从 75 跌至 26，路径点也只到 39；上下文增长将中位最终回合 token 翻倍至三倍，墙钟时间加倍。
7. **失败模式具有特征性**：25 个失败中 22 个以明确"成功"声明终止，"自我诊断但不自我修正"是典型认知缺陷；错误主要在指代消解和停止决策，而非感知；缺失碰撞/位姿信号会放大几何陷阱（如镜子、网格孔洞造成的迷惑）。
8. **真机测试**：推理与感知能力迁移良好（条件分支、属性区分、多段路线状态保持），但缺乏身体感知、标定运动和空间记忆，导致身体卡死、转向不足、无持久地图等具身化失效。

## 7. 优点

- **概念清晰**：提出"谁控制交互循环"的新分类轴，区分策略/工作流/智能体三种组织形态，并给出可操作的判定标准（控制权威而非仅是否使用 LLM）。
- **实验设计严谨**：
  - 最小接口作为诊断性探针，排除导航专用脚手架的混淆；
  - 单轴消融（模型、框架、接口互相固定）干净地分离贡献来源；
  - 三次复现报告均值±标准差，明确给出运行方差的经验尺度；
  - 混合接口为"脚手架在智能体控制下"提供了直接证据。
- **分析深入**：对 25 个失败情节逐帧审计，提炼出可操作的失败分类；物理部署揭示真实瓶颈在具身体验而非语言推理。
- **视角建设性**：将模型、框架、接口视为互补的优化路径，提出引导循环——脚手架产生经验，经验训练模型，更强模型简化脚手架。

## 8. 不足与局限

- **评估规模偏小**：主基准仅 100 个情节，单次运行单元格居多，SR 标准差 1.2–3.5 意味着部分结论（如 harness 差异、某些模型间差异）在统计上不够稳健。
- **与训练型方法对比不公平**：训练型结果使用完整 val-unseen（约数千个情节），零样本行使用 rand100 子集，且不同系统所用模型和服务路径不同，对比仅具参考价值。
