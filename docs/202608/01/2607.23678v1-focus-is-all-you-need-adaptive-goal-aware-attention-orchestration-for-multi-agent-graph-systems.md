## 摘要
大型语言模型（LLM）使自主智能体能够进行推理、规划和工具使用。近期系统越来越多地将这些智能体组织为专用、互连节点的图结构。尽管基于图的编排支持灵活的分解与协调，但它带来了一个关键挑战：	extbf{注意力分配}。随着工作流规模的增长，现有方法往往均匀地执行图组件，将资源浪费在无关或低影响的任务上。我们提出	extbf{注意力编排}（Attention Orchestration），一种将Transformer式注意力从词元表示扩展到工作流级智能体协调的范式。我们的框架	extbf{自适应目标感知注意力编排}（AGAO）基于用户目标、图依赖和计算约束动态估计智能体的重要性。AGAO结合了三个组件：（1）目标感知注意力，衡量用户目标与智能体能力之间的语义相关性；（2）拓扑感知注意力，对智能体图中的结构依赖进行建模；（3）资源感知注意力，在异构智能体之间分配预算和执行优先级。这些机制共同将静态智能体图转化为自适应系统，将计算聚焦于目标关键推理路径。在多种多智能体工作负载上的实验表明，与现有基于图的执行策略相比，AGAO在提高任务有效性的同时减少了不必要的计算、延迟和词元消耗。我们的工作确立了	extbf{注意力工程}（Attention Engineering）作为可扩展、智能多智能体系统的一个方向。代码：https://github.com/MingzhouFan97/AGAO。

## Abstract
Large language models (LLMs) enable autonomous agents for reasoning, planning, and tool use. Recent systems increasingly organize these agents as graphs of specialized, interconnected nodes. Although graph-based orchestration supports flexible decomposition and coordination, it creates a key challenge: \textbf{attention allocation}. As workflows grow, existing approaches often execute graph components uniformly, wasting resources on irrelevant or low-impact tasks. We introduce \textbf{Attention Orchestration}, a paradigm that extends Transformer-style attention from token representations to workflow-level agent coordination. Our framework, \textbf{Adaptive Goal-aware Attention Orchestration (AGAO)}, dynamically estimates agent importance based on user objectives, graph dependencies, and computational constraints. AGAO combines three components: (1) goal-aware attention, measuring semantic relevance between user goals and agent capabilities; (2) topology-aware attention, modeling structural dependencies in agent graphs; and (3) resource-aware attention, allocating budgets and execution priorities across heterogeneous agents. Together, these mechanisms transform static agent graphs into adaptive systems that focus computation on goal-critical reasoning paths. Experiments across diverse multi-agent workloads show that AGAO improves task effectiveness while reducing unnecessary computation, latency, and token consumption compared with existing graph-based execution strategies. Our work establishes \textbf{Attention Engineering} as a direction for scalable, intelligent multi-agent systems. Code: https://github.com/MingzhouFan97/AGAO.

- **整体定位**：论文提出了"注意力工程"（Attention Engineering）作为继循环工程、图工程之后的第三代智能体系统设计范式，强调"图结构定义可能交互，注意力机制决定哪些交互值得计算资源"。

## 2. 论文提出的方法论

**核心思想**：AGAO在用户目标与智能体图执行之间引入一个"注意力驱动执行层"，将智能体视为**动态可选择的计算单元**而非固定工作流操作符，依据演化中的任务目标持续评估每个智能体的重要性，并调整执行优先级、路由决策与计算资源。

**三个层次化注意力模块**：

1. **目标感知注意力（Goal-aware Attention）**：衡量用户目标与智能体能力之间的语义对齐程度。
   - 将目标编码为查询向量 \( Q_g = W_q f_g(q) \)
   - 构造包含能力描述、历史执行信息和当前任务状态的智能体表示 \( z_i = [x_i; h_i; s_i] \)
   - 计算注意力得分 \( e_i = Q_g K_i^T / \sqrt{d} \)，经softmax归一化得到 \( \alpha_i^{goal} \)

2. **拓扑感知注意力（Topology-aware Attention）**：将图结构信息纳入注意力估计。
   - 提取每个节点的结构化特征（依赖距离、前驱关系、后继影响、图中心性等）
   - 在标准自注意力中引入拓扑偏置矩阵 \( A^{topo} = softmax(QK^T/\sqrt{d} + B_G) \)
   - 定义结构影响力得分 \( s_i^{critical} = \eta_1 d_i^{in} + \eta_2 d_i^{out} + \eta_3 c_i^{path} \)
   - 融合语义与结构注意力：\( \alpha_i^{graph} = \gamma \alpha_i^{goal} + (1-\gamma)\alpha_i^{topo} \)

3. **资源感知注意力（Resource-aware Attention）**：将注意力得分转化为具体执行决策。
   - **模型路由**：根据注意力分数分配大/中/小三种模型档位（\( M_{large}, M_{medium}, M_{small} \)）
   - **Token预算分配**：\( T_i = T_{total} \frac{\exp(\alpha_i^*)}{\sum_j \exp(\alpha_j^*)} \)
   - **执行优先级调度**：\( P_i = \alpha_i^* \cdot w_i \)

**自适应图路由**：注意力状态通过执行反馈动态更新，\( \alpha^{t+1} = \Phi(\alpha^t, o^t, G, q) \)，并支持三类路由决策（执行/挂起/剪枝），使智能体可以在执行过程中动态调整参与状态。

**优化目标**：最大化任务效用同时最小化计算成本与延迟：\( \max_\pi J(\pi) = Q(y, q) - \lambda_1 C(\pi) - \lambda_2 L(\pi) \)

## 3. 实验设计

- **数据集/场景**：
  - **MBPP**（8个编程任务）：包含规格分析、实现、测试、调试、审查、定稿等角色的九节点图
  - **HotpotQA**（8个多跳问答任务）：包含分解、检索、证据选择、推理、验证、定稿等角色的九节点图
- **Benchmark**：论文称为MAG-Focus基准（手写九节点图），任务清单、图模板、提示、工具、重试行为与单次运行预算均固定
- **对比方法**（5种执行策略）：
  1. **Random**：依赖合法的固定种子随机路由器，随机选择最多两个就绪节点
  2. **Static**：按固定图顺序执行所有依赖合法节点
  3. **Semantic**：根据任务提示与节点能力描述的词法重叠选择最多两个就绪节点
  4. **MoE-style**：使用词法相关性+拓扑得分的固定混合选择节点，无反馈与自适应资源路由
  5. **AGAO**（本文方法）：结合词法目标相关性、拓扑得分与规则反馈，可跳过低分节点，并在低/中/高三档模型间路由
- **评估指标**：MBPP用pass@1；HotpotQA用token级F1；另报告激活节点数、累计智能体时间、gateway记录的前后端token数

## 6. 论文的主要结论与发现

- **MBPP上AGAO表现最优**：pass@1达0.875（7/8），显著优于MoE-style（0.750）、Static（0.625）、Random与Semantic（各0.500）
- **HotpotQA上AGAO效果中等**：F1为0.340，超过Static（0.319）、Random（0.285）和Semantic（0.244），但**低于MoE-style（0.417）**
- **效率提升是AGAO最核心优势**：相比Static，AGAO在MBPP和HotpotQA上分别减少27.8%和19.4%的激活节点，降低56.0%和50.3%的累计智能体时间
- **成本效益分析**：AGAO虽比基线使用更多输入token（路由与上下文构造所致），但输出token大幅减少。由于输出token定价为输入token的6倍，AGAO在API成本上更经济
- **消融实验**揭示了三个机制缺一不可：移除目标评分虽提高MBPP（0.875→1.000）但降低QA性能并大幅增加执行时间；移除拓扑降低双任务质量；移除资源路由导致MBPP锐减；完整AGAO提供了最稳定的质量-效率平衡

## 8. 不足与局限
