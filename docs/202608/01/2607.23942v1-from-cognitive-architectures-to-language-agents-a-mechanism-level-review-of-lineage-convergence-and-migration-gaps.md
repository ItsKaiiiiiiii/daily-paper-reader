## 摘要
记忆、规划、反思和工具使用常被作为特征标签进行比较，这掩盖了决定智能体实际运行方式的控制语义。本评述连接了十个历史认知架构、八个语言智能体运行时家族以及四十二个以机制为中心的现代系统。我们通过状态、控制、转换、持久性、失败、学习与资源治理来重构每种机制，并将证据关联（E1-E4）与迁移深度（D0-D4）分别编码。由此呈现的图景并不均衡。现代智能体已将自适应记忆、失败恢复、动态团队选择、工作流搜索、技能归纳、资源调度和不确定性条件化行动的大部分内容可操作化，尽管通常是通过独立趋同而非有记录的继承来实现。最显著的剩余机会在于机制间的耦合。最接近基线的筛选弥合了一个提出的鸿沟：GraSP已经结合了校准的多技能选择、类型化编译、验证、有界修复以及重规划或ReAct回退。剩余五个束仍待解决：激活与延迟和行动效用；类型化僵局与孤立子状态及分辨率编译；有界内容竞争与广播和接纳学习；持久意图与重新考虑和实时方法权威；以及不确定性伴随资源分配、中断和停止。我们贡献了一个独特机制目录、一个可审计的证据深度框架，以及一个可证伪的议程，用于将这些束作为可组合的运行时不变量进行检验。

## Abstract
Memory, planning, reflection, and tool use are often compared as feature labels, obscuring the control semantics that determine how an agent actually runs. This review connects ten historical cognitive architectures, eight language-agent runtime families, and forty-two mechanism-focused modern systems. We reconstruct each mechanism through state, control, transition, persistence, failure, learning, and resource governance, then code evidence relation (E1-E4) separately from migration depth (D0-D4). The resulting landscape is uneven. Modern agents have operationalized substantial parts of adaptive memory, failure recovery, dynamic team selection, workflow search, skill induction, resource scheduling, and uncertainty-conditioned action, although often through independent convergence rather than documented inheritance. The strongest remaining opportunities lie in couplings among mechanisms. Closest-baseline screening closes one proposed gap: GraSP already combines calibrated multi-skill selection, typed compilation, verification, bounded repair, and replanning or ReAct fallback. Five residual bundles remain: activation with latency and action utility; typed impasse with isolated substates and resolution compilation; bounded content competition with broadcast and admission learning; persistent intention with reconsideration and live method authority; and uncertainty with resource allocation, interruption, and stopping. We contribute a distinctive-mechanism catalog, an auditable evidence-depth framework, and a falsifiable agenda for testing these bundles as composable runtime invariants.

## 2. 方法论

**核心思路**：以“机制”（mechanism）为分析单元——一个消耗显式状态、由可识别触发器激活、对转换实施控制、并可能改变后续行为的操作；而不是以架构或框架为比较单位。

**七字段机制表示**：

\[
K = \langle S, C, T, P, F, L, R \rangle
\]

其中：
- **S**（State）：运行状态基质；
- **C**（Control）：控制中枢；
- **T**（Transition trigger）：转换触发器；
- **P**（Persistence）：持久性边界；
- **F**（Failure）：失败语义；
- **L**（Learning）：学习算子；
- **R**（Resource）：资源/治理策略。

## 6. 主要结论与发现

1. **迁移深度不均**：现代语言智能体已深度实现（D3/D4）自适应记忆策略、故障诊断和恢复、可逆执行分支、动态团队选取、工作流搜索、技能归纳与编译、资源调度、不确定性条件化的行动，但多源于独立趋同（E4 或 E3），而非显式谱系继承（E1）。
2. **语义变化**：记忆从可达性法则变为策略行动；失败从控制状态变为恢复内容；工作空间改变了候选类型和广播语义；承诺将目标持久性与轨迹收敛分离；技能迁移先有学习后有治理；资源和不确定性控制仍局部持有。
3. **五个残留耦合包**：
   - **B1 激活–延迟–效用**：运行内存项应承载激活、预测检索延迟、下游价值和维护成本；统一四者缺乏单一控制法则。
   - **B2 类型化僵局–子状态–编译**：无审查系统将类型化僵局、受保护子状态、类型化返回和条件安全编译组合成一个执行协议。
   - **B3 内容竞争–工作空间–广播学习**：内存/代理/工具/监视器/计划的类型化候选应在有界工作空间中竞争，后果更新未来接纳；该循环未完整组合。
   - **B4 意图–重新考虑–方法权威**：缺少便携的完整承诺生命周期（持续、重新考虑、委派、挂起、放弃、方法切换）且不静默改变目标。
   - **B6 不确定性–资源–中断–停止**：校准的不确定性应跨越记忆、规划、工具、执行和停止阶段传播，并分配 token/时间/工具/验证预算及中断权限。
4. **B5 已闭合（GraSP）**：GraSP 已实现校准多技能路由、类型化预/后条件 DAG 编译、节点验证、有界类型修复和全局重规划/ReAct 回退的完整链条，属 E3/D4 实现，不再作为残留假设。
5. **保留不变量与缺失不变量的分离**：D4 不代表完整迁移（例如 SCALAR 可达 D4 但缺乏跨域可移植性和可靠显式计划回退）。

## 7. 优点

- **机制级可比性**：通过七字段统一表示使不同术语基板、实现基质和任务域的历史/现代系统可并排比较，避免框架 API 被误认为学习控制律。
- **双轴独立编码**：证据关系（E1–E4）与迁移深度（D0–D4）独立，消除两类过度断言（“引用了架构就是实现了它”和“实现了功能就是继承了它”）。
- **可审计性**：提供声明包、完整证据账本、版本固定的仓库 commit、D3/D4 重编码包；编码规则明确、阈值可查。
- **负向筛选方法**：先产生六候选再以最邻近基线做对抗性筛选，B5 被 GraSP 关闭——这展示该框架可以删除研究议程项，体现框架的自证能力。
- **可证伪的残留假设设计**：每个残留束都明确指定运行插入点、控制法则、最接近基线和主要证伪条件，并给出预注册协议模板，可转换为可操作实验。
- **等价测试**：四个等价测试防止表面映射（消息总线≠工作空间等），显著提高映射质量。
- **诚实披露限制**：明确不声称信度、不声称 PRISMA 完整性、不声称因果性能效果，将历史价值表达为可证伪的控制假设。
- **版本固定**：将官仓库证据（仅用于建立接口）和论文机制/性能声明分开。

## 8. 不足与局限

- **单编码者偏见风险**：D3/D4 声明未经独立重编码验证，论文明确承认此限制，要求第二作者重编码并在提交前上报分歧。
- **语料有界性与时效性**：语料冻结于 2026-07-26，后续研究可能提高 D 级或填补残留；arXiv 预印本与正式期刊的审稿状态差异未完全区分。
- **无系统检索召回率**：搜索接口命中数未冻结，不能证明更大文献中仍无完成 B1–B4/B6 的系统。
- **无实验验证**：论文提出五个残留束的可证伪议程，但未执行任何对比实验验证这些耦合是否确有因果价值；现有结果只是可行性证据，而非跨域因果价值。
- **解释性判断不可避免**：七字段提取、保留/缺失不变量的判定充满解释性，即使用框架规范可见，仍不能替代独立编码。
- **历史架构与现代用途之间的目的差异**：认知架构追求对认知的稳定说明，现代智能体优化特定任务的构成；相似行为可由不同过程产生，历史机制可能带来不必要的工程开销。
- **缺乏绩效声明**：论文不宣称历史机制会提高可靠性、效率、泛化性或自主性，评价局限于机制可行性而非跨域价值；没有对五个残留束进行因果效果测试，因此无法确认其在实际运行时中是否有效。
- **与“泛化”有关的局限**：例如 GraSP 虽然闭合了 B5 架构意义上的空缺，但其报告结果并不确立通用迁移；论文明确将此视为外部效度问题而非缺失运行时链。
- **E3/E4 编码中直接的谱系证据缺失**：大多数现代系统的迁移属于趋同而非继承，这种判断依赖于“未发现明确谱系”的负向证据，搜索范围受限。
