## 摘要
大型语言模型多智能体系统（LLM-MAS）依赖智能体间的通信来解决复杂推理任务，然而关于共识性能与计算资源之间严格保证的研究仍然有限。在此，我们提出一种新颖的方法，将集体信念动态表征为离散时间切换系统，其中通信拓扑具有不同的共识收缩率和令牌成本。通过用剩余计算预算增强信念动态，我们定义了一个共识安全集，该集合同时捕获一致性和资源可行性。我们推导了共识时间和令牌消耗的显式界限，并构造了一个共识-预算证书区域，保证在资源耗尽之前实现有限时间收敛。我们进一步建立了自适应拓扑切换在收敛速度与通信成本之间实现权衡的条件，相较于固定拓扑策略。数值实验和实际LLM-MAS部署显示了预测的共识-成本权衡，展示了控制论证书如何实现AI系统中的资源感知协调。

## Abstract
Large language model multi-agent systems (LLM-MAS) rely on inter-agent communication to solve complex reasoning tasks, yet rigorous guarantees relating consensus performance to computational resources remain limited. Here, we present a novel way to characterize collective belief dynamics as a discrete-time switched system in which communication topologies have distinct consensus-contraction rates and token costs. By augmenting the belief dynamics with the remaining computational budget, we define a consensus safe set that jointly captures agreement and resource feasibility. We derive explicit bounds on consensus time and token expenditure and construct a consensus-budget certificate region guaranteeing finite-time convergence without resource exhaustion. We further establish conditions under which adaptive topology switching achieves a trade-off between convergence speed and communication cost relative to fixed-topology strategies. Numerical experiments and live LLM-MAS deployments show the predicted consensus-cost trade-offs, demonstrating how control-theoretic certificates can enable resource-aware coordination in AI systems.

## 2. 论文提出的方法论

**核心思想**：
将 LLM-MAS 的集体信念动态建模为**离散时间切换系统**，其中每个通信拓扑（模式）具有不同的共识收缩率（consensus-contraction rate）和 token 成本。系统的"harness"架构扮演监督控制器的角色，根据当前分歧水平动态选择通信拓扑。

**关键定义与技术细节**：

| 概念 | 定义/公式 |
|------|-----------|
| 智能体信念状态 | xᵢ(k) ∈ Rᵈ，第 i 个智能体在第 k 轮通信的 d 维偏好向量 |
| 集体状态矩阵 | Xₖ ∈ R^{N×d}，每行为一个智能体的信念向量 |
| 通信图与权重矩阵 | G_σ = (V, E_σ)，权重矩阵 W_σ 为双随机矩阵（doubly stochastic） |
| 分歧子空间 | 1^⊥ = {v ∈ R^N : 1^T v = 0} |
| 分歧度量 | D(k) = (1/√N)‖PXₖ‖_F，其中 P = I − (1/N)11^T 为正交投影矩阵 |
| 共识收缩率 | λ_σ = ‖W_σ \|_{1^⊥}\|₂，λ_σ < 1 表示模式 σ 共识收缩 |
| 信念动态 | X_{k+1} = W_{σ_k} X_k |
| 预算动态 | b_{k+1} = b_k − c_{σ_k} |
| 范数阈值切换 | σ_k = 1（稠密拓扑）当 D(k) > η；σ_k = 2（稀疏拓扑）当 D(k) ≤ η |
| ε-共识安全集 | Ω_ε = {(X, b) : D(X) ≤ ε, b ≥ 0} |

**核心技术结果**：

- **定理 1（资源感知共识）**：给定 D(0) > η > ε > 0，定义 K₁ = ⌈log(η/D(0)) / log λ₁⌉，K₂ = ⌈log(ε/η) / log λ₂⌉，则系统在最多 K* = K₁ + K₂ 轮内达到 ε-共识，总通信成本 B* = K₁c₁ + K₂c₂。

- **推论 1（拓扑权衡）**：当 λ₁ < λ₂ 时，K_complete ≤ K* ≤ K_ring；当 c₁/c₂ ≥ log λ₁/log λ₂ 时，自适应策略比 ring-only 更快、比 complete-only 更省 token，兼具两者优势。

- **定理 2（共识-预算证书）**：若初始状态 (X₀, b₀) 属于证书区域 Ω_cert = {(X, b) : b ≥ B*(D(X))}，则轨迹在 K* 轮内到达 Ω_ε 且预算不耗尽（b_{K*} ≥ 0）。

- **算法 1（范数阈值自适应共识）**：循环执行——当 D(k) > ε 时，根据阈值 η 选择模式，检查预算是否充足，然后更新信念和预算。

## 6. 论文的主要结论与发现

1. **理论框架有效**：切换系统模型能准确刻画 LLM-MAS 的共识-预算动态，定理 1-2 给出的边界条件得到数值与真实部署的一致验证。

2. **自适应策略的 Pareto 效率**：
   - 数值模拟中：自适应策略 3 轮达成共识（800 tokens），完全图 2 轮（1200 tokens），环形图 6 轮（600 tokens）。
   - 自适应比环形图快 3 轮（多花 200 tokens），比完全图省 400 tokens（多花 1 轮）——在延迟与成本之间取得了最佳折中。

3. **证书区域可预测不安全行为**：
   - 紧预算运行（b₀ = 650 < B* = 1000）如定理 2 预测，触发 BUDGET FAIL。
   - Claude 在完全图策略下的真实部署中，估计 B*(D(0)) ≈ 120,250 > b₀ = 100,000，预测并验证了预算耗尽的失败。

4. **不同 LLM 行为差异显著**：
   - GPT-5.4-Mini 在自适应策略下最快达成共识（9 轮，41,727 tokens）。
   - Gemini-2.5-Flash 在完全图下受益明显（9 轮 vs 自适应 14 轮），说明额外通信对某些模型有帮助。
   - GPT 在接近共识时，完全拓扑反而"帮倒忙"（多余的全局反馈导致分歧上升），说明收缩率 λ_σ 依赖分歧水平 D(k)，不仅是固定常数。

5. **所有真实 LLM 部署都呈现两阶段收敛轨迹**（自适应策略下）：Mode 1 阶段分歧快速下降（陡峭斜率），Mode 2 阶段降速（平缓斜率），与理论预测一致。

## 7. 优点

- **形式化保证**：提供了明确的理论边界（K*、B*）而不是仅凭经验的启发式。定理 2 的证书区域 Ω_cert 具有实际操作性——部署前即可通过初始分歧和预算判断是否安全。

- **实践指导价值**：为 MAS 设计者提供了"部署前离线认证"的思路——在实际调用 API 之前，就可以计算 K*、B*，判断给定预算是否足以完成任务。
- **实际问题意识**：明确指出 LLM-MAS 的资源消耗是真实且迫切的问题，将理论研究与可持续发展的关切联系了起来。

## 8. 不足与局限

- **模型假设的理想化**：
  - 假设所有模式都是共识收缩的（λ_σ < 1）。真实部署中 GPT 在环形模式下出现了 λ_σ > 1 的情况（第 7、9 轮），论文在注 3 中承认了这一点，但未提供应对非收缩模式的完整理论。
  - 假设同步激活、零通信延迟、外生切换机制。真实 MAS 中异步通信和延迟是常态。
  - 每个模式有固定常数成本 c_σ，但真实 LLM 的 token 消耗每轮动态变化（论文在部署中只能事后估计）。

- **参数辨识困难**：λ_σ 和 c_σ 依赖于 LLM 隐藏设计特征，论文在真实部署中无法在运行前确定这些参数（只能在事后从日志反推）。这大大限制了定理 2 在实际中的直接可操作性。论文自己也承认，开发运行前估计 λ_σ、c_σ 的方法是实际应用的关键前提。

- **LLM 行为的不可预测性**：真实 LLM 并非严格遵循线性矩阵乘法（式 5）的动态。论文必须显式提示智能体"每轮妥协"才能保证收缩性，否则分歧可能上升甚至发散。提示工程（prompt engineering）对系统行为有根本性影响，这不在理论框架之内。

- **实验规模与统计效度不足**：每种条件仅 1 次运行，缺乏重复实验或方差报告；没有跨任务泛化验证；token 计数的跨模型缩放（0.75、0.45）可能引入偏差——虽然论文声称只关注行为特征而非跨模型成本比较，但这种非自然缩放仍会影响结果的直观可比性。
