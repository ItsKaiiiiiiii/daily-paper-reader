## 摘要
多智能体大语言模型（LLM）系统旨在通过将任务分解给具有专门功能的多个智能体来改善推理，但多个智能体的存在本身并不能保证推理的连贯性或输出与任务目标的一致性。本文引入了一种定量人种学（QE）方法，用于基于智能体交互产生的对话来诊断和重新设计多智能体LLM系统。我们以自动作文评分为例情境测试了该方法，应用认知网络分析（ENA）对一个五智能体多智能体辩论系统进行建模，并检验产生正确与错误评分决策的辩论之间的差异。结果表明，在初始系统中，正确的评分决策以基于评分标准的论证、同意和阐述为特征。相比之下，错误的评分决策以扩展的命题-挑战-回应交流为特征，这些交流与评分标准的一致性较低。随后，我们利用这些发现修改了智能体的提示词。修订后的系统将精确评分准确率从27.78%提高到40.28%，并将错误辩论的话语转向正确辩论的基于评分标准的模式，使两者几乎无法区分。基于这些结果，我们认为QE可以通过追踪智能体互动模式与系统表现之间的关系、为提示词重新设计提供信息，并评估这些重新设计是否同时改变了结果和互动模式，来支持AI推理的诊断到重新设计的循环。

## Abstract
Multi-agent large language model (LLM) systems are designed to improve reasoning by decomposing tasks across multiple agents with specialized functions, but the presence of multiple agents does not inherently guarantee coherent reasoning or outputs that align with task objectives. This paper introduces a quantitative ethnographic (QE) approach for diagnosing and redesigning multi-agent LLM systems based on the discourse produced through agent interactions. We test this approach using automated essay scoring as an example context, applying Epistemic Network Analysis (ENA) to model a five-agent multi-agent debate system and examine differences between debates that produced correct versus incorrect scoring decisions. Results show that, in the initial system, correct scoring decisions were characterized by rubric-grounded justification, agreement, and elaboration. Incorrect scoring decisions, in contrast, were characterized by extended proposition-challenge-response exchanges that were less consistently tied to rubric criteria. We then used the findings to revise the agents' prompts. The revised system improved exact scoring accuracy from 27.78% to 40.28% and shifted the discourse of incorrect debates toward the rubric-grounded pattern of correct ones, making the two nearly indistinguishable. Based on these results, we argue that QE can support a diagnostic-to-redesign loop for AI reasoning by tracing how patterns of agent interaction relate to system performance, informing prompt redesign, and evaluating whether those redesigns change both outcomes and interaction patterns.

## 1. 核心问题与整体含义

- **研究动机**：多智能体大语言模型（LLM）系统通过将复杂任务分解给多个具有专门角色的智能体来提升推理能力，但"多智能体"本身并不保证推理的连贯性或输出与任务目标的一致性。此类系统常出现协调失败、过早共识、无根据推论等多种推理错误，尤其当推理过程是多轮复杂的辩论时，问题更难定位。
- **核心困境**：现有评估多依赖输出级指标（如准确率），只能告诉我们系统何时失败，却无法解释在智能体之间的话语层面为何失败。单纯频率统计的文本分析方法无法捕捉智能体交互的相互依赖结构。
- **整体含义**：提出一种基于**定量人种学（QE）**与**认知网络分析（ENA）**的方法论，将多智能体LLM生成的辩论记录视为可分析的话语，通过追踪话语模式与系统表现的关系，构建"诊断→重新设计→再评估"的闭环，以指导对提示词的系统性改进。该方法论框架不局限于作文评分，可推广至临床决策支持、法律推理、协作规划等任何产生审慎性话语的多智能体系统。

## 2. 方法论

- **核心思想**：使用ENA将智能体间的辩论话语建模为网络——节点为话语编码，边为编码在对话中的共现关系——从而区分正确与错误输出背后的论证结构差异；再将诊断结果转化为具体的提示词修订目标，并检验修订是否同时改变了输出表现和话语结构。
- **系统架构**：采用Toulmin论证模型构建五智能体辩论系统（TSMD）：
  - **Claim Agent**：提出初始分数（1–6）
  - **Grounds Agent**：识别文本证据
  - **Warrant Agent**：将证据映射到评分标准
  - **Rebuttal Agent**：挑战论点、考虑分数修订（支持双向修订——上调或下调）
  - **Judge Agent**：综合辩论、给出最终分数
  - 每个智能体均接收作文全文、ASAP 2.0评分标准和此前全部回合的辩论记录。
- **话语编码**：采用会话论证编码方案（CACS）对每个智能体回合进行编码，共使用10个代码：Assertion、Proposition、Elaboration、Amplification、Justification、Agreement、Acknowledgement、Objection、Challenge、Response。两个编码者先联合校准，再独立编码，分歧通过社会化调和达成共识。
- **ENA建模要点**：
  - 每个作文对应的完整辩论被视为一个独立会话/边界，共现计数不跨作文；
  - 采用无限移动窗口，因为论点可被后续回合跨距离引用、挑战或发挥；
  - 通过均值旋转（means rotation）使第一维度（MR1）最大化准确组与不准确组之间的分离；
  - 组间差异使用双尾Welch's t-test检验（因两组样本量不等：20 vs 52），效应量用Cohen's d报告。
- **提示修订策略**（由RQ1诊断结果驱动）：
  - **Warrant Agent**被要求必须先命名相关评分标准，再评估作文是否达标——直接针对欠缺基于标准的论证（Justification）问题；
  - **Grounds与Warrant Agent**被禁止提出新分数，将提出分数的行为限制在Claim与Rebuttal Agent，以减少无锚定的命题行为；
  - 评分标准、采样参数和整体架构在两个实验轮中保持不变。

## 3. 实验设计

- **数据集**：ASAP 2.0语料库，选取72篇美国中学生议论文，按六个分数等级分层抽样（每级12篇），确保覆盖全分数区间。
- **评分标准**：六点评分量表（1=极少掌握至6=清晰一致掌握），金标分数由训练有素的专家评分者给出。
- **模型**：所有智能体使用Qwen 2.5 72B Instruct开源模型，温度0.3，每回合上限400新token，五个智能体参数一致。
- **对比设计**：同一72篇作文在初始提示与修订提示下分别评分，构成配对设计；未设置单智能体基线或消融实验。
- **测试指标**：精确匹配准确率（Judge最终分数与金标完全一致的比例）；McNemar χ²检验用于配对改进的显著性检验。

## 5. 实验数量与充分性

- **实验组数**：共两个阶段实验（初始轮72篇、修订轮72篇），围绕三个研究问题展开分析：RQ1初始轮正确/错误辩论的话语结构差异；RQ2提示修订前后准确率对比；RQ3修订轮中正确/错误辩论的话语结构是否收敛。
- **统计检验**：RQ1采用Welch's t检验，RQ2采用单尾McNemar检验（配对设计），RQ3将修订轮数据投影到初始轮ENA空间进行比较。
- **充分性评估**：
  - **充分之处**：配对设计有效控制了作文样本、架构、模型等混杂因素；RQ3的话语层面验证使结论超越了"仅准确率提升"的层次。
  - **不足之处**：① 缺少单智能体基线和逐项消融实验（无法确定哪条具体提示变化最有效）；② 仅使用单一模型（Qwen 2.5 72B）和单一领域（作文评分）；③ 各分数等级的样本量较小（每级12篇），分组后准确/不准确组样本量不均衡；④ 未进行多轮迭代诊断-重设计验证。

## 6. 主要结论与发现

- **RQ1——正确与错误辩论的话语结构显著不同**：初始轮中，20场正确辩论与52场错误辩论在MR1维度上差异显著（t = -4.69, p < .001, d = 1.19）。正确辩论表现为以**Justification、Agreement、Elaboration、Assertion**之间的紧密连边为特征的"基于标准的收敛"模式；错误辩论则表现为**Proposition、Challenge、Response**之间的连边，即缺乏标准锚定的"无锚争议"模式。
- **RQ2——ENA驱动的提示修订显著提升准确率**：精确准确率从27.78%（20/72）提升至40.28%（29/72），相对提高约45%，McNemar检验显著（χ²(1)=3.24, 单尾p=.0359）。其中12篇保持正确、8篇变错、17篇由错转对、35篇仍然错误。话语频率层面，Justification从52次增至225次，Agreement从139次增至159次，Objection从57次降至12次，Response从43次降至5次，与修订意图一致。
- **RQ3——修订后话语结构趋同**：修订轮中准确（29篇）与不准确（43篇）辩论的质心分离从初始轮的0.29降至约0（t(58.30) = -0.03, p = .97, d = 0.01），两组在投影空间中几乎不可区分——说明修订在话语层面发挥了预期作用，而不仅仅是改变了输出。
- **方法论意义**：角色分离的多智能体设计并不自动保证产生预期的论证推理，必须显式要求智能体引用评分标准；频率型文本分析无法捕捉到正确与错误组在编码频率相似但连接结构迥异的差异，而ENA能够检测到这种结构差异。

## 7. 优点

- **方法创新性强**：首次将量化人种学（QE）/ENA系统性地应用于AI生成话语的分析与系统改进，打开了"以话语结构指导AI系统重设计"的新途径。
- **诊断-重设计闭环完整**：诊断结果直接转化为具体提示修改目标（如"要求Warrant Agent命名标准"），并通过RQ3验证话语层面的机制变化，而非仅依赖输出指标。
- **统一的理论框架**：系统架构和话语分析均以Toulmin论证模型为理论基础，编码方案选用成熟的CACS，保持了从设计到评估的概念一致性。
- **统计方法恰切**：配对数据采用McNemar检验、不均衡组采用Welch's t检验、报告效应量，体现了方法论上的严谨性。
- **诚实的局限性讨论**：论文明确承认了提示修改可能带来的"所有辩论统一听起来有依据"的风险，以及单一领域/模型验证的局限。

## 8. 不足与局限

- **绝对准确率仍然有限**：修订后40.28%的准确率意味着大部分作文评分仍然错误，说明"缺乏标准锚定的论证"并非错误推理的唯一机制，其他因素（如标准理解质量、证据选择、智能体间协商深度）未纳入分析与干预范围。
- **缺少必要的对照实验**：未设置单智能体基线、无消融实验来隔离每条提示改动的影响，无法判断是特定某条修改还是组合修改起作用。
- **单领域、单模型验证**：仅测试了作文评分场景和Qwen 2.5 72B一种模型，跨模型和跨任务的稳定性未知。
- **样本量较小**：72篇作文、每等级12篇的样本规模限制了统计功效，分组的组间样本不均衡也可能影响检验稳健性。
- **潜在的表面趋同风险**：RQ3观察到的组间话语收敛可能部分源于提示词使所有辩论（无论正确与否）都表现为统一地"基于标准"，而非真正改善了不准确辩论的推理质量——这是基于话语的分析无法完全排除的威胁。
- **编码过程成本较高**：依赖人工CACS编码与社会调和，限制了方法在大规模语料上的可扩展性；自动化编码的替代方案未被测试。
- **未进行迭代验证**：诊断-重设计循环仅执行了一轮，尚未展示多轮迭代能否带来持续的准确率提升。
