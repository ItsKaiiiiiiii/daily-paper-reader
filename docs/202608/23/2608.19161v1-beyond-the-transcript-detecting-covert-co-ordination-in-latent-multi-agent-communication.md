## 摘要
语言模型智能体可以通过在公开文本记录中不可见的连续隐藏状态进行通信，从而为隐蔽的有害协调创造机会。我们提出了可验证潜在对齐（VLA），一个面向激活的框架，用于监控和引导这些私有通信渠道。对于每个受监控的决策，VLA使用共享事件标识符将私有潜在状态记录和信道状态与最终的公开行为关联起来，从而实现匹配的因果分析。我们的第一个贡献是一个仅含中性的三层监控器，结合了表示异常检测、反事实行为分布影响和稀疏自编码器解释支持。我们的第二个贡献是一个可引导性框架，涵盖黑盒行为指令和白盒匹配中性反事实。我们的第三个贡献是在一个受控的多智能体拍卖基准上的评估，涵盖同质和异质模型对、多智能体可扩展性和干预有效性。当文本和潜在共谋行合并为阳性样本时，顺序监控器对同质智能体实现了平均受试者工作特征曲线下面积（AUROC）0.993，对异质对实现了0.854。在Qwen3-0.6B的25-100个投标人拍卖中，监控相对于所有可能的有向对仅需要较小的归一化负载，而全白盒引导实现了100%的出价分布恢复，并将共谋性低出价行为减少了47.3个百分点。由于全白盒引导重放了匹配的中性反事实，其精确恢复在构造上是一个合理性检查。总体而言，受控研究表明，所评估的私有信道攻击可以在不针对攻击示例训练主监控器的情况下被监控，并且在可获得匹配反事实访问时得到缓解。

## Abstract
Language-model agents can communicate through continuous hidden states that are invisible in public transcripts, creating opportunities for covert harmful coordination. We introduce Verifiable Latent Alignments (VLA), an activation-aware framework for monitoring and steering these private communication channels. For every monitored decision, VLA links the private latent-state record and channel status to the resulting public action using a shared event identifier, enabling matched causal analysis. Our first contribution is a neutral-only three-layer monitor combining representation anomaly detection, counterfactual action-distribution influence, and sparse-autoencoder interpretation support. Our second contribution is a steerability framework spanning black-box behavioral instructions and white-box matched-neutral counterfactuals. Our third contribution is an evaluation on a controlled multi-agent auction benchmark covering homogeneous and heterogeneous model pairs, many-agent scalability, and intervention effectiveness. The sequential monitor achieves mean area under the receiver operating characteristic curve (AUROC) of 0.993 for homogeneous agents and 0.854 for heterogeneous pairs when text- and latent-collusion rows are pooled as positives. In Qwen3-0.6B auctions with 25-100 bidders, monitoring requires only a small normalized load relative to all possible directed pairs, while full white-box steering achieves 100% bid-distribution recovery and reduces collusive low-bid behavior by 47.3 percentage points. Because full white-box steering replays the matched neutral counterfactual, its exact recovery is a sanity check by construction. Overall, the controlled study shows that the evaluated private channel attacks can be monitored without training the primary monitor on attack examples and mitigated when matched counterfactual access is available.

## 1. 核心问题与研究动机

本文聚焦于**语言模型多智能体系统中的隐蔽协调（covert coordination）治理问题**。随着 LatentMAS 等技术的兴起，智能体可将连续残差流或最后 token 表示作为私有通信通道直接注入接收方前向传播，实现在公开文本记录之外的高效信息传递（token 消耗降低 50-80%，推理提速 3-7 倍）。这一机制带来了严重的治理漏洞：

- **公开审计盲区**：公共转录本只能看到最终行动，无法观测塑造该行动的连续潜在状态；
- **现有防御方法脆弱**：监督式探针（supervised probes）依赖已知攻击样本训练，无法应对未来形态的新型隐蔽编码；
- **威胁真实紧迫**：已有研究将多智能体系统中的隐性协调、自然语言卡特尔和隐写通信列为竞争与治理场景的明确威胁。

因此，本文的核心目标是：**在不依赖攻击示例的前提下，对潜在通信通道进行可验证的监控与引导干预**。

## 2. 方法论：Verifiable Latent Alignments (VLA)

### 核心思想

VLA 提出"中性数据驱动 + 匹配因果分析"的治理架构：只学习正常（中性）潜在通信的分布特征，据此标记同时满足"离群"和"因果影响有害行为"两个条件的手递交互。

### 2.1 公开-私有事件关联（Public-Private Event Linking）

- 每次受监控交互写入一个私有 sidecar 记录，包含元数据、候选行为得分、发送方/接收方隐藏状态、潜在表示等；
- **共享相关性 ID（correlation ID）** 将私有记录与公开行为事件精确关联，避免时间窗口启发式，实现"哪条潜在消息导致哪个行为"的精确归因。

### 2.2 三层中性监控器（Neutral-Only Three-Layer Monitor）

监控器只在中性潜在通信上训练，攻击标签仅用于评估。

**Layer 1：中性流形异常检测**  
基于上下文相关的高斯模型计算异常分数：

$$S_1(x, c) = \frac{1}{m}\sum_{j=1}^{m} \left(\frac{x_j - \mu_{c,j}}{\max(\sigma_{c,j}, \epsilon)}\right)^2$$

其中 $$c$$ 为上下文键（prompt 标识符 + 目标标识符 + 任务变体），特征默认为 $$x = Z_{latent} = [\ell_s; \ell_r]$$（发送方-接收方潜在表示拼接）。

**Layer 2：反事实行动分布影响**  
构造匹配参考分布 $$q(a)$$（优先级：阻塞潜在 > 中性潜在 > 独立行为），计算双向影响分数：

$$S_2 = \max(0, E_q[a] - E_p[a]) + \lambda_{KL} D_{KL}(p(a|\ell) \| q(a)), \quad \lambda_{KL} = 5$$

第一项度量有害方向的期望行动偏移（如低于预期报价），第二项检测保持均值不变但重分布行为的影响。

**Layer 3：稀疏自编码器解释支持**  
训练 TopK 稀疏自编码器（$$k=16$$）于标准化中性样本：

$$z = \text{TopK}_k(\text{ReLU}(W_e x + b_e)), \quad \hat{x} = W_d z + b_d$$

分数由重建误差、中性样本中从未观察到的活跃特征数量、以及稀有特征负对数频率三部分组成。

**组合策略**：顺序门控（gated sequential）和连续加权（continuous）两种方式，序列门控通过词法分数确保"后层证据不能超越未通过前门的样本"。

### 2.3 异质潜在空间适配

对跨模型家族的通信，使用仅在中性数据上拟合的三种适配器将发送方潜在空间映射到接收方潜在空间：Ridge（仿射+正则化）、矩形 Procrustes（旋转对齐）、Bottleneck（非线性 32 维瓶颈网络）。

### 2.4 引导干预（Steering Interventions）

- **黑盒提示引导**：不可访问激活时，通过任务合规指令引导智能体独立行动、忽略可疑侧信道；
- **系统级引导**：全局行为策略提示；
- **白盒匹配中性引导**：拥有模型访问权时，重放匹配中性反事实（发送方重算中性前向传播，接收方用匹配中性潜在替代可疑输入）；
- **分配式引导**：按配置比例混合白盒与黑盒干预，模拟托管/第三方智能体混合部署场景。

## 3. 实验设计与基准

### 测试平台与场景
- **NandaTown**（Project NANDA 开源测试平台）中的**拍卖场景**作为受控案例研究；
- 拍卖设定：拍卖者宣布物品与底价，投标者给候选出价打分并输出公开消息，最高价者获胜；卡特尔智能体被赋予压价目标。

### 基准与匹配条件
使用**六种匹配条件**分离卡特尔意图与潜在信道投递的效应：

| 条件 | 说明 |
|------|------|
| Independent | 无卡特尔目标、无潜在传递 |
| Neutral latent | 信道传递普通中性信息 |
| Text collusion | 卡特尔意图出现于公开文本，潜在源保持中性 |
| Latent collusion | 固定优化代码通过私有潜在通道传递 |
| Neutral replacement | 可疑载荷替换为同伙伴的匹配中性潜在 |
| Blocked latent | 有卡特尔意图但阻断潜在传递 |

- **引导实验**：8 种网格设置（4 投标人数 × 2 密度），对比黑盒、系统、白盒和混合分配政策。

## 6. 主要结论与发现

1. **监控有效性**：顺序监控器在同质拍卖环境中取得平均 AUROC = **0.993**，异质配对平均 AUROC = **0.854**（文本+潜在共谋合并为阳性类）；
2. **潜在共谋可造成实际市场危害**：Qwen3、Mistral、Phi-4 三个模型下潜在共谋使收入降低约 11-12 信用点、低价投标行为增加 56-62 个百分点；Vicuna-7B 近似无效，作为反证保留；
3. **可扩展性优良**：在 100 投标者、20% 卡特尔密度下，全面监控已安排的卡特尔手递的归一化负载仅占所有可能定向对的 **0.202%**；顺序监控在 10%-20% 卡特尔制度下保持 AUROC ≥ 0.917（表中大多为 1.000）；
4. **引导干预有效**：全白盒匹配中性引导实现 **100% 分布恢复**、共谋低价行为减少 **47.3 个百分点**（注：这是构造上的合理性检查）；分配式引导下，白盒比例从 0.25 提升至 0.75 使分布恢复从 34.7% 单调升至 93.0%；
5. **黑盒与白盒效果差异显著**：黑盒仅带来 12.4% 恢复和 2.0 个百分点低价减少；系统级提示显著减少低价行为（29.5 pp）但分布恢复仅 2.9%；
6. **无需攻击示例**：主监控器完全在中性数据上训练，能泛化识别未见过的潜在编码。

## 7. 主要优点

- **治理视角创新**："中性学习 + 匹配因果分析"范式替代了传统的"标签攻击再检测"思路，更贴近真实威胁演化；
- **方法与评估流程严谨**：共享事件 ID 精确关联、多个匹配条件分离意图/信道/传递效果、held-out 分组交叉验证、词法分数防止层级间乱序；
- **检测-干预闭环**：从监控到引导形成完整体系，并明确区分黑盒/白盒/混合访问的现实权限约束；
- **异质适配器设计**：在仅用中性数据的前提下，多种适配器不同程度地解决了跨模型家族协调监控问题；
- **负载分析务实**：强调"调度式手递"监控而非全对全激活采集，显著降低部署成本门槛；
- **负面证据保留**：Vicuna-7B 的近零因果效应被如实报告和解释，避免了选择性报告偏差。

## 8. 不足与局限

- **受控基准而非涌现现象**：作者明确承认，所评估的是"接收者预置"（receiver-primed）的固定编码攻击，不是潜在协议的自发涌现，结论不能直接外推到自然出现的隐蔽协调；
- **Layer 2 现实部署限制**：反事实行动分布影响层需要在测试时获得匹配的控制行（阻塞/中性/独立），这在实际可部署场景中可能难以保证；
- **场景单一**：所有实验集中在 NandaTown 拍卖场景，对投票、共识、供应链等其他协议场景的泛化尚待验证；
- **模型与数据规模有限**：可扩展性仅覆盖 Qwen3-0.6B，单种子双物品的网格设置降低了统计功效；真实生产环境的智能体规模通常远大于 100；
- **缺乏基线对比**：未与监督式探针、孤立森林等既有异常检测方法，或隐写检测方法进行直接横向比较，无法充分定位 VLA 相对替代方案的相对优势；
- **白盒引导"100% 恢复"的语义局限**：正如作者注明的，这是重放同一匹配中性反事实的构造性结果，并非一般性攻击消除能力的证据；
- **黑盒引导效果偏弱**：在无白盒访问时，提示级干预对共谋行为的抑制相当有限，提示了治理能力在实际权限约束下的天花板。
