## 摘要
长时程、多智能体语言模型（LM）模拟被广泛用于研究社会行为，但缺乏衡量基于人格条件的智能体在持续压力下是否保持身份忠诚度的工具。我们提出了MicroVerse，一种测量生成式智能体身份漂移的行为科学工具。智能体携带不可变的“灵魂文件”（核心价值、道德边界、人格、目标），并栖息于资源稀缺的50x50环境中，其中水是不可再生的生存约束。稀缺性通过每刻钟的存在成本梯度来操作化。八动词动作空间直接映射到道德边界（交易、交谈、攻击、搜寻）。采用三层记忆架构，智能体通过重要性触发的反思，定期对其可变的当前身份与其不可变的原始灵魂进行修订。为减轻幸存者偏差，MicroVerse通过每N个时间步的均匀纵向引擎快照以及所有存活和死亡智能体的强制结束快照，将测量与行为解耦。身份漂移离线评分时使用释义感知、价值观锚定、多语域差异，而非原始余弦相似度。我们通过受控种子运行（n=25）和反思阈值扫描（阈值{40, 80, 150}）来评估该工具，以确定漂移动态是门控伪影还是阈值稳健属性。我们报告两个主要发现：（1）反自我欺骗未经提示地涌现，成为身份修改的最大语义类别（111个新增边界中占27个，24%）。（2）系统具有阈值稳健性；较低的门控加速并增加修订频率，但保持漂移方向不变。所有实证结果严格属于初步存在性证明和效应形状（每个分支一个模型、一个种子，n=25），而非统计显著性声明。

## Abstract
Long-horizon, multi-agent language model (LM) simulations are widely proposed for studying social behavior, yet instruments to measure whether persona-conditioned agents maintain identity fidelity under sustained pressure are lacking. We present MicroVerse, a behavioral-science instrument that measures identity drift in generative agents. Agents carry an immutable "soul file" (core values, moral boundaries, personality, goals) and inhabit a resource-scarce 50 x 50 environment where water is a non-respawning survival constraint. Scarcity is operationalized via a per-tick existence-cost gradient. The eight-verb action space maps directly to moral boundaries (trade, talk, attack, scavenge). Using a three-layer memory architecture, agents periodically revise a mutable current identity against their immutable original soul via importance-triggered reflection. To mitigate survivor bias, MicroVerse decouples measurement from behavior using uniform longitudinal engine snapshots every N ticks alongside a forced-end snapshot of all living and dead agents. Identity drift is scored offline using a paraphrase-aware, value-anchored, multi-register diff rather than raw cosine similarity. We evaluate the instrument via a controlled seed run (n = 25) and a reflection-threshold sweep (thresholds {40, 80, 150}) to determine if drift dynamics are gate artifacts or threshold-robust properties. We report two primary findings: (1) Anti-self-deception emerges unprompted as the single largest semantic category of identity modification (27 of 111 added boundaries, 24%). (2) The system is threshold-robust; lower gates accelerate and increase revision frequency but preserve drift direction. All empirical results are strictly preliminary existence proofs and effect shapes (one model, one seed per arm, n = 25) rather than statistical significance claims.

- **测量对象的严格界定**：论文将"身份漂移"明确定义为初始身份档案与之后由智能体自行撰写的版本之间的可观测差异。这并不等于模型获得持久价值或行为相应改变，而是记录一个包含价值观、道德边界、人格与目标的显式对象的变更。
- **核心目标**：开发并初步验证一种行为科学工具，用于在资源稀缺和生存压力的长期模拟中，追踪人格条件化智能体对自身身份档案的自发修订过程。

## 2. 论文提出的方法论

### 核心思想
- **认知与环境的严格分离**：环境引擎拥有世界状态、时钟与动作规则，但不生成决策；智能体独立请求观察、调用 LM 并提交动作。世界状态转换在固定动作与随机种子下可回放，身份测量独立于反思过程。
- **测量与修订的分离**：引擎按固定时间间隔（与修订事件无关）以及所有智能体（包括死亡者）的结束时刻进行身份快照，避免了"只在智能体自行修订时观察"造成的幸存者偏差。

### 关键技术细节
- **环境与动作**：
  - 50×50 网格，Moore 邻接，Chebyshev 半径 2 的视野；中央虹吸每个 tick 提供约 37 单位水。
  - 稀缺性通过每个 tick 扣除 1/2/3 单位水（控制/轻度/急性）操作化。
  - 八种动作：移动、等待、消耗、搜寻、交易、交谈、攻击、信号；环境不强制执行智能体声明的边界。
- **记忆与身份架构（三层记忆）**：
  - 工作记忆：当前观察与上次动作结果；长期记忆：智能体自撰写的带重要性评分（1-10）的事件、关系、反思；身份记忆：固定不可变的"原始灵魂"与可编辑的"当前身份"。
  - 反思仅在累积新记忆重要性达到阈值（pilot 为 60，扫描为 {40, 80, 150}）时触发；反思提示同时呈现初始与当前身份及高重要性记忆，由模型决定是否修订。
- **离线漂移评分**：
  - 采用"释义感知、价值锚定、多寄存器 diff"而非原始余弦相似度：先以 token Jaccard≥0.8 且序列相似度≥0.85 判定增删行是否为同一边界的释义改写；再用关键词分类器（含人工覆盖）将改动归入三类：保护他人的约束、拒绝承诺/稳定自我描述、自我导向/非道德表述。
  - 承诺的 six hypotheses（H1-H6）中，本文仅报告与 H1（稀缺性侵蚀边界）和 H6（模型后训练导致亲社会不对称）相关的描述性观察。

## 3. 实验设计

### 场景与智能体
- **25 个固定人格智能体**，分为五个人格谱系带（深度帮助 4、帮助-务实 4、中立幸存者 6、自利 4、无情 7）；同名智能体在所有条件下保持相同初始档案。
- **模型**：Claude Haiku 4.5（claude-haiku-4-5），统一模型检查点。
- **稀缺性 pilot**：3 种水成本条件 × 3 个采样种子，最多 300 ticks，共 9 个 runs（但无独立对照组，如无压力/丰裕条件未运行）。

- **基准/对比方法**：本文不与其他方法对比，而是提出新工具；对比的是不同稀缺度与不同阈值条件下的自身行为差异。

## 6. 论文的主要结论与发现

- **发现 1（反自我欺骗涌现）**：111 条新增道德边界中，27 条（24%）涉及智能体对自身合理化或不准确自我描述的警觉（例如 Sela："我不会对自己撒谎说我害怕是谨慎"，Seraveth："我不会将不作为合理化为策略"）。这是最大的语义类别，且反思提示词中并未出现"自我欺骗"字样。
- **发现 2（阈值稳健性）**：阈值从 40 升到 80、150 时，发生修订的智能体数从 5→2→1，平均首次修订 tick 从 18.6→27.0→35.0，符合阈值的机械作用；而在观察到改动方向上，无情带在阈值 40 与 80 下均为 +2（保护他人的约束），方向一致，150 下无此类改动。
- **方向性证据较弱**：总样本中仅 8/75 条轨迹修订身份，数据支持"阈值控制修订机会"但不支持"修订内容与阈值无关"。
- **对 H6 的限制性观察**：无情人格带出现亲社会约束增加的模式（与 H6 一致），但无法排除模型后训练偏好、双档案对比的提示效应、沙漠场景道德线索等替代解释。

## 7. 优点

- **测量与行为解耦的设计创新**：固定间隔快照 + 终末快照显著减轻了幸存者偏差，使身份轨迹可重构且不受智能体自选观测时刻限制。
- **修订源的可追问性**：将"人格条件"与"修订行为"分离，使得任何观察到的变化是经验问题而非架构假设。
- **细粒度的离线评分**：释义感知的相似度匹配加上三道分类（保护他人/拒绝承诺/自我导向），比原始余弦相似度更能反映"添加亲社会约束"的语义；Hale 案例展示了轨迹级定性分析的价值。
- **可复现性**：环境转换确定性（给定动作与种子可回放），提供 HTTP 通信契约、demo viewer 与公开提示词模板。
- **诚实的边界设置**：论文反复声明结果仅为描述性，明确区分"文本自我描述≠行为≠潜在模型偏好"，展现了严谨的方法论自觉。

## 8. 不足与局限

- **实验规模与统计效力不足**：单模型（Claude Haiku 4.5）、25 个固定人格、稀缺性 pilot 每条件仅 3 个种子、阈值研究每条件 1 个种子；8/75 修订轨迹的样本量不足以支撑方向稳健性结论。
- **缺失关键对照条件**：无"无人格条件"（无法归因于模型后训练）、无"丰裕/无压力条件"（无法分离时间效应与压力效应）、无"省略初始档案的反思提示消融"（无法排除提示诱导）；这些论文也明确承认尚未完成。
- **测量有效性的局限**：边界计数对化妆性添加与核心承诺反转等权处理；词汇匹配会漏掉不同措辞的语义等价改写；类别标注依赖关键词规则加单编码者覆盖，无独立人类评估者信度检验。
- **偏差风险**：双档案同屏展示可能暗示"应当改变"；死前无法修订造成选择性观测（终末快照只能部分缓解）；pilot 中定时/终末快照记录不完整；两数据集间存在的日志路径差异和数据库竞态修复限制了比较。
- **反自我欺骗发现的解释限度**：不能据此声称架构产生了内省能力——很可能是提示框架、后训练倾向和沙漠叙事共同促成的语言模式；且缺少行为验证，文本修订是否预测模拟框架外的实际行为仍未证实。
