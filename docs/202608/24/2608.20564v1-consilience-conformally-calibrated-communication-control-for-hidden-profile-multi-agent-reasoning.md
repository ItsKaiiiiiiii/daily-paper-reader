## 摘要
多智能体LLM系统通过汇集不同视角可以改进推理，但其有效性取决于通信的协调，特别是在隐配置场景中，每个智能体仅持有正确决策所需的部分证据。现有的协议，包括固定调度、轮询交换和非结构化辩论，无法保证对话行为的适当性。我们提出Consilience，一种推理时编排框架，在分布式私有信息下既引导又认证多智能体通信。在每一轮中，Consilience使用一个紧凑状态总结讨论，该状态捕获不确定性、分歧、证据增益、冗余和过早共识，然后选择通信干预（质疑、澄清、寻求证据或路由）和合适的发言者。其核心贡献是一种逐轮共形校准程序，提供无分布、有限样本保证：在每一轮讨论中，以到达该轮为条件，控制器提议动作的一步遗憾以概率至少1-alpha被校准阈值界定；接受机制通过替换不可接受的提议来强制执行相同保证。在跨越12个开放和封闭权重语言模型的HiddenBench风格隐配置任务上，Consilience相较于固定和非结构化讨论协议提高了决策准确性和通信效率，有时超过全信息基线（即每个智能体观察所有证据）。这些结果表明，经认证的自适应通信控制可能比增加信息可用性更有价值，为可靠的多智能体LLM协调提供了实用机制。

## Abstract
Multi-agent LLM systems can improve reasoning by pooling diverse perspectives, but their effectiveness depends on coordinating communication, particularly in hidden-profile settings where each agent holds only part of the evidence required for a correct decision. Existing protocols, including fixed schedules, round-robin exchange, and unstructured debate, provide no guarantee that a conversational action is appropriate. We propose Consilience, an inference-time orchestration framework that both steers and certifies multi-agent communication under distributed private information. At each turn, Consilience summarizes the discussion using a compact state capturing uncertainty, disagreement, evidence gain, redundancy, and premature consensus, then selects both a communication intervention (challenge, clarify, seek evidence, or route) and an appropriate speaker. Its central contribution is a round-wise conformal calibration procedure that provides a distribution-free, finite-sample guarantee: at each discussion round, conditional on reaching that round, the one-step regret of a controller's proposed action is bounded by a calibrated threshold with marginal probability at least 1 - alpha; an acceptance mechanism enforces the same guarantee for the executed action by replacing inadmissible proposals. On HiddenBench-style hidden-profile tasks spanning 12 open and closed weight language models, Consilience improves decision accuracy and communication efficiency over fixed and unstructured discussion protocols, sometimes surpassing a full-information baseline where every agent observes all evidence. These results demonstrate that certified adaptive communication control can be more valuable than increasing information availability, providing a practical mechanism for reliable multi-agent LLM coordination.

- **研究背景**：大语言模型（LLM）越来越多地被部署为多智能体系统，多个智能体通过交换论据、相互批评、联合决策来提升推理能力。然而，已有研究表明，多智能体讨论并不总是优于单智能体，可能重复能力、放大相关性错误，或在有说服力但错误的结论上过早收敛。
- **核心问题（隐配置问题）**：在**隐配置（hidden-profile）**场景中，任务相关信息被分布在不同智能体手中，任何单一智能体都不拥有做出正确决策所需的全部信息。社会心理学研究发现，人类群体存在"公共信息偏差"——共享信息更容易被提及和强化，独特信息则被忽视，导致群体倾向于支持次优方案。LLM 群体同样复现了这类集体推理失败（HiddenBench 基准证实）。
- **现有方法的不足**：固定调度、轮询交换、非结构化辩论等协议无法保证对话动作的适当性；无法根据讨论状态自适应地决定是否需要引出缺失证据、澄清分歧、质询结论、路由信息或终止讨论。
- **核心命题**：通信控制应被当作**顺序决策问题**而非固定提示协议；经认证的自适应通信控制可能比单纯增加信息可用性更有价值。

### 2. 论文提出的方法论

#### 2.1 总体框架

Consilience 是一个推理时（inference-time）编排框架，采用闭环通信控制，包含五个阶段：

**Stage 1：信念获取与状态构建**
- 每个智能体基于公共转录本和私有信息报告信念分布 \(p_i^{(t)}\)；聚合信念为算术平均 \(\bar{p}^{(t)}\)。
- 构建六维紧凑状态 \(s_t = [H_t, D_t, R_t, G_t, C_t, P_t]\)：
  - \(H_t\)：群体不确定性（聚合信念的归一化熵）
  - \(D_t\)：智能体间分歧（Jensen–Shannon 散度）
  - \(R_t\)：消息冗余度（词法重叠 + LLM 评估）
  - \(G_t\)：证据增益（是否贡献此前未共享、决策相关的新事实）
  - \(C_t\)：通信成本（归一化转录本长度）
  - \(P_t\)：过早共识（高置信+弱证据+早期轮次的组合信号）
- 定义**替代讨论损失** \(J(s_t) = \alpha_H H_t + \alpha_D D_t + \alpha_R R_t - \alpha_G G_t + \alpha_C C_t + \alpha_P P_t\)，作为局部控制信号。

**Stage 2：通信动作提议**
- 动作空间为四种干预：**Challenge**（质询当前主流答案）、**Clarify**（澄清分歧）、**SeekEvidence**（请求未共享事实）、**Route**（引导未充分发言的智能体贡献判别性事实）；允许自适应终止的控制器额外包含 **Vote**。
- 提供三种控制器变体：
  - **规则控制器**：基于状态变量的固定阈值
  - **学习控制器（MLP）**：以穷举反事实奖励训练的多层感知机（6→12→4）
  - **LLM 控制器**：基于完整转录本和状态选择动作（另有含 Vote 的变体）

**Stage 3：反事实评估与共形接受**
- 对每个候选动作，从同一冻结状态独立执行分支评估，计算一步改进 \(r_t(s_t, a) = J(s_t) - J(s^a_{t+1})\)。
- 定义**一步遗憾**作为非一致性分数：
  \[
  \mathcal{R}_t(s_t, a) = J(s^{a}_{t+1}) - \min_{a' \in \mathcal{A}_m^t(s_t)} J(s^{a'}_{t+1})
  \]
- **共形校准**：基于固定控制器生成的校准轨迹，逐轮构建遗憾分数集合，设定阈值 \(\epsilon_t^m\)（第 \(k_t = \lceil(n_t+1)(1-\alpha)\rceil\) 个最小校准分数）。
- **在线接受**：若控制器提议动作的遗憾超过阈值，则用共形集内最小遗憾动作替换（确定性回退规则 Select）。

**Stage 4：动作条件路由**
- 分歧导向动作（Challenge/Clarify）→ 选择与群体分歧最大的智能体；
- 证据获取动作（SeekEvidence/Route）→ 选择发言次数最少的智能体；
- 选定智能体生成动作条件消息，更新公共转录本与信念。

**Stage 5：终止与集体预测**
- 当 Vote 被选中/满足早停条件/达到最大轮数时终止；采用多数投票加置信度平局打破规则产生最终答案。

#### 2.2 理论保证

**命题 1（逐轮边际遗憾覆盖）**：固定控制器 \(m\) 和轮次 \(t\)，在可交换性假设下（校准与测试轨迹由同一固定策略生成、控制器固定），控制器提议动作的遗憾以边际概率至少 \(1 - \alpha\) 被阈值 \(\epsilon_t^m\) 界定；执行动作满足遗憾 ≤ 阈值的确定性保证（因为被拒绝的提议会被共形集成员替换）。若分数几乎必然互异，则覆盖概率恰为 \(k_t/(n_t+1)\)，落在 \([1-\alpha, 1-\alpha + 1/(n_t+1))\) 区间内。

- **生成基准的可比性缺陷**：旅行规划基准为自建近似版本，论文已明确声明不能与原 GroupTravelBench 直接比较；将其作为主结果之一呈现时，削弱了该部分结论的外部效度。
- **异构智能体实验深度不足**：虽报告了 14 种异构组合的总体效果，但未深入分析"异构性类型"（如能力差距、模型家族差距、专长分工）对通信控制的交互影响。
- **对事实性错误与幻觉的鲁棒性未检验**：SeekEvidence 依赖智能体"贡献此前未共享的决策相关事实"，但若被路由的智能体本身持有错误事实或产生幻觉，框架缺乏校验与纠正机制；在实际高风险场景中这是一个关键盲区。

### 9. 对领域与后续研究的启示

- **通信协议设计范式转变**：本工作证明多智能体通信控制的"策略化"（policy-based）优于"脚本化"（script-based），为后续研究提供了从提示工程走向决策过程建模的新范式。
- **共形预测在 LLM 智能体中的应用前景**：将共形预测从单步预测推广到多智能体在线决策的逐轮风险控制，展示了其在"可证性 + 实用性"间的桥梁价值；未来可沿此方向扩展至更复杂动作空间（如并行嵌套动作）和非交换场景的在线重校准。
- **状态表征的可迁移性**：MLP 在 5 个任务上训练即可泛化到 60 个未见任务，说明"群体不确定性–分歧–冗余–证据增益"等抽象状态特征具有跨任务稳健性，为构建任务无关的通用通信控制器提供了实证基础。
- **未解决的关键问题**：①如何将遗憾校准从"固定策略"扩展为"自适应策略"（如在策略上收集校准数据）；②如何设计更好的替代损失或直接以任务准确率可微地训练控制器；③如何引入事实核查与证据溯源机制以对抗幻觉；④如何将通信成本显式纳入奖励、实现成本敏感的早期停止。

### 10. 总体评价

Consilience 是一项完成度高、方法创新性强、理论–实验结合紧密的研究。它将隐配置场景下的多智能体讨论重新定义为顺序通信控制问题，用反事实评估 + 共形校准给出有边际保证的自适应干预机制，并在大规模跨模型实验中展示了相较非受控轮询的巨大提升（HiddenBench 平均准确率 0.26 → 0.83）。尽管存在计算开销偏高、共形保证适用条件受限、学习控制器表现不及规则控制器等不足，论文的框架设计、评估严谨性和可复现性总体处于同类工作前列。其核心论断——"自适应通信控制值得被当作一种决策问题来对待"——对多智能体 LLM 系统的后续设计具有重要的启发价值。总体可视为多智能体推理控制领域的一篇方法基准性工作。
