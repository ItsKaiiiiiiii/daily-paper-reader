## 摘要
智能体框架通过协调智能体与环境的交互，显著提升了长周期任务上的性能。然而，通过复杂框架进行强化学习仍然在很大程度上未被探索，因为将此类训练扩展到长周期智能体任务带来了根本性挑战。在这项工作中，我们提出了一个统一的黑盒强化学习框架，用于通过复杂框架对通用智能体进行稳定且可扩展的优化。具体而言，我们首先构建了一个基于沙箱的执行基础设施，将任务环境和框架隔离在临时沙箱中，以实现大规模并发轨迹采样。然后，我们将策略优化与不透明的框架执行解耦，并在模型边界放置一个服务代理来捕获模型调用。为了重建多轮轨迹并提高训练效率，我们将捕获的调用组织成前缀树，并进一步调整基于评论家的PPO和无评论家的GRPO，以优化恢复的树结构。同时，我们在整个优化过程中保持训练-推理一致性。最后，我们引入了混合框架训练，允许单个模型通过异构框架进行联合优化。使用Qwen3-30A3B，黑盒强化学习通过OpenClaw和Claude Code在ClawGym-Bench上将Pass@1分别提高了9.98和14.81个百分点，同时在200-400个优化步骤中保持稳定。此外，该框架在更具挑战性的任务上（如JobBench和OfficeQA）也取得了一致的收益。总体而言，我们的框架通过黑盒框架实现了对通用智能体的有效、稳定且可扩展的优化，支持跨异构执行系统的统一训练。

## Abstract
Agent harnesses have substantially improved performance on long-horizon tasks by coordinating agent interactions with the environment. However, reinforcement learning through complex harnesses remains largely unexplored, as scaling such training to long-horizon agent tasks introduces fundamental challenges. In this work, we present a unified black-box RL framework for stable and scalable optimization of general agents through complex harnesses. Concretely, we first build a sandbox-based execution infrastructure that isolates task environments and harnesses within temporary sandboxes for large-scale concurrent rollouts. We then decouple policy optimization from opaque harness execution and place a serving proxy at the model boundary to capture model calls. To reconstruct multi-turn trajectories and improve training efficiency, we organize the captured calls into prefix trees and further adapt both critic-based PPO and critic-free GRPO to optimize over the recovered tree structure. Meanwhile, we maintain training-inference consistency throughout the optimization process. Finally, we introduce mix-harness training, allowing a single model to be jointly optimized by heterogeneous harnesses. With Qwen3-30A3B, black-box RL improves Pass@1 on ClawGym-Bench by 9.98 and 14.81 points through OpenClaw and Claude Code, respectively, while remaining stable over 200-400 optimization steps. Moreover, the framework yields consistent gains on more challenging tasks such as JobBench and OfficeQA. Overall, our framework enables effective, stable, and scalable optimization of general agents through black-box harnesses, supporting unified training across heterogeneous execution systems.

## 1. 论文的核心问题与整体含义

- **背景与动机**：Agent harness（如 Claude Code、Codex、OpenClaw）已成为长程自主智能体的基础执行层，能显著提升复杂任务性能。然而，通过这类复杂、不透明的 harness 进行强化学习（RL）尚未被充分探索。
- **核心问题**：如何通过复杂 harness 开展黑盒 RL，从而稳定、可扩展地优化通用智能体策略？
- **三大挑战**：
  1. 通用智能体任务需要专用的有状态环境，大规模并发 rollout 对执行基础设施要求极高；
  2. 黑盒 harness 暴露的模型调用是碎片化、分叉、冗余的，难以直接用于 RL；且不透明内部逻辑容易加剧训练—推理不一致；
  3. 不同 harness 在交互协议、工具接口、上下文管理等方面差异大，框架需支持异构 harness 的灵活接入与统一训练。
- **整体含义**：论文提出了一套统一的黑盒 RL 框架，将复杂部署 harness 作为训练接口，使通用智能体能够在真实执行系统中被直接优化，并支持跨多个异构 harness 的联合训练。

## 2. 论文提出的方法论

- **总体设计**：将策略优化与 harness 执行解耦，把 harness 视为不透明的 rollout 引擎，仅在模型服务边界捕获模型调用，不修改 harness 内部逻辑。

- **基础设施（沙箱化执行）**：
  - 每个任务环境与所选 harness 在临时沙箱内启动，沙箱按需分配、完成后销毁，实现大规模并发与隔离；
  - 通过沙箱内的 MCP 服务器提供外部能力（如 Web 搜索、任务专用工具），无需改动 harness 原生流程。

- **服务代理与轨迹捕获**：
  - 在模型边界放置 serving proxy，所有模型请求都经过该代理；
  - 代理调用当前 rollout 策略，返回响应，并记录输入 token、生成 token、rollout log-probabilities 与任务元数据。

- **前缀树构建**：
  - 将一次 rollout 中捕获的模型调用组织成 rollout 级前缀树，重建共享交互结构；
  - 每个根到叶路径为一条候选多轮轨迹；叶节点对应 harness 引入的多种分支（上下文压缩、子代理等）。

- **轨迹过滤**：
  - 移除“死叶”（因重试或无效生成而未被继续的轨迹）；
  - 丢弃叶节点过多的过分支 rollout，防止噪声信号进入梯度更新；
  - 排除子代理轨迹与压缩轨迹，因为它们与主任务奖励不对齐。

- **基于树结构的策略优化**：
  - 同一 rollout 的多条保留轨迹共享同一终止奖励；
  - 共享前缀节点的 token 只计入一次 loss，避免高分叉 rollout 获得不成比例的训练权重；
  - **GRPO 适配**：按任务—harness 组内 rollout 的奖励归一化计算优势；
  - **PPO 适配**：同一 rollout 内轨迹独立处理，γ=1、λ=1，GAE 退化为 Âₜ = R_i − V_φ(s_t)，简化分支轨迹的 credit assignment。

- **训练—推理一致性**：
  - 采用 token-in-token-out 纪律：训练使用推理引擎生成的原始 token，harness 使用的文本视图由同一 token 解码得到，不反向编码回训练轨迹；
  - 使用 token 级重要性采样校正：w_t = min(exp(log π_old − log π_rollout), c̄)，缓解训练引擎与推理引擎概率计算不一致造成的 off-policy 偏差。

- **Mix-harness 训练**：
  - 将同一任务与不同 harness 配对为任务—harness 实例，同批次混合，但优势估计在各任务—harness 组内独立归一化，避免跨 harness 奖励分布干扰；
  - 支持单个模型从多个异构 harness 的 rollout 联合优化。

- **工程保护机制**：
  - 超时强制终止、沙箱故障丢弃；
  - 伪流式解析（缓冲 token 并持续发送 SSE，结束时用非流式解析器一次解析）；
  - Trajectory 完整捕获的 settling 等待机制。

## 6. 论文的主要结论与发现

- 黑盒 RL 可以在不修改复杂 harness 的前提下，稳定优化通用智能体策略，并带来显著性能增益；
- 训练—推理一致性（token-in-token-out + 重要性采样）对黑盒 RL 至关重要；
- 前缀树结构能有效恢复分叉多轮轨迹，并支持 PPO 与 GRPO 的树结构优化；
- Mix-harness 训练可行：一个模型可从异构 harness 联合学习，性能不低于任一单 harness 训练结果；
- 轻量冷启动可提供更好的行为先验，带来更平滑的训练动力学和更高下游性能，但并非必要；
- 白盒 AgentLoop RL 在同一循环内效果更强，但向黑盒 harness 迁移时不如直接黑盒训练；不同 harness 存在共享的底层智能体能力。
- 框架可扩展到 JobBench、OfficeQA 等更复杂任务，且无需针对任务格式修改训练管线。

## 7. 优点

- **系统性强**：从基础设施、轨迹重建、优化算法到工程稳定性，形成完整端到端黑盒 RL 方案；
