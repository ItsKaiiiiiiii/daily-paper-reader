## 摘要
训练LLM智能体通常依赖基于专家轨迹的监督微调，或基于人类指定任务和手工验证器的在线强化学习。尽管有效，但这两种方法都受限于外部指定的任务和监督信号，限制了智能体训练的可扩展性和多样性。我们研究了一种环境学习范式，其中智能体仅通过与环境的交互来获得交互和操作能力，无需外部指定任务。我们提出了State2State，一种环境衍生的中期训练方法，将探索到的环境状态转化为训练目标，挑战智能体达到指定的目标状态。通过从环境探索中派生任务，并通过基于规则的状态匹配来验证成功，State2State提供了可扩展且可验证的训练目标，无需专家监督或手动任务设计。在ALFWorld和ScienceWorld上的实验表明，State2State作为独立的环境学习阶段，在大多数设置下都能提升智能体的性能。作为下游强化学习的初始化，它进一步提升了最终性能和学习效率，并提供了跨环境泛化的有前景证据。

## Abstract
Training LLM agents commonly relies on supervised fine-tuning from expert trajectories or online reinforcement learning over human-specified tasks with handcrafted verifiers. Though effective, both remain bottlenecked by externally specified tasks and supervision signals, limiting the scalability and diversity of agent training. We study an environment learning paradigm in which agents acquire interaction and manipulation capabilities solely through environment interaction, without externally specified tasks. We propose State2State, an environment-derived mid-training method that converts explored environment states into training objectives, challenging agents to reach a specified target state. By deriving tasks from environment exploration and verifying success through rule-based state matching, State2State provides scalable and verifiable training objectives without expert supervision or manual task design. Experiments on ALFWorld and ScienceWorld show that State2State improves agent performance as a standalone environment-learning stage in most settings. As initialization for downstream RL, it further improves final performance and learning efficiency, with promising evidence of cross-environment generalization.

## 1. 核心问题与整体含义（研究动机与背景）

- **现有范式的瓶颈**：当前训练 LLM 智能体主要有两条路径：
  - **SFT（监督微调）**：模仿人类专家或更强教师模型的轨迹。问题在于轨迹获取成本高、继承源模型的能力上限、且任务覆盖范围受限。
  - **RLVR（可验证奖励强化学习）**：通过在线交互学习，但瓶颈转移到任务与奖励的构造上——仍需外部指定合适难度的目标及手工设计的验证器。
- **核心问题**：能否让智能体**仅从环境本身获得监督信号**（即"环境学习"），在没有外部教师、人工任务、任务特定奖励的情况下，习得环境感知与操作能力？
- **定位**：该研究将环境学习视为智能体的**中期训练（mid-training）**阶段——先习得通用的环境技能先验，再在人类指定任务上进行后续 RL 对齐。其监督来源对比可概括为：SFT 依赖专家轨迹，任务中心 RL 依赖人工任务与验证器，而本文的环境学习范式只依赖环境本身。

## 2. 方法论

**核心思想**：将探索到的可达环境状态转化为**可验证的目标状态达成（state-reaching）任务**，智能体需要把初始状态变换为给定的目标状态，任务成功与否通过**规则化的状态匹配**来判定，从而实现"任务和奖励均源自环境"。

**三个主要阶段**：

1. **环境探索（Environment Exploration）**
   - 采用**随机策略**（而非 LLM 探索者），理由：成本低、可高度并行、可探索更多样化的状态空间；LLM 探索者带有任务导向先验，会偏向人类任务分布附近的狭窄区域。
   - 可轻量调整采样分布，例如 ScienceWorld 中前期偏重导航动作以增强探索广度、后期偏重科学/状态改变动作以加深交互深度。

2. **State2State 任务构建（Task Construction）**
   - 以**观测（observation）**作为状态的操作性表示。
   - **过滤**无效/无信息量的观测（如错误消息）；
   - **多样性采样**：优先覆盖唯一观测，限制同一观测的重复次数（如最多 5 次）；
   - **可复现性验证**：从相同初始配置重放对应探索轨迹 3 次，仅保留可稳定到达的观测；
   - 每个任务由初始配置 + 目标观测构成。

3. **State2State 中期训练（Mid-Training）**
   - 使用 **GRPO** 算法 + **动态采样（DAPO dynamic sampling）**：丢弃奖励完全相同的 rollout 组，持续采样直到获得有信息量的 batch，以应对状态匹配奖励的稀疏性。
   - **奖励函数**为二元规则匹配：
     \[
     r_t = \begin{cases} 1, & \text{match}(o(s_t), o^\star) \\ 0, & \text{otherwise} \end{cases}
     \]
     在文本环境中实例化为归一化精确匹配。
   - 训练完成后，作为初始化权重接入下游人类任务的 RL 训练（如 800 步标准任务训练）。这一设计将"环境能力获取"与"人类意图对齐"解耦。

## 6. 主要结论与发现

1. **独立环境学习有效**：State2State 作为独立阶段在大多数设置下优于 base 模型（ALFWorld 上 Qwen3-4B 提升约 +11.4 avg；Qwen3-8B 在 ScienceWorld 上亦有提升）。唯一例外是 Qwen3-4B 在 ScienceWorld 上略有下降（归因于小模型面对稀疏、严格的状态匹配目标的难度）。
2. **更强的下游 RL 初始化**：State2State + RL 在全部环境和模型规模上取得最优（如 ALFWorld Qwen3-8B 达 97.45 avg，ScienceWorld 达 56.00 avg），且超越 GPT-5.2 等强提示模型。
3. **提升学习效率**：在 ScienceWorld 上，State2State + Human-Task GRPO 约 50 步即达到基线约 150 步的水平，说明环境技能先验能加速后续学习。
4. **潜在能力需下游 RL 释放**：对 Qwen3-8B，State2State 单独训练的增益（+1.96 / +1.63）小于叠加 RL 后的增益（+5.09 / +3.87），说明环境学习获得的是可复用但"潜在"的能力，需人类意图对齐后才能充分转化为任务解决性能。
5. **跨环境泛化有前景**：ScienceWorld State2State 中期训练迁移到 ALFWorld（89.44 avg）优于同步数的 ScienceWorld 人类任务 RL 迁移（86.87 avg），说明环境派生的目标比人类任务更具通用迁移价值。
6. **可扩展到 GUI 环境**：MobileWorld 上 MAI-UI-8B 从 0.275 提升到 0.308，无需下游人类任务 RL。

## 7. 优点

- **范式创新**：首次系统地提出"环境学习"作为智能体中期训练范式，任务与奖励均从环境派生，摆脱对外部教师、人工任务和任务特定验证器的依赖。
- **可扩展性与可验证性兼备**：随机探索成本极低（无需 LLM 推理）、可高度并行；规则化状态匹配提供可信的二元奖励，天然适配 GRPO 类对比式 RL。
- **随机探索的巧妙论证**：实验证明随机探索优于 LLM 探索（因 LLM 先验窄化状态覆盖），这一反直觉结论有实证支撑。
- **实验设计清晰**：通过"单独训练 vs 叠加 RL"的对比，有效区分了环境学习本身的贡献与"潜在能力释放"的贡献；跨环境迁移实验控制步数、SFT 顺序实验、不同 RL 骨干兼容性等分析维度丰富。
- **结论务实**：承认 State2State 是中期训练而非 compute-matched 替代，定位准确。

## 8. 不足与局限

- **模型规模有限**：仅评估 Qwen3-4B/8B，未覆盖前沿大规模模型（虽在 MobileWorld 用了 MAI-UI-8B，但无下游 RL 阶段）。大模型可能因更强先验或探索能力与 State2State 交互方式不同，缺乏系统性 scaling 分析。
- **环境类型受限**：主实验集中在文本环境（ALFWorld、ScienceWorld），其状态可复现、奖励便于精确匹配；对视觉、Web、软件工程、真实设备控制等更复杂环境的适用性未验证（MobileWorld 仅作为初步尝试）。
- **严格状态匹配的困难**：精确字符串匹配作为验证器过于严格，可能使部分合理但表述不同的状态被误判为失败，对小模型尤其不友好（Qwen3-4B 在 ScienceWorld 的负增益即与此相关）。
- **数据规模与基线不对齐**：SFT/AEE 基线仅 200 条轨迹，而 State2State 数据集达 4,256–8,000 条，规模差异可能影响对比公平性。
- **算力信息不透明**：未披露 GPU 型号、数量、总训练时长，影响可复现性和成本评估。
- **下游 RL 的步数/超参以基线收敛为准**，未系统搜索 State2State+RL 的最优训练配置，存在一定调参偏差风险。
