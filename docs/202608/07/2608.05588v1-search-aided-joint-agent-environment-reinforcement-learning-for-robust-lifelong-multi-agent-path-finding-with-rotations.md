## 摘要
终身多智能体路径规划（LMAPF）要求为持续接收新目标的智能体重复规划无碰撞路径，这些智能体在到达当前目标后立即获得新目标。尽管已有许多基于学习的规划器被提出用于LMAPF，但大多数依赖于过度简化的运动学假设，可能忽略了对实际性能至关重要的运动约束。在本工作中，我们研究了一个更现实的LMAPF模型，该模型源自许多现实世界的自动化仓库系统，称为LMAPF-R2，它纳入了鲁棒安全约束和原地旋转约束。这些约束显著增加了协调难度，尤其是在高度受限的空间中。为了应对这些挑战，我们提出了搜索辅助的联合强化学习（SJRL）。我们首先用因果PIBT增强神经策略，这是一种基于单步搜索的规划器，用于解决智能体的碰撞并传播其意图。然后，我们引入了一个统一的强化学习公式，联合优化智能体和环境策略，其中环境策略学习图边成本，通过反向Dijkstra搜索提供全局运动指导。实验表明，SJRL在多个高密度地图上相较于强搜索规划器Causal-PIBT取得了显著改进。我们进一步在包含8个物理机器人和248个虚拟机器人的挑战性混合现实仓库环境中验证了SJRL。

## Abstract
Lifelong Multi-Agent Path Finding (LMAPF) requires repeatedly planning collision-free paths for agents that continuously receive new goals upon reaching their current ones. While many learning-based planners have been proposed for LMAPF, most rely on oversimplified kinematic assumptions that may overlook motion constraints critical to real-world performance. In this work, we study a more realistic LMAPF model derived from many real-world automated warehouse systems, termed LMAPF-R2, which incorporates robust safety constraints and in-place rotation constraints. These constraints substantially increase coordination difficulty, particularly in highly constrained spaces. To address these challenges, we propose Search-Aided Joint Reinforcement Learning (SJRL). We first augment neural policies with Causal PIBT, a single-step search-based planner that resolves agents' collisions and propagates their intentions. We then introduce a unified RL formulation that jointly optimizes agent and environment policies, where the environment policy learns graph edge costs to provide global movement guidance via backward Dijkstra search. Experiments demonstrate that SJRL achieves significant improvements over the strong search-based planner, Causal-PIBT, across multiple high-density maps. We further validate SJRL in a challenging mixed-reality warehouse environment with 8 physical robots and 248 virtual robots.

- 本文主张学习式 LMAPF 研究应拥抱更现实且可扩展的模型，以弥合规划与执行之间的建模鸿沟，同时保持高密度场景下的可扩展性。

## 2. 论文提出的方法论

**核心思想：**
- 提出 **搜索辅助联合强化学习（SJRL）**，遵循两大设计原则：
  1. **搜索与学习的互补结合**：用搜索算法（Causal PIBT）作为碰撞屏蔽机制增强神经策略，并传播智能体意图。
  2. **智能体与环境双视角协调优化**：联合优化智能体策略（局部反应式协调）和环境策略（全局运动引导），使二者相互强化。

**关键技术细节：**

- **MDP 建模**：
  - 环境策略在时间步 0 采样边成本，执行反向 Dijkstra 搜索，计算图中所有状态（顶点-朝向对）间的最小成本距离，将智能体 11×11 局部视图内的启发式距离作为智能体策略的输入。
  - 智能体策略预测**下一顶点（subgoal）**而非原始动作，一旦确定子目标即变为 busy 状态，通过贪婪动作（先旋转、等待、再前进）执行。
  - 奖励设计：每步 −1 惩罚时间消耗；到达子目标时给予进度奖励 `dist(sprev,g) − dist(scurr,g)`；另加 5×5 局部视图内的团队平均奖励。

- **智能体策略**：
  - 基于 SILLM 的神经架构（CNN + 通信模块 + MLP），输入包括障碍物特征图、优先级特征图（PIBT 优先级）、busy/free 状态通道，以及四通道启发式距离图（对应四个朝向）。
  - **引入两条跳跃连接**：将启发式距离直接拼接到 CNN 和通信模块的输出特征中，强化 agent 决策与全局引导之间的依赖。
  - 用**同步 Causal PIBT 变体**替换 CS-PIBT：仅空闲智能体参与联合决策，busy 智能体的当前位置和子目标视为障碍，禁止循环移动。
  - 选择子目标时先尝试神经策略的最高概率选择，再按启发式距离升序考虑其余候选。通过 DFS 与优先级继承形成意图传播链，将高优先级的意图沿链传递，显著提升长走廊场景中的协调探索效率。

- **环境策略（引导图优化）**：
  - 实现为 5 层 3×3 卷积的 CNN，输入障碍物特征图和预计算的模拟统计特征（顶点访问频率与边遍历频率）。
  - 输出每条边的成本高斯分布的均值与方差（共 10 个输出通道），通过 arctan 变换将边成本映射到 [1,10]；训练时采样成本，推理时使用均值。
  - 将每条边视为一个共享奖励的虚拟智能体，使用 MAPPO 训练。

- **联合训练流程**：
  - Causal PIBT 在训练和推理中均使用，被视为环境的一部分，由 PPO 直接优化策略，无需对 PIBT 的动作修正做梯度校正。
  - 先以均匀边成本（5.5）对智能体策略进行**预热训练**，再进入联合训练阶段，以降低环境策略优化早期的高方差问题。

## 6. 论文的主要结论与发现

1. **SJRL 显著优于强基线**：在所有 6 张地图上，SJRL 相比 Causal-PIBT 均有明显吞吐量提升，且智能体密度越高优势越大。
2. **联合学习优于单独学习**：SJRL 一致优于 SARL（仅智能体学习）和 SERL（仅环境学习），验证了两个策略可互补增强——SARL 局部缓解拥堵，SERL 全局均衡流量，SJRL 兼得二者。
3. **环境策略 RL 优化可行**：SERL 在多数地图上与 CMA-ES 相当或略优，说明用 RL 优化引导图具有潜力。
4. **模型选择至关重要**：基于 LMAPF-R2 的 SARL/SJRL 优于基于标准模型的 SILLM、MAGAT+、HMAGAT（即使用 ADG 执行框架），说明真实的运动学建模对学习式规划器性能有显著影响。
5. **子目标预测 + Causal PIBT 有效应对探索挑战**：NACS 和 NVCS 均远逊于 Causal-PIBT，在走廊结构（Warehouse、Random 地图）上差距最大。原因在于 Causal PIBT 通过意图传播耦合长走廊中智能体的决策，使随机探索下难以实现的协同移动变得可行。
6. **跳跃连接对联合学习更关键**：skip connections 对 SARL 和 SJRL 都有提升，但对 SJRL 更为重要，说明其建立了决策与全局引导间的强依赖，有助于环境策略的优化。
7. **专家初始化带来显著增益但非必需**：专家边成本初始化使所有方法（包括 Causal-PIBT）受益，但 SJRL 从零训练仍不及带初始化的版本，表明 PPO 可能陷入次优局部最优。
8. **物理验证成功**：在 8+248 的混合现实仓库中，SJRL 吞吐量（1.01）明显优于 NORL（0.72）、SERL（0.84）和 SARL（0.87）。

## 7. 优点

- **建模现实性**：首次将鲁棒约束与旋转约束同时引入学习式 LMAPF，缩小了规划与执行之间的建模差距，具有明确的工业价值。
- **方法创新性**：
  - 搜索与学习的深度融合：Causal PIBT 既作碰撞屏蔽又作意图传播机制，在训练/推理中统一使用，设计优雅。
  - 智能体与环境联合优化：将引导图优化嵌入 RL 框架，与智能体策略联合训练，开辟了环境策略学习的新范式。
  - 子目标预测的策略层次设计：有效缓解了多智能体 RL 在长走廊等场景中的指数级探索困难。
- **实验全面性**：多地图、多密度、多对比方法、多消融维度的组合，加上物理机器人验证，证据链较完整。
- **工程实用性**：推理速度低于 0.05 秒/时间步，引导图可预计算，具备实际部署条件。
- **可视化分析**：通过等待动作热力图直观揭示了不同方法在局部/全局协调上的行为差异，增强了结论的可解释性。

## 8. 不足与局限

- **跨地图泛化缺失**：训练和评估在同一地图上进行，未验证跨地图的泛化能力。虽符合公共仓库场景假设，但限制了方法的通用性表述。
- **初始化依赖**：SJRL 从零训练无法达到带专家边成本初始化版本的性能，表明 PPO 的局部最优问题限制了联合学习的上限，也说明方法对先验知识有一定依赖。
- **与 SOTA 方法比较的公平性存疑**：SILLM、MAGAT+、HMAGAT 基于标准模型，SARL/SJRL 基于 LMAPF-R2，模型本身不同，性能差异部分归因于模型选择而非算法能力。作者也承认 IL 方法对 LMAPF-R2 的适配需大量修改，留作未来工作。
- **IL 方法未充分适配**：未将 SILLM 等 IL 方法适配到 LMAPF-R2 后进行对比，使“LMAPF-R2 更适合学习式规划器”这一结论的验证不完整。
- **通信模块沿用旧架构**：直接采用 SILLM 的通信模块，未针对 LMAPF-R2 的更高协调难度设计更有效的通信机制（作者也在附录中承认此局限并列为未来方向）。
- **无跨图扩展实验**：未测试更大规模（如数千智能体）的可扩展性，尽管 SILLM 原论文支持上万规模。
- **奖励设计的复杂性**：团队奖励依赖局部平均，启发式奖励依赖真实距离；该设计虽有效，但缺乏对各奖励项贡献的消融分析。
- **假设简化仍存在**：如 4 邻接网格图、离散时间步、单一机器人类型（差速驱动），对更复杂场景（如 Car-like 机器人、连续空间）的适用性未验证。
