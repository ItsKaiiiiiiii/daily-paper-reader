## 摘要
自动化高密度存储系统（如仓库、机器人停车场、工厂物流等）需要成群的智能体在稀缺的关键任务资源中移动，然后停泊在不阻碍未来操作的位置。我们引入了枢轴与站点多智能体路径规划（PS-MAPF），这是MAPF的一种变体，其中一部分承担任务的智能体必须各自访问一组可互换的枢轴（例如工作站）中的一个，然后整个车队终止于匿名站点，每个站点一个智能体。我们完整地刻画了可解性：在2-边连通图上的每个实例都是可解的；而在任意连通图上，相对于未占用顶点数量的结构性有效距离度量给出了充要条件。我们证明，即使只有一个枢轴，最小化站点完工时间或站点流经时间也是NP-hard的。我们提出了三种算法：一个完整的基线、一个基于SAT的最优求解器，以及枢轴优先规划（PPP）。其中，PPP能够解决74-89%的基准实例，其完工时间和流经时间比基线低数个数量级。

## Abstract
Automated high-density storage systems (warehouses, robotic parking, plant logistics, etc.) require fleets of agents to move through scarce task-critical resources and then park without obstructing future operations. We introduce Pivot-and-Station Multi-Agent Path Finding (PS-MAPF), a MAPF variant in which a subset of tasked agents must each visit one of a set of interchangeable pivots (e.g., workstations) before the entire fleet terminates at anonymous stations, one agent per station. We characterize solvability completely: every instance on a 2-edge-connected graph is solvable, and, on arbitrary connected graphs, a structural effective-distance measure relative to the number of unoccupied vertices gives a necessary and sufficient condition. We prove that minimizing station-makespan or station-flowtime is NP-hard already with a single pivot. We present three algorithms, a complete baseline, a SAT-based optimal solver, and Pivot-Prioritized Planning (PPP), the last solving 74-89% of benchmark instances with makespan and flowtime orders of magnitude below the baseline.

# 论文核心内容总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：自动化高密度存储系统（如Ocado、Amazon Sequoia等仓库，机器人停车场，工厂物流）需要大量机器人在固定拓扑（轨道、传送带、网格）中移动。这些系统中存在两类关键位置：
  - **Pivots（枢轴）**：必须访问的任务关键资源（工作站、取货/送货点、充电接口），功能上可互换；
  - **Stations（站点）**：所有智能体最终停泊的位置，任意智能体可停入任意站点，每个站点一个智能体。
- **问题定义**：论文提出**PS-MAPF**（Pivot-and-Station Multi-Agent Path Finding），要求部分"被指派任务"的智能体必须先访问至少一个枢轴，然后整个车队（包括无任务的智能体）停入匿名站点，同时全程无碰撞。该问题将"枢轴访问协调"与"终端停泊规划"联合优化。
- **核心动机**：现有MAPF变体均未完整覆盖这一需求——经典MAPF无中间资源访问；匿名MAPF（AMAPF）无强制枢轴访问；TAPF的目标分组可交换但无中间资源；MCPF虽结合中间目标与匿名终点，但需求方向相反（MCPF要求每个目标被某智能体访问，PS-MAPF要求每个任务智能体访问某个枢轴），且不区分子集。因此需要新的建模与算法。

## 2. 方法论

### 2.1 可解性刻画

- **2-边连通图上的充分性**（定理1）：若每个任务智能体的起点与某个枢轴2-边连通，则实例一定有解。证明思路：利用两条边不相交路径构造环，通过同步旋转（rotation）运动将智能体逐步推向枢轴；所有任务智能体依次完成枢轴访问后，剩余问题退化为Anonymous MAPF（命题1保证可解）。
- **任意连通图上的充要条件**（定理2）：
  - 定义 **p-适配配置**：未占用顶点为空，或包含枢轴p且诱导子图连通；
  - 定义 **有效距离** d_eff_p(o(i))：基于2-边连通元树（condensation tree）上的路径，考虑非平凡分量和分支单点分量的额外代价；
  - **关键条件**：对每个任务智能体i，存在枢轴p和可达的p-适配配置c，使得 d_eff_p(c(i)) ≤ |V| - |A|（即未占用顶点数）。
  - 该条件可在多项式时间内检查（对每个枢轴做多项式次p-适配约简）。
- **良构实例**（定义5）：若每个任务智能体到某枢轴存在一条路径，除起点外不经过其他智能体的起点，则该实例必定可解（命题3）。

### 2.2 复杂度分析

- **NP-hard证明**（定理3、定理4）：从3SAT归约（类似Yu & LaValle 2013的构造）。关键洞察：将唯一枢轴p战略性地放置，配合上/下路径和子句/变量子图的设计，可以迫使最优解中每个智能体到达预定的站点，从而使最小化station-makespan和station-flowtime的分析类似于经典MAPF。
- **关键结论**：即使只有一个枢轴，最小化station-makespan或station-flowtime也是NP-hard。这形成了尖锐的复杂度跳跃：无枢轴时（即AMAPF）可在多项式时间内求解，加入单一枢轴即NP-hard。

### 2.3 三种算法

1. **基线算法（BA）**（算法A）：
   - 由可解性证明直接构造，完备但质量极差；
   - Phase 1：逐任务智能体处理，先约简到p-适配配置，通过清空路径和推进操作将智能体送至枢轴，然后**逆运动**将系统状态回退到初始配置（保证后续智能体互不干扰）；
   - Phase 2：将剩余问题当作Anonymous MAPF，用流方法求解；
   - 时间复杂度：O(|At|·n³) ≤ O(n⁴)。

2. **Pivot-Prioritized Planning（PPP）**（算法B）：
   - Phase 1：按优先级顺序（SH最短优先、LH最长优先、RND随机、LC最少冲突、MC最多冲突）依次对任务智能体执行Space-Time A*搜索，在预留表R中避让已规划智能体的时空占用，将低优先级起点视为静态障碍；
   - Phase 2：将剩余配置建模为时间扩展图上的**最大流**问题，在窗口 [τmax, τmax+2|V|] 内搜索，找到从注入点到站点集合的 |A| 条单位流；
   - 完备性：不保证找到解，但返回的解一定有效（命题7）；
   - 时间复杂度：O(n⁴m)，其中n=|V|, m=|E|。

3. **SAT-Based最优求解器**：
   - 采用匿名化编码：仅用2个状态（pivot-oriented P 和 station-oriented S）的二元变量 x^q_v,t 和 y^q_u,v,t，变量数不依赖|A|；
   - 约束包括：冲突避免（C1a、C1b）、流守恒（C2a-C2e）、初始/终止条件（C3a-C3d）；
   - 定理5：Φ(T)可满足当且仅当存在station-makespan ≤ T的解；
   - 使用CP-SAT求解器，逐步增加T寻找最优值；
   - 下界：基于枢轴瓶颈的排序距离（定理6），提供迭代的初始T值。

- **可解性完备刻画**：2-边连通图上所有实例可解；任意连通图上，有效距离≤未占用顶点数是充要条件；
- **复杂度下界确定**：单枢轴即NP-hard（makespan和flowtime）——揭示"匿名目标+Pivot约束"的组合会导致根本性的复杂度跳跃；
- **算法效果**：
  - PPP在74%-89%的基准实例上成功求解，station-makespan和station-flowtime比BA低**2-3个数量级**，运行时间仅为BA的约1/2（仓库图）；
  - PPP平均makespan与SAT最优解的差距仅0.55-2.73步，质量接近最优；
  - 在优先级启发式中，MC（最多冲突优先）整体表现最强：在两个高密度地图上平均运行时间最低，在空图上成功率最高，其余指标保持竞争力；
  - PPP的失败集中在极端瓶颈场景（1-5个pivot、75-100% tasked比例）。

## 7. 优点

- **理论深度强**：可解性充要条件使用2-边连通元分解和有效距离的新概念，具有独立的图论价值；复杂度证明清晰展示了与经典MAPF归约的关键差异；
- **建模贴近实际**：明确区分tasked/untasked智能体和可互换pivot，比MCPF等现有变体更符合仓储物流的运作逻辑；
- **算法谱系完整**：从完备但低质量（BA）→ 多项式启发式（PPP）→ 最优（SAT），覆盖不同需求场景；
- **匿名编码设计精巧**：将智能体状态压缩为P/S两种类型，变量数不再依赖智能体数量，这是在大规模密集场景下可行的关键；
- **下界分析完善**：定理6的基于枢轴瓶颈的排序下界为SAT搜索提供了有效剪枝。

## 8. 不足与局限

- **实验场景有限**：所有实验均为合成网格或Moving AI标准地图，缺少真实仓库拓扑（如格架/升降机混合布局）的验证；
- **BA实用性差**：虽然完整，但实验中在60秒内无法求解任何实例，作为baseline的本质更像是"理论上存在"而非实际可用；
- **PPP不完备**：无最优性保证，且在高密度极端场景下失败率明显，缺乏对失败原因的深入分析（论文仅归因于"Phase 2流不可行"）；
- **缺少与前沿MAPF方法的对比**：未与CBS、LaCAM*等其他MAPF求解器对比，难以定位PS-MAPF算法在更广泛算法空间中的相对地位；
- **多pivot类型未扩展**：仅处理了单一可互换pivot类，实际问题中可能存在功能不同的多类pivot；
- **未考虑离线的计算预算约束**：SAT求解器在最坏情况下指数级开销，在超大规模实例上的时钟可扩展性存疑。
