## 摘要
将大型语言模型（LLMs）特化到不同能力，支撑了从个性化助手到多智能体系统（MAS）的成功。单智能体范式依赖预定义的角色或导向向量来引发特化，但它们强加单一固定的特化，无法适应多样化的查询。相反，MAS通过编排具有不同文本角色的智能体来实现动态多视角问题解决，但融合这些特化需要多轮交互，这会增加上下文长度和推理成本。为解决这些局限，我们提出角色混合（Mixture of Roles, MoRe），它自适应地将多个特化组合成单一导向向量，用于单轮推理。具体来说，MoRe学习一个多样化的导向向量码本，每个向量编码一个潜在角色。一个查询感知路由器动态地将码本融合成包含多个角色的导向向量。通过用组合向量引导骨干LLM，MoRe在单智能体、单轮推理过程中实现多视角特化。所提出的MoRe可以通过三阶段SFT课程和GRPO后训练高效训练，同时骨干LLM保持冻结。在推理和个性基准上的实验表明，MoRe平均比单智能体基线高出2.2%，并实现了与MAS相当的性能，同时将token成本降低20倍。

## Abstract
Specializing Large Language Models (LLMs) toward distinct abilities underpins successes ranging from personalized assistants to multi-agent systems (MAS). Single-agent paradigms rely on pre-defined personas or steering vectors to induce specialization, yet they impose a single fixed specialization that fails to adapt to diverse queries. Conversely, MAS achieves dynamic multi-perspective problem solving by orchestrating agents with distinct text-based roles, but fusing these specializations requires multi-turn interactions that inflate context length and inference cost. To address these limitations, we propose Mixture of Roles (MoRe), which adaptively composes multiple specializations into a single steering vector for single-turn inference. Specifically, MoRe learns a diversified codeboox of steering vectors, each of which encodes a latent role. A query-aware router dynamically fuses the codebook into a steering vector that encompasses multiple roles. By steering the backbone LLM with the composed vector, MoRe enables multi-perspective specialization in a single-agent, single-turn inference process. The proposed MoRe can be efficiently trained via a three-stage SFT curriculum and GRPO post-training, while the backbone LLM remains frozen. Experiments across reasoning and personality benchmarks show that MoRe outperforms single-agent baselines by 2.2% on average, and achieves performance on par with MAS while reducing token cost by 20x.

## 2. 论文提出的方法论

### 2.1 核心思想
- 将多角色的融合从**文本空间**迁移到**激活空间（activation space）**：不在多智能体间进行多轮文本协商，而是将不同角色编码为可学习的转向向量（steering vectors），在模型的残差流中直接组合。
- 保持骨干 LLM **完全冻结**，仅训练一个轻量级"作曲家"（composer）模块。

### 2.2 关键组件

**（1）专业化码本（Specialization Codebook）**
- 维护一组可学习向量 \(\{e_n\}_{n=1}^N \subset \mathbb{R}^d\)，每个向量编码一个潜在角色/专长方向。
- 初始化策略：使用对比激活加法（CAA）从角色化提示中提取 M 个对比方向作为前 M 个码本条目；其余条目用凸组合初始化，锚定在行为上有意义的区域。

**（2）查询感知路由器（Query-aware Router）**
- 每个码本条目关联一个可学习探针向量 \(u_n \in \mathbb{R}^d\)，构成探针矩阵 \(U \in \mathbb{R}^{N \times d}\)。
- 通过**多头交叉注意力**让探针矩阵作为 Query，输入查询的 token 嵌入作为 Key/Value，得到查询感知表示 \(Z \in \mathbb{R}^{N \times d}\)。
- 经 MLP 生成路由 logits \(g \in \mathbb{R}^N\)，使用 **Top-K 稀疏路由**加权融合码本条目：
  \[
  v_Q = \sum_{n \in T_K} w_n e_n, \quad w_n = \frac{\exp(g_n)}{\sum_{j \in T_K} \exp(g_j)}
  \]
- 将组合向量 \(v_Q\) 注入中间层（第 \(\lfloor L/2 \rfloor\) 层）的最后一个 prompt token 的残差流。

### 2.3 训练流程

**三阶段 SFT 课程学习**（骨干冻结）：
1. **阶段一**：仅优化码本，均匀采样单个候选向量进行训练，确保每个候选单独有效。
2. **阶段二**：冻结码本，训练路由器学习 Top-K 组合，辅以负载均衡损失防止路由坍缩。
3. **阶段三**：联合优化码本与路由器，使候选向量适应查询相关的组合模式。

**GRPO 后训练**：
- 将策略定义为**角色子集选择**（Top-K 无序子集采样），而非 token 级别策略。
- 将冻结 LLM 作为黑盒环境，奖励完全归因于路由器的动作，实现精确信用分配。
- 对每个查询采样 G 个转向向量进行 rollout，使用组相对优势（group-relative advantage）更新路由器。
- 优势函数：\(A_j = (r_j - \bar{r}) / (\text{std}(r) + \epsilon)\)，采用标准 GRPO 裁剪目标。

## 6. 论文的主要结论与发现

1. **特化确实提升 LLM 性能**：与 Vanilla 相比，各类特化方法均带来更高的平均准确率和更好的排名；但**单一角色并非普遍最优**，角色有效性高度依赖任务类型。
2. **MoRe 优于所有单智能体基线**：平均超越最佳单智能体基线（ActAdd）约 0.96–0.97 个百分点；在需要长推理链的任务（数学）上优势更明显。
3. **MoRe 与 MAS 性能相当，但效率大幅提升**：以单次推理达到多智能体水平，token 消耗约为 MAS 的 **1/20**。
4. **MoRe 在个性控制上表现卓越**：显著优于 NPTI 和 IRIS，且跨骨干模型、跨人格维度的一致性更强（平均分最高、波动最小）。
5. **路由器学到了有意义的角色组合模式**：
   - 数学任务偏好"数学家"角色；
   - MedQA 组合"教师/怀疑者/医生"角色；
   - MMLU 等广泛覆盖任务呈更分散的路由模式。
6. **设计选择得到验证**：在中间层、对最后一个 prompt token 进行转向效果最佳；适度 Top-K（如 K=3）和多于 7 个码本条目构成最佳平衡。

## 7. 优点

- **核心创新性强**：首次将多角色融合从文本空间迁移到激活空间，提出了"单智能体单轮推理实现多视角协同"的新范式，有效弥合单智能体与 MAS 之间的性能—效率鸿沟。
- **训练范式精巧**：三阶段 SFT 课程 + GRPO 后训练的设计逻辑清晰——先保证码本独立有效，再训练路由器组合，最后联合优化；GRPO 策略定义在角色子集空间而非 token 空间，实现精确信用分配。
- **极致轻量高效**：冻结骨干 LLM，仅训练 0.017% 参数即可实现显著性能提升；GRPO rollout 免梯度跟踪，训练开销可控。
- **模块化设计**：码本初始化可利用现成的文本角色（可解释性好），且码本条目数量可灵活调整，便于扩展。
- **分析细致深入**：对码本多样性、路由行为、转向传播效果进行了完整的可视化和定量分析，实验验证扎实。

## 8. 不足与局限

- **依赖内部状态访问**：MoRe 需要读取骨干模型的中间隐藏状态，**无法直接用于黑盒 API 模型**（如 GPT-4、Claude API），应用范围受限。
- **可解释性不足**：尽管码本通过文本角色初始化，但训练后学习到的候选向量是潜在的、隐含的，难以解释每个向量具体对应何种行为或能力。
- **粗粒度路由**：当前为查询级人设，在整个生成过程中保持不变；更细粒度的 token 级或推理步骤级路由可能带来额外自适应能力，但也会增加计算开销。
- **评估偏差风险**：个性评估依赖 LLM-as-judge（Claude），可能继承评估模型的偏好或不一致性；推理评估同样采用 LLM-as-judge 协议。
- **实验覆盖局限**：仅在 8B 规模模型上验证，未测试更大规模 LLM；推理与个性实验的基线集合不一致，比较完整性有待加强。
- **计算资源细节不透明**：未报告具体训练时长、GPU 小时数等，阻碍了复现时的成本估算。
