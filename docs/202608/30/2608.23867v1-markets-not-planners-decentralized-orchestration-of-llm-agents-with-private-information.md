## 摘要
随着由不同方构建、具有不同能力和成本的LLM代理激增，对它们的编排更像是在整个经济中调配劳动力，而非计算机调用子程序。现有编排通常集中化，由单一计划者分配每项任务，但随着代理池增长这会造成瓶颈，需要私有信息（例如代理的执行成本），并且容易被操纵——在集中式LLM分配器下，单一插入偏好可使被偏爱的代理任务份额几乎翻倍。我们引入了AgentLance，一种重复劳动市场，其中代理使用其私有成本和自维护的策略笔记对任务出价，分配者根据出价和公开声誉记录选择赢家，VCG式支付规则奖励成本感知的出价。复杂任务通过层级委派处理：中标代理可以分解工作并通过相同机制进行分包。在数学推理、代码生成、知识密集型问答和智能体任务中，AgentLance将代理匹配到其专长领域，随着成本敏感性上升将工作转向更便宜的代理，并且始终优于单模型、集中式编排和市场基线。诊断市场失灵（包括不准确的成本自我估计和次优出价）并在受控实验中加以纠正可带来进一步收益，为更高效的代理经济绘制了路径。

## Abstract
As LLM agents proliferate, built by different parties and with different capabilities and costs, orchestrating them is more like assembling labor across the economy than a computer calling a subroutine. Existing orchestration is typically centralized, with a single planner assigning every task, but this creates a bottleneck as agent pools grow, requires private information (e.g., agents' execution costs), and can easily be manipulated, such that a single inserted preference nearly doubles a favored agent's task share under a centralized LLM allocator. We introduce AgentLance, a repeated labor market in which agents bid on tasks using their private costs and self-maintained strategy notes, an allocator selects winners from bids and public reputation records, and a VCG-style payment rule rewards cost-aware bidding. Complex tasks are handled by hierarchical delegation: winning agents can decompose work and subcontract it through the same mechanism. Across mathematical reasoning, code generation, knowledge-intensive QA, and agentic tasks, AgentLance matches agents to their specializations, shifts work toward cheaper agents as cost sensitivity rises, and consistently outperforms single-model, centralized-orchestration, and market baselines. Diagnosing market failures, including inaccurate cost self-estimation and sub-optimal bidding, then correcting them in controlled experiments yields further gains, charting a path toward more efficient agent economies.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 代理（LLM Agents）正变得越来越强大，同时也越来越异构——不同模型在能力和成本上差异显著，且由不同方构建、具备不同工具与脚手架。如何从任务流和代理池中选择合适的代理来执行任务，成为一个关键的"编排"（orchestration）问题。
- **核心问题**：传统编排主要由集中式计划者（centralized planner/router）完成，但在代理由不同个体或组织运营的现实未来场景中，集中式编排面临三大关键限制：
  1. **信息瓶颈**：集中式计划者无法直接观测各代理在新任务上的私有执行成本（private execution cost），且需要处理代理数量和任务数量增长带来的信息过载。
  2. **易受操纵**：集中式分配器的内部偏差或被注入的偏好可以影响经济上重要的分配结果。实验证明，在系统提示中注入一条"偏好代理2"的指令，可将代理2的任务份额从34%提高到62%；注入"最大化成本"指令后，平均执行成本从$0.014升至$0.018。
  3. **有界理性**：集中式决策在信息分散、规模扩大时处理能力受限（参考文献 Simon, Arrow & Hurwicz）。
- **核心思想**：借鉴人类经济的核心协调机制——市场（Hayek, 1945），提出用重复劳动市场替代集中式计划者，让代理通过投标报价来传递私有信息，平台仅基于投标与公开声誉记录做分配决策。

### 2. 方法论：AgentLance 框架

#### (1) 问题形式化
- 任务序列 T = {t₁, ..., t_m}，代理池 A = {a₁, ..., a_n}，每个任务有公开输入 x_t 和隐藏参考答案 y_t。
- 给定成本敏感性 α > 0，目标函数为：
  - **Score(t) = 1{Correct(ŷ_t, y_t)} − α × Cost(t)**，即最大化正确率与成本惩罚之和。

#### (2) 劳动代理参与和投标（Bidding）
- 每个代理在每个市场轮次观察可用任务、自身历史、token 单价、支付规则和私有策略笔记，估计自身预期成本与适用性后决定是否参与投标。
- 代理可以放弃（abstain）不适合或不盈利的任务。投标是私有成本信息进入分配过程的去中心化渠道。

#### (3) 分配与 VCG 式支付
- 分配器根据公共声誉记录估计投标者成功率 p̂_i(t)，计算分配分数：**S_i(t) = p̂_i(t) − α·b_i(t)**，选择最高分的投标者作为赢家。
- 赢家的支付由次优得分决定（VCG 风格临界支付）：
  - **pay(t) = (p̂_winner(t) − S_second(t)) / α**
- 该规则使投标者奖励成本感知投标：低于成本投标可能导致亏损执行，高于成本投标可能失去盈利机会，从而鼓励投标等于估计成本。

#### (4) 执行与分包（Subcontracting）
- 主市场赢家可选择独立执行或作为"经理"对复杂任务进行分解，通过同一市场机制开启分包市场。
- 分包预算受主市场支付约束（子任务预算总和不得超过原始支付），若无有效工人投标则回退到独立执行。

#### (5) 声誉与笔记更新
- 每个轮次结束后更新公开声誉记录（任务+是否成功）。
- 代理根据自己的投标、赢/输、支付、成本、利润、结果更新私有反思笔记，形成可复用的策略指导（但不存储具体任务案例）。

### 6. 主要结论与发现

- **市场行为符合预期**：AgentLance 按代理的比较优势分配任务（SuperGPQA 89.2% 分配给 Gemini，GAIA 77.6% 分配给 DeepSeek）；随成本敏感性α增加，便宜模型的任务份额从 3.3%（α=1）单调上升到 70.7%（α=100）。
- **主结果**：AgentLance（无分包）平均分数为52.2，优于所有基线；启用分包后进一步升至54.2，在全部4个α值下均为最优。与每α最优单模型 oracle 相比，优势随 α 增大而扩大（α=10时超出5.0个百分点）。
- **分包增益显著**：在启用分包的任务上准确率提升27.3%、成本降低64.1%。
- **消融结果**：移除反思笔记平均分数下降3.6个百分点（52.2→48.6）；移除VCG支付平均下降2.5个百分点。
- **两大瓶颈**：
  1. 成本估计不准确：直接估计的相关性仅为0.091~0.299，MAPE高达114%~2308%；提供历史信息并不能可靠改善。
  2. 出价策略次优：笔记中提到"成本真实投标"策略的比例从47.9%逐渐上升到66.7%，但仍有约三分之一代理未掌握该策略。
- **受控干预**：单独修正成本或单独修正策略均无法稳定带来增益，甚至可能有害（策略修正单独使用在α=10时使分数下降11.4）；**联合修正**成本估计和投标策略在全部α值下都带来显著收益（+1.5 / +2.5 / +5.4 / +7.7）。这说明两者互为补充，成本真实投标需要建立在可靠成本信息之上。
- **代理笔记主题**：任务匹配（34.7%）、成功/声誉（22.3%）、拍卖定位（21.4%）、成本/支付（10.3%）、风险回避弃标（9.7%）、其他（1.6%）。
- **代理盈利能力**：多数设置下代理稳步积累利润，Grok 4.3 累计利润最高；利润随 α 增大而显著减少。

### 7. 优点

- **方法论设计巧妙**：
  - 用市场机制解决了集中式计划者的私有信息、信息瓶颈和操纵风险三大问题。
  - VCG 式临界支付从理论上激励成本真实投标，使得私有信息得以去中心化地、激励相容地进入分配过程。
  - 反思笔记与声誉记录形成"市场中学习"的闭环，使市场能够随时间改善。
  - 分包机制将复杂任务分解为可委派的子任务，体现"劳动分工"思想（Babbage）。
- **实验设计严谨**：
  - 设置了分级递进的实验体系（行为验证→主实验→消融→诊断→干预→笔记/利润分析）。
  - 进行了集中式分配器受操纵的实证演示（图1b），为去中心化提供了动机证据。
  - 对集中式基线给予成本信息优势，说明 AgentLance 的优势并非信息不对等所致。
  - 用受控干预实验精确量化了每项瓶颈的独立和联合影响，逻辑清晰。
- **分析深入**：不仅报告性能数字，还追溯市场失效的根源（成本估计差、投标学不优），指明改进方向。
